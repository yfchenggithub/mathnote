\begin{summarybox}
\textbf{\textcolor{CSummary}{F014｜一分钟掌握}}

\textbf{一句话：两段自己走得对，还要在交接处接得对。}

对于 $f(x)=\begin{cases}g(x),&x\le x_0,\\h(x),&x>x_0,\end{cases}$ 设 $L$ 是右边靠近 $x_0$ 时的\textbf{有限}高度：
\[
 \boxed{\begin{array}{l}
 \text{严格递增：左段严格增＋右段严格增＋}g(x_0)\le L,\\[3pt]
 \text{严格递减：左段严格减＋右段严格减＋}g(x_0)\ge L.
 \end{array}}
\]

\textbf{考场三步：}
\begin{enumerate}[leftmargin=*,itemsep=0.2em]
\item \textbf{看左段：}斜率、底数或导数满足什么条件？
\item \textbf{看右段：}增减方向与左段是否一致？
\item \textbf{看接口：}递增不准往下跳，递减不准往上跳；把条件合起来求参数范围。
\end{enumerate}

\textbf{最容易丢分的三句话：}
\begin{itemize}[leftmargin=*,itemsep=0.2em]
\item 严格递增的接口\textbf{可以取等}（$\le$），严格递减也可以（$\ge$）。
\item 整体单调\textbf{不要求图象一定连起来}；向正确方向跳也允许。
\item 若右边没有有限的起始高度，别硬用 $L$，改成\textbf{直接比较每一个右边点}：递增 $g(x_0)<h(x)$；递减 $g(x_0)>h(x)$（$x>x_0$）。
\end{itemize}

\textbf{延伸一眼看懂：}三段、四段的函数也一样处理：\textbf{每一段方向一致，每一道分界都不能反向跳跃。}某段没包括分界点，就比较它\emph{靠近分界点时的高度}。

\end{summarybox}
