\begin{summarybox}
	\textbf{\textcolor{CSummary}{F14 速记：段内同向，接口不逆向}}

	设 $f(x)=\begin{cases}g(x),&x\le x_0,\\h(x),&x>x_0,\end{cases}$
	且 $L=\lim_{x\to x_0^+}h(x)$ 为有限实数。

	\begin{itemize}[leftmargin=*, itemsep=0.4em]
		\item \textbf{严格递增：} $g$、$h$ 在各自区间严格递增，且 $g(x_0)\le L$。
		\item \textbf{严格递减：} $g$、$h$ 在各自区间严格递减，且 $g(x_0)\ge L$。
		\item \textbf{接口可取等：} 左值等于右极限，仍可保持整体严格单调。
		\item \textbf{不用强求连续：} 只禁止向错误方向跳跃。
	\end{itemize}

	\textbf{\textcolor{CSummary}{做题顺序：}}
	先判两段的严格单调方向，再算 $g(x_0)$ 与右极限 $L$，最后把所有参数条件取交集。

	\textbf{\textcolor{CSummary}{约定：}}
	这里“递增、递减”指严格单调；若题目采用非严格定义，把两段的严格单调相应改为非严格，接口不等号不变。
\end{summarybox}
