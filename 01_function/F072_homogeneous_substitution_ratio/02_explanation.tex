\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	零次齐次不等式在变量同时缩放时函数值不变，因此只需考虑比值 $t=x_1/x_2$，将问题降为一元函数。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（零次齐次性）：}]
			函数 $F$ 满足 $F(\lambda x_1,\lambda x_2)=F(x_1,x_2)$（$\lambda>0$）。所以 $F(x_1,x_2)$ 的值只与 $x_1/x_2$ 有关，与绝对大小无关。
		\item[\textbf{要点二（比值归一化）：}]
			固定 $x_2=1$，令 $t=x_1/x_2$，则 $x_1=t$，$x_2=1$，从而 $F(x_1,x_2)=F(t,1)$。原不等式化为 $\varphi(t)=F(t,1)\ge0$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（比值决定函数值）}}
	在 $x_1x_2$ 平面上，原点出发的射线上的点具有相同的比值 $t$。由于零次齐次性，函数 $F$ 在每条射线上取常值。因此不等式的成立范围完全由比值区间决定。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（二元化一元）}}
	将双变量不等式通过比值 $t$ 转化为单变量不等式，是“减元”思想的典型体现。转化的关键是函数满足零次齐次性。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高考常见技巧）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（双变量不等式证明）：} 如对数均值不等式、指数型不等式，通过比值换元化为单变量函数，利用导数证明单调性。
		\item \textbf{考法二（极值点偏移问题）：} 在极值点偏移中常构造齐次式，换元后研究函数单调性。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	\textbf{见到双变量且式子可写成“分子分母同次”时，立即想到 $t=x_1/x_2$ 消元。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（对称分式结构）：} 不等式中同时出现 $x_1^k,x_2^k$ 且分子分母次数相同。
		\item \textbf{场景二（指数对数混合）：} 如 $\dfrac{x_1-x_2}{\ln x_1-\ln x_2}$，分子分母均为一次，零次齐次。
	\end{itemize}

\end{explanationbox}
