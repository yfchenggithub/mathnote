\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	对于 $e^x$ 和 $x$，常用切线 $y=ex$ 放缩；对于 $x$ 和 $\ln x$，可用直线 $y=x$ 放缩 $e\ln x$。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（切线放缩）：}] 指数不等式 $e^x\ge ex$ 表明 $e^x$ 在 $x=1$ 处的切线为 $y=ex$，且 $e^x$ 恒在该直线上方。
		\item[\textbf{要点二（同构对称）：}] 令 $x=\ln t$ 可得 $t\ge e\ln t$，即对数不等式，体现指数与对数的对称性。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（切线背景）}}

	$e^x$ 是凸函数，$x=1$ 处切线为 $y=ex$；$\ln x$ 是凹函数，$x=e$ 处切线为 $y=x/e$，即 $x=e\ln x$ 形式。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（函数最值）}}

	不等式等价于 $e^x - ex\ge 0$ 和 $x-e\ln x\ge 0$，说明相应函数最小值为 $0$，取等点对应切线点。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（导数放缩）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（恒成立求参）：} 题设中含 $e^x$ 或 $\ln x$ 的恒成立问题，常转化为这些不等式放缩。
		\item \textbf{考法二（比较大小）：} 利用不等式直接比较 $e^x$ 与 $ex$ 或 $x$ 与 $e\ln x$ 的大小关系。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{代换 $x\to \ln x$ 或 $x\to x-\ln a$ 可实现指数与对数的互化，是解决指对混合题的核心技巧。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（不等式证明）：} 需证明 $e^x\ge kx$ 或 $x\ge k\ln x$ 形式，可调整参数后套用。
		\item \textbf{场景二（函数最值）：} 求 $f(x)=e^x - ax$ 最值，$a=e$ 时临界；求 $g(x)=x-a\ln x$ 最值，$a=e$ 临界。
	\end{itemize}
\end{explanationbox}
