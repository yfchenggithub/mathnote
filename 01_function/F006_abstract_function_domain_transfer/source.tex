% F006 抽象函数定义域互推规则：简明描述
% 本结论解决：不知道 f 的具体式子，也能判断 f(g(x)) 中哪些 x 可以使用。
% D 表示 f(t) 原本允许接收的全部输入数。
\[
 f[g(x)]\text{有意义}
 \quad\Longleftrightarrow\quad
 g(x)\text{有意义，且 }g(x)\in D.
\]
\[
 f(ax+b)\text{的定义域为 }A,\ a\ne 0
 \quad\Longrightarrow\quad
 f(t)\text{的定义域}=\{ax+b\mid x\in A\}.
\]
% 第二条要求 A 是完整定义域，且 ax+b 在全体实数中能取遍每个实数。
% 对 x^2 等只能取部分实数的式子，不可直接用第二条断定 f 的完整定义域。
