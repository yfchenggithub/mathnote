\begin{summarybox}
\textbf{一句话记忆：} 一次项与负反比例项同向增长，两支各自递增，每支遍历实数。
\[
\boxed{f(x)=Ax-B/x\quad(A,B>0,\ x\ne0)}
\]
\begin{itemize}
\item 单调：两个定义区间分别严格递增。
\item 值域：每支均为 $\mathbb R$；奇函数。
\item 零点：$\pm\sqrt{B/A}$。
\item 同一高度 $c$：$x_-x_+=-B/A$，$x_-+x_+=c/A$。
\end{itemize}
\textbf{证明路线：} 作差、同增相加、判别式与韦达、求导。比较大小先判断是否在同一支；求区间最值先看定义域及端点能否取到。
\end{summarybox}
