\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	洛必达法则本质上把求未定式极限转化为求导数比值的极限；在恒成立问题中，它像一把钥匙，帮我们打开参数范围的入口。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（未定式判定）：}]
			使用前必须确认极限为 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 型，否则不能直接套用。
		\item[\textbf{要点二（求导替换）：}]
			在原极限满足条件的前提下，将分子分母分别求导，再对新分式求极限。
		\item[\textbf{要点三（必要性思想）：}]
			在恒成立问题中，用洛必达求出的参数范围只是必要条件，必须检验充分性才能确保正确。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（切线斜率比）}}
	当 $x\to x_0$ 时，$f(x)$ 和 $g(x)$ 同时趋近于 $0$，它们的比值近似等于切线斜率之比（在 $x_0$ 附近），即 $\frac{f'(\xi)}{g'(\xi)}$（$\xi$ 介于 $x$ 与 $x_0$ 之间），因此洛必达法则本质上是局部线性近似．

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（导数比等价）}}
	在未定式中，分子分母趋向 $0$ 或 $\infty$ 的速度由导数体现；将原极限转化为导数比，实际上是在比较变化率的极限，从而简化计算．

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（求参探路）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接计算）：} 直接给出 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 型极限，要求用洛必达法则求解。
		\item \textbf{考法二（参数探路）：} 在含参不等式恒成立问题中，先分离参数得到 $a\le h(x)$ 或 $a\ge h(x)$，用洛必达求出 $h(x)$ 在端点的极限，从而确定参数取值范围（必要），再证明充分性。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	洛必达法则只保证在导数比极限存在时原极限与之相等，但反过来不成立（若导数比极限不存在，原极限仍可能存在）。使用时务必验证条件，且不能循环求导。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（端点极限）：} 分离参数后，发现 $h(x)$ 在区间端点处呈现 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$，利用洛必达计算该端点的极限值。
		\item \textbf{场景二（必要范围）：} 将计算出的极限值作为参数 $a$ 的临界值，写出 $a\le$ 或 $a\ge$ 形式，再通过构造函数证明该范围下不等式成立。
	\end{itemize}

\end{explanationbox}
