\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	\textbf{对数是在求指数：同底的积变加、商变减、指数可提前；不同底数先换底。}

	\medskip
	\textbf{\textcolor{CSummary}{四句快记}}
	\begin{itemize}[leftmargin=*, itemsep=0.4em, topsep=0.3em]
		\item \textbf{乘变加：} $\log_a(MN)=\log_a M+\log_a N$。
		\item \textbf{除变减：} $\log_a(M/N)=\log_a M-\log_a N$。
		\item \textbf{幂变乘：} $\log_a M^m=m\log_a M$。
		\item \textbf{换底上真下底：} $\log_a b=\dfrac{\log_c b}{\log_c a}$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{使用前检查}}

	底数 $a,c>0$ 且不等于 $1$；真数 $M,N,b>0$；指数 $m$ 可为任意实数。\textbf{尤其不能拆真数中的加减法，也不能把负数放进对数。}

	\medskip
	\textbf{\textcolor{CSummary}{考试最快用法}}

	同底加减先合并；遇到根号、乘方先提指数；不同底数相乘先试换底约分。
\end{summarybox}
