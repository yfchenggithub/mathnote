% F010 单调函数在闭区间上的值域——简明版
% 用于内容索引；详细推导、例题及注意事项见 01--06。
\textbf{问题：}已知 $x\in[a,b]$，怎样快速求 $y=f(x)$ 的值域？

\textbf{条件：}函数在 $[a,b]$ 上有定义、单调且连续。

\textbf{结论：}
\[
\begin{cases}
\text{值域}=[f(a),f(b)],&\text{单调递增};\\
\text{值域}=[f(b),f(a)],&\text{单调递减}.
\end{cases}
\]

\textbf{提醒：}只有单调、没有连续时，仍能判断两端是最值，
但不能断言中间每个数都能取到。
