\textbf{结论名称：} 函数图像的上下平移变换（上加下减）

\textbf{适用条件：} 已知函数 \(y=f(x)\) 的图像，沿 \(y\) 轴方向进行平移。\(b>0\) 时，“上加”指向上平移 \(b\) 个单位，“下减”指向下平移 \(b\) 个单位。

\textbf{变量说明：}
\begin{itemize}
\item \(f(x)\)：原函数解析式；
\item \(b\)：非负平移量（\(b\geq 0\)），决定平移的方向与距离；
\item 平移后的函数：\(y=f(x)+b\)（上移），\(y=f(x)-b\)（下移）。
\end{itemize}

\textbf{核心公式：}
\[
\boxed{y = f(x) \pm b}
\]
其中“\(+b\)”表示上移 \(b\) 个单位，“\(-b\)”表示下移 \(b\) 个单位。

\textbf{使用场景：}
\begin{itemize}
\item 由基本初等函数图像快速得到变形后的图像；
\item 求函数值域的简单变换（值域整体上下平移）；
\item 图像上下平移不改变函数的单调区间长度、奇偶性（若原为奇函数，上移后不再过原点）等。
\end{itemize}

\textbf{简单例子：}
将抛物线 \(y=x^2\) 向上平移 \(3\) 个单位，由上加得
\[
y = x^2 + 3.
\]
将 \(y=\sin x\) 向下平移 \(0.5\) 个单位，得
\[
y = \sin x - 0.5.
\]
原顶点 \((0,0)\) 移到 \((0,3)\)，原正弦图像整体下移 \(0.5\)，易手算验证。
