\begin{explanationbox}
  \textbf{\textcolor{CExplanation}{为什么会想到“上加下减”？}}
  想象电梯：在同一层按钮上，电梯整体上升$3$层，每个人所在的层数都加$3$；下降$2$层，每个人所在的层数都减$2$。函数图像也一样：\textbf{同一个$x$的位置不动，只改变这个位置的高度$y$}。

  \medskip
  \textbf{\textcolor{CExplanation}{先看一个具体点}}
  假设图像上有点$P(2,4)$：
  \[
    (2,4)\xrightarrow{\text{上移 }3}(2,7),\qquad
    (2,4)\xrightarrow{\text{下移 }2}(2,2).
  \]
  原来$x=2$时，函数值是$4$；上移$3$后，同样$x=2$，函数值变成$7=4+3$。\textbf{不只这个点：图像上每一个点都这样变。}

  \textbf{\textcolor{CExplanation}{再看整条曲线}}
  例如$y=x^2$：在$x=0,1,2$时，原函数值分别是$0,1,4$。上移$2$后，变成$2,3,6$，恰好是\textbf{每个结果都加$2$}，所以是$y=x^2+2$，而不是$y=(x+2)^2$。

  \medskip
  \textbf{\textcolor{CExplanation}{一眼分清“上下”与“左右”}}
  \begin{itemize}[leftmargin=*,itemsep=0.25em,topsep=0.2em]
    \item $y=\boxed{f(x)+2}$：\textbf{括号外}加$2$，图像\textbf{上移$2$}。
    \item $y=\boxed{f(x+2)}$：\textbf{括号内}的$x$加$2$，图像\textbf{左移$2$}（前提是整体把$x$换成$x+2$）。
  \end{itemize}
  \textbf{原因：}上下移动改的是\textbf{高度$y$}；左右移动改的是\textbf{位置$x$}。两个“加$2$”放的位置不同，图像移动方向也不同。

  \medskip
  \textbf{\textcolor{CExplanation}{什么时候考试用得最快？}}
  已知原式和方向，直接在\textbf{整个$f(x)$外面}加减；已知新旧两式，若它们只差一个常数，就看这个常数正负判断上下方向；连续上下平移，把带符号的变化量直接相加。
\end{explanationbox}
