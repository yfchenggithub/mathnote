\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	函数在闭区间上的最高点和最低点，要么出现在区间的两端，要么出现在内部导数等于零或导数不存在的点上。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（最值存在性）：}]
			闭区间上连续的函数必有最大值和最小值。这是最值定理保证的。
		\item[\textbf{要点二（分类讨论）：}]
			设最值点，若在内部且可导，则导数为零；若在内部且不可导，则为不可导点；否则最值在端点。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（临界位置）}}
	函数图像在闭区间上是一条连续曲线，其最高点（峰）和最低点（谷）要么在边界，要么在切线水平或出现尖点处。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（函数值比较）}}
	求最值转化为求函数在若干关键点（端点、驻点、不可导点）的函数值，再从中找出最大、最小值。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（解题工具）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求最值）：} 给出具体函数，按步骤求出最值。
		\item \textbf{考法二（恒成立求参数）：} 将恒成立问题转化为求函数最值。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	\textbf{最值是整体概念，极值是局部概念。最值点可能是极值点，也可能不是（端点），而极值点也不一定是最值点。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（具体函数最值）：} 凡是求闭区间上连续函数的最值，直接套用本结论。
		\item \textbf{场景二（不等式证明）：} 通过构造辅助函数，转化为求最值。
	\end{itemize}

\end{explanationbox}
