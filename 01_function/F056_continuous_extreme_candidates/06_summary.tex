\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	\textbf{闭区间上连续函数的最值一定在端点、导数为零或不可导点构成的集合中。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（函数条件）：} $f$ 在 $[a,b]$ 上连续，且在 $(a,b)$ 内可导（允许有限个不可导点）。
		\item \textbf{条件2（区间条件）：} 所求区间为闭区间 $[a,b]$，否则最值可能无定义。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（端点与不可导点）：} 求最值时不要只顾解 $f'(x)=0$，必须将端点、不可导点全部纳入比较。
		\item \textbf{检查项（单调性预判）：} 先判断单调性可快速确定最值点，减少计算量。
	\end{itemize}

\end{summarybox}
