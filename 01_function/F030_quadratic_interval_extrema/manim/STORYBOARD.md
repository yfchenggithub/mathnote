# F030 数学审计与分镜

事实源为本 UID 六段 TeX 及 meta.json。独立模型 f(x)=(x−2)²+1，轴固定为2。

依次展示来源中的三个允许区间：[0,4]、[3,4]、[0,1]，最后回到[0,4]。区间之间通过端点的连续移动连接，每一帧均满足 m<n；每一帧都是固定区间最值结论的一次应用。不要误解为主结论要求区间持续变化。

蓝色粗线为允许图像，灰线只定位。最近位置由2截入[m,n]得到，青点显示最小值；最远端点显示橙点和最大值，等距时两个端点均显示。标记、数值和曲线全部取独立数学模型。数值显示为两位小数并明确近似。底部固定两行品牌。

检查开闭条件、轴恰在端点、端点等距、最近点随区间进入退出的变化。用户视觉与 Android 真机未确认前不得最终冻结。
