\paragraph{例1：导数变号，找出哪段上升、哪段下降}
求 $f(x)=x^3-3x+1$ 的单调区间。
\[
f'(x)=3(x+1)(x-1).
\]
把数轴按 $-1$、$1$ 分成三段，导数正负号依次为 $+,-,+$，所以：
\begin{itemize}
  \item 严格递增：$(-\infty,-1]$ 和 $[1,+\infty)$；
  \item 严格递减：$[-1,1]$。
\end{itemize}

\textbf{检查一下：}$f(-1)=3$，$f(1)=-1$，确实从 $x=-1$ 到 $x=1$ 在下降。

\paragraph{例2：只有一个位置导数为零，仍然严格递增}
\begin{center}\input{assets/tikz/F001_cubic_zero_derivative.tex}\end{center}
\end{minipage}\par\medskip
判断 $g(x)=x^3$ 的单调性。
\[
g'(x)=3x^2\ge0,
\]
导数只有在 $x=0$ 时等于 $0$，其余位置都大于 $0$。因此 $g(x)$ 在整个实数范围内严格递增。

\textbf{不用导数再核对一遍：}对任意 $a<b$，
\[
b^3-a^3=(b-a)(a^2+ab+b^2)>0.
\]
\textbf{回看配图：}导数在原点接触横轴，并未变号；函数没有掉头。

\paragraph{例3：含参数题，等于号不能丢}
已知
\[
f(x)=x^3-3ax,\qquad a\in\mathbb R,
\]
求 $f(x)$ 在整个实数范围内严格递增时 $a$ 的取值范围。

先求导：
\[
f'(x)=3x^2-3a=3(x^2-a).
\]
因为 $x^2\ge0$，所以要使导数对所有 $x$ 都不小于 $0$，只需 $a\le0$。

\begin{itemize}
  \item $a<0$：$x^2-a>0$ 始终成立，函数严格递增。
  \item $a=0$：函数变成 $x^3$，只有 $x=0$ 时导数为 $0$，依然严格递增。
  \item $a>0$：例如在 $x=0$ 处，$f'(0)=-3a<0$；在 $0$ 附近有一小段导数为负，不可能在整个实数范围内严格递增。
\end{itemize}
因此答案是
\[
\boxed{a\le0}.
\]
\textbf{这道题的关键：}不能误认为严格递增必须满足 $f'(x)>0$ 处处成立，否则会漏掉 $a=0$。

\paragraph{例4：严格递增还能快速判断零点个数}
若 $f(x)$ 在某个区间上严格递增，那么方程 $f(x)=0$ 在这段区间内\textbf{最多只有一个解}。

理由很简单：如果有 $a<b$ 两个解，就同时有 $f(a)=0$ 和 $f(b)=0$，与严格递增要求的 $f(a)<f(b)$ 矛盾。
\textbf{注意：}最多一个不等于一定有一个。想证明``恰好一个''，还要先想办法说明确实存在一个解。

\paragraph{例5：怎样证明一个方程恰好有一个实数根？}
\begin{center}\input{assets/tikz/F001_unique_zero_bracket.tex}\end{center}
\end{minipage}\par\medskip
证明方程
\[
x^3+x-1=0
\]
在 $0$ 与 $1$ 之间\textbf{恰好有一个解}。

\textbf{第1步：先证明至少有一个解。}
设 $f(x)=x^3+x-1$。它是多项式函数，在 $[0,1]$ 上连续，而且
\[
f(0)=-1<0,\qquad f(1)=1>0.
\]
由连续性和两端异号，依据零点存在定理，$(0,1)$ 内至少有一个零点；图中的 $\alpha$ 就表示这个交点。

\textbf{第2步：再证明最多只有一个解。}
\[
f'(x)=3x^2+1>0.
\]
所以 $f(x)$ 在整个实数范围内严格递增，在 $[0,1]$ 上当然也严格递增。假设有两个不同的零点 $a<b$，则严格递增要求 $f(a)<f(b)$，但两者都等于 $0$，矛盾。因此最多只有一个零点。

\textbf{第3步：合起来得出结论。}
\[
\boxed{\text{至少一个}+\text{最多一个}=\text{恰好一个}}
\]
所以方程在 $(0,1)$ 内恰好有一个实数根；事实上，由于 $f'(x)>0$ 对所有实数成立，它在整个实数范围内也只有这一个根。

\textbf{一眼就会用：}只凭导数判断严格单调，只能得到``最多一个零点''；还要检查两端函数值一正一负，并且中间连续，才能说``恰好一个零点''。
