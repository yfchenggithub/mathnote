\begin{summarybox}
\paragraph{一眼记住：导数看升降，等于零别急着下结论}
\textbf{基础四句：}
\[
\begin{aligned}
f'(x)>0&\ \Longrightarrow\ \text{严格递增},\\
f'(x)<0&\ \Longrightarrow\ \text{严格递减},\\
f'(x)\ge0&\ \Longleftrightarrow\ \text{不会下降},\\
f'(x)\le0&\ \Longleftrightarrow\ \text{不会上升}.
\end{aligned}
\]
这些判断都要求在\textbf{同一段连续的区间内}使用，并满足中间可以求导的条件。

\textbf{关键补充：}
\[
\boxed{\ f'(x)\ge0+\text{没有整段水平线}
\ \Longrightarrow\ \text{严格递增}\ }
\]
更方便的常用情况：$f'(x)\ge0$，导数等于 $0$ 的点只有有限个 $\Longrightarrow$ 严格递增。

\textbf{记住三个例子：}
\begin{itemize}
  \item $x^3$：$x=0$ 时导数为 $0$，但整体仍严格递增。
  \item 常函数 $y=2$：导数始终为 $0$，只能说不会下降，不能说严格递增。
  \item $-1/x$：两侧各自递增，不能跨过 $x=0$ 合并。
\end{itemize}

\textbf{做题五步：}定取值范围 $\to$ 求导 $\to$ 找导数为 $0$ 的位置 $\to$ 分段判断正负 $\to$ 检查端点并写结论。

\textbf{额外收益：}严格递增或严格递减的函数，在同一区间内与 $x$ 轴\textbf{最多相交一次}；导数等于 $0$ 的位置\textbf{未必是最高点或最低点}。


\textbf{补充一：导数不存在，也可能严格递增。}
\[
f(x)=\sqrt[3]{x}\ \text{在全体实数上严格递增，但 }f'(0)\text{ 不存在。}
\]
记住：$f'(x)>0$ 是证明严格递增的\textbf{方便条件}，却不是所有严格递增函数都必须满足的条件。

\textbf{补充二：证明方程恰好有一个根，分两步走。}
\begin{enumerate}
  \item \textbf{先找得到：}函数在 $[a,b]$ 上连续，且 $f(a)f(b)<0$，所以 $(a,b)$ 之间至少有一个零点；
  \item \textbf{再证明不会有第二个：}函数在 $[a,b]$ 上严格单调，所以至多有一个零点。
\end{enumerate}
\[
\boxed{\text{连续且两端异号}+\text{严格单调}
\Longrightarrow\text{中间恰好一个零点}}
\]
\textbf{相关结论：}罗尔定理与零点个数关系（F081）单独学习；F001 重点仍是用导数判断增减、再利用单调性做题。
\end{summarybox}
