\textbf{结论名称：} 极值点个数讨论（\(f'(x)=0\) 的解与变号分析）

\textbf{适用条件：} 函数 \(f(x)\) 在区间上可导，且 \(f'(x)\) 的零点可求出（或可根据参数讨论），零点两侧 \(f'(x)\) 的符号容易判断。

\textbf{变量说明：} 目标函数 \(f(x)\)，定义域为 \(D\)；\(f'(x)\) 为其导函数；方程 \(f'(x)=0\) 在 \(D\) 内的实根集合设为 \(\{x_1,x_2,\dots\}\)。

\textbf{核心公式：} 极值点的判定法则：
\[
\boxed{\text{若 } f'(x_0)=0 \text{ 且 } f'(x) \text{ 在 } x_0 \text{ 左右两侧变号，则 } x_0 \text{ 为极值点；若不变号，则 } x_0 \text{ 不是极值点。}}
\]
极值点个数等于 \(f'(x)=0\) 的实根中使得 \(f'(x)\) 发生变号的根的个数。

\textbf{使用场景：} 高考题中求显式函数的极值点个数，或含参数讨论极值点个数时，先求导并因式分解，求出导函数零点，再通过列表或穿根法分析零点左右导数的符号变化，最终确定极值点。

\textbf{简单例子：} 求 \(f(x)=x^{3}-3x\) 的极值点个数。
解：\(f'(x)=3x^{2}-3=3(x-1)(x+1)\)，令 \(f'(x)=0\) 得 \(x=-1\) 和 \(x=1\)。
当 \(x<-1\) 时 \(f'(x)>0\)；\(-1<x<1\) 时 \(f'(x)<0\)；\(x>1\) 时 \(f'(x)>0\)。
因此 \(f'(x)\) 在 \(x=-1\) 两侧由正变负，该点为极大值点；在 \(x=1\) 两侧由负变正，该点为极小值点。两个零点均变号，故极值点个数为 \(2\)。
