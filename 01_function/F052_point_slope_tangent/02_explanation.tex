\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	函数在某点可导时，该点切线斜率等于导数值；利用点斜式即可直接写出切线方程。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（斜率即导数）：}]
			$f'(x_0)$ 是切线的斜率。
		\item[\textbf{要点二（点斜式结构）：}]
			直线上一点 $(x_0, y_0)$ 和斜率 $k$ 决定直线方程 $y - y_0 = k(x - x_0)$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（导数与斜率）}}
	函数 $y=f(x)$ 的图象在 $x_0$ 处的切线斜率等于 $f'(x_0)$，因此切线方程可直接写出。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（线性逼近）}}
	切线是曲线在切点附近的一次近似，$f(x) \approx f(x_0) + f'(x_0)(x - x_0)$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高考应用）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求切线方程）：} 已知函数表达式和切点横坐标，直接套结论。
		\item \textbf{考法二（逆求参数）：} 已知切线过某点或已知切线方程，反求函数参数。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	只要可导，切线的“斜率”就有确定值，剩下就是直线方程问题，不要将导数与直线方程割裂。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景（典型题型）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（切点已知）：} 直接代入点斜式。
		\item \textbf{场景二（切点未知）：} 设切点 $(t, f(t))$，用导数写切线，再列条件求解。
	\end{itemize}

\end{explanationbox}
