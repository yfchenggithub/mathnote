\textbf{结论名称：} 指数函数图像性质（$a>1$ 与 $0<a<1$ 的异同）

\textbf{适用条件：} 函数形式为 $y=a^x$，其中 $a>0$ 且 $a\neq 1$。

\textbf{变量说明：} 底数 $a$ 分 $a>1$（增长型）和 $0<a<1$（衰减型）；定义域 $x\in\mathbb{R}$；值域 $y\in(0,+\infty)$；图像恒过定点 $(0,1)$，渐近线为 $y=0$。

\textbf{核心公式：}
\[
\boxed{
\begin{array}{l}
a>1 \;\Longrightarrow\; y=a^x \text{ 在 } \mathbb{R} \text{ 上单调递增},\; x<0\Rightarrow 0<y<1,\; x>0\Rightarrow y>1;\\[4pt]
0<a<1 \;\Longrightarrow\; y=a^x \text{ 在 } \mathbb{R} \text{ 上单调递减},\; x<0\Rightarrow y>1,\; x>0\Rightarrow 0<y<1.
\end{array}
}
\]
此外，$y=a^x$ 与 $y=(1/a)^x$ 的图像关于 $y$ 轴对称。

\textbf{使用场景：} 比较同底指数幂的大小；解指数不等式；根据图像走势判定底数范围；画指数函数草图。

\textbf{简单例子：}
比较大小：(1) $2^{0.3}$ 与 $2^{0.5}$：底数 $2>1$，单调递增，$0.3<0.5$，故 $2^{0.3}<2^{0.5}$。
(2) $0.5^2$ 与 $0.5^3$：底数 $0<0.5<1$，单调递减，$2<3$，故 $0.5^2 > 0.5^3$。
