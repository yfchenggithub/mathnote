\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	如果函数在一点两侧的导数符号相反，那么函数在该点由增变减或由减变增，从而取得极值。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（符号判据）：}]
			核心是 $f'(x)$ 在 $x_0$ 左右是否变号。只要左正右负，就是极大值；左负右正，就是极小值。
		\item[\textbf{要点二（单调性反转）：}]
			导数符号对应单调性：$f'(x)>0$ 函数单增，$f'(x)<0$ 单减。符号翻转意味着单调性改变，极值点由此产生。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（切线斜率变号）}}
	在 $x_0$ 处，若左侧切线斜率为正（上升），右侧为负（下降），则形成“峰”；反之形成“谷”。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（变化率判号）}}
	导数衡量函数变化率。变号表明 $x_0$ 是增减交替点，函数在这一点附近达到局部最大或最小。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（极值判别考法）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求极值点）：} 给定函数，求导数，找驻点和不可导点，然后逐一判断两侧导数符号，确定极值类型。
		\item \textbf{考法二（参数讨论）：} 已知含参函数在某个点取极值，利用导数变号条件建立方程或不等式求参数。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	\textbf{变号最关键：} 导数等于零只是必要条件，真正决定极值的是导数是否在这一点两侧变号。即使导数不存在（如 $y=|x|$ 在 $x=0$），只要变号，同样有极值。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（可导函数极值）：} 一步：求导 $f'(x)$；二步：解 $f'(x)=0$ 得候选点；三步：在候选点附近取点，比较导数符号，判定极值。
		\item \textbf{场景二（不可导点极值）：} 对 $x_0$ 是分段点或尖点，需要分段判断左右导数符号，同样适用变号判据。
	\end{itemize}

\end{explanationbox}
