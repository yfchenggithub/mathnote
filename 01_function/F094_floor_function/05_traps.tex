\begin{trapbox}
\textbf{易错一｜负数直接截去小数。} $\lfloor-1.2\rfloor=-2$，不是 $-1$；其小数部分为 $-1.2-(-2)=0.8$，不是 $-0.2$。

\textbf{易错二｜端点写反。} $\lfloor x\rfloor=2$ 对应 $[2,3)$，不是 $(2,3]$。

\textbf{易错三｜忘记整数边界。} $\lfloor x\rfloor\le2.5$ 不能直接推出 $x<3.5$；应先转为 $\lfloor x\rfloor\le2$。

\textbf{易错四｜随意拆加法。} $\lfloor0.6+0.6\rfloor=1$，但 $\lfloor0.6\rfloor+\lfloor0.6\rfloor=0$。

\textbf{易错五｜认为取整函数是奇函数或周期函数。} $\lfloor0.2\rfloor=0$，$\lfloor-0.2\rfloor=-1$。且对任意 $T>0$，函数不可能有周期：若 $T$ 是周期，则 $\lfloor jT\rfloor=\lfloor0\rfloor=0$ 对所有正整数 $j$ 成立，但取 $jT\ge1$ 即矛盾。

\textbf{易错六｜认为严格递增。} $\lfloor1.2\rfloor=\lfloor1.8\rfloor=1$，所以只能称单调不减。
\end{trapbox}
