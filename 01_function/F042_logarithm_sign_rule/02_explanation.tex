\begin{explanationbox}
  \textbf{\textcolor{CExplanation}{为什么会想到这个办法？}}

  题目经常只问“这个对数大于 $0$ 吗”，并不要求算出它的具体值。例如 $\log_2 7$ 不好口算，但我们知道 $2^0=1$，想从 $1$ 变成 $7$，指数一定要取正数，所以 $\log_2 7>0$。\textbf{判断正负，通常不必计算对数。}

  \medskip
  \textbf{\textcolor{CExplanation}{先弄懂：对数其实在问什么？}}
  \[
    \log_a b=x\quad\Longleftrightarrow\quad a^x=b.
  \]
  它问的是：“把 $a$ 乘方多少次，才得到 $b$？”现在把 $x$ 的正负分成两类看：
  \begin{itemize}[leftmargin=*,itemsep=0.25em,topsep=0.25em]
    \item 底数 $a>1$（例如 $2$）：正指数把结果变到 $1$ 的\textbf{右边}，负指数把结果变到 $1$ 的\textbf{左边}。
    \item 底数 $0<a<1$（例如 $\frac12$）：方向\textbf{正好相反}。正指数得到小于 $1$ 的数，负指数得到大于 $1$ 的数。
  \end{itemize}
  \begin{center}
  \input{assets/tikz/F042_logarithm_sign_rule_02_explanation_01.tex}
  \end{center}
  \textbf{看出规律：}底数和结果 $b$ 都在 $1$ 的同一侧，指数 $x$ 就为正；分别在两侧，指数 $x$ 就为负。

  \medskip
  \textbf{\textcolor{CExplanation}{再看图：为什么一定要和 $1$ 比？}}

  因为任何合法底数都满足 $a^0=1$，所以 $\log_a1=0$。两种对数函数都经过 $(1,0)$；这是正数、负数的分界点。
  \begin{center}
  \input{assets/tikz/F042_logarithm_sign_rule_02_explanation_02.tex}
  \end{center}
  \textbf{为什么图像方向相反？}当底数大于 $1$，输入的数越大，对数值越大；当底数在 $0$ 与 $1$ 之间，输入越大，对数值反而越小。

  \medskip
  \textbf{\textcolor{CExplanation}{考试中什么时候用得最快？}}
  \begin{itemize}[leftmargin=*,itemsep=0.25em,topsep=0.25em]
    \item \textbf{判正负：}例如 $\log_{0.3}5<0$，一眼就能确定，无须换底。
    \item \textbf{解不等式：}例如 $\log_2(x-1)>0$，只需 $x-1>1$，得到 $x>2$。
    \item \textbf{带参数：}例如 $\log_a(a^2+1)$，因为真数总大于 $1$，所以底数大于 $1$ 时为正，底数小于 $1$ 时为负。
  \end{itemize}
  \textbf{\textcolor{CExplanation}{快懂口诀：}}先看能不能取对数，再看底和真在 $1$ 的哪边；\textbf{同侧正，异侧负，真数等于 $1$ 是零。}
\end{explanationbox}
