\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	存在性命题转化为最值比较：$\exists x,\ f(x)\ge a \iff \max f\ge a$；$\exists x,\ f(x)\le a \iff \min f\le a$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（最值存在）：} 函数 $f(x)$ 在区间 $D$ 上必须有最大值和最小值。
		\item \textbf{条件 2（常数任意）：} $a$ 为任意常数，无需特殊条件。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（验证前提）：} 使用前务必检查最值是否存在，否则结论失效。
		\item \textbf{检查项（量词方向）：} 注意区分存在性与恒成立，存在性用最值中的“大”（最大值），恒成立用最值中的“小”（最小值）。
	\end{itemize}

\end{summarybox}
