\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	构造$F(x)=\frac{f(x)}{x}$并求导，分母$x^{2}>0$，因此$F'(x)$的正负完全由分子$x f'(x)-f(x)$决定。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（求导结果）：}]
			对$F(x)=\frac{f(x)}{x}$使用商法则，得$F'(x)=\frac{x f'(x)-f(x)}{x^{2}}$。
		\item[\textbf{要点二（符号判定）：}]
			因为$x^{2}>0$，所以$F'(x)$与$x f'(x)-f(x)$同号。
		\item[\textbf{要点三（单调对应）：}]
			若$x f'(x)-f(x)>0$则$F'(x)>0$，$F(x)$递增；若小于$0$则递减。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（斜率视角）}}
	$F(x)=\frac{f(x)}{x}$可视为点$(x,f(x))$与原点连线的斜率，因此$F'(x)$的正负表示该连线斜率随$x$增大而上升或下降。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（简化判号）}}
	该结论将分式函数$\frac{f(x)}{x}$的单调性判断转化为$x f'(x)-f(x)$的符号判别，后者往往更易从题目条件获得，从而简化计算。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（命题方向）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（构造比大小）：} 在需比较$\frac{f(a)}{a}$与$\frac{f(b)}{b}$大小的问题中，构造函数$F(x)=\frac{f(x)}{x}$，利用其单调性得出结论。
		\item \textbf{考法二（条件转化）：} 已知条件给出$x f'(x)-f(x)>0$（或$<0$），可直接推出$\frac{f(x)}{x}$的单调区间，省去求导判号过程。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	关键是“分子集中”：求导后分子自动出现$x f'(x)-f(x)$，与分母平方无关，符号判断只需看分子。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（直接判断）：} 题目要求讨论$F(x)=\frac{f(x)}{x}$的单调性，直接求导并应用本结论。
		\item \textbf{场景二（构造函数证明）：} 需证明形如$\frac{f(a)}{a}>\frac{f(b)}{b}$时，构造$F(x)$并证明其单调性。
	\end{itemize}

\end{explanationbox}
