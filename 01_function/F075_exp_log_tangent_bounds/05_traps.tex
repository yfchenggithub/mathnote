\begin{trapbox}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CTrap}{易错点一（忽略定义域）}}] 错误地将 $\ln x \le x-1$ 应用于 $x\le 0$ 的情形。
		\item[\textbf{\textcolor{CTrap}{正确理解（定义域检验）：}}] 对数 $\ln x$ 仅当 $x>0$ 时有定义，放缩必须在定义域内使用。
		\item[\textbf{\textcolor{CTrap}{错因分析（遗忘定义域）：}}] 学生容易忘记对数定义域，机械套用放缩，导致后续推导出错。
	\end{description}

	\medskip
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CTrap}{易错点二（等号条件误判）}}] 认为 $e^x \ge x+1$ 与 $\ln x \le x-1$ 取等条件一致，从而推出 $e^x-\ln x \ge 2$ 可取等。
		\item[\textbf{\textcolor{CTrap}{正确理解（取等条件区分）：}}] 两个不等式的取等条件不同（$x=0$ 与 $x=1$），且 $x>0$ 时 $e^x > x+1$ 恒成立，故 $e^x-\ln x > 2$。
		\item[\textbf{\textcolor{CTrap}{错因分析（等号误用）：}}] 未具体检验取等条件，误以为组合后等号仍能达成。
	\end{description}

	\medskip
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CTrap}{易错点三（符号处理不当）}}] 在将 $\ln x \le x-1$ 变为 $-\ln x$ 时，不等号方向不变。
		\item[\textbf{\textcolor{CTrap}{正确理解（不等号法则）：}}] 乘负数后不等号反向：$\ln x \le x-1 \implies -\ln x \ge -(x-1)$。
		\item[\textbf{\textcolor{CTrap}{错因分析（符号处理疏忽）：}}] 对不等式性质掌握不牢，忽略方向改变。
	\end{description}
\end{trapbox}
