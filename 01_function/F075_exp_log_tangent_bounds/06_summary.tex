\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	$\ln x \le x-1$（$x>0$），$e^x \ge x+1$（$x\in\mathbb{R}$），$e^x \ge ex$（$x\in\mathbb{R}$），这三个切线放缩是处理指数对数不等式最基本的工具。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（定义域限制）：} $\ln x$ 放缩必须 $x>0$；指数放缩全体实数可用。
		\item \textbf{条件 2（等号位置）：} 记住各取等点，组合时需特别分析。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（忽略定义域）：} 对数放缩只对 $x>0$ 有效。
		\item \textbf{检查项（等号是否一致）：} 组合放缩时检查取等条件是否兼容，否则只能得到弱不等式。
	\end{itemize}
\end{summarybox}
