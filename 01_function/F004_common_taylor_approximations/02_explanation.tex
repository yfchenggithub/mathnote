\begin{explanationbox}
\textbf{\textcolor{CExplanation}{一句话直觉}}
当 $x$ 很小时，足够光滑的曲线可以用一个多项式来“临摹”；保留的项越多，通常贴合得越准。

\medskip
\textbf{\textcolor{CExplanation}{核心拆解}}
\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
    \item[\textbf{要点一（切线近似）：}] 一次项 $f'(0)x$ 反映曲线在 $0$ 处的切线方向，称为线性近似。
    \item[\textbf{要点二（曲率修正）：}] 二次项 $\frac{f''(0)}{2!}x^2$ 反映曲线的弯曲程度，使近似更贴近。
    \item[\textbf{要点三（余项控制）：}] 写成 $O(x^m)$ 或 $o(x^m)$ 是为了说明省略部分的阶数，尤其适合极限题中的严格比较。
\end{description}

\medskip
\textbf{\textcolor{CExplanation}{几何本质（多项式拟合）}}
泰勒多项式与原函数在 $x=0$ 处具有相同的函数值、导数值以及若干高阶导数值，所以曲线在该点附近会“贴合”得越来越紧。

\medskip
\textbf{\textcolor{CExplanation}{代数意义（导数系数）}}
多项式的系数依次是
\[
f(0),\quad f'(0),\quad \frac{f''(0)}{2!},\quad \frac{f'''(0)}{3!},\quad \dots
\]
即函数在 $0$ 处的各阶导数除以对应阶乘。

\medskip
\textbf{\textcolor{CExplanation}{考点价值（常见题型）}}
\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
    \item \textbf{考法一（极限计算）：} 利用带余项的展开式求未定式极限，如 $\lim_{x\to0}\frac{e^x-1-x}{x^2}$。
    \item \textbf{考法二（函数估值）：} 计算函数在 $0$ 附近的值，如 $\sin 0.1$ 的快速估算。
    \item \textbf{考法三（复合函数展开）：} 先展开内层函数，再代入外层展开式，注意保留到题目需要的阶数。
\end{itemize}

\medskip
\textbf{\textcolor{CExplanation}{顿悟点}}
不要只记“近似等于”，更要记住“保留到哪一阶”和“省略项大约从哪一阶开始”。极限题中，阶数往往比数值更重要。

\medskip
\textbf{\textcolor{CExplanation}{使用场景}}
\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
    \item \textbf{场景一（导数综合题）：} 题干出现“当 $|x|$ 很小时”或 $x\to0$，可考虑启用泰勒近似。
    \item \textbf{场景二（极限题）：} 分子分母低阶项抵消时，用展开式找出首个非零项。
    \item \textbf{场景三（物理近似）：} 单摆小角度近似 $\sin\theta\approx\theta$ 等，必须注意 $\theta$ 用弧度制。
\end{itemize}
\end{explanationbox}
