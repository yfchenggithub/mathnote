\textbf{结论名称：} 含参函数单调性讨论模板（五种常见参数类型）

\textbf{适用条件：} 函数可导，导函数 \(f'(x)\) 含有参数且能化为多项式、指数、对数或分式等初等函数，导数的零点个数及符号可由参数取值完全决定。

\textbf{变量说明：} \(x\) 为自变量，参数常用 \(a,k,\lambda\) 等，定义域为 \(D\)；单调区间由 \(f'(x)>0\) 及 \(f'(x)<0\) 的解集划分。

\textbf{核心公式：} 讨论 \(f'(x)>0\)，按参数所在结构分为五类，其解集模型如下：
\[
\boxed{
\begin{cases}
\text{一次型：} & kx+b>0 \;\Rightarrow\; \text{分 } k>0,\;k=0,\;k<0; \\[4pt]
\text{二次可分解型：} & a(x-m)(x-n)>0 \;\Rightarrow\; \text{比较 } m,n \text{ 及 } a \text{ 符号}; \\[4pt]
\text{二次不可分解型：} & ax^2+bx+c>0 \;\Rightarrow\; \text{判 } \Delta,\;a \text{ 符号}; \\[4pt]
\text{指数/对数型：} & e^x-a>0 \text{ 或 } \ln x+a>0 \;\Rightarrow\; \text{化为 } x \gtrless g(a); \\[4pt]
\text{分式/根式型：} & \dfrac{x-a}{x}>0 \;\Rightarrow\; \text{穿根法结合定义域}.
\end{cases}
}
\]

\textbf{使用场景：} 高考导数大题求含参函数的单调区间，或已知单调性反求参数范围，可套用上述模型快速建立分类标准。

\textbf{简单例子：} 讨论 \(f(x)=e^x-ax\) 的单调性。  
解：\(f'(x)=e^x-a\).  
当 \(a\le 0\) 时，\(f'(x)>0\) 恒成立，\(f(x)\) 在 \(\mathbb{R}\) 上递增；  
当 \(a>0\) 时，令 \(f'(x)=0\) 得 \(x=\ln a\).  
\(x<\ln a\) 时 \(f'(x)<0\)，\(x>\ln a\) 时 \(f'(x)>0\)，  
故 \(f(x)\) 在 \((-\infty,\ln a)\) 递减，在 \((\ln a,+\infty)\) 递增。
