\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	\textbf{讨论含参函数单调性，先将导函数化为标准型，再按参数分类解不等式。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（导函数标准化）：} 导函数可化为五种标准结构之一。
		\item \textbf{条件2（参数完全分类）：} 对参数的所有可能取值进行分类。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（定义域判别式）：} 分式、对数型必先定定义域；二次型必算判别式。
		\item \textbf{检查项（边界参数覆盖）：} 参数临界值（如 $k=0$、$a=0$、$\Delta=0$ 等）是否单独讨论。
	\end{itemize}

\end{summarybox}
