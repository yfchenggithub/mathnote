\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	含参函数单调性讨论，只需将导函数化为标准形式，再对参数分类解不等式即可。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（标准形式识别）：}]
			将导函数整理为一次、二次、指数、对数、分式等标准结构之一。
		\item[\textbf{要点二（参数主导符号）：}]
			参数决定导函数符号的不等式解集形状，需按参数不同取值分类。
		\item[\textbf{要点三（定义域前提）：}]
			对数、分式、根式型必须优先确定定义域，再在定义域内讨论符号。
		\item[\textbf{要点四（穿根法应用）：}]
			对可分解的因式乘积，穿根法可直观确定各区间符号。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（切线与升降）}}
	导函数 $f'(x)$ 的正负对应切线斜率正负，正斜率时函数上升，负斜率时函数下降。分类讨论 $f'(x)>0$ 的区域即为函数单调增区间。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（解含参不等式）}}
	讨论单调性本质上就是解含参不等式 $f'(x)>0$ 和 $f'(x)<0$。将导函数化为标准形式后，利用一次、二次、指对数不等式的解法，按参数分类讨论即可得到解集。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高考高频）}}
	全国卷及各省市导数题第一问常考含参函数的单调性讨论，掌握五种标准模板可快速准确得分，是导数题解答的基础分。

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	先看导函数形式，对照模板再分类，避免盲目展开导数式。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（一次型参数线性）：} 导函数为 $kx+b$ 形式，适合线性参数。
		\item \textbf{场景二（二次型参数二次）：} 导函数为二次式，适合含二次参数或自然参数。
		\item \textbf{场景三（指数对数型）：} 导函数含 $e^x$ 或 $\ln x$，适合含指数对数参数。
		\item \textbf{场景四（分式型含定义域）：} 导函数为分式，需结合定义域讨论。
	\end{itemize}

\end{explanationbox}
