\[
	\textbf{二级结论：洛必达法则处理 } \frac{0}{0} \text{ 型极限}
\]

若函数 \(f(x)\)、\(g(x)\) 在 \(x \to a\) 时满足

\[
	\lim_{x \to a} f(x)=0,\qquad \lim_{x \to a} g(x)=0,
\]

且在 \(a\) 的某个去心邻域内，\(f'(x)\)、\(g'(x)\) 存在，并且

\[
	g'(x)\neq 0,
\]

如果极限

\[
	\lim_{x \to a}\frac{f'(x)}{g'(x)}
\]

存在或为无穷大，则有

\[
	\boxed{
		\lim_{x \to a}\frac{f(x)}{g(x)}
		=
		\lim_{x \to a}\frac{f'(x)}{g'(x)}
	}
\]

\[
	\textbf{核心理解：}
\]

当分子、分母同时趋近于 \(0\) 时，原函数的比值极限可以转化为导数的比值极限。

\[
	\textbf{常见用法：}
\]

对于极限

\[
	\lim_{x\to 0}\frac{\sin x}{x},
\]

因为

\[
	\lim_{x\to 0}\sin x=0,\qquad \lim_{x\to 0}x=0,
\]

所以可以使用洛必达法则：

\[
	\lim_{x\to 0}\frac{\sin x}{x}
	=
	\lim_{x\to 0}\frac{(\sin x)'}{x'}
	=
	\lim_{x\to 0}\frac{\cos x}{1}
	=
	1.
\]

\[
	\textbf{结论：}
\]

\[
	\boxed{
		\lim_{x\to 0}\frac{\sin x}{x}=1
	}
\]

\[
	\textbf{易错提醒：}
\]

洛必达法则不能直接用于普通的代入型极限，只有当极限是

\[
	\frac{0}{0}
	\quad\text{或}\quad
	\frac{\infty}{\infty}
\]

这两种未定式时，才可以考虑使用。
