# F005 无穷比无穷型

事实源：01_statement.tex 的另一个可用情况、04_examples.tex 例5、05_traps.tex 易错二与五。仅表现正无穷的代表例子，不声称穷尽所有无穷型。

1. 固定 f=2x²+3x+1，g=x²+1。x从2增至10，曲线、同横坐标动点与实时值同步；两者不断增大，∞/∞不是商的答案。
2. 切换坐标系，明确纵轴现在是比值。x从10增至80，同屏追踪f/g与f′/g′，两者逐渐靠近水平线2。有限数值不冒充达到无穷。
3. 保留曲线与端点，给出导数比=2+3/(2x)→2和原极限2。明确“有限位置通常不相等；相同的是极限”，并显示可导、g′≠0、导数比极限存在等条件。
