\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	\textbf{三次函数的极值来自导函数的零点；导函数是二次函数，所以只要看它的判别式，也就是看 $B^2-3AC$ 的符号。}

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（极值点来源）：}]
		      三次函数
		      \[
			      f(x)=Ax^3+Bx^2+Cx+D
		      \]
		      的极值点只可能出现在 $f'(x)=0$ 的位置。

		\item[\textbf{要点二（导函数结构）：}]
		      求导得
		      \[
			      f'(x)=3Ax^2+2Bx+C.
		      \]
		      这是一个二次函数，其零点个数由判别式决定。

		\item[\textbf{要点三（判别式角色）：}]
		      $f'(x)$ 的判别式为
		      \[
			      \Delta_{f'}=(2B)^2-4\cdot3A\cdot C=4(B^2-3AC)=4\Delta.
		      \]
		      因为 $4>0$，所以 $\Delta_{f'}$ 与 $\Delta$ 同号。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（导函数图像）}}

	$f'(x)$ 是一条抛物线。它与 $x$ 轴有两个交点时，$f'(x)$ 的符号会发生两次变化，原函数就会出现两个极值点；它与 $x$ 轴无交点或只有一个切点时，$f'(x)$ 不变号，原函数就没有极值点。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（方程判别式）}}

	判断三次函数有没有极值，本质上转化为判断二次方程
	\[
		3Ax^2+2Bx+C=0
	\]
	有没有两个不同实根。因此不必先求出极值点坐标，只看 $B^2-3AC$ 的符号即可。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（快速判趋势）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（选填提速）：} 在选择题中直接利用 $\Delta$ 的符号判断三次函数极值点个数，避免完整求导列表。
		\item \textbf{考法二（含参分类）：} 参数影响系数时，先算 $\Delta=B^2-3AC$，再讨论 $\Delta>0$ 或 $\Delta\le0$。
		\item \textbf{考法三（单调性判断）：} 当 $\Delta\le0$ 时，再结合 $A$ 的符号判断整体递增或递减。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{三次函数看起来复杂，但它的“转向次数”由导函数这条抛物线决定；抛物线是否穿过 $x$ 轴，就由 $B^2-3AC$ 决定。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（解析式已知）：} 直接给出 $A,B,C$ 的值，判断极值点个数。
		\item \textbf{场景二（含参讨论）：} 参数出现在 $A,B,C$ 中，利用 $\Delta$ 的符号分类讨论。
		\item \textbf{场景三（单调性证明）：} 要证明三次函数在 $\mathbb{R}$ 上单调时，常转化为证明 $f'(x)$ 恒不小于 $0$ 或恒不大于 $0$。
	\end{itemize}
\end{explanationbox}
