\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	三次函数的图像是中心对称的S形曲线，对称中心就是其凹凸性改变的点（拐点）。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（拐点定义）：}]
			二阶导为零的点称为拐点，它改变函数的凹凸性。
		\item[\textbf{要点二（对称条件）：}]
			若点$(x_0,f(x_0))$是对称中心，则对任意$t$，有$f(x_0+t)+f(x_0-t)=2f(x_0)$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（凹凸分界点）}}
	三次函数图像从一侧的凹（凸）转向另一侧的凸（凹），这个转折点恰好就是对称中心。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（二阶导为零）}}
	对称中心横坐标是方程$f''(x)=0$的根，即$6ax+2b=0$的解$\displaystyle x=-\frac{b}{3a}$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（对称求参数）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（对称求值）：} 利用对称中心可快速计算关于对称中心对称的两点函数值之和。
		\item \textbf{考法二（参数反求）：} 已知对称中心坐标，可以直接列方程求出$b$等参数。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	三次函数的对称性只与$a$和$b$有关，常数项$c,d$不影响对称中心横坐标。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（直接代入）：} 给出具体三次函数，套用公式$(-\frac{b}{3a}, f(-\frac{b}{3a}))$得对称中心。
		\item \textbf{场景二（对称验证）：} 通过验证$f(x_0+t)+f(x_0-t)=2f(x_0)$来判断点是否为对称中心。
	\end{itemize}

\end{explanationbox}
