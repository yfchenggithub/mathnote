# F040 指数变化分镜与数学审计

事实源为本 UID 正式六段 TeX 与 meta.json。模型独立计算 x>0 的实数幂，不读取其他 UID 私有模型。负底数分数幂仅在例4的独立测试函数中按奇次根意义解释，不混入连续实指数模型。

动画固定系数为1，依次让指数从−1增至0、1/2、1、2，再连续返回−1，停留于五个代表状态。曲线定义域显示段为[0.23,2.2]，数学统一讨论范围仍为x>0；显示段内所有曲线均处于固定坐标窗口，绝不把x=0传给幂模型。

共同点(1,1)固定，两个彩点对应底数1/2和2。改变指数时，左点与右点向相反方向移动，且在指数0时两者都位于高度1。曲线、追踪点和两个数值均来自同一模型；屏幕读数明确使用近似符号并保留两位小数。升降、陡缓的说明由实际指数分类给出。

固定坐标比例，图形为主要视觉对象；辅助标签不追随点挤入曲线。两行品牌全程固定。数学测试、真实五类关键帧、过渡帧及全帧技术检查分别验收；Android与用户视觉确认保持PENDING，不能宣称最终冻结。
