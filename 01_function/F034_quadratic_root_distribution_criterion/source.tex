\textbf{结论名称：} 二次函数零点分布（判别式+对称轴+端点值）\newline
\textbf{适用条件：} 设二次函数 $f(x)=ax^2+bx+c\ (a\neq0)$，讨论方程 $f(x)=0$ 在区间 $(m,n)$（或 $[m,n]$）内的根的分布。\newline
\textbf{变量说明：} $a,b,c$ 为实系数；判别式 $\Delta=b^2-4ac$；对称轴 $x_0=-\dfrac{b}{2a}$；端点函数值 $f(m),f(n)$。\newline
\textbf{核心公式：}
方程在 $(m,n)$ 内有两个不等实根（$a\neq0$）的充要条件为
\[
\boxed{\Delta>0,\quad m<-\frac{b}{2a}<n,\quad a\cdot f(m)>0,\quad a\cdot f(n)>0 }.
\]
仅有一个实根在 $(m,n)$ 内的常见充要条件为 $f(m)f(n)<0$（且需排除另一根在区间外或重根在端点的情形，需结合对称轴和判别式验根）。\newline
\textbf{使用场景：} 已知含参二次方程在指定区间内有两个不同实根，求参数的取值范围；或判断二次函数在区间内的变号情况。\newline
\textbf{简单例子：} 若方程 $x^2-2mx+m^2-1=0$ 在 $(0,3)$ 内有两个不等实根，求 $m$ 的范围。\newline
解：$f(x)=x^2-2mx+m^2-1$，$\Delta=4>0$ 恒成立。对称轴 $x=m\in(0,3)$。$f(0)=m^2-1>0\Rightarrow m<-1$ 或 $m>1$；$f(3)=m^2-6m+8>0\Rightarrow m<2$ 或 $m>4$。结合得 $1<m<2$。
