\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	当指数底数与对数底数相同（均为 $a$ 且符合条件）时，指数与对数可以相互抵消，即 $a^{\log_a N}=N$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（底数要求）：} $a>0$，$a\neq 1$。
		\item \textbf{条件2（真数要求）：} $N>0$。
		\item \textbf{条件3（同底条件）：} 指数底与对数底完全相同。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（定义域优先）：} 总是先检查真数 $N>0$，再使用恒等式。
		\item \textbf{检查项（底数一致）：} 使用前必须核对指数与对数的底数是否相同。
	\end{itemize}

\end{summarybox}
