\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	构造 $F(x)=\dfrac{f(x)}{e^x}$，利用 $F'(x)=\dfrac{f'(x)-f(x)}{e^x}$ 的符号判断 $F(x)$ 的单调性，从而比较函数值或解抽象不等式。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（函数可导）：} $f(x)$ 在指定区间上可导。
		\item \textbf{条件2（不等式可化）：} 已知 $f'(x)$ 与 $f(x)$ 的关系可整理成 $f'(x)-f(x) > 0$（或 $<0, \geq 0, \leq 0$）的形式。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（分母恒正）：} $e^x>0$ 恒成立，所以 $F'(x)$ 的符号与 $f'(x)-f(x)$ 完全一致，不要误以为分母会改变符号。
		\item \textbf{检查项（构造验证）：} 构造后确认 $F(x)$ 的定义域包含所有要比较的点，且 $e^x$ 在定义域内非零（恒成立）。
	\end{itemize}
\end{summarybox}
