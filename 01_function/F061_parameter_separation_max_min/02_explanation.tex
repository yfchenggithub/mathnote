\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	分离参数法通过将参数与变量分开，把恒成立条件转化为比较参数与函数最值的关系，从而简化问题。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（参数分离）：}] 将不等式转化为$a \ge f(x)$或$a \le f(x)$，使参数单独在一边。
		\item[\textbf{要点二（等价转化）：}] 利用结论：$a \ge f(x)$恒成立$\iff a \ge \max f(x)$；$a \le f(x)$恒成立$\iff a \le \min f(x)$。
		\item[\textbf{要点三（最值求解）：}] 求出函数$f(x)$在给定区间上的最大值或最小值，代入即得参数范围。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（图像比较）}}

	不等式$a \ge f(x)$恒成立表示函数$y=f(x)$的图像始终在直线$y=a$的下方或与之相切，因此$a$必须不低于函数的最高点。同理$a \le f(x)$对应图像始终在直线上方，$a$不高于最低点。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（最值转化）}}

	将参数范围问题归结为求函数最值，把参变量分离后，参数成为待定常数，问题转化为值域或最值问题。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（解题关键）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（导数求最值）：} 常与导数结合，通过导数判断单调性、极值来求最值，进而确定参数范围。
		\item \textbf{考法二（分类讨论化简）：} 分离参数可避免直接分类讨论，将问题转化为独立函数的研究。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	分离参数后，参数“消失”于函数研究，只需集中精力分析不含参数的函数在区间上的性态。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（恒成立问题）：} 给定区间上含参不等式恒成立，且参数可分离。
		\item \textbf{场景二（含参函数题）：} 函数的单调性、极值、零点等含参问题常转化为恒成立后使用分离参数法。
	\end{itemize}
\end{explanationbox}
