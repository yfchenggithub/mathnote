\begin{summarybox}

	\textbf{\textcolor{CSummary}{一句话核心}}

	分离参数法将含参恒成立问题转化为函数最值问题：$a\ge f(x)$恒成立$\iff a\ge \max f(x)$；$a\le f(x)$恒成立$\iff a\le \min f(x)$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（参数可分离）：} 不等式能化为$a\ge f(x)$或$a\le f(x)$的形式。
		\item \textbf{条件 2（最值存在）：} 函数$f(x)$在给定区间上存在最大值和最小值。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（方向对应）：} 注意不等号方向与最值类型的对应：$\ge$对应最大值，$\le$对应最小值。
		\item \textbf{检查项（分离正确）：} 分离参数时确保不等号方向不变（或正确处理变号），同时检查函数最值是否确实存在。
	\end{itemize}
\end{summarybox}
