\textbf{F086｜平方根的快速估算与精度控制}
\textbf{解决：}不使用计算器，怎样把 $\sqrt{10}$、$\sqrt2$ 估到需要的小数位？
\[\boxed{\sqrt A\approx t+\frac{A-t^2}{2t}}\quad(A>0,t>0).\]
先找 $t^2$ 靠近 $A$，再用完全平方公式作小量修正。\textbf{保证精度}要核对平方或给出上下界；“约等于”不自动保证三位小数。
\textbf{例：}$\sqrt{10}\approx3+\frac{10-9}{6}=\frac{19}{6}=3.1667$，再用更近的数或放大后估可继续改进。
\textbf{误差恒等式：}$\bigl(t+\frac{A-t^2}{2t}\bigr)-\sqrt A=\frac{(t-\sqrt A)^2}{2t}\ge0$。
