# F015 动点伙伴分镜
事实源：本 UID 六段 TeX 与 meta.json；没有机械复制其他 UID 模型。
上图 y=x² 的点 (t,t²)、(−t,t²) 关于 y 轴对称；下图 y=x³ 的点 (t,t³)、(−t,−t³) 关于原点对称。
定义域均为 R。参数 t 从0.5到1.5并返回；同时追踪两种配对，强调“输入成对”和“输出规律”分两关。
两图分别横纵同尺度；两图间单位长度可以不同，不跨图比较长度。橙色连线是辅助线，不是函数图像。
曲线与动点全部由同一数学模型计算；四项自动测试包含241个动画状态及101个奇偶分解样本。
所有浮点读数加≈；两行品牌文案全程固定。用户视觉与Android验收待确认。
