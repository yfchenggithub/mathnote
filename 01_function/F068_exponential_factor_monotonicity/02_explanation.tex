\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	构造 $e^x f(x)$ 后，求导直接出现 $f'(x)+f(x)$，从而将条件转化为单调性。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（乘积求导）：}] 由 $(e^x)'=e^x$，对 $F(x)=e^x f(x)$ 求导得 $F'(x)=e^x f'(x)+e^x f(x)$，合并得 $F'(x)=e^x[f'(x)+f(x)]$。
		\item[\textbf{要点二（符号判据）：}] 因为 $e^x>0$ 恒成立，所以 $F'(x)$ 的符号完全由 $f'(x)+f(x)$ 决定。
		\item[\textbf{要点三（等价转化）：}] 若 $f'(x)+f(x)>0$，则 $F'(x)>0$，$F(x)$ 严格递增；反之递减；等于零则为常数。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（变换视角）}}

	从复合变换看，$e^x f(x)$ 可以视为 $f(x)$ 乘以一个恒正函数 $e^x$，乘性放大不改变零点分布，但引入导数和项。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（线性组合）}}

	该构造本质上是将 $f'(x)+f(x)$ 视为一个整体，利用 $e^x$ 的微分性质将其表示为 $(e^x f(x))'$，实现了从 $f'(x)+f(x)$ 到导数形式的转换。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（构造转换）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（构造证明）：} 已知 $f'(x)+f(x)>0$，构造 $e^x f(x)$ 说明其递增。
		\item \textbf{考法二（求导代换）：} 题目含有 $f'(x)+f(x)$ 的等式，可构造 $e^x f(x)$ 求导简化。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	看到 $f'(x)+f(x)$ 就想到 $e^x f(x)$；看到 $f'(x)-f(x)$ 则想到 $e^{-x}f(x)$。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（不等式条件）：} 条件给出 $f'(x)+f(x) > 0$，需要证明 $f(x)$ 单调性或比较大小。
		\item \textbf{场景二（零点问题）：} 方程 $f'(x)+f(x)=0$ 可转化为 $(e^x f(x))'=0$，进而 $e^x f(x)$ 为常数。
	\end{itemize}
\end{explanationbox}
