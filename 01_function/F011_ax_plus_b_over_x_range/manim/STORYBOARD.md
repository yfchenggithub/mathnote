# F011 动画数学审计与分镜

事实源：同 UID 六段 TeX 与 meta.json；不修改数学源与现有图片。

- 值域：A,B>0，x≠0；正支最小值 2√(AB)，负支最大值 −2√(AB)，取等横坐标 ±√(B/A)。动画明确以 A=B=1 示范，结尾回到一般式；换支时淡出重置，绝不经过 x=0。
- 距离：k>0，P=(a,k/a)、Q=(−b,−k/b)，a,b 独立且为正。x+y=±2√k 隔开两支，法向量 (1,1)，线距 2√(2k)。最优 a=b=√k，而非预先假设 Q=−P。
- `F011Range`：沿正支减到最小值停顿，再增；负支增到最大值停顿，再减；投影到值域轴并显示中间缺口、闭端点和一般公式。
- `F011BranchDistance`：非对称点对独立移动、实时距离；引入平行支撑线与公垂线；两点移向接触点，显示等号及一般 k 公式。
- 两图使用 576×1024、浅背景、固定底部两行品牌文案；共用的只有该 UID 内的字体与证据记录辅助，不依赖其他 UID 模型或 Scene。
- 采用 scripts/manim 冻结工具渲染、导出、全帧验证；先本地验收，再显式写入 images 新文件；用户视觉与 Android 真机验收分别待用户确认。
