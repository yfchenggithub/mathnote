\textbf{\textcolor{CStatement}{这条结论解决什么问题？}}

题目没有告诉我们 $f(x)$ 的具体式子，只告诉我们它是奇函数或偶函数，以及图像在右半边是往上走还是往下走。
这时仍然可以解出 $f(x-1)+f(2x)>0$、$f(x+1)>f(3-x)$ 这类不等式，\textbf{不需要猜出函数的解析式}。

\medskip
\textbf{\textcolor{CStatement}{先核对两个条件}}
\begin{enumerate}[leftmargin=*,itemsep=0.35em]
  \item \textbf{定义域：}函数定义在整个实数范围，或定义在一个以 $0$ 为中间位置、左右对称且包含 $0$ 的区间（例如 $[-3,3]$）。下文 $a,b$ 都必须在定义域内。
  \item \textbf{奇偶性与严格单调：}已知 $f(-x)=-f(x)$（奇函数）或 $f(-x)=f(x)$（偶函数）；并且在定义域的\textbf{右半边（$x\geqslant0$）严格递增或严格递减}。
\end{enumerate}
这里“严格递增”指：只要 $u<v$，一定有 $f(u)<f(v)$；“严格递减”则一定有 $f(u)>f(v)$。\textbf{仅仅“不下降”还不够。}

\medskip
\end{statementbox}\clearpage\begin{statementbox}\textbf{\textcolor{CStatement}{结论一：奇函数，两个函数值相加}}

\textbf{右半边严格递增：}
\[
\boxed{\ f(a)+f(b)>0\iff a+b>0\ }
\]
\textbf{右半边严格递减：}
\[
\boxed{\ f(a)+f(b)>0\iff a+b<0\ }
\]
无论递增还是递减，\textbf{等于零时}都有
\[
\boxed{\ f(a)+f(b)=0\iff a+b=0\ }.
\]
\textbf{记法：}奇函数把 $f(a)+f(b)$ 变成 $f(a)-f(-b)$，于是只用比 $a$ 和 $-b$。

\medskip
\end{statementbox}\clearpage\begin{statementbox}\textbf{\textcolor{CStatement}{结论二：偶函数，两个函数值比大小}}
\input{assets/tikz/F019_even_distance}


\textbf{右半边严格递增：}
\[
\boxed{\ f(a)>f(b)\iff |a|>|b|\ }
\]
\textbf{右半边严格递减：}
\[
\boxed{\ f(a)>f(b)\iff |a|<|b|\ }
\]
无论递增还是递减，\textbf{相等时}都有
\[
\boxed{\ f(a)=f(b)\iff |a|=|b|\iff a=b\text{ 或 }a=-b\ }.
\]
\textbf{记法：}偶函数先把左右两边都搬到 $y$ 轴右侧，再比较它们离 $0$ 有多远。

\medskip
\textbf{\textcolor{CStatement}{最短使用步骤}}

\textbf{看奇偶 $\longrightarrow$ 看右半边升降 $\longrightarrow$ 去掉 $f$ $\longrightarrow$ 解普通不等式 $\longrightarrow$ 检查定义域。}
\end{statementbox}
