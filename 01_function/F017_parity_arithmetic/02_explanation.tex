\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	奇偶函数的四则运算规则可类比正负数的符号运算：奇函数对应负号，偶函数对应正号。乘法结果奇偶性等同符号乘积（同号得偶，异号得奇）；加减法仅同符号合并时保持原符号（同奇同偶）。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（加减规则）：}]
			当两个函数同为奇函数或同为偶函数时，它们的和或差保持原奇偶性。代入定义可验证：奇函数之和满足$F(-x)=-F(x)$，偶函数之和满足$F(-x)=F(x)$。奇函数与偶函数相加无固定奇偶性。
		\item[\textbf{要点二（乘除规则）：}]
			奇函数与奇函数相乘相当于负号乘负号得正，结果为偶函数；奇函数与偶函数相乘得奇函数；偶函数与偶函数相乘得偶函数。除法与乘法规则相同（分母非零）。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（对称变换）}}
	函数的奇偶性对应图像对称性：奇函数关于原点旋转对称，偶函数关于$y$轴翻折对称。四则运算后的函数图像由各图像经过相应运算得到，其对称性由上述规则决定。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（定义验证）}}
	运算结果的奇偶性可直接通过奇偶定义验证：对任意$x$在公共定义域内，计算$F(-x)$并代入$f(-x)$与$g(-x)$的奇偶关系，化简可得$F(-x)=\pm F(x)$，从而判定奇偶。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（题型应用）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（抽象函数判断）：} 给定函数奇偶性（可能未给解析式），要求判断经过四则运算后新函数的奇偶性。直接套用规则即可，避免重复验证。
		\item \textbf{考法二（参数求解）：} 已知运算结果的奇偶性，反推参数满足的条件，常结合不等式或函数性质。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	\textbf{将函数奇偶视为符号“$-$”和“$+$”，运算规则对应符号运算，记忆口诀“同偶异奇”。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（直接判断）：} 在选择题或填空题中，若已知两函数奇偶，可秒推运算后奇偶性，快速排除选项。
		\item \textbf{场景二（证明简化）：} 在解答题中，先预判目标函数奇偶性，可简化后续证明步骤（如只需证明一半定义域）。
	\end{itemize}

\end{explanationbox}
