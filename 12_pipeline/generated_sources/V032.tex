\textbf{结论名称：} 平行四边形对角线向量定理（平方和恒等式）

\textbf{适用条件：} 任意平行四边形（两组对边分别平行且相等），同时适用于矩形、菱形、正方形。

\textbf{变量说明：} 设平行四边形两邻边对应的向量为 $\vec{a}$ 与 $\vec{b}$，则两条对角线分别对应向量 $\vec{a}+\vec{b}$ 与 $\vec{a}-\vec{b}$。记边上模长 $a=|\vec{a}|$，$b=|\vec{b}|$。

\textbf{核心公式：} 
\[
\boxed{|\vec{a}+\vec{b}|^{2} + |\vec{a}-\vec{b}|^{2} = 2\bigl(|\vec{a}|^{2} + |\vec{b}|^{2}\bigr)}
\]
即对角线长的平方和等于四边长的平方和：
\[
AC^{2} + BD^{2} = AB^{2} + BC^{2} + CD^{2} + DA^{2} = 2(AB^{2} + AD^{2})
\]

\textbf{使用场景：}
\begin{enumerate}
\item 已知两邻边长，快速求两对角线平方和，无需夹角；
\item 由一条对角线与一边反推另一边之长；
\item 推导三角形中线长公式（取对角线一半即为中线）。
\end{enumerate}

\textbf{简单例子：} 
在 $\square ABCD$ 中，$AB=3$，$AD=4$，则对角线平方和为 
\[
AC^{2}+BD^{2}=2(3^{2}+4^{2})=2\times 25=50.
\]
若再知 $\angle A=60^{\circ}$，可由余弦定理算出 $AC^{2}=3^{2}+4^{2}-2\cdot3\cdot4\cdot\cos120^{\circ}=37$，则 $BD^{2}=50-37=13$，无须重复计算。
