\textbf{结论名称：} 乘法公式（平方差、完全平方、立方和差）

\textbf{适用条件：} \(a,b\) 为任意实数或代数式，在满足乘法分配律与交换律的系统（如实数、多项式、分式）中均成立。

\textbf{变量说明：} \(a,b\)：实数或代数式；公式中 \(\pm\) 与 \(\mp\) 对应：上号同上号，下号同下号。

\textbf{核心公式：}
\[
\boxed{a^2 - b^2 = (a+b)(a-b),\qquad (a\pm b)^2 = a^2 \pm 2ab + b^2,\qquad a^3 \pm b^3 = (a\pm b)(a^2 \mp ab + b^2)}
\]

\textbf{使用场景：} 初中代数式的化简、因式分解、分母有理化；高中数列裂项求和、不等式放缩的基础工具。

\textbf{简单例子：}
\begin{itemize}
  \item 平方差速算：\(103\times 97 = (100+3)(100-3)=100^2-3^2=10000-9=9991\)。
  \item 立方差因式分解：\(x^3-8 = x^3-2^3 = (x-2)(x^2+2x+4)\)。
\end{itemize}
