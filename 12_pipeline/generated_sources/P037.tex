\textbf{结论名称：} 中线长公式（阿波罗尼奥斯定理）

\textbf{适用条件：} 任意三角形，已知三边长。

\textbf{变量说明：} 在 $\triangle ABC$ 中，$a=BC$，$b=CA$，$c=AB$，$m_a$ 为顶点 $A$ 到边 $BC$ 中点的中线长，其余 $m_b,m_c$ 类似。

\textbf{核心公式：} 
\[ \boxed{m_a^{2} = \frac{1}{4}(2b^{2} + 2c^{2} - a^{2})} \]
同理 $m_b^{2} = \frac{1}{4}(2a^{2} + 2c^{2} - b^{2})$，$m_c^{2} = \frac{1}{4}(2a^{2} + 2b^{2} - c^{2})$。

\textbf{使用场景：} 已知三边快速求中线长；中线与边长的相互推导；解三角形中的长度计算或证明中线相关不等式。

\textbf{简单例子：} 在 $\triangle ABC$ 中，$a=6$，$b=5$，$c=5$，求 $m_a$。
\[ m_a^{2} = \frac{1}{4}(2\times 5^{2} + 2\times 5^{2} - 6^{2}) = \frac{100-36}{4} = 16 \implies m_a = 4. \]
验证：等腰三角形中，底边中线即为高，由勾股定理得高为 $\sqrt{5^{2}-3^{2}}=4$，结果一致。
