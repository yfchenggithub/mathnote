\textbf{结论名称：}二项式系数最大项

\textbf{适用条件：}给定正整数 \(n\)，考虑二项式系数（组合数）\(\binom{n}{k}\)（\(k=0,1,\dots,n\)）或形如 \((a+b)^n\) 展开式中不含系数的二项式系数项。

\textbf{变量说明：} \(n\) 为二项式的幂次（正整数）；\(k\) 为项的序号，取遍 \(0,1,\dots,n\)。

\textbf{核心公式：}
\[
\boxed{
\begin{cases}
n \text{为偶数时，中间一项最大：} \displaystyle\binom{n}{\frac{n}{2}};\\[6pt]
n \text{为奇数时，中间两项相等且最大：} \displaystyle\binom{n}{\frac{n-1}{2}}=\binom{n}{\frac{n+1}{2}}.
\end{cases}
}
\]

\textbf{使用场景：}快速确定二项展开式中系数绝对值最大的项（当各项系数仅为组合数时）；处理与组合数最值有关的选择、填空问题。

\textbf{简单例子：}
\begin{itemize}
\item \(n=6\)（偶数）：最大项为 \(\displaystyle\binom{6}{3}=20\)。
\item \(n=7\)（奇数）：最大项为 \(\displaystyle\binom{7}{3}=35\) 和 \(\displaystyle\binom{7}{4}=35\)。
\end{itemize}
