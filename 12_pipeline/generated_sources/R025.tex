\textbf{结论名称：} 条件概率的定义

\textbf{适用条件：} 同一随机试验中的两个事件 \(A, B\)，且 \(P(A)>0\)。

\textbf{变量说明：} \(P(B \mid A)\) 表示在事件 \(A\) 发生的条件下，事件 \(B\) 发生的条件概率；\(P(AB)\) 或 \(P(A \cap B)\) 表示 \(A\) 与 \(B\) 同时发生的概率。

\textbf{核心公式：} 
\[
\boxed{P(B \mid A) = \frac{P(AB)}{P(A)}}
\]

\textbf{使用场景：} 已知部分信息（事件 \(A\) 已发生）后，重新评估事件 \(B\) 的概率；也是乘法公式、全概率公式与贝叶斯公式的基础。

\textbf{简单例子：} 抛一枚均匀硬币两次，样本空间 \(\Omega=\{HH,HT,TH,TT\}\)，各结果等可能。设事件 \(A=\)“第一次正面”\(=\{HH,HT\}\)，事件 \(B=\)“两次均为正面”\(=\{HH\}\)。则 \(P(A)=\frac{1}{2}\)，\(P(AB)=\frac{1}{4}\)，于是 \(P(B \mid A) = \frac{P(AB)}{P(A)}=\frac{1/4}{1/2}=\frac{1}{2}\)，即在已知第一次正面的条件下，两次均为正面的概率为 \(\frac{1}{2}\)。
