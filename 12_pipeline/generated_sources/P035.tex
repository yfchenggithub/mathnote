\textbf{结论名称：} 三角形内角平分线定理

\textbf{适用条件：} 在 $\triangle ABC$ 中，$AD$ 是内角 $\angle BAC$ 的平分线，且点 $D$ 落在对边 $BC$ 上。

\textbf{变量说明：} $AB$ 与 $AC$ 为夹 $\angle A$ 的两边；$BD$ 与 $DC$ 为对边 $BC$ 被角平分线分成的两段。

\textbf{核心公式：} 
\[
\boxed{\frac{BD}{DC} = \frac{AB}{AC}}
\]

\textbf{使用场景：} 
已知三角形两边长及角平分线对分点的信息，可求线段长度或比例；在几何证明中替换共线段的比分，或与角平分线长公式、面积关系等联用。

\textbf{简单例子：} 
在 $\triangle ABC$ 中，$AB=6$，$AC=4$，$AD$ 平分 $\angle A$ 交 $BC$ 于 $D$，且 $BC=5$。求 $BD$ 和 $DC$。

解：设 $BD=x$，则 $DC=5-x$。由定理得
\[
\frac{x}{5-x} = \frac{6}{4} = \frac{3}{2} \implies 2x=15-3x \implies x=3.
\]
故 $BD=3$，$DC=2$，可验 $\frac{3}{2}=\frac{6}{4}$ 成立。
