\textbf{结论名称：} 双曲线焦半径公式（根据点所在支判断正负）

\textbf{适用条件：} 双曲线标准方程为 \(\frac{x^2}{a^2}-\frac{y^2}{b^2}=1\;(a>0,b>0)\)，焦点在 \(x\) 轴上，点 \(P(x_0,y_0)\) 在双曲线上。

\textbf{变量说明：} \(a\) 为实半轴长，\(c=\sqrt{a^2+b^2}\) 为半焦距，离心率 \(e=\frac{c}{a}>1\)，左、右焦点分别为 \(F_1(-c,0),\,F_2(c,0)\)，\(x_0\) 为点 \(P\) 的横坐标。

\textbf{核心公式：}
\[
\boxed{|PF_1| = |a + ex_0|,\qquad |PF_2| = |a - ex_0|}
\]
根据点所在支去掉绝对值：
\begin{itemize}
\item 当 \(P\) 在右支（\(x_0\ge a\)）时，\(|PF_1|=ex_0+a,\;|PF_2|=ex_0-a\)；
\item 当 \(P\) 在左支（\(x_0\le -a\)）时，\(|PF_1|=-(ex_0+a),\;|PF_2|=-(ex_0-a)\)。
\end{itemize}

\textbf{使用场景：} 已知双曲线上一点的横坐标，快速求该点到两焦点的距离；或反向由焦半径求点的坐标、离心率等。

\textbf{简单例子：} 双曲线 \(\frac{x^2}{4}-\frac{y^2}{5}=1\)，\(a=2,\;b=\sqrt5,\;c=3,\;e=\frac32\)。
取右支点 \(P(3,\frac52)\)，则
\[
|PF_1| = \bigl|2+\tfrac32\times3\bigr| = \tfrac{13}{2},\quad
|PF_2| = \bigl|2-\tfrac32\times3\bigr| = \tfrac52 .
\]
取左支点 \(P'(-3,\frac52)\)，则
\[
|P'F_1| = \bigl|2+\tfrac32\times(-3)\bigr| = \tfrac52,\quad
|P'F_2| = \bigl|2-\tfrac32\times(-3)\bigr| = \tfrac{13}{2} .
\]
直接用两点间距离公式可验证结果一致。
