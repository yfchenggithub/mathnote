\textbf{结论名称：}8字型相似（交叉相似模型）  

\textbf{适用条件：}两直线相交产生对顶角；通常有一组对边平行，如 $AB\parallel CD$，直线 $AC$ 与 $BD$ 交于点 $O$，构成 $\triangle OAB$ 与 $\triangle OCD$；无平行时若有另一组角对应相等也可得相似。  

\textbf{变量说明：}$O$ 为两直线交点，$A,C$ 在一条直线上，$B,D$ 在另一条直线上；对应边：$OA$ 与 $OC$，$OB$ 与 $OD$，$AB$ 与 $CD$；公共角 $\angle AOB = \angle COD$（对顶角）。  

\textbf{核心公式：}若 $AB\parallel CD$，则 $\triangle OAB \sim \triangle OCD$，且  
\[
\boxed{\frac{OA}{OC} = \frac{OB}{OD} = \frac{AB}{CD}}
\]  

\textbf{使用场景：}平行线段间的长度比例转化；梯形两腰延长线与对角线形成的比例计算；解析几何中点差法所得中点弦斜率关系中几何比例的代数化背景。  

\textbf{简单例子：}如图，$AB\parallel CD$，$AC$ 与 $BD$ 交于点 $O$。已知 $OA=3$，$OC=5$，$AB=6$，求 $CD$。  
由 $\dfrac{AB}{CD}=\dfrac{OA}{OC}$ 得 $\dfrac{6}{CD}=\dfrac{3}{5}$，解得 $CD=10$。可验证 $\dfrac{OB}{OD}$ 同样等于 $\dfrac{3}{5}$。
