\textbf{结论名称：} 回归直线过样本中心点 \((\bar{x},\bar{y})\)

\textbf{适用条件：} 一元线性回归模型 \(\hat{y} = \hat{b}x + \hat{a}\)，且参数 \(\hat{a},\hat{b}\) 由最小二乘法确定。

\textbf{变量说明：} 样本数据 \((x_i,y_i),\,i=1,\dots,n\)；样本均值 \(\bar{x}=\frac1n\sum x_i\)，\(\bar{y}=\frac1n\sum y_i\)；\(\hat{b}\) 为回归斜率，\(\hat{a}\) 为回归截距。

\textbf{核心公式：}
\[
\boxed{\bar{y} = \hat{b}\bar{x} + \hat{a}}
\]
即回归直线必经过样本中心点 \((\bar{x},\bar{y})\)。

\textbf{使用场景：} 已知回归斜率快速求截距；检验回归方程是否合理；利用中心点简化最小二乘的正规方程推导。

\textbf{简单例子：} 已知数据点 \((1,2),\,(2,3),\,(3,4),\,(4,5)\)，计算得 \(\bar{x}=2.5,\ \bar{y}=3.5\)。若由最小二乘法求得 \(\hat{b}=1\)，利用回归直线过中心点性质：
\[
\hat{a} = \bar{y} - \hat{b}\bar{x} = 3.5 - 1 \times 2.5 = 1,
\]
故回归直线方程为 \(\hat{y} = x + 1\)，经验证各点均落在该直线上。
