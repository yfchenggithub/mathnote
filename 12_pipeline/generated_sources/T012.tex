\textbf{结论名称：} 半角公式（正弦、余弦平方及正切半角）

\textbf{适用条件：} 任意角 $\alpha$，其中正切半角公式要求相应的分母不为零：$\tan\frac{\alpha}{2} = \frac{\sin\alpha}{1+\cos\alpha}$ 要求 $\cos\alpha \neq -1$；$\tan\frac{\alpha}{2} = \frac{1-\cos\alpha}{\sin\alpha}$ 要求 $\sin\alpha \neq 0$。

\textbf{变量说明：} $\alpha$ 为任意实数（或角度），所有三角值均按常规定义，公式不改变角的象限符号，需根据 $\frac{\alpha}{2}$ 所在象限单独判断正负号。

\textbf{核心公式：}
\[
\boxed{\sin^2\frac{\alpha}{2} = \frac{1-\cos\alpha}{2},\qquad \cos^2\frac{\alpha}{2} = \frac{1+\cos\alpha}{2},\qquad \tan\frac{\alpha}{2} = \frac{\sin\alpha}{1+\cos\alpha} = \frac{1-\cos\alpha}{\sin\alpha}}
\]

\textbf{使用场景：} 用于降幂、求半角的三角函数值、化简含平方的三角表达式，以及在积分与三角方程中将二次三角式转化为一次式。

\textbf{简单例子：} 取 $\alpha = 120^\circ$，则 $\cos120^\circ = -\frac12$。计算 $\sin^2 60^\circ = \frac{1-(-1/2)}{2} = \frac{3}{4}$，$\cos^2 60^\circ = \frac{1+(-1/2)}{2} = \frac{1}{4}$，$\tan 60^\circ = \frac{\sin120^\circ}{1+\cos120^\circ} = \frac{\sqrt3/2}{1-1/2} = \sqrt3$，与直接计算一致。
