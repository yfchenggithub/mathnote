\textbf{结论名称：} 排列组合四大策略——捆绑法、插空法、隔板法、排除法

\textbf{适用条件：} 
捆绑法：元素必须相邻；插空法：元素互不相邻；隔板法：相同元素分给不同对象（默认每组至少一个）；排除法：直接计算复杂而反面较简单或具有“至少”“至多”限制。

\textbf{变量说明：} 
$n$ 为元素总数，$m$ 为需相邻或不相邻的元素个数，$k$ 为插入元素个数；隔板法中 $n$ 为相同元素总数，$m$ 为组数（盒子数）。

\textbf{核心公式：}
\[
\boxed{
\begin{array}{l}
\text{捆绑法： } m!\,(n-m+1)! \\[4pt]
\text{插空法： } n!\,A_{n+1}^{k} \;\;(\text{先排 }n\text{ 个无限制元素，在 }n+1\text{ 空位中选 }k\text{ 个排列}) \\[4pt]
\text{隔板法： } \displaystyle\binom{n-1}{m-1} \;\;(n\text{ 个相同元素分给 }m\text{ 个对象，每对象至少 }1\text{ 个}) \\[4pt]
\text{排除法：总数}-\text{不符合条件的排法数}
\end{array}
}
\]

\textbf{使用场景：} 
相邻问题用捆绑，不相邻用插空，相同物品分配用隔板，含“至少/至多”且反面易求用排除。

\textbf{简单例子：} 
5 人排队，甲、乙必须相邻：$2!\,(5-2+1)! = 48$ 种；甲、乙不相邻：先排其余 3 人 $3!$，在 4 个空位选 2 个排甲、乙 $A_4^2=12$，共 $6\times12=72$ 种（或用排除法 $5!-48=72$）。10 个相同球分给 3 人，每人至少 1 个：$\binom{10-1}{3-1}=36$ 种。
