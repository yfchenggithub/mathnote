\textbf{结论名称：}向量减法的三角形法则（共起点，连终点，指向被减）

\textbf{适用条件：}已知两个向量共起点，求它们的差向量，或对向量减法进行几何作图。

\textbf{变量说明：}设 $\vec{a}=\overrightarrow{OA}$，$\vec{b}=\overrightarrow{OB}$，起点 $O$ 为公共起点，$A$ 为被减向量终点，$B$ 为减向量终点。

\textbf{核心公式：}
\[
\boxed{\overrightarrow{BA} = \vec{a} - \vec{b}}
\]
几何意义：共起点 $O$ 的两个向量相减，其差向量为连接两终点（$B$ 与 $A$）的有向线段，方向由减向量终点 $B$ 指向被减向量终点 $A$。

\textbf{使用场景：}将向量减法转化为几何加法（如 $\vec{a}-\vec{b}=\vec{a}+(-\vec{b})$ 的图示）；根据坐标或图形直接定位差向量；简化向量加减混合运算的作图。

\textbf{简单例子：}已知 $\overrightarrow{OA}$ 对应的坐标为 $(3,4)$，$\overrightarrow{OB}$ 对应的坐标为 $(1,2)$，则 $\vec{a} - \vec{b} = (3-1,\;4-2) = (2,2)$。按三角形法则，连接终点 $B(1,2)$ 与 $A(3,4)$ 并指向 $A$，得 $\overrightarrow{BA}$，其长度与方向恰为差向量，坐标亦为 $(2,2)$，验证了公式。
