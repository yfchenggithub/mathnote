\textbf{结论名称：}余弦定理变形（已知三边求角的余弦公式）

\textbf{适用条件：}任意三角形 \(ABC\)，已知三边长度 \(a,b,c\)（或可求出三边）时，求内角的余弦值或判断三角形形状。

\textbf{变量说明：} \(a,b,c\) 分别为 \(\triangle ABC\) 中角 \(A,B,C\) 的对边，\(A,B,C\) 为三角形的三个内角。

\textbf{核心公式：}
\[
\boxed{\cos A = \frac{b^{2}+c^{2}-a^{2}}{2bc}}
\]
同理可轮换得到：
\[
\cos B = \frac{a^{2}+c^{2}-b^{2}}{2ac}, \qquad 
\cos C = \frac{a^{2}+b^{2}-c^{2}}{2ab}.
\]

\textbf{使用场景：}已知三边求任意一个内角（结合反三角函数）；或通过最大角的余弦值符号判断三角形形状：正为锐角三角形，零为直角三角形，负为钝角三角形。

\textbf{简单例子：}在 \(\triangle ABC\) 中，已知 \(a=7,\; b=8,\; c=9\)，求角 \(A\) 的余弦值。
由公式 \(\displaystyle \cos A = \frac{8^{2}+9^{2}-7^{2}}{2\times8\times9} = \frac{64+81-49}{144} = \frac{96}{144} = \frac{2}{3}\)，手算可验证。
