\textbf{结论名称：} 双变量不等式转单变量：齐次换元 \( t = \frac{x_1}{x_2} \)

\textbf{适用条件：} 待证双变量不等式具有齐次结构（多为零次齐次），或可通过比值将双变量分离为单变量形式。

\textbf{变量说明：} 设 \( x_1, x_2 > 0 \)，通常不妨设 \( x_1 > x_2 > 0 \)，令 \( t = \dfrac{x_1}{x_2} \)，则 \( t > 1 \)；若只要求对称而不分大小，取 \( t>0, \, t\neq 1 \)。

\textbf{核心公式：}
零次齐次不等式 \( F(x_1,x_2) \ge 0 \) 可化为单变量不等式：
\[
\boxed{ t = \frac{x_1}{x_2} \;(x_1,x_2>0,\,x_1\neq x_2) \;\Longrightarrow\; F(x_1,x_2) = \varphi(t) \ge 0 }
\]
例如对数均值不等式的一部分：
\[
\frac{x_1 - x_2}{\ln x_1 - \ln x_2} < \frac{x_1 + x_2}{2}
\;\Longleftrightarrow\;
\frac{t - 1}{\ln t} < \frac{t + 1}{2} \quad (t>1).
\]

\textbf{使用场景：} 高考导数压轴题中证明双变量对称不等式，如极值点偏移、对数均值不等式、比值代换型不等式。

\textbf{简单例子：}
已知 \( x_1 > x_2 > 0 \)，证明：\( \displaystyle \frac{x_1 - x_2}{\ln x_1 - \ln x_2} < \frac{x_1 + x_2}{2} \)。
\textbf{解：} 设 \( t = \frac{x_1}{x_2} > 1 \)，原式等价于 \( \frac{t - 1}{\ln t} < \frac{t + 1}{2} \)，即 \( \ln t > \frac{2(t - 1)}{t + 1} \;(t>1) \)。令 \( h(t) = \ln t - \frac{2(t - 1)}{t + 1} \)，则 \( h'(t) = \frac{(t-1)^2}{t(t+1)^2} > 0 \)，且 \( h(1)=0 \)，故 \( h(t)>0 \)，原不等式得证。
