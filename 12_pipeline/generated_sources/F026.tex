\textbf{结论名称：} 双对称性推周期性

\textbf{适用条件：} 函数 \(f(x)\) 定义在 \(\mathbb{R}\) 上，且满足以下三组条件之一（\(a\neq b\)）：
(1) 关于两条直线 \(x=a\) 与 \(x=b\) 对称：\(f(a+x)=f(a-x)\), \(f(b+x)=f(b-x)\)；
(2) 关于两个点 \((a,c)\) 与 \((b,c)\) 对称：\(f(a+x)+f(a-x)=2c\), \(f(b+x)+f(b-x)=2c\)；
(3) 关于一条直线 \(x=a\) 与一个点 \((b,c)\) 对称：\(f(a+x)=f(a-x)\) 且 \(f(b+x)+f(b-x)=2c\)。

\textbf{变量说明：} \(a,b\) 为实常数且 \(a\neq b\)；\(c\) 为实常数；\(T\) 为函数的周期。

\textbf{核心公式：}
\[
\boxed{
\begin{aligned}
&\text{若 } f(a+x)=f(a-x) \text{ 且 } f(b+x)=f(b-x), \text{ 则 } T=2|a-b|;\\
&\text{若 } f(a+x)+f(a-x)=2c \text{ 且 } f(b+x)+f(b-x)=2c, \text{ 则 } T=2|a-b|;\\
&\text{若 } f(a+x)=f(a-x) \text{ 且 } f(b+x)+f(b-x)=2c, \text{ 则 } T=4|a-b|.
\end{aligned}
}
\]

\textbf{使用场景：} 在抽象函数问题中，由双对称条件快速求出周期，进而计算函数值、判断奇偶性等，在高考选填题中直接应用。

\textbf{简单例子：} 设函数 \(f(x)\) 满足 \(f(1+x)=f(1-x)\) 且 \(f(4+x)=f(4-x)\)，且 \(f(0)=2\)，求 \(f(18)\)。\\
解：由两条对称轴 \(x=1\) 和 \(x=4\)，根据结论得周期 \(T=2|4-1|=6\)。于是 \(f(18)=f(0+3\times6)=f(0)=2\)。
