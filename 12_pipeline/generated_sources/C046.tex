\textbf{结论名称：} 圆锥曲线的通径公式

\textbf{适用条件：} 椭圆、双曲线、抛物线的标准方程。

\textbf{变量说明：} 椭圆 \(\frac{x^2}{a^2}+\frac{y^2}{b^2}=1\;(a>b>0)\) 与双曲线 \(\frac{x^2}{a^2}-\frac{y^2}{b^2}=1\) 中，\(a\) 为长半轴(实半轴)长，\(b\) 为短半轴(虚半轴)长；抛物线 \(y^2=2px\)（或 \(x^2=2py\)）中，\(p>0\) 为焦点到准线的距离。通径是过焦点且垂直于长轴(或对称轴)的弦。

\textbf{核心公式：}
\[
\text{椭圆、双曲线: } \boxed{L=\frac{2b^2}{a}}\qquad
\text{抛物线: } \boxed{L=2p}
\]
或写成：
\[
\text{椭圆 }\frac{x^2}{a^2}+\frac{y^2}{b^2}=1:\boxed{\frac{2b^2}{a}};\quad
\text{双曲线 }\frac{x^2}{a^2}-\frac{y^2}{b^2}=1:\boxed{\frac{2b^2}{a}};\quad
\text{抛物线 }y^2=2px:\boxed{2p}.
\]

\textbf{使用场景：} 快速求焦点弦中的通径长，或利用通径端点的坐标简化与焦点弦有关的计算。

\textbf{简单例子：}
椭圆 \(\frac{x^2}{25}+\frac{y^2}{9}=1\)，\(a=5,b=3\)，通径长 \(\frac{2\times 9}{5}=\frac{18}{5}\)；
双曲线 \(\frac{x^2}{9}-\frac{y^2}{4}=1\)，\(a=3,b=2\)，通径长 \(\frac{2\times 4}{3}=\frac{8}{3}\)；
抛物线 \(y^2=8x\)，\(2p=8\)，通径长 \(8\)。
