\textbf{结论名称：} 两圆位置关系的判定（利用圆心距 $d$ 与半径和差比较）

\textbf{适用条件：} 平面上两个已知半径的圆，且可求出圆心距 $d$；通常约定 $R \ge r > 0$。

\textbf{变量说明：} 设大圆半径为 $R$，小圆半径为 $r$（$R \ge r$），两圆心距离为 $d$。  
令 $S = R+r$，$T = R-r$。

\textbf{核心公式：}
\[
\boxed{
\begin{cases}
d > R+r & \text{外离（0个交点）}\\[2pt]
d = R+r & \text{外切（1个交点）}\\[2pt]
R-r < d < R+r & \text{相交（2个交点）}\\[2pt]
d = R-r & \text{内切（1个交点）}\\[2pt]
0 \le d < R-r & \text{内含（0个交点）}
\end{cases}
}
\]

\textbf{使用场景：} 快速判断两圆的公共点个数及位置关系，常用于解析几何中圆与圆的位置分析、轨迹问题和动态几何题。

\textbf{简单例子：} 已知 $\odot O_1$ 半径 $R=3$，$\odot O_2$ 半径 $r=2$，圆心距 $d = O_1O_2 = 4$。  
计算 $R+r=5$，$R-r=1$。由于 $1 < 4 < 5$，满足 $R-r < d < R+r$，所以两圆相交，有两个公共点。
