\textbf{结论名称：} 辅助角公式（合一变形公式）。

\textbf{适用条件：} \(a,b\) 为实数且不同时为零，\(x\) 为任意角（公式在 \(\mathbb{R}\) 上恒成立）。

\textbf{变量说明：} \(a,b\) 为同角正、余弦的系数；\(\varphi\) 为由 \(a,b\) 决定的辅助角，其终边经过点 \((a,b)\)。

\textbf{核心公式：}
\[
\boxed{a\sin x + b\cos x = \sqrt{a^{2}+b^{2}}\,\sin(x+\varphi)}
\]
其中 \(\varphi\) 满足 \(\displaystyle\cos\varphi = \frac{a}{\sqrt{a^{2}+b^{2}}},\ \sin\varphi = \frac{b}{\sqrt{a^{2}+b^{2}}}\)，或 \(\displaystyle\tan\varphi = \frac{b}{a}\)（\(\varphi\) 象限由 \(a,b\) 的符号决定）。亦可表示为 \(\sqrt{a^{2}+b^{2}}\cos(x-\varphi')\)。

\textbf{使用场景：} 将同角正余弦的线性组合化为单一三角函数，用于求周期、最值、单调区间、解三角方程与不等式，以及在物理中合成简谐振动。

\textbf{简单例子：} 化简 \(\sin x + \cos x\)。取 \(a=1,b=1\)，则 \(\sqrt{a^{2}+b^{2}}=\sqrt{2}\)，由 \(\tan\varphi=1\) 且点 \((1,1)\) 在第一象限得 \(\varphi=\frac{\pi}{4}\)，故
\[
\sin x + \cos x = \sqrt{2}\sin\!\left(x+\frac{\pi}{4}\right).
\]
由此可得该式的最大值为 \(\sqrt{2}\)，最小值为 \(-\sqrt{2}\)，最小正周期为 \(2\pi\)。
