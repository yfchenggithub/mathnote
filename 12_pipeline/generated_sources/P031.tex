\textbf{结论名称：} 外心到三顶点的距离等于外接圆半径

\textbf{适用条件：} 任意非退化三角形 \(ABC\)，点 \(O\) 为三角形外心（三边垂直平分线的交点）。

\textbf{变量说明：} 设 \(\triangle ABC\) 三个顶点为 \(A,B,C\)，外心为 \(O\)，外接圆半径为 \(R\)。三点到外心的距离分别记作 \(OA,OB,OC\)。

\textbf{核心公式：}
\[
\boxed{OA = OB = OC = R}
\]
进一步，结合正弦定理有 \(\displaystyle R = \frac{a}{2\sin A}=\frac{b}{2\sin B}=\frac{c}{2\sin C}\)（其中 \(a=BC\)，\(b=CA\)，\(c=AB\)）。

\textbf{使用场景：}
\begin{itemize}
  \item 判断某点是否为三角形的外心（验证该点到三顶点距离相等）。
  \item 已知外心位置，直接得到外接圆半径，或由外接圆半径反求边长。
  \item 与直角三角形性质结合：直角三角形斜边中点为外心，其到三顶点距离均为斜边的一半。
\end{itemize}

\textbf{简单例子：} 在直角三角形 \(ABC\) 中，\(\angle C = 90^\circ\)，\(BC = 3\)，\(AC = 4\)，则斜边 \(AB = 5\)。外心 \(O\) 为斜边 \(AB\) 的中点，外接圆半径 \(R = \frac{5}{2} = 2.5\)。容易验证：\(OA = OB = 2.5\)，且 \(OC = \frac{1}{2}\sqrt{2(AC^2 + BC^2) - AB^2} = \frac{1}{2}\sqrt{2(16+9)-25} = 2.5\)，满足 \(OA = OB = OC = R\)。
