\textbf{结论名称：}手拉手模型（共顶点旋转全等）

\textbf{适用条件：}两个顶角相等的等腰三角形（或等边三角形、正方形）共顶点，其中一个绕公共顶点任意旋转。

\textbf{变量说明：}公共顶点 $A$，$\triangle ABC$ 与 $\triangle ADE$ 满足 $AB=AC$，$AD=AE$，顶角 $\angle BAC=\angle DAE=\alpha$。连接非公共顶点的对应点得线段 $BD$ 与 $CE$。

\textbf{核心公式：}
\[
\triangle ABD \cong \triangle ACE \quad \text{(SAS)}
\]
\[
\boxed{BD = CE,\qquad \angle(BD, CE) = \alpha\ \ (\text{或 } 180^\circ - \alpha)}
\]

\textbf{使用场景：}中考旋转全等压轴题，证明线段相等、求两线段夹角、判定特殊三角形，或结合旋转求轨迹与最值。

\textbf{简单例子：}已知 $\triangle ABC$ 与 $\triangle ADE$ 均为等边三角形，$A$ 为公共顶点，$AB=2$，$AD=1$。将 $\triangle ADE$ 绕 $A$ 旋转至 $\angle BAD = 120^\circ$，连接 $BD$、$CE$。由手拉手模型得 $\triangle ABD \cong \triangle ACE$，故 $CE=BD$。在 $\triangle ABD$ 中用余弦定理：
\[
BD = \sqrt{2^2 + 1^2 - 2 \times 2 \times 1 \times \cos 120^\circ} = \sqrt{7}.
\]
因此 $CE = \sqrt{7}$，且 $BD$ 与 $CE$ 的夹角等于等边三角形的内角 $60^\circ$。
