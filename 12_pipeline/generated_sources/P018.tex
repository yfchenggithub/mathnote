\textbf{结论名称：} 点关于直线的对称点坐标公式

\textbf{适用条件：} 已知点 \(P(x_0,y_0)\) 与直线 \(l: Ax+By+C=0\)，且 \(A,B\) 不同时为零。

\textbf{变量说明：} \(x_0,y_0\) 为已知点 \(P\) 的坐标；\(A,B,C\) 为直线方程的一般式系数；所求对称点记为 \(P'(x',y')\)。

\textbf{核心公式：} 
\[
\boxed{
\begin{cases}
x' = x_0 - \dfrac{2A(Ax_0+By_0+C)}{A^2+B^2} \\[8pt]
y' = y_0 - \dfrac{2B(Ax_0+By_0+C)}{A^2+B^2}
\end{cases}
}
\]

\textbf{使用场景：} 求点关于直线的对称点坐标，用于光线反射、角平分线问题、距离和最值等平面几何场景。

\textbf{简单例子：} 求点 \(P(1,0)\) 关于直线 \(x-y+1=0\) 的对称点。  
取 \(A=1,B=-1,C=1\)，计算 \(Ax_0+By_0+C = 1\cdot1 + (-1)\cdot0 + 1 = 2\)。  
代入公式得：
\[
x' = 1 - \frac{2\cdot1\cdot2}{2} = -1,\qquad 
y' = 0 - \frac{2\cdot(-1)\cdot2}{2} = 2.
\]
对称点为 \((-1,2)\)。可验证中点 \((0,1)\) 在直线上，且连线斜率为 \(-1\) 与直线斜率 \(1\) 垂直。
