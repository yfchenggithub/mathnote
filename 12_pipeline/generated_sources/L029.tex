\textbf{结论名称：} 数学归纳法证明通项公式（先猜后证）

\textbf{适用条件：} 已知数列递推关系及首项，已通过观察、构造等方法猜得通项形式 \(a_n=f(n)\)，且 \(f(n)\) 为关于 \(n\) 的明确表达式。

\textbf{变量说明：} \(n\in\mathbb{N}^*\)；\(a_n\) 为数列第 \(n\) 项；\(f(n)\) 为猜想通项公式；初始条件 \(a_1\)（或 \(a_0\)）已知。

\textbf{核心公式：}
\[
\boxed{
\begin{array}{l}
\text{奠基：} \; a_1 = f(1) \text{ 成立}\\[2pt]
\text{递推：} \; \text{若 } a_k = f(k) \text{ 成立，则 } a_{k+1} = f(k+1) \text{ 成立}
\end{array}
\;\Longrightarrow\; a_n = f(n)\;(n\in\mathbb{N}^*)
}
\]

\textbf{使用场景：} 递推关系不易直接求解通项时，先通过有限项观察或构造得出猜想，再用数学归纳法完成严格证明；常见于累加型、累乘型、一次线性递推等。

\textbf{简单例子：}
已知数列 \(\{a_n\}\) 满足 \(a_1=1\)，\(a_{n+1}=2a_n+1\)。\newline
观察前几项：\(a_1=1=2^1-1,\; a_2=3=2^2-1,\; a_3=7=2^3-1\)，猜测 \(a_n=2^n-1\)。
\textbf{证明：}
(1) 奠基：当 \(n=1\) 时，\(a_1=2^1-1=1\)，成立。\newline
(2) 递推：假设 \(n=k\) 时成立，即 \(a_k=2^k-1\)，则
\[
a_{k+1}=2a_k+1=2(2^k-1)+1=2^{k+1}-1,
\]
即 \(n=k+1\) 时猜想也成立。\newline
由数学归纳法，\(\forall n\in\mathbb{N}^*\)，\(a_n=2^n-1\)。
