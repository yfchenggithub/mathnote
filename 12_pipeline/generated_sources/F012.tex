\textbf{结论名称：}函数值域的几何意义法（斜率/距离）

\textbf{适用条件：}函数解析式可变形为动点与定点连线的斜率，或动点到两定点的距离之和（差）的结构。

\textbf{变量说明：}
斜率型：将函数化为 \(y=\frac{u(x)-y_0}{v(x)-x_0}\)，定点 \((x_0,y_0)\)，动点 \((v(x),u(x))\)；
距离型：将函数写成 \(f(x)=\sqrt{(x-m)^2+a^2}+\sqrt{(x-n)^2+b^2}\)（\(a,b>0\)），动点 \(P(x,0)\)，定点 \(A(m,-a),\,B(n,b)\)。

\textbf{核心公式：}
\begin{enumerate}
  \item 斜率型：值域由定点与曲线（或区域）上点的连线斜率范围确定。
  \item 距离型：若 \(a,b>0\)，则
  \[
    \boxed{ f(x) \in \bigl[ \sqrt{(m-n)^2+(a+b)^2},\ +\infty \bigr) }
  \]
  当且仅当 \(P\) 落在线段 \(AB\) 在 \(x\) 轴上的投影内时取得最小值 \(|AB|\)。
\end{enumerate}

\textbf{使用场景：}分式型函数、根式和（差）型函数的最值与值域问题，通常能避免导数繁算。

\textbf{简单例子：}
求 \(f(x)=\sqrt{x^2+1}+\sqrt{(x-3)^2+4}\) 的值域。
配方：\(f(x)=\sqrt{(x-0)^2+1^2}+\sqrt{(x-3)^2+2^2}\)，
令 \(A(0,-1),\,B(3,2)\)，动点 \(P(x,0)\)，
则 \(f(x)=|PA|+|PB|\)，最小值 \(|AB|=\sqrt{3^2+3^2}=3\sqrt{2}\)，无最大值，
故值域为 \([3\sqrt{2},\,+\infty)\)。
