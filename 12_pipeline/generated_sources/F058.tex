\textbf{结论名称：} 三次函数图像的两种基本形状（\(f'(x)\)有无实根）

\textbf{适用条件：} 三次函数 \(f(x)=ax^{3}+bx^{2}+cx+d\ (a\neq 0)\)。

\textbf{变量说明：} \(a,b,c,d\in\mathbb{R}\)，\(a\neq0\)；引入判别式 \(\Delta = b^{2}-3ac\)（导函数 \(f'(x)=3ax^{2}+2bx+c\) 的简化判别式），其符号决定 \(f'(x)=0\) 的实根个数。

\textbf{核心公式：}
\[
\boxed{\Delta = b^{2}-3ac\quad
\begin{cases}
\Delta >0 \Rightarrow f(x)\text{ 有两个极值点（增减增或减增减）}\\[2pt]
\Delta \le 0 \Rightarrow f(x)\text{ 单调，无极值点}
\end{cases}}
\]
更具体地，当 \(a>0\) 时：
\[
\Delta>0 \implies \text{先增后减再增};\qquad \Delta\le 0 \implies \text{单调递增}.
\]
当 \(a<0\) 时：
\[
\Delta>0 \implies \text{先减后增再减};\qquad \Delta\le 0 \implies \text{单调递减}.
\]

\textbf{使用场景：} 快速判断三次函数的单调区间与极值个数，画函数简图，分析含参三次函数零点、不等式恒成立及切线位置等问题。

\textbf{简单例子：} 
取 \(f(x)=x^{3}-3x\)，\(a=1,b=0,c=-3\)，得 \(\Delta =0^{2}-3\cdot1\cdot(-3)=9>0\)，故有两个极值点：\(x=-1\) 为极大值点（值 \(2\)），\(x=1\) 为极小值点（值 \(-2\)），图像呈先增后减再增。\\
取 \(g(x)=x^{3}+3x\)，\(a=1,b=0,c=3\)，得 \(\Delta = -9<0\)，\(g'(x)=3x^{2}+3>0\)，函数单调递增，无极值点。
