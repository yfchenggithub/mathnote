\textbf{结论名称：}导数公式表（幂/指/对/三角）

\textbf{适用条件：}函数在对应定义域内可导（基本初等函数在其定义域内都是可导的）。

\textbf{变量说明：}
$x$---自变量；$a$---常数，其中指数函数和对数函数的底数满足 $a>0$ 且 $a\neq 1$；
三角函数中角度以弧度为单位。

\textbf{核心公式：}
\[
\boxed{
\begin{array}{ll}
\text{幂函数：}& \displaystyle (x^\alpha)' = \alpha x^{\alpha-1}\quad(\alpha\in\mathbb{R}) \\[6pt]
\text{指数函数：}& \displaystyle (a^x)' = a^x\ln a,\qquad (e^x)' = e^x \\[6pt]
\text{对数函数：}& \displaystyle (\log_a x)' = \frac{1}{x\ln a},\qquad (\ln x)' = \frac{1}{x} \\[6pt]
\text{正弦：}& (\sin x)' = \cos x \\[6pt]
\text{余弦：}& (\cos x)' = -\sin x
\end{array}
}
\]

\textbf{使用场景：}直接求导、复合函数求导、切线斜率计算、单调区间与极值判断中需要调用基本初等函数的导数。

\textbf{简单例子：}
已知 $f(x)=x^3+2e^x-3\ln x+\sin x$，求 $f'(x)$。
逐项求导：$(x^3)'=3x^2$，$(2e^x)'=2e^x$，$(-3\ln x)'=-\dfrac{3}{x}$，$(\sin x)'=\cos x$，
因此 $f'(x)=3x^2+2e^x-\dfrac{3}{x}+\cos x$。
