\textbf{结论名称：}万能公式（用 $\tan\frac{x}{2}$ 表达 $\sin x$、$\cos x$、$\tan x$）

\textbf{适用条件：}$x \neq \pi + 2k\pi\ (k\in\mathbb{Z})$，保证 $\tan\frac{x}{2}$ 有意义；使用 $\tan x$ 公式时还需 $x\neq \frac{\pi}{2}+k\pi$。

\textbf{变量说明：}设 $t = \tan\frac{x}{2}$，其中 $x$ 为任意满足条件的角度，$t \in \mathbb{R}$。

\textbf{核心公式：}
\[
\boxed{\sin x = \frac{2t}{1+t^2},\qquad \cos x = \frac{1-t^2}{1+t^2},\qquad \tan x = \frac{2t}{1-t^2}}\quad \bigl(t=\tan\tfrac{x}{2}\bigr)
\]

\textbf{使用场景：}将三角有理式统一转化为 $t$ 的有理函数，常用于三角积分、解三角方程以及表达式化简。

\textbf{简单例子：}已知 $\tan\frac{x}{2}=\frac12$，求 $\sin x$、$\cos x$、$\tan x$。\\
令 $t=\frac12$，代入公式：
\[
\sin x = \frac{2\cdot\frac12}{1+\bigl(\frac12\bigr)^2} = \frac{1}{\frac54} = \frac45,\quad
\cos x = \frac{1-\frac14}{1+\frac14} = \frac{\frac34}{\frac54} = \frac35,\quad
\tan x = \frac{\frac45}{\frac35} = \frac43.
\]
