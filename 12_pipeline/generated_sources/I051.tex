\textbf{结论名称：}凑项凑系数求最值（拆项、添项、配系数使乘积为定值）

\textbf{适用条件：}变量均为正数，表达式可通过拆项、添项或引入待定系数，转化为若干正项之和（或积），且这些项的积（或和）为常数，从而能直接使用均值不等式。

\textbf{变量说明：}设 \(x>0\)（或更多正变量），需人为将原式变形为正项 \(A_1,A_2,\dots,A_n\)，使得 \(\prod A_i\) 或 \(\sum A_i\) 为定值，并保证等号成立条件与题设相容。

\textbf{核心公式：}
基于均值不等式，通过凑项使乘积为定值：
\[
\boxed{a_1 + a_2 + \cdots + a_n \ge n\sqrt[n]{a_1 a_2 \cdots a_n}\qquad (a_i>0)}
\]
当且仅当 \(a_1 = a_2 = \cdots = a_n\) 时取等。拆项、添系数即构造满足 \(a_1a_2\cdots a_n = \text{常数}\) 的正项。

\textbf{使用场景：}求形如 \(x + \frac{k}{x}\)、\(ax + \frac{b}{x^m}\) 等分式函数的最值；高次多项式与分式组合的最值；已知和为定值求积的最大值或已知积为定值求和的最小值时，通过配系数使条件成立。

\textbf{简单例子：}
求 \(f(x)=2x+\frac{3}{x^2}\,(x>0)\) 的最小值。
\textbf{解：}将 \(2x\) 拆为 \(x+x\)，三项均为正：
\[
x + x + \frac{3}{x^2} \ge 3\sqrt[3]{x \cdot x \cdot \frac{3}{x^2}} = 3\sqrt[3]{3}.
\]
等号成立当 \(x = x = \frac{3}{x^2}\)，即 \(x^3 = 3\)，\(x = \sqrt[3]{3}\)。故最小值为 \(3\sqrt[3]{3}\)。（拆项后三项乘积为定值 \(3\)）
