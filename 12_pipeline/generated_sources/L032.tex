\textbf{结论名称：} 裂项相消——分式型 \(\frac{1}{n(n+k)} = \frac{1}{k}\Bigl(\frac{1}{n} - \frac{1}{n+k}\Bigr)\)

\textbf{适用条件：} 分母为两个关于 \(n\) 的一次因式乘积，且两因式之差为非零常数 \(k\)，分子为常数（通常为 \(1\)）。

\textbf{变量说明：} \(n\) 为数列项序号（取自然数），\(k\) 为分母两因式的固定差值（\(k \neq 0\)，常为正整数）。

\textbf{核心公式：} \[ \boxed{ \frac{1}{n(n+k)} = \frac{1}{k}\left( \frac{1}{n} - \frac{1}{n+k} \right) } \]

\textbf{使用场景：} 求形如 \(\sum \frac{c}{n(n+k)}\) 的前 \(m\) 项和，通过裂项将和式写成相邻项相消的形式，快速求出部分和。

\textbf{简单例子：} 取 \(k=1\)，计算 \(S_{10} = \sum_{n=1}^{10} \frac{1}{n(n+1)}\)。
由公式得 \(\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}\)，因此
\[ S_{10} = \Bigl(1 - \frac{1}{2}\Bigr) + \Bigl(\frac{1}{2} - \frac{1}{3}\Bigr) + \cdots + \Bigl(\frac{1}{10} - \frac{1}{11}\Bigr) = 1 - \frac{1}{11} = \frac{10}{11}. \]
