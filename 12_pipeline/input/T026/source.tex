\textbf{结论名称：} 正弦定理的变形（边用对角正弦与外接圆半径表示）：\( a=2R\sin A,\; b=2R\sin B,\; c=2R\sin C \)。

\textbf{适用条件：} 任意三角形 \(\triangle ABC\)，\(R\) 为该三角形外接圆的半径。

\textbf{变量说明：} \(a,b,c\) 分别为 \(\angle A,\angle B,\angle C\) 的对边；\(R\) 为 \(\triangle ABC\) 外接圆半径。

\textbf{核心公式：}
\[
\boxed{a=2R\sin A,\quad b=2R\sin B,\quad c=2R\sin C}
\]

\textbf{使用场景：} 已知外接圆半径和一角求对边；边化角进行三角恒等变形；判断三角形形状或导出边角混合关系。

\textbf{简单例子：} 在 \(\triangle ABC\) 中，已知外接圆半径 \(R=1\)，\(A=30^\circ\)，求边 \(a\)。由公式得
\[
a = 2R\sin A = 2\times 1\times \sin 30^\circ = 2\times \frac12 = 1.
\]
