\textbf{结论名称：} 等体积法求点到平面的距离（换底求高）

\textbf{适用条件：} 已知三棱锥（四面体）的体积，或能方便地以另外的方式算出三棱锥体积，且目标点所在平面的面积易求。常用于直接作垂线困难，但换顶点后体积和高均易求的情形。

\textbf{变量说明：}
$h$ — 所求点到目标平面 $\alpha$ 的距离；
$V$ — 以该点为顶点、平面 $\alpha$ 为底面的三棱锥的体积；
$S_{\text{底}}$ — 平面 $\alpha$ 上作为底面的三角形或可分割图形的面积。

\textbf{核心公式：}
\[
\boxed{h = \frac{3V}{S_{\text{底}}}}
\]

\textbf{使用场景：}
1. 空间几何中求点到平面的距离，直接作垂线段坐标难求时；
2. 已知异面直线公垂线段困难，但可构造三棱锥利用等体积法转化；
3. 球内接多面体中与点面距离相关的最值问题；
4. 三棱锥体积公式组合应用：固定体积，换底求高。

\textbf{简单例子：}
在三棱锥 $P-ABC$ 中，$PA\perp\text{底面}ABC$，$AB=AC=1$，$AB\perp AC$，$PA=1$。求点 $A$ 到平面 $PBC$ 的距离 $h$。

解：以 $ABC$ 为底、$PA$ 为高：
\[
V_{P-ABC} = \frac{1}{3}\times \left(\frac{1}{2}\times 1\times 1\right) \times 1 = \frac{1}{6}.
\]
$\triangle PBC$ 中，$PB=PC=\sqrt{2}$，$BC=\sqrt{2}$，其为等边三角形，面积
\[
S_{\triangle PBC} = \frac{\sqrt{3}}{4} \times (\sqrt{2})^2 = \frac{\sqrt{3}}{2}.
\]
因为 $V_{A-PBC}=V_{P-ABC}$，由等体积法：
\[
h = \frac{3\times \frac{1}{6}}{\frac{\sqrt{3}}{2}} = \frac{\sqrt{3}}{3}.
\]
