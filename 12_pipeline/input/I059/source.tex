\textbf{结论名称：} 柯西不等式的变形 $(a+b)(\frac1a+\frac1b)\ge4$。

\textbf{适用条件：} $a>0,\;b>0$，即两正实数。

\textbf{变量说明：} $a,b$ 为正实数，常用于分母含变量的分式和。

\textbf{核心公式：} \[
\boxed{(a+b)\!\left(\frac{1}{a}+\frac{1}{b}\right)\ge 4}
\]
等号成立当且仅当 $a=b$。

\textbf{使用场景：} 已知两正数和或积，求分式最值；证明含 $\frac1a+\frac1b$ 的不等式；将和与倒数和互相转化。

\textbf{简单例子：} 取 $a=2,\;b=8$，则 $a+b=10$，$\frac1a+\frac1b=\frac12+\frac18=\frac58$，左式 $=10\times\frac58=6.25\ge4$，满足不等式。当 $a=b=3$ 时，左式 $=6\times\frac23=4$，等号成立。
