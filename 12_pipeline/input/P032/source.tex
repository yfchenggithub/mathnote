\textbf{结论名称：}垂心性质：垂心与各顶点连线垂直于对边

\textbf{适用条件：}任意 $\triangle ABC$（非退化三角形），其垂心 $H$ 存在且唯一。

\textbf{变量说明：}设 $\triangle ABC$ 的三个顶点为 $A,B,C$，$H$ 为三条高线的交点（垂心）。

\textbf{核心公式：}
\[
\boxed{AH\perp BC,\qquad BH\perp AC,\qquad CH\perp AB}
\]
等价向量形式：
\[
\overrightarrow{AH}\cdot\overrightarrow{BC}=0,\quad \overrightarrow{BH}\cdot\overrightarrow{AC}=0,\quad \overrightarrow{CH}\cdot\overrightarrow{AB}=0.
\]

\textbf{使用场景：}处理与高相关的垂直证明、角度推导、向量内积条件；在三角形的心（垂心、重心、外心）综合题中建立垂直关系。

\textbf{简单例子：}取 $A(0,0),\;B(2,0),\;C(1,\sqrt{3})$（正三角形），其垂心即重心 $H(1,\frac{\sqrt{3}}{3})$。计算得
$\overrightarrow{AH}=(1,\frac{\sqrt{3}}{3}),\;\overrightarrow{BC}=(-1,\sqrt{3})$，内积
$\overrightarrow{AH}\cdot\overrightarrow{BC}=1\cdot(-1)+\frac{\sqrt{3}}{3}\cdot\sqrt{3}=-1+1=0$，故 $AH\perp BC$，验证性质成立。
