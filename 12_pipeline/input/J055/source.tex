\textbf{结论名称：} 判别式 \(\Delta = b^2-4ac\) 控制交点个数与最值

\textbf{适用条件：} 一元二次函数 \(y=ax^2+bx+c\) 或一元二次方程 \(ax^2+bx+c=0\)，其中 \(a \neq 0\)，且方程的解或函数的零点均在实数范围内讨论。

\textbf{变量说明：} \(a,b,c\in\mathbb{R}\) 为二次项、一次项系数及常数项，\(\Delta = b^2 - 4ac\) 为判别式；\(y_{\text{极}}\) 表示二次函数的最值（当 \(a>0\) 时为最小值，\(a<0\) 时为最大值）。

\textbf{核心公式：}
\[
\boxed{\Delta = b^2-4ac\ \Longrightarrow\ 
\begin{cases}
\Delta > 0 \iff \text{与 }x\text{ 轴有两个交点},\\[2pt]
\Delta = 0 \iff \text{与 }x\text{ 轴有一个交点（相切）},\\[2pt]
\Delta < 0 \iff \text{与 }x\text{ 轴无交点}.
\end{cases}}
\]
\[
\boxed{y_{\text{极}} = -\dfrac{\Delta}{4a}}
\]

\textbf{使用场景：} 快速判断二次函数图像与 \(x\) 轴（或直线 \(y=k\)）的交点个数；由 \(\Delta\) 符号讨论一元二次方程根的分布；用判别式法求二次分式函数的值域；解析几何中判定直线与二次曲线的位置关系。

\textbf{简单例子：} 已知 \(y = x^2 - 4x + 3\)，求与 \(x\) 轴的交点个数及最小值。  
解：\(a=1,\ b=-4,\ c=3\)，\(\Delta = (-4)^2 - 4\cdot1\cdot3 = 16-12=4>0\)，故与 \(x\) 轴有两个交点。  
由 \(a=1>0\)，最小值 \(y_{\min} = -\dfrac{\Delta}{4a} = -\dfrac{4}{4\cdot1} = -1\)（配方验证：\(y=(x-2)^2-1\)）。
