\textbf{结论名称：} 平均数、中位数、众数、方差与标准差公式

\textbf{适用条件：} 对一组数据（样本或总体）进行集中趋势与离散程度的描述统计。

\textbf{变量说明：}
设数据集为 \(x_1, x_2, \dots, x_n\)，\(n\) 为数据个数；若数据以频数分布给出，\(x_i\) 为取值，\(f_i\) 为对应的频数（或权重），总频数 \(N = \sum f_i\)。

\textbf{核心公式：}
\[
\boxed{
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i 
\quad\text{或}\quad 
\bar{x} = \frac{\sum x_i f_i}{\sum f_i}
}
\]
\[
\boxed{
s^2 = \frac{1}{n}\sum_{i=1}^{n} (x_i - \bar{x})^2 
\quad\text{或}\quad 
s^2 = \frac{\sum (x_i - \bar{x})^2 f_i}{\sum f_i}
}
\]
\[
\boxed{s = \sqrt{s^2}}
\]
方差计算常用等价变形：\(s^2 = \frac{1}{n}\sum x_i^2 - \bar{x}^2\)。

中位数：将数据从小到大排序，若 \(n\) 为奇数，中位数为第 \(\frac{n+1}{2}\) 个数据；若 \(n\) 为偶数，中位数为第 \(\frac{n}{2}\) 与第 \(\frac{n}{2}+1\) 个数据的平均数。

众数：数据中出现次数最多的数值，可能不止一个。

\textbf{使用场景：}
描述数据的平均水平和离散程度；在比较两组数据稳定性、处理加权成绩、分析频数分布表时常用。方差和标准差用于衡量数据波动大小，标准差与原数据量纲一致。

\textbf{简单例子：}
给定数据：\(2, 3, 3, 5, 7\)（\(n=5\)）。
平均数为：
\(\bar{x} = \frac{2+3+3+5+7}{5} = 4\)；
排序后中位数为第 \(3\) 个数据，即 \(3\)；
众数为出现次数最多的 \(3\)；
方差：
\(s^2 = \frac{(2-4)^2 + (3-4)^2 + (3-4)^2 + (5-4)^2 + (7-4)^2}{5} 
= \frac{4+1+1+1+9}{5} = 3.2\)；
标准差：\(s = \sqrt{3.2} \approx 1.7889\)。
