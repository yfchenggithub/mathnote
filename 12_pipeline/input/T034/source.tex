\textbf{结论名称：} 内角平分线定理

\textbf{适用条件：} 在任意三角形中，一个内角的平分线将对边分成两段。

\textbf{变量说明：} 在 $\triangle ABC$ 中，$AD$ 平分 $\angle BAC$ 并交 $BC$ 于点 $D$，则 $BD$ 与 $DC$ 为点 $D$ 分 $BC$ 所得的两条线段，$AB$ 与 $AC$ 为夹边。

\textbf{核心公式：} \[ \boxed{\frac{BD}{DC} = \frac{AB}{AC}} \]

\textbf{使用场景：} 已知三角形两边求角平分线分割对边的比例；与相似、正弦定理等配合求边长或点的位置。

\textbf{简单例子：} 在 $\triangle ABC$ 中，$AB=6$，$AC=4$，$\angle A$ 的平分线交 $BC$ 于 $D$，且 $BC=10$。由定理得 $\frac{BD}{DC}=\frac{6}{4}=\frac{3}{2}$，又 $BD+DC=10$，解得 $BD=6$，$DC=4$。
