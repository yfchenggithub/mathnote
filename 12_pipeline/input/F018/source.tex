\textbf{结论名称：} 复合函数的奇偶性——“内偶则偶，内奇同外”

\textbf{适用条件：} 外函数 \(f(u)\) 定义在 \(\mathbb{R}\) 或其对称子集上；内函数 \(g(x)\) 定义域关于原点对称；讨论 \(f(g(x))\) 的奇偶性，不考虑广义奇偶及非对称定义域。

\textbf{变量说明：} 设 \(u = g(x)\) 为内函数，\(y = f(u)\) 为外函数，复合函数 \(F(x) = f(g(x))\)。\(g\) 的奇偶性为已知条件，\(f\) 可为任意函数（存在性的前提是值域包含于定义域）。

\textbf{核心公式：}
\[
\boxed{
\begin{aligned}
&\text{若 } g(x) \text{ 为偶函数，则 } F(x) \text{ 为偶函数；}\\
&\text{若 } g(x) \text{ 为奇函数, 则 } F(x) \text{ 与 } f(u) \text{ 同奇偶。}
\end{aligned}
}
\]

\textbf{使用场景：} 快速判断多层复合函数奇偶性；在积分化简、对称性分析、解抽象函数选择题时直接使用，无需展开验证。

\textbf{简单例子：} 设 \(f(u) = u^3 - u\)（奇函数），\(g(x) = \sin x\)（奇函数）。复合得 \(F(x) = \sin^3 x - \sin x\)。因为内奇且外奇，所以 \(F(x)\) 为奇函数。验证：\(F(-x) = \sin^3(-x) - \sin(-x) = -\sin^3 x + \sin x = -F(x)\)，满足奇函数定义。
