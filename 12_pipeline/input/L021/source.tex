\textbf{结论名称：}累乘法

\textbf{适用条件：}已知数列 \(\{a_n\}\) 满足 \(a_{n+1}=a_n\cdot f(n)\)，且 \(a_n\neq 0\) 对所有 \(n\in\mathbb{N}^*\) 成立，\(f(n)\) 为给定的正整数上的函数。

\textbf{变量说明：} \(a_n\) 为数列第 \(n\) 项；\(f(n)\) 为已知的第 \(n\) 项因子；连乘指标 \(k\) 从 \(1\) 取到 \(n-1\)。

\textbf{核心公式：}
\[
\boxed{a_n = a_1\prod_{k=1}^{n-1}f(k)\quad (n\geqslant 2)}
\]

\textbf{使用场景：} 递推关系可化为 \(a_{n+1}/a_n = f(n)\) 的形式时，利用累乘消去中间项直接得到通项，常见于分式型、指数型递推。

\textbf{简单例子：} 已知 \(a_1=2\)，\(a_{n+1}=a_n\cdot\dfrac{n+1}{n}\)，求 \(a_n\)。
取 \(f(n)=\dfrac{n+1}{n}\)，则
\[
a_n = 2\prod_{k=1}^{n-1}\frac{k+1}{k} = 2\cdot\frac{2}{1}\cdot\frac{3}{2}\cdots\frac{n}{n-1}=2n.
\]
验证：\(a_1=2\)，\(a_2=2\cdot\frac{2}{1}=4\)，\(a_3=4\cdot\frac{3}{2}=6\)，满足递推。
