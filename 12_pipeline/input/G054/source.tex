\textbf{结论名称：} 几何体截面问题——坐标法求截面与棱的交点

\textbf{适用条件：} 建立空间直角坐标系后，已知截面$\pi$上三个不共线的点，需求$\pi$与几何体各棱的交点以确定截面多边形。

\textbf{变量说明：} 设几何体的棱为线段$AB$，方向向量$\vec{v}=\overrightarrow{AB}$；截面$\pi$由点$P,Q,R$确定，法向量$\vec{n}=\overrightarrow{PQ}\times\overrightarrow{PR}$；记$\vec{a}=\overrightarrow{OA}$，$\vec{p}=\overrightarrow{OP}$。

\textbf{核心公式：}
将$\pi$的方程$\vec{n}\cdot(\vec{x}-\vec{p})=0$与$AB$的参数方程$\vec{x}=\vec{a}+t\vec{v}$联立，得参数
\[
\boxed{ t = \frac{\vec{n}\cdot(\vec{p}-\vec{a})}{\vec{n}\cdot\vec{v}} }
\]
若$t\in[0,1]$，则交点$X$在棱$AB$上；否则该棱与截面无交。依次求出所有棱上的$t$，连接同一面内的交点即得截面多边形。

\textbf{使用场景：} 高考中正方体、长方体、棱柱等可建系的几何体，已知三点作截面、求截面面积、周长或判断截面形状等问题。

\textbf{简单例子：}
正方体$ABCD$-$A_1B_1C_1D_1$棱长为$2$，以$A$为原点建系。截面过$AB$中点$P(1,0,0)$、$AD$中点$Q(0,1,0)$和$C_1(2,2,2)$，求与棱$BB_1$的交点。
计算$\vec{n}=\overrightarrow{PQ}\times\overrightarrow{PC_1}=(-1,1,0)\times(1,2,2)=(2,2,-3)$，截面方程：$2x+2y-3z=2$。棱$BB_1$：$\vec{a}=(2,0,0)$，$\vec{v}=(0,0,2)$，$\vec{p}=(1,0,0)$。代入公式：
\[
t = \frac{(2,2,-3)\cdot\bigl((1,0,0)-(2,0,0)\bigr)}{(2,2,-3)\cdot(0,0,2)} = \frac{-2}{-6}=\frac13\in[0,1],
\]
交点$X=(2,0,\tfrac23)$在棱$BB_1$上。继续用此法可求出截面与其他棱的交点，进而得到完整截面多边形。
