\textbf{结论名称：} 两点分布（0--1分布）的期望与方差

\textbf{适用条件：} 随机变量 \(X\) 服从参数为 \(p\) 的两点分布，即 \(X\) 只取 \(0\) 与 \(1\) 两个值，且 \(P(X=1)=p\)，\(P(X=0)=1-p\)，其中 \(0 \le p \le 1\)。

\textbf{变量说明：} \(p\) 为“成功”概率；\(X\) 为一次伯努利试验中成功的次数（成功记 \(1\)，失败记 \(0\)）。

\textbf{核心公式：} 
\[
\boxed{E(X)=p,\qquad D(X)=p(1-p)}
\]

\textbf{使用场景：} 描述单次随机试验的成败结果，如一次抛硬币的正反面、一件产品是否合格、一次射击是否命中。

\textbf{简单例子：} 抛一枚非均匀硬币，设正面朝上的概率 \(p=0.3\)。令 \(X=1\) 表示正面朝上，\(X=0\) 表示反面朝上，则 \(X\) 服从两点分布。期望 \(E(X)=0.3\)，方差 \(D(X)=0.3\times 0.7=0.21\)。
