\textbf{结论名称：}三次函数零点个数判定（1个/2个/3个）

\textbf{适用条件：}实系数三次函数 \(f(x)=ax^{3}+bx^{2}+cx+d\ (a\neq0)\)，在其定义域 \(\mathbb{R}\) 上连续可导。

\textbf{变量说明：} \(a,b,c,d\in\mathbb{R},\ a\neq0\)；\(x_1,x_2\) 为导数 \(f'(x)=3ax^{2}+2bx+c\) 的两个实根（\(x_1<x_2\)）；\(\Delta'=4(b^{2}-3ac)\) 为导数的判别式。

\textbf{核心公式：}
\[
\boxed{
f(x_1)f(x_2)
\begin{cases}
<0 \Rightarrow \text{三个零点}\\[2pt]
=0 \Rightarrow \text{两个零点}\\[2pt]
>0 \Rightarrow \text{一个零点}
\end{cases}
}
\]
若 \(\Delta'\le 0\)，则 \(f(x)\) 在 \(\mathbb{R}\) 上单调，恰有一个零点。

\textbf{使用场景：}高考中快速判断三次函数图像与 \(x\) 轴的交点个数，常用于选填题或解答题中分析根的存在性。

\textbf{简单例子：} \(f(x)=x^{3}-3x+1\)。\(f'(x)=3x^{2}-3\)，极值点为 \(x=\pm1\)，\(f(-1)=3,\ f(1)=-1\)，\(f(-1)f(1)=-3<0\)，故有三个零点。
