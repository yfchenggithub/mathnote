\textbf{结论名称：} 半角模型（正方形内含\(45^\circ\)角 / 等腰三角形含半角）

\textbf{适用条件：} 正方形 \(ABCD\) 中，点 \(E,F\) 分别在边 \(BC,CD\) 上，且 \(\angle EAF = 45^\circ\)；亦可将旋转思想推广至等腰三角形顶角含半角的情形。

\textbf{变量说明：} 以正方形为例，设边长 \(AB = a\)，\(BE = x\)，\(DF = y\)，\(EF = z\)。

\textbf{核心公式：} 将 \(\triangle ADF\) 绕点 \(A\) 旋转 \(90^\circ\) 至 \(\triangle ABG\)，可证 \(\triangle AEF \cong \triangle AEG\)，得
\[
\boxed{EF = BE + DF}
\]
由勾股定理推得边长关系：\(xy = a^2 - a(x+y)\)。

\textbf{使用场景：} 中考几何压轴题中处理含\(45^\circ\)角的线段和差、求边长、与勾股定理结合求值或最值。

\textbf{简单例子：} 边长为 \(4\) 的正方形 \(ABCD\)，\(E\) 在 \(BC\) 上，\(F\) 在 \(CD\) 上，\(\angle EAF = 45^\circ\)，\(BE=1\)，求 \(DF\) 与 \(EF\)。
解：代入 \(a=4,x=1\) 到 \(xy = a^2 - a(x+y)\)，得
\(y = 16 - 4(1+y) \Rightarrow 5y = 12 \Rightarrow y = \frac{12}{5}\)。
则 \(EF = x+y = 1 + \frac{12}{5} = \frac{17}{5}\)。
验证：\(CE=3,\; CF=4-\frac{12}{5}=\frac{8}{5}\)，\(CE^2+CF^2 = \frac{289}{25} = EF^2\)，成立。
