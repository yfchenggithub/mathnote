\textbf{结论名称：} 等差数列通项公式的推广形式

\textbf{适用条件：} $\{a_n\}$ 是等差数列，公差为 $d$，且 $m,n$ 为正整数。

\textbf{变量说明：} $a_n$ 与 $a_m$ 分别表示数列的第 $n$ 项与第 $m$ 项，$d$ 为数列的公差。

\textbf{核心公式：} \[ \boxed{a_n = a_m + (n-m)d} \]

\textbf{使用场景：} 已知等差数列中任意一项与公差时，可直接求另一项；已知任意两项时，可用于求公差或项数。

\textbf{简单例子：} 在等差数列 $\{a_n\}$ 中，已知 $a_3=5$，公差 $d=2$，求 $a_7$。  
由公式得：$a_7 = a_3 + (7-3)\times 2 = 5 + 8 = 13$。  
验证：$a_4=7,\ a_5=9,\ a_6=11,\ a_7=13$，与公式结果一致。
