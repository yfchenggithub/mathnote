\textbf{结论名称：} 函数周期的常见表达式

\textbf{适用条件：} 对于定义域内的任意 \(x\)，\(x\pm T\) 仍属于定义域，且 \(T\) 为非零常数。

\textbf{变量说明：} \(T\) 为函数 \(f(x)\) 的周期（常指最小正周期）；\(a, b\) 为给定的非零实常数。

\textbf{核心公式：}
\[
\boxed{
\begin{array}{ll}
\text{(1) 基本定义：} & f(x+T)=f(x)\quad (T\neq 0) \\[4pt]
\text{(2) } f(x+a)=f(x) & \Rightarrow T=|a| \\[4pt]
\text{(3) } f(x+a)=-f(x) & \Rightarrow T=2|a| \\[4pt]
\text{(4) } f(x+a)=\pm\dfrac{1}{f(x)} & \Rightarrow T=2|a| \\[4pt]
\text{(5) } f(x+a)=f(x+b)\;(a\neq b) & \Rightarrow T=|a-b|
\end{array}
}
\]

\textbf{使用场景：} 求抽象函数的周期、根据周期递推求函数值、由对称性与周期性互推、函数图像重复规律分析等。

\textbf{简单例子：} 
已知定义在 \(\mathbb{R}\) 上的函数 \(f(x)\) 满足 \(f(x+2)=-\dfrac{1}{f(x)}\)，且 \(f(1)=2\)，求 \(f(2025)\)。

解：由公式 (4) 得周期 \(T=2\times 2=4\)。又 \(2025=4\times 506+1\)，故 \(f(2025)=f(1)=2\)。
