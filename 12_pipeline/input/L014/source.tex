\textbf{结论名称：} 等差数列前 \(n\) 项和的最值

\textbf{适用条件：} 等差数列 \(\{a_n\}\)，公差 \(d \neq 0\)。

\textbf{变量说明：} \(a_1\) 为首项，\(d\) 为公差，\(S_n\) 为前 \(n\) 项和，\(n\in\mathbb{N}^*\)。

\textbf{核心公式：}
\[
S_n = na_1 + \frac{n(n-1)}{2}d = \frac{d}{2}n^2 + \left(a_1 - \frac{d}{2}\right)n.
\]
\[
\boxed{ d<0,\ a_n \ge 0,\ a_{n+1} \le 0 \Rightarrow \max S_n;\qquad d>0,\ a_n \le 0,\ a_{n+1} \ge 0 \Rightarrow \min S_n. }
\]

\textbf{使用场景：} 求等差数列前 \(n\) 项和的最大值或最小值，并确定对应的项数 \(n\)。

\textbf{简单例子：} 在等差数列 \(\{a_n\}\) 中，\(a_1 = 9,\ d = -4\)，求 \(S_n\) 的最大值及相应的 \(n\)。
由 \(a_n = 13-4n \ge 0\) 得 \(n \le 3.25\)，则 \(a_3=1>0,\ a_4=-3<0\)，故当 \(n=3\) 时 \(S_n\) 最大，最大值 \(S_3 = 9+5+1 = 15\)。
