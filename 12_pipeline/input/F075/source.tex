\textbf{结论名称：} 导数证明不等式常用放缩链

\textbf{适用条件：} $\ln x \le x-1$ 要求 $x>0$；$e^x \ge x+1$ 与 $e^x \ge ex$ 对 $x\in\mathbb{R}$ 成立，取等条件分别为 $x=1$ 和 $x=1$（或 $x=0$）。

\textbf{变量说明：} $x$ 为实数，视具体放缩式需满足对应定义域。

\textbf{核心公式：}
\[
\boxed{\ln x \le x-1\ (x>0),\qquad e^x \ge x+1,\qquad e^x \ge ex\ (x\in\mathbb{R})}
\]
常见组合：相加可得 $e^x - \ln x \ge 2$ 等。

\textbf{使用场景：} 高考导数题中，将含指、对数的超越不等式放缩为多项式，便于求最值或证明。

\textbf{简单例子：} 证明：当 $x>0$ 时，$e^x - \ln x \ge 2$。
由 $e^x \ge x+1$（$x=0$ 取等），
由 $\ln x \le x-1$ 得 $-\ln x \ge 1-x$（$x=1$ 取等），
两式相加：$e^x - \ln x \ge (x+1)+(1-x)=2$。因等号不能同时成立，故原不等式成立。
