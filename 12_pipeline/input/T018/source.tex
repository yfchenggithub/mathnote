\textbf{结论名称：} $\sin x+\cos x$、$\sin x-\cos x$、$\sin x\cos x$ 三者知一求二

\textbf{适用条件：} $x\in\mathbb{R}$，适用于同角正弦、余弦的和、差与积之间的互化。

\textbf{变量说明：} 设 $t_1=\sin x+\cos x$，$t_2=\sin x-\cos x$，$p=\sin x\cos x$，三者由平方关系联系。$t_1,t_2\in[-\sqrt2,\sqrt2]$，$p\in[-\tfrac12,\tfrac12]$。

\textbf{核心公式：}
\[
\boxed{(\sin x\pm\cos x)^2=1\pm 2\sin x\cos x}
\]
由此得互化公式：
\[
\sin x\cos x = \frac{(\sin x+\cos x)^2-1}{2} = \frac{1-(\sin x-\cos x)^2}{2}
\]
\[
(\sin x+\cos x)^2 + (\sin x-\cos x)^2 = 2
\]

\textbf{使用场景：} 已知三者之一的值，快速求另外两个，避免直接解 $\sin x,\cos x$。常用于三角函数条件求值、化简、证明以及同角关系式的变形计算。

\textbf{简单例子：} 已知 $\sin x+\cos x=\dfrac{1}{5}$，求 $\sin x\cos x$ 和 $\sin x-\cos x$（$x$为第四象限角）。
\vspace{0.5em}

解：$\sin x\cos x = \dfrac{(1/5)^2-1}{2} = \dfrac{1/25-1}{2} = -\dfrac{12}{25}$。
\vspace{0.5em}

$(\sin x-\cos x)^2 = 1 - 2\left(-\dfrac{12}{25}\right) = \dfrac{49}{25}$。在第四象限$\sin x<0,\cos x>0$，故$\sin x-\cos x<0$，得$\sin x-\cos x = -\dfrac{7}{5}$。
