\textbf{结论名称：} 有限集合中满足条件的子集个数的分类与分步计数

\textbf{适用条件：} 已知有限集合 \(A\)，\(|A|=n\)，求满足某种特定条件 \(P\) 的子集个数，且条件 \(P\) 可划分为若干个互斥的子条件（分类），或元素的归属可逐步独立确定（分步）。

\textbf{变量说明：} 设满足条件的子集总数为 \(N\)；若分类处理，第 \(i\) 类情形的子集个数为 \(N_i\)；若分步处理，第 \(j\) 步有 \(n_j\) 种独立选择。

\textbf{核心公式：}
分类加法计数原理：
\[ \boxed{N = N_1 + N_2 + \cdots + N_k} \]
分步乘法计数原理：
\[ \boxed{N = n_1 \times n_2 \times \cdots \times n_m} \]
常用结论（无限制及含特定元素）：
\[ \boxed{|P(A)| = 2^n},\qquad \boxed{N(\text{含指定 }m\text{ 个元素}) = 2^{n-m}} \]

\textbf{使用场景：} 高考题中要求计算同时包含某些元素且不包含另一些元素，或子集的元素和、元素积满足特定性质的子集个数。

\textbf{简单例子：} 
设 \(A=\{1,2,3,4\}\)，求包含元素 \(1\) 且不含元素 \(4\) 的子集个数。
解：元素 \(1\) 必选，元素 \(4\) 必不选，元素 \(2,3\) 均可选或不选，按分步乘法，共 \(2\times2=4\) 种。满足条件的子集为 \(\{1\},\{1,2\},\{1,3\},\{1,2,3\}\)，共 \(4\) 个，验证正确。
