\textbf{结论名称：}分式不等式解法（移项、通分、化乘积、穿根）

\textbf{适用条件：}分式不等式经移项、通分后可化为 \(\frac{P(x)}{Q(x)}>0\) 或 \(\frac{P(x)}{Q(x)}\ge 0\) 等形式，其中 \(P(x),Q(x)\) 为多项式。

\textbf{变量说明：} \(P(x),Q(x)\) 已分解为一次因式的乘积且首项系数化为正；零点为分子、分母各因式的根，其中分母的零点为空心点。

\textbf{核心公式：}
\[
\boxed{\frac{P(x)}{Q(x)}>0 \iff P(x)Q(x)>0},\qquad 
\boxed{\frac{P(x)}{Q(x)}\ge 0 \iff 
\begin{cases} P(x)Q(x)\ge 0,\\ Q(x)\neq 0 \end{cases}}
\]
转化后对 \(P(x)Q(x)\) 使用穿根法（数轴标根）确定符号区间。

\textbf{使用场景：}求解含分式的不等式，尤其是分子分母可分解为一次或二次因式的情形，能快速通过零点分区判断符号。

\textbf{简单例子：}解 \(\displaystyle\frac{x-1}{x+2}\ge 0\)。

转化：\((x-1)(x+2)\ge 0\) 且 \(x+2\neq 0\)。

零点：\(x=1,\;x=-2\)。

穿根：从数轴右上方起，过 \(x=1\) 穿根，过 \(x=-2\) 穿根，得 \(x\le -2\) 或 \(x\ge 1\)。

限制分母：去掉 \(x=-2\)，最终解集为 \((-\infty,-2)\cup[1,+\infty)\)。验证：\(x=-3\) 满足，\(x=0\) 不满足，\(x=1\) 满足。
