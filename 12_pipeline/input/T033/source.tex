\textbf{结论名称：} 三角形面积公式 \(S=\dfrac{abc}{4R}\)（外接圆半径）

\textbf{适用条件：} 任意三角形，已知三边长和外接圆半径，或可通过已知条件先求出外接圆半径。

\textbf{变量说明：} \(a,b,c\) 为 \(\triangle ABC\) 的三边长，\(R\) 为三角形外接圆半径，\(S\) 为三角形面积。

\textbf{核心公式：} \[ \boxed{S = \frac{abc}{4R}} \]

\textbf{使用场景：} 避免求角直接由三边及外接圆半径计算面积；与正弦定理 \(a=2R\sin A\) 联用，由两边一角及外接圆半径求面积；在涉及外接圆的综合问题中简化运算。

\textbf{简单例子：} 在 \(\triangle ABC\) 中，\(a=3,\;b=4,\;c=5\)，其外接圆半径 \(R=\dfrac{c}{2}=2.5\)，则面积为
\[ S = \frac{3\times4\times5}{4\times2.5} = \frac{60}{10} = 6, \]
与直角边求面积 \(S=\frac12\times3\times4=6\) 结果一致。
