\textbf{结论名称：}底面外接圆+高求外接球：\(R^2=r^2+(h/2)^2\)（球心在底面外心正上方）

\textbf{适用条件：}底面存在外接圆（如正多边形、圆），且几何体的所有侧棱均垂直于底面（常见于直棱柱、圆柱），此时外接球球心恰好位于底面外心正上方、高线中点处。

\textbf{变量说明：}
\(R\)——外接球半径；
\(r\)——底面外接圆半径；
\(h\)——几何体的高（两底面之间的距离，或顶点到底面的垂直距离）。

\textbf{核心公式：}
\[
\boxed{R^2 = r^2 + \left(\frac{h}{2}\right)^2}
\]

\textbf{使用场景：}直棱柱（正棱柱）、圆柱以及底面有外接圆且侧棱垂直底面的几何体的外接球半径计算，尤其适合高考中直接求外接球表面积或体积的选填题。

\textbf{简单例子：}
正三棱柱底面边长为 \(2\sqrt{3}\)，高为 \(2\)。底面外接圆半径 \(r=\frac{2\sqrt{3}}{\sqrt{3}}=2\)，则外接球半径
\[
R=\sqrt{2^2+\left(\frac{2}{2}\right)^2}=\sqrt{4+1}=\sqrt{5}.
\]
