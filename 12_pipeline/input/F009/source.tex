\textbf{结论名称：} 函数值域——换元法（根式、三角换元）

\textbf{适用条件：} 函数中含有形如 $\sqrt{ax+b}$、$\sqrt{a^2-x^2}$、$\sqrt{x^2\pm a^2}$ 等结构，通过换元可转化为整式或三角函数。

\textbf{变量说明：} 对一次根式，设 $t=\sqrt{ax+b}\;(t\ge0)$，反解 $x=\frac{t^2-b}{a}$；对 $\sqrt{a^2-x^2}$，设 $x=a\sin\theta\;(\theta\in[-\frac{\pi}{2},\frac{\pi}{2}])$；对 $\sqrt{x^2+a^2}$，设 $x=a\tan\theta$；对 $\sqrt{x^2-a^2}$，设 $x=a\sec\theta$。

\textbf{核心公式：}
\[
\boxed{t = \sqrt{ax+b}\;(t\ge 0)\ \Longrightarrow\ x = \frac{t^2-b}{a}}
\]
\[
\boxed{x = a\sin\theta,\ \theta\in\Big[-\frac{\pi}{2},\frac{\pi}{2}\Big]\ \Longrightarrow\ \sqrt{a^2-x^2} = a\cos\theta}
\]

\textbf{使用场景：} 求无理函数的值域或最值，通过换元去掉根号，转化为二次函数、三角函数等熟悉函数处理。

\textbf{简单例子：} 求 $y = x + \sqrt{1-x^2}\;(x\in[-1,1])$ 的值域。\\
令 $x=\sin\theta,\;\theta\in[-\frac{\pi}{2},\frac{\pi}{2}]$，则
\[
y = \sin\theta + \cos\theta = \sqrt{2}\sin\!\Big(\theta+\frac{\pi}{4}\Big).
\]
由 $\theta+\frac{\pi}{4}\in\Big[-\frac{\pi}{4},\frac{3\pi}{4}\Big]$ 得 $\sin(\theta+\pi/4)\in\Big[-\frac{\sqrt{2}}{2},1\Big]$，故 $y\in[-1,\sqrt{2}]$。
