\textbf{结论名称：} 圆系方程（过两圆交点的圆系 / 过直线与圆交点的圆系）

\textbf{适用条件：} 两圆相交（或内切、外切时需注意退化）或直线与圆相交，用于表示经过这些公共交点的所有圆（除个别退化情形）。

\textbf{变量说明：} 
圆 \(C_1: x^2+y^2+D_1x+E_1y+F_1=0\)，圆 \(C_2: x^2+y^2+D_2x+E_2y+F_2=0\)，\(\lambda\in\mathbb{R},\ \lambda\neq -1\)；直线 \(l: Ax+By+C=0\)，圆 \(C: x^2+y^2+Dx+Ey+F=0\)，\(\mu\in\mathbb{R}\)。

\textbf{核心公式：} 
过两圆 \(C_1,C_2\) 交点的圆系（不含 \(C_2\)）：
\[
\boxed{(x^2+y^2+D_1x+E_1y+F_1)+\lambda(x^2+y^2+D_2x+E_2y+F_2)=0}
\]
过直线 \(l\) 与圆 \(C\) 交点的圆系：
\[
\boxed{x^2+y^2+Dx+Ey+F+\mu(Ax+By+C)=0}
\]

\textbf{使用场景：} 已知所求圆经过两已知圆（或已知直线与圆）的交点，并满足另一条件（如过定点、圆心在某直线上、与某直线相切等），可先写出圆系方程，再由条件确定参数，避免直接求交点坐标。

\textbf{简单例子：} 
求过直线 \(l:x+y-1=0\) 与圆 \(C:x^2+y^2=2\) 的交点，且过点 \(P(2,0)\) 的圆的方程。\\
设圆方程为 \(x^2+y^2-2+\mu(x+y-1)=0\)，代入 \(P(2,0)\)：
\[
4+0-2+\mu(2+0-1)=2+\mu=0 \Rightarrow \mu=-2.
\]
得圆方程 \(x^2+y^2-2-2(x+y-1)=0\)，即 \(x^2+y^2-2x-2y=0\)。检验可知它经过两交点与 \(P\)。
