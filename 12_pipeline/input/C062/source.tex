\textbf{结论名称：} 抛物线中点弦结论（弦中点 \(M(x_0,y_0)\)，弦斜率 \(k=p/y_0\)）\par
\textbf{适用条件：} 抛物线为标准形式 \(y^2=2px\)（或 \(y^2=-2px\) 可类似推导），弦所在直线不与 \(y\) 轴平行，弦中点 \(M(x_0,y_0)\) 满足 \(y_0\neq 0\)，且弦的斜率存在。\par
\textbf{变量说明：} \(p\) 为抛物线焦准距（\(p>0\) 时开口向右，\(p<0\) 时开口向左），\(M(x_0,y_0)\) 为弦的中点坐标，\(k\) 为弦所在直线的斜率。\par
\textbf{核心公式：}
\[
\boxed{k = \frac{p}{y_0}}
\]
\par
\textbf{使用场景：} 已知抛物线方程及弦的中点坐标，快速求弦的斜率或直线方程；处理中点弦相关的定值、定点问题；避免联立直线与抛物线的复杂运算。\par
\textbf{简单例子：} 已知抛物线 \(y^2=4x\)，弦 \(AB\) 的中点为 \(M(2,1)\)，求弦所在直线的斜率。\par
由 \(y^2=4x\) 得 \(2p=4\)，即 \(p=2\)。中点纵坐标 \(y_0=1\)，代入公式得斜率 \(k = p/y_0 = 2/1 = 2\)。因此弦所在直线的斜率为 \(2\)。\par
