\textbf{结论名称：} 线性回归方程的最小二乘估计

\textbf{适用条件：} 两个变量具有线性相关关系，给定样本数据 $(x_i, y_i)\ (i=1,\dots,n)$，且 $\sum (x_i-\bar{x})^2 \neq 0$。

\textbf{变量说明：} $x_i, y_i$ 为样本观测值；$\bar{x}=\frac{1}{n}\sum x_i$，$\bar{y}=\frac{1}{n}\sum y_i$；$\hat{b}$ 为斜率估计值，$\hat{a}$ 为截距估计值，$\hat{y}$ 为回归预测值。

\textbf{核心公式：}
\[
\boxed{\hat{b} = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}, \qquad \hat{a} = \bar{y} - \hat{b}\bar{x}}
\]
回归直线方程为 $\hat{y} = \hat{b}x + \hat{a}$，且直线必过样本中心点 $(\bar{x}, \bar{y})$。

\textbf{使用场景：} 已知样本数据求线性回归方程；根据自变量预测因变量；计算相关系数 $r$ 时分子部分相同。

\textbf{简单例子：} 已知三点 $(1,1),\ (2,2),\ (3,2)$，求线性回归方程。

解：$\bar{x}=2$，$\bar{y}=\frac{5}{3}$；
\[
\sum (x_i-\bar{x})(y_i-\bar{y}) = (-1)\times(-\tfrac{2}{3}) + 0\times\tfrac{1}{3} + 1\times\tfrac{1}{3} = 1,
\]
\[
\sum (x_i-\bar{x})^2 = (-1)^2 + 0^2 + 1^2 = 2,
\]
故 $\hat{b} = \frac{1}{2} = 0.5$，$\hat{a} = \frac{5}{3} - 0.5\times 2 = \frac{2}{3}$。
回归方程为 $\hat{y} = 0.5x + \frac{2}{3}$。
