\textbf{结论名称：} 正弦型函数 $y=A\sin(\omega x+\varphi)$ 的周期与单调区间求法

\textbf{适用条件：} $A\neq0$，$\omega>0$，$x\in\mathbb{R}$.

\textbf{变量说明：} $A$——振幅，$\omega$——角频率，$\varphi$——初相，$k\in\mathbb{Z}$.

\textbf{核心公式：}
\[
\boxed{T = \frac{2\pi}{\omega},\qquad 
\begin{cases}
\text{增区间：} -\dfrac{\pi}{2}+2k\pi \le \omega x+\varphi \le \dfrac{\pi}{2}+2k\pi \\[6pt]
\text{减区间：} \dfrac{\pi}{2}+2k\pi \le \omega x+\varphi \le \dfrac{3\pi}{2}+2k\pi
\end{cases}}
\]
解出 $x$ 的范围即得单调区间.

\textbf{使用场景：} 求正弦型函数的周期、单调区间、最值点横坐标，用于图像与性质分析.

\textbf{简单例子：} 求 $y=2\sin\!\left(3x+\dfrac{\pi}{4}\right)$ 的周期和单调增区间.\\
周期 $T=\dfrac{2\pi}{3}$.\\
由 $-\dfrac{\pi}{2}+2k\pi \le 3x+\dfrac{\pi}{4} \le \dfrac{\pi}{2}+2k\pi$ 解得
\[
-\frac{\pi}{4}+\frac{2k\pi}{3} \le x \le \frac{\pi}{12}+\frac{2k\pi}{3},\;k\in\mathbb{Z},
\]
故单调递增区间为 $\left[-\dfrac{\pi}{4}+\dfrac{2k\pi}{3},\ \dfrac{\pi}{12}+\dfrac{2k\pi}{3}\right]$ ($k\in\mathbb{Z}$).
