\textbf{结论名称：}降幂公式  
\textbf{适用条件：}对任意实数 \(x\) 成立，由二倍角余弦公式 \(\cos 2x = 1-2\sin^2 x = 2\cos^2 x -1\) 变形得到。  
\textbf{变量说明：} \(x\) 为自变量（弧度或角度），\(\sin x,\cos x,\cos 2x\) 为标准三角函数。  
\textbf{核心公式：}\[
\boxed{\sin^2 x = \frac{1-\cos 2x}{2}},\qquad 
\boxed{\cos^2 x = \frac{1+\cos 2x}{2}}
\]  
\textbf{使用场景：}将三角函数的平方转化为一次余弦，常用于三角化简、求不定积分、解三角方程以及周期与最值分析。  
\textbf{简单例子：}取 \(x=\frac{\pi}{6}\)，则 \(\sin^2\frac{\pi}{6}=\frac{1}{4}\)，公式给出 \(\frac{1-\cos\frac{\pi}{3}}{2}=\frac{1-\frac12}{2}=\frac14\)；\(\cos^2\frac{\pi}{6}=\frac{3}{4}\)，公式给出 \(\frac{1+\cos\frac{\pi}{3}}{2}=\frac{1+\frac12}{2}=\frac34\)，均成立。
