\textbf{结论名称：} 向量垂直的坐标判定

\textbf{适用条件：} 平面直角坐标系中，两个非零向量。

\textbf{变量说明：} 设向量 \(\vec{a}=(x_1,y_1)\)，\(\vec{b}=(x_2,y_2)\)，且 \(\vec{a}\neq\mathbf{0},\ \vec{b}\neq\mathbf{0}\)。

\textbf{核心公式：} 
\[
\boxed{x_1 x_2 + y_1 y_2 = 0 \quad\Longleftrightarrow\quad \vec{a} \perp \vec{b}}
\]

\textbf{使用场景：} 将几何中的垂直关系转化为代数坐标运算，用于判定两向量垂直、已知垂直求参数、或证明两直线方向向量垂直等。

\textbf{简单例子：} 已知 \(\vec{a}=(m,2)\)，\(\vec{b}=(-1,3)\)，且 \(\vec{a}\perp\vec{b}\)。由 \(m\cdot(-1)+2\cdot3=0\) 得 \(-m+6=0\)，解得 \(m=6\)。检验：\(\vec{a}=(6,2), \vec{b}=(-1,3)\)，满足 \(6\times(-1)+2\times3=0\)。
