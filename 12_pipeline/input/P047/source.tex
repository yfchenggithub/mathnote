\textbf{结论名称：}四点共圆的判定条件（对角互补、同侧等角、相交弦逆定理、割线逆定理）

\textbf{适用条件：}四点一般位置（不共线），分别满足：四边形对角互补；两定点同侧张角相等；两线段相交或延长后相交且满足线段乘积相等。

\textbf{变量说明：}$A,B,C,D$ 为待判定的四点；$P$ 为直线 $AB$ 与 $CD$ 的交点（适用于相交弦或割线情形）；角度均指通常的平面几何角。

\textbf{核心公式：}
\[
\begin{aligned}
&\text{对角互补：}\quad \boxed{\angle A+\angle C=180^\circ \iff A,B,C,D\text{ 共圆}}\\
&\text{同侧等角：}\quad \boxed{\angle ACB=\angle ADB \iff A,B,C,D\text{ 共圆}\;(C,D\text{ 在 }AB\text{ 同侧})}\\
&\text{相交弦逆定理：}\quad \boxed{PA\cdot PB=PC\cdot PD \iff A,B,C,D\text{ 共圆}}\;(\text{交点在两线段内部})\\
&\text{割线逆定理：}\quad \boxed{PA\cdot PB=PC\cdot PD \iff A,B,C,D\text{ 共圆}}\;(\text{交点在两线段延长线上})
\end{aligned}
\]

\textbf{使用场景：}在平面几何证明中快速判定四点共圆，进而使用圆周角定理、圆幂定理等；解析几何中可将共圆条件转化为角度或线段乘积关系。

\textbf{简单例子：}
\begin{enumerate}
  \item 对角互补：四边形 $ABCD$，已知 $\angle A=70^\circ,\angle C=110^\circ$，则 $A,B,C,D$ 共圆。
  \item 相交弦逆定理：线段 $AB$ 与 $CD$ 相交于点 $P$，$PA=4$，$PB=9$，$PC=6$，$PD=6$。因 $4\times 9=36=6\times 6$，满足 $PA\cdot PB=PC\cdot PD$，故 $A,B,C,D$ 四点共圆。
\end{enumerate}
