\textbf{结论名称：}圆周角定理（同弧或等弧所对的圆周角等于圆心角的一半）

\textbf{适用条件：}在同圆或等圆中，弧相同（或弧相等）；需指明圆周角与圆心角对应同一段弧。

\textbf{变量说明：}设$\odot O$中，$\wideparen{AB}$为所考察的弧，$\angle AOB$为弧$AB$所对的圆心角，点$C$为圆上不与$A,B$重合的一点，$\angle ACB$为弧$AB$所对的圆周角。

\textbf{核心公式：}
\[
\boxed{\angle ACB = \frac{1}{2}\angle AOB}
\]
且同弧（或等弧）所对的圆周角相等；若$C$在劣弧上，则圆周角对应另一侧的圆心角（即$360^\circ-\angle AOB$）的一半。

\textbf{使用场景：}圆中的角度计算与转化、三角形外接圆问题、解析几何中利用圆心角与圆周角关系简化角度推理。

\textbf{简单例子：}在$\odot O$中，弦$AB$所对的圆心角$\angle AOB=100^\circ$，点$C$在优弧$AB$上，则$\wideparen{AB}$（劣弧）所对的圆周角$\angle ACB = \frac{1}{2}\times 100^\circ = 50^\circ$；若点$D$在劣弧$AB$上，则$\angle ADB$对应优弧$AB$所对圆心角$360^\circ-100^\circ=260^\circ$，故$\angle ADB = 130^\circ$，且$\angle ACB + \angle ADB = 180^\circ$。
