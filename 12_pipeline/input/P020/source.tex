\textbf{结论名称：}一般方程表示圆的条件

\textbf{适用条件：}方程形如 \(x^2+y^2+Dx+Ey+F=0\)，不含\(xy\)项，且\(x^2\)与\(y^2\)系数相等且已化为1。

\textbf{变量说明：} \(D,E,F\)为实常数。

\textbf{核心公式：} 当且仅当
\[
\boxed{D^{2}+E^{2}-4F>0}
\]
时，方程表示一个圆。此时圆心为\(\displaystyle\left(-\frac{D}{2},-\frac{E}{2}\right)\)，半径为\(\displaystyle r=\frac{1}{2}\sqrt{D^{2}+E^{2}-4F}\)。

\textbf{使用场景：} 判定一个二元二次方程是否表示圆，并直接求出圆心坐标与半径。

\textbf{简单例子：} 判断方程\(x^2+y^2-4x+6y-3=0\)是否表示圆。
解：这里\(D=-4,\;E=6,\;F=-3\)，计算
\[
D^2+E^2-4F = 16+36-4\times(-3)=16+36+12=64>0,
\]
故该方程表示一个圆。圆心为\((2,-3)\)，半径\(r=\frac{1}{2}\sqrt{64}=4\)。
