\textbf{结论名称：}相似三角形存在性问题中对应关系的分类讨论

\textbf{适用条件：}已知一个三角形（定点）及其中一条边上的定点，在另一条边上存在一动点，使得以定点、动点和公共顶点构成的新三角形与原三角形相似。需要根据对应顶点不确定进行分类讨论。

\textbf{变量说明：}设原三角形为 \(\triangle ABC\)（点 \(A,B,C\) 均为定点），点 \(D\) 为边 \(AB\) 上的已知定点，点 \(E\) 为边 \(AC\) 上的动点（满足 \(\triangle ADE\) 与 \(\triangle ABC\) 相似）。记 \(AB = c\)，\(AC = b\)，\(AD = d\)，\(AE = x\)（未知）。

\textbf{核心公式：}由于 \(\angle DAE = \angle BAC\)（公共角），相似只有两种可能的对应顺序：
\[
\boxed{
\frac{AD}{AB} = \frac{AE}{AC} \quad \text{或} \quad \frac{AD}{AC} = \frac{AE}{AB}
}
\]
前者对应 \(\triangle ADE \sim \triangle ABC\)，后者对应 \(\triangle ADE \sim \triangle ACB\)。

\textbf{使用场景：}中考压轴题中，在抛物线、直线或三角形边上给定一个定点，另一动点在特定轨迹上，要求构造相似三角形。由于对应顶点没有指明，必须按上述两种比例关系分类讨论，再解出动点坐标或线段长度。

\textbf{简单例子：}在 \(\triangle ABC\) 中，\(AB = 9\)，\(AC = 6\)，点 \(D\) 在 \(AB\) 上且 \(AD = 3\)，点 \(E\) 在 \(AC\) 上。若 \(\triangle ADE\) 与 \(\triangle ABC\) 相似，求 \(AE\) 的长。
解：分两种情况。
\begin{itemize}
\item 当 \(\triangle ADE \sim \triangle ABC\) 时，\(\frac{AD}{AB}=\frac{AE}{AC}\)，即 \(\frac{3}{9}=\frac{AE}{6}\)，得 \(AE=2\)。
\item 当 \(\triangle ADE \sim \triangle ACB\) 时，\(\frac{AD}{AC}=\frac{AE}{AB}\)，即 \(\frac{3}{6}=\frac{AE}{9}\)，得 \(AE=4.5\)。
\end{itemize}
所以 \(AE\) 的长为 \(2\) 或 \(4.5\)。
