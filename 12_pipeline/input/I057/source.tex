\textbf{结论名称：}琴生不等式取等条件（变量相等）

\textbf{适用条件：}函数 \(f\) 在区间 \(I\) 上为严格凸函数（或严格凹函数，此时不等号方向相反）；变量 \(x_i\in I\)，权重 \(\lambda_i>0\) 且 \(\sum_{i=1}^n \lambda_i = 1\)。

\textbf{变量说明：} \(x_i\)：自变量；\(\lambda_i\)：对应权重；\(n\)：变量个数；\(f\)：严格凸（或严格凹）函数。

\textbf{核心公式：}
\[
\boxed{ f\!\left(\sum_{i=1}^{n}\lambda_i x_i\right) = \sum_{i=1}^{n}\lambda_i f(x_i) \;\Longleftrightarrow\; x_1 = x_2 = \cdots = x_n }
\]
（对于严格凹函数，不等号反向，取等条件同为所有变量相等。）

\textbf{使用场景：}利用琴生不等式证明对称不等式后直接写出等号成立条件；在优化问题中由凸性确定唯一极值点。

\textbf{简单例子：}取 \(f(x)=x^2\)（严格凸），\(\lambda_1=\lambda_2=\frac12\)，由琴生不等式得
\[
\left(\frac{x+y}{2}\right)^2 \le \frac{x^2+y^2}{2},
\]
整理即 \(x^2+y^2 \ge 2xy\)，等号成立当且仅当 \(x=y\)。
