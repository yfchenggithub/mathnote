\textbf{结论名称：} 极点极线定义（配极变换）

\textbf{适用条件：} 给定一条非退化的圆锥曲线 \(\Gamma\)（标准方程或一般二次方程），以及平面上一点 \(P\)（可在曲线外、上或内）。

\textbf{变量说明：} 以椭圆为例，设 \(\Gamma:\frac{x^2}{a^2}+\frac{y^2}{b^2}=1\)，点 \(P(x_0,y_0)\)；双曲线 \(\frac{x^2}{a^2}-\frac{y^2}{b^2}=1\) 与抛物线 \(y^2=2px\) 类似替换。一般形式：\(\Gamma:Ax^2+Bxy+Cy^2+Dx+Ey+F=0\)。

\textbf{核心公式：} 点 \(P\) 关于标准椭圆（或双曲线、抛物线）的极线方程为
\[
\boxed{\frac{x_0 x}{a^2} \pm \frac{y_0 y}{b^2} = 1},\qquad \boxed{y_0 y = p(x+x_0)}
\]
一般二次曲线下，极线方程为
\[
A x_0 x + \frac{B}{2}(x_0 y + y_0 x) + C y_0 y + \frac{D}{2}(x+x_0) + \frac{E}{2}(y+y_0) + F = 0 .
\]

\textbf{使用场景：} 由极点直接写出切点弦或切线方程；处理定点、定值问题；简化涉及极点极线背景的高考压轴题（如定点定直线、调和分割）。

\textbf{简单例子：} 已知椭圆 \(\frac{x^2}{4}+y^2=1\)，点 \(P(2,1)\)。代入公式得极线：\(\frac{2x}{4}+1\cdot y=1 \Rightarrow x+2y-2=0\)。若点 \(P(2,2)\)（在椭圆外），该极线恰为从 \(P\) 所作两条切线的切点弦所在直线。
