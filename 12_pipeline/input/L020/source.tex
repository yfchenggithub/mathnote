\textbf{结论名称：}累加法求通项公式

\textbf{适用条件：}递推关系形如 \(a_{n+1}=a_n+f(n)\)（即 \(a_{n+1}-a_n=f(n)\)），且 \(f(n)\) 可求和。

\textbf{变量说明：} \(a_n\) 为数列第 \(n\) 项，\(a_1\) 为首项，\(f(n)\) 为关于 \(n\) 的已知表达式，\(n\in\mathbb{N}^*\)，\(k\) 为求和指标。

\textbf{核心公式：}
\[
\boxed{a_n = a_1 + \sum_{k=1}^{n-1} f(k) \quad (n \geqslant 2)}
\]

\textbf{使用场景：}递推式为差分为 \(f(n)\) 的线性形式，如 \(a_{n+1}=a_n + n\)，\(a_{n+1}=a_n + 2^n\)，\(a_{n+1}=a_n + \frac{1}{n(n+1)}\) 等，可直接套用累加公式写出通项。

\textbf{简单例子：}已知 \(a_1=1\)，\(a_{n+1}=a_n + n\)，求 \(a_n\)。

解：这里 \(f(n)=n\)，由累加法得
\[
a_n = 1 + \sum_{k=1}^{n-1} k = 1 + \frac{n(n-1)}{2}.
\]
验证：\(a_2 = 1+1=2\)，\(a_3 = 2+2=4\)，公式计算 \(a_3 = 1+3=4\)，一致。
