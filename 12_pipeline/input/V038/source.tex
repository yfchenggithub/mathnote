\textbf{结论名称：} 向量三角不等式

\textbf{适用条件：} 任意向量 \(\mathbf{a},\mathbf{b}\)（平面或空间向量）.

\textbf{变量说明：} \(\mathbf{a},\mathbf{b}\) 为向量，\(|\mathbf{a}|,|\mathbf{b}|\) 分别表示其模长；式中 \(\pm\) 同时表示向量和与向量差两种情形.

\textbf{核心公式：} 
\[
\boxed{\bigl| |\mathbf{a}| - |\mathbf{b}| \bigr| \leq |\mathbf{a} \pm \mathbf{b}| \leq |\mathbf{a}| + |\mathbf{b}|}
\]

\textbf{使用场景：} 估计向量和（差）的模的取值范围，证明与模相关的不等式，求模的最值，判断向量共线或反向时的模取等条件.

\textbf{简单例子：} 
设 \(|\mathbf{a}| = 3,\ |\mathbf{b}| = 4\)，则 \(|\mathbf{a} + \mathbf{b}|\) 的取值范围为 \([\,|3-4|,\, 3+4\,] = [1,7]\). 
当 \(\mathbf{a}\) 与 \(\mathbf{b}\) 同向时，\(|\mathbf{a}+\mathbf{b}| = 7\)（取最大值）；反向时 \(|\mathbf{a}+\mathbf{b}| = 1\)（取最小值）；若 \(\mathbf{a}\) 与 \(\mathbf{b}\) 不共线，模长严格介于 \(1\) 与 \(7\) 之间.
