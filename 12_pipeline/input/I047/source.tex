\textbf{结论名称：} 含多个绝对值的不等式（分段讨论法/几何意义法）

\textbf{适用条件：} 不等式含有两个或两个以上一次绝对值，如 \( |x-a|\pm|x-b|\ge c \) 或 \(\sum |x-a_i| \) 型。

\textbf{变量说明：} \(a,b\)（或 \(a_i\)）为常数，通常设 \(a<b\)；\(x\) 为实数变量；\(c\) 为给定实数。

\textbf{核心公式：} 
零点分段法：令各绝对值为零求出零点 \(x_1<x_2<\cdots<x_n\)，将数轴分为若干区间，逐段去绝对值求解，最后合并。
几何意义法：将 \(|x-a|\) 视为数轴上 \(x\) 到 \(a\) 的距离。常用最值结论：
\[
\boxed{|x-a|+|x-b|\ge |a-b|,\qquad \bigl| |x-a|-|x-b| \bigr|\le |a-b|}
\]
等号条件：前者当 \(a\le x\le b\) 时取等；后者当 \(x\notin(a,b)\) 时取等（含端点）。

\textbf{使用场景：} 
求解形如 \(|x-1|+|x+2|\ge 5\) 的不等式；求形如 \(|x-a|+|x-b|\) 的最小值；处理“距离和/差”型最值问题。

\textbf{简单例子：}
解不等式 \(|x-1|+|x+2|>4\)。
零点为 \(x= -2,\;1\)。分三段讨论：
\begin{itemize}
\item 当 \(x<-2\)：\(-(x-1)-(x+2)>4 \Rightarrow -2x-1>4 \Rightarrow x<-\frac{5}{2}\)，结合条件得 \(x<-\frac{5}{2}\)。
\item 当 \(-2\le x\le 1\)：\(-(x-1)+(x+2)=3>4\)，无解。
\item 当 \(x>1\)：\((x-1)+(x+2)=2x+1>4 \Rightarrow x>\frac{3}{2}\)，结合条件得 \(x>\frac{3}{2}\)。
\end{itemize}
故解集为 \((-\infty,-\frac{5}{2})\cup(\frac{3}{2},+\infty)\)。
