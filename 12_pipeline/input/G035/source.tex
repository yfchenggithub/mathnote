\textbf{结论名称：} 墙角模型补形法：三条侧棱两两垂直的三棱锥$\rightarrow$补长方体求外接球

\textbf{适用条件：} 三棱锥（四面体）从同一顶点出发的三条侧棱两两垂直，即“墙角”结构，可补形成长方体。

\textbf{变量说明：} 设共顶点的三条两两垂直的侧棱长分别为 $a,\,b,\,c$。

\textbf{核心公式：} 外接球半径
\[
\boxed{R = \frac{1}{2}\sqrt{a^{2}+b^{2}+c^{2}}}
\]
外接球直径等于补成长方体的体对角线长 $\sqrt{a^{2}+b^{2}+c^{2}}$，球心位于长方体中心。

\textbf{使用场景：} 已知从同一顶点出发的三条棱长且两两垂直，求该三棱锥的外接球半径、表面积或体积，直接套用长方体对角线。

\textbf{简单例子：} 三棱锥 $P\text{-}ABC$ 满足 $PA\perp PB,\; PB\perp PC,\; PC\perp PA$，且 $PA=2,\; PB=3,\; PC=4$，补成长方体后，外接球半径为
\[
R = \frac{1}{2}\sqrt{2^{2}+3^{2}+4^{2}} = \frac{\sqrt{29}}{2}.
\]
