\textbf{结论名称：}倍长中线法（延长中线一倍构造全等）  

\textbf{适用条件：}在三角形中已知一条中线，需证明线段相等、平行，或集中分散的边、角条件时使用。  

\textbf{变量说明：}在 $\triangle ABC$ 中，$D$ 为 $BC$ 的中点，$AD$ 为中线。延长 $AD$ 至点 $E$，使得 $DE=AD$，并连接 $BE$（或连接 $CE$）。  

\textbf{核心公式：}  
由 $BD=CD$，$AD=DE$，及对顶角 $\angle ADC = \angle EDB$，可得  
\[
\boxed{\triangle ADC \cong \triangle EDB \quad (\text{SAS})}
\]
主要推论：$AC=BE$ 且 $AC \parallel BE$（若连接 $CE$ 则 $AB=CE$ 且 $AB\parallel CE$）。  

\textbf{使用场景：}  
\begin{enumerate}
\item 证明与中点相关的线段相等、平行或角度相等；
\item 通过全等将分散的边长或角度集中到一个三角形中，求解取值范围或构造平行四边形；
\item 在向量背景中，倍长中线可得 $\overrightarrow{AE}=\overrightarrow{AB}+\overrightarrow{AC}$，从而将中线与边向量统一。
\end{enumerate}

\textbf{简单例子：}  
在 $\triangle ABC$ 中，$AB=5$，$AC=3$，$AD$ 为 $BC$ 边上的中线。求中线 $AD$ 的取值范围。  

解：倍长 $AD$ 至 $E$，连接 $BE$。由全等得 $BE=AC=3$。在 $\triangle ABE$ 中，由三角形三边关系：  
\[
AB-BE < AE < AB+BE \;\Longrightarrow\; 5-3 < 2AD < 5+3
\]
即 $2 < 2AD < 8$，故 $\boxed{1 < AD < 4}$。该范围可通过取边界附近的三角形直接验证。
