\textbf{结论名称：} 等腰三角形存在性——两圆一线法

\textbf{适用条件：} 已知平面内两定点 $A$、$B$，在给定轨迹（如直线、抛物线）上寻找第三点 $P$，使 $\triangle ABP$ 为等腰三角形。等腰顶点不明确时需分类讨论。

\textbf{变量说明：} 设 $A(x_1,y_1)$，$B(x_2,y_2)$，两点间距离 $d=|AB|=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$。动点 $P(x,y)$ 受轨迹方程 $f(x,y)=0$ 约束。

\textbf{核心公式：}
\[
\boxed{
\begin{cases}
(x-x_1)^2+(y-y_1)^2 = (x-x_2)^2+(y-y_2)^2 & (\text{一线：}PA=PB)\\[4pt]
(x-x_1)^2+(y-y_1)^2 = d^2 & (\text{圆}A\text{：}PA=AB)\\[4pt]
(x-x_2)^2+(y-y_2)^2 = d^2 & (\text{圆}B\text{：}PB=AB)
\end{cases}
}
\]
将以上三类方程分别与轨迹 $f(x,y)=0$ 联立求解，并剔除使三点共线的解。

\textbf{使用场景：} 中考数学“动点构成等腰三角形”存在性压轴题；已知两定点在坐标系（含二次函数、网格）中求第三点的分类讨论模型。

\textbf{简单例子：} 
已知 $A(0,0)$，$B(2,0)$，动点 $P$ 在直线 $y=1$ 上。求使 $\triangle ABP$ 为等腰三角形的点 $P$。

解：$d=AB=2$，轨迹 $y=1$。
\begin{enumerate}
    \item $PA=PB$：中垂线 $x=1$，与 $y=1$ 交于 $P_1(1,1)$；
    \item $PA=AB=2$：圆 $x^2+y^2=4$，令 $y=1$ 得 $x=\pm\sqrt{3}$，$P_{2,3}(\pm\sqrt{3},1)$；
    \item $PB=AB=2$：圆 $(x-2)^2+y^2=4$，令 $y=1$ 得 $x=2\pm\sqrt{3}$，$P_{4,5}(2\pm\sqrt{3},1)$。
\end{enumerate}
均不共线，共 $5$ 个满足条件的点。
