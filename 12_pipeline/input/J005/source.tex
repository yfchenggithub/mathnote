\textbf{结论名称：}一线三等角模型（K型全等/相似）
\textbf{适用条件：}三个相等的角（常为直角）的顶点共线，且角的两边分别相交构成两个三角形；可分同侧与异侧两种情形。
\textbf{变量说明：}设点$A,B,C$共线，$\angle ABD = \angle BCE = \angle DBE = \theta$，得$\triangle ABD$与$\triangle BCE$；当$\theta=90^\circ$时称“一线三垂直”。
\textbf{核心公式：}
由等角推出$\triangle ABD \sim \triangle BCE$，对应边成比例
\[
\boxed{\frac{AB}{BC} = \frac{BD}{CE} = \frac{AD}{BE}}
\]
若有一组对应边相等（如$AB=BC$或$BD=CE$），则$\triangle ABD \cong \triangle BCE$。
\textbf{使用场景：}几何中证明全等或相似、求线段长度；平面直角坐标系中构造K型全等/相似求点坐标，解决最值与存在性问题。
\textbf{简单例子：}如图，$A,B,C$共线，$\angle ABD=\angle BCE=\angle DBE=90^\circ$，$AB=3$，$BC=2$，$BD=4$，求$CE$。
由$\triangle ABD \sim \triangle BCE$得$\frac{AB}{BC}=\frac{BD}{CE}$，即$\frac{3}{2}=\frac{4}{CE}$，解得$CE=\frac{8}{3}$。
