\textbf{结论名称：} 函数图像的左右平移变换

\textbf{适用条件：} 函数 \(y=f(x)\) 的定义域为实数集或其子区间，平移变换不改变函数的对应法则结构，仅改变自变量输入位置；适用于所有基本初等函数及其复合函数。

\textbf{变量说明：} 
\(f\)：原函数；\(x\)：自变量；\(a\)：平移量，常数 \(a>0\) 表示沿 \(x\) 轴平移的单位长度。

\textbf{核心公式：}
\[
\boxed{
\begin{aligned}
&\text{向左平移 } a \text{ 个单位：} \; y = f(x+a),\\
&\text{向右平移 } a \text{ 个单位：} \; y = f(x-a),
\end{aligned}
\qquad (a>0)
}
\]
记忆口诀：左加右减（在自变量 \(x\) 上加上 \(a\) 向左移，减去 \(a\) 向右移）。

\textbf{使用场景：} 
已知原函数解析式求水平平移后的解析式；由图像平移关系反推参数；判断两函数是否为左右平移关系；在三角函数、二次函数等图像变换问题中应用。

\textbf{简单例子：} 
将二次函数 \(y=x^2\) 的图像向右平移 \(2\) 个单位，求所得函数解析式。
解：由“左加右减”，右移 \(a=2\) 时，将 \(x\) 替换为 \(x-2\)，得 \(y=(x-2)^2\)。原顶点 \((0,0)\) 移至 \((2,0)\)，开口方向与形状不变。若向左平移 \(2\) 个单位，则得 \(y=(x+2)^2\)，顶点移至 \((-2,0)\)。
