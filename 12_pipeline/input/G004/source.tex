\[
	\textbf{椭球表面积结论}
\]

设椭圆
\[
	\frac{x^2}{a^2}+\frac{y^2}{b^2}=1
\]
绕 \(x\) 轴旋转一周，得到旋转椭球。

\[
	\boxed{
		S=2\pi\int_{-a}^{a}y\sqrt{1+\left(y'\right)^2}\,dx
	}
\]

其中
\[
	y=b\sqrt{1-\frac{x^2}{a^2}}.
\]

\[
	\textbf{情形一：}a>b
\]

此时长轴在旋转轴上，令
\[
	e=\sqrt{1-\frac{b^2}{a^2}},
\]
则
\[
	\boxed{
		S=2\pi b^2\left(1+\frac{a}{be}\arcsin e\right)
	}
\]

也可写为
\[
	\boxed{
		S=2\pi b^2+\frac{2\pi ab}{e}\arcsin e
	}
\]

\[
	\textbf{情形二：}a<b
\]

此时短轴在旋转轴上，令
\[
	e=\sqrt{1-\frac{a^2}{b^2}},
\]
则
\[
	\boxed{
		S=2\pi b^2\left(1+\frac{1-e^2}{e}\operatorname{artanh}e\right)
	}
\]

其中
\[
	\operatorname{artanh}e
	=
	\frac12\ln\frac{1+e}{1-e}.
\]

也可写为
\[
	\boxed{
		S=2\pi b^2+\frac{2\pi a^2}{e}\operatorname{artanh}e
	}
\]

\[
	\textbf{特殊情形：}a=b=R
\]

此时椭球退化为球，表面积为
\[
	\boxed{
		S=4\pi R^2
	}
\]
