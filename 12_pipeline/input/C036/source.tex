\textbf{结论名称：} 椭圆的第一定义（到两定点距离之和为定值）

\textbf{适用条件：} 平面上两定点 \(F_1, F_2\) 的距离 \(2c = |F_1F_2|\) 满足 \(2a > 2c > 0\)，动点 \(P\) 到两定点距离之和为常数 \(2a\)。

\textbf{变量说明：} \(P\) 为椭圆上任意一点，\(F_1, F_2\) 为椭圆的两个焦点，\(2a\) 为长轴长（常数），\(2c = |F_1F_2|\) 为焦距，\(a > c > 0\)，\(b^2 = a^2 - c^2\) 为短半轴平方。

\textbf{核心公式：}
\[
\boxed{|PF_1| + |PF_2| = 2a \quad (2a > |F_1F_2|)}
\]
若焦点在 \(x\) 轴上，中心在原点，标准方程为 \(\displaystyle \frac{x^2}{a^2}+\frac{y^2}{b^2}=1\)；焦点在 \(y\) 轴上则为 \(\displaystyle \frac{y^2}{a^2}+\frac{x^2}{b^2}=1\)。

\textbf{使用场景：} 判断动点轨迹是否为椭圆、由定义直接求椭圆标准方程、焦点三角形周长分析、与焦半径相关的距离和问题。

\textbf{简单例子：} 已知两定点 \(F_1(-3,0),\,F_2(3,0)\)，动点 \(P\) 满足 \(|PF_1|+|PF_2|=10\)。则 \(2c=6\)，\(c=3\)；\(2a=10\)，\(a=5\)；\(b=\sqrt{a^2-c^2}=4\)。由定义知轨迹为焦点在 \(x\) 轴上的椭圆，标准方程为 \(\frac{x^2}{25}+\frac{y^2}{16}=1\)。
