设椭圆
\[
	E:\frac{x^2}{a^2}+\frac{y^2}{b^2}=1\quad (a>b>0),
\]
直线
\[
	l:Ax+By+C=0\quad (A,B\text{不同时为}0).
\]

椭圆上一点 \(P(x,y)\) 到直线 \(l\) 的距离为
\[
	d(P,l)=\frac{|Ax+By+C|}{\sqrt{A^2+B^2}}.
\]

记
\[
	R=\sqrt{a^2A^2+b^2B^2}.
\]

则
\[
	\max_{P\in E}(Ax+By)=R,\qquad
	\min_{P\in E}(Ax+By)=-R.
\]

因此，椭圆上一点到直线 \(l\) 的距离最小值为
\[
	d_{\min}=
	\begin{cases}
		0,                             & |C|\le R, \\[4pt]
		\dfrac{|C|-R}{\sqrt{A^2+B^2}}, & |C|>R.
	\end{cases}
\]

距离最大值为
\[
	d_{\max}=\frac{|C|+R}{\sqrt{A^2+B^2}}.
\]

即
\[
	\boxed{
		d_{\min}=
		\max\left\{0,\frac{|C|-\sqrt{a^2A^2+b^2B^2}}{\sqrt{A^2+B^2}}\right\}
	}
\]
\[
	\boxed{
		d_{\max}=
		\frac{|C|+\sqrt{a^2A^2+b^2B^2}}{\sqrt{A^2+B^2}}
	}
\]
