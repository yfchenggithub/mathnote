\textbf{结论名称：} 切线方程（点斜式）

\textbf{适用条件：} 函数 \(y=f(x)\) 在 \(x_0\) 处可导，且切线不与 \(x\) 轴垂直（即 \(f'(x_0)\) 存在有限值）。若切线垂直于 \(x\) 轴，公式不适用，需单独写成 \(x=x_0\)。

\textbf{变量说明：} \(f(x)\) 为曲线对应的函数，\((x_0, f(x_0))\) 为切点坐标，\(f'(x_0)\) 表示函数在 \(x_0\) 处的导数，即切线的斜率。

\textbf{核心公式：}
\[
\boxed{y - f(x_0) = f'(x_0)(x - x_0)}
\]

\textbf{使用场景：} 已知曲线方程及切点横坐标，直接写出切线方程；结合导数的几何意义，由切线斜率反求参数；判断某直线是否为曲线的切线。

\textbf{简单例子：} 求曲线 \(y = x^2\) 在点 \((1,1)\) 处的切线方程。  
求导得 \(f'(x) = 2x\)，于是切斜率 \(f'(1) = 2\)。代入公式得 \(y - 1 = 2(x - 1)\)，整理为 \(y = 2x - 1\)。可验证该直线在 \(x=1\) 处与曲线值相等且导数相同。
