\textbf{结论名称：} 三垂直模型（弦图）

\textbf{适用条件：} 两个直角三角形共用斜边（构成矩形）或共用直角边（构成一线三垂直）；亦可将四个全等的直角三角形拼成弦图，其中相邻三角形直角边首尾相接，围成大正方形。

\textbf{变量说明：} 直角三角形两直角边长分别为 \(a\) 与 \(b\)（不妨设 \(a\ge b>0\)），斜边长为 \(c\)。在弦图中，四个全等的直角三角形拼成边长为 \(a+b\) 的大正方形，中间形成边长为 \(a-b\) 的小正方形。

\textbf{核心公式：} 利用全等三角形对应边相等，结合面积割补可推得勾股定理
\[
\boxed{a^{2}+b^{2}=c^{2}}
\]

\textbf{使用场景：} 平面直角坐标系中遇垂直条件建系求线段长；面积法证明勾股定理；中考几何压轴题中通过构造全等或相似转化边角关系。

\textbf{简单例子：} 取 \(a=3,\;b=4\)，则 \(c=\sqrt{3^{2}+4^{2}}=5\)。弦图中大正方形面积 \((3+4)^2=49\)，中间小正方形面积 \((4-3)^2=1\)，四个直角三角形总面积 \(4\times\frac{1}{2}\times3\times4=24\)。由面积关系 \(24+1=25=5^{2}\)，验证 \(a^{2}+b^{2}=c^{2}\) 成立。
