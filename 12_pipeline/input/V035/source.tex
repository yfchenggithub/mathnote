\textbf{结论名称：}向量法求点到直线的距离

\textbf{适用条件：}已知直线 \(l\) 上一点 \(A\) 及方向向量 \(\vec{v}\neq\mathbf{0}\)，\(P\) 为平面内任意一点（该法对三维空间点线距同样适用，此处以平面情形为主）。

\textbf{变量说明：}设 \(A(x_0,y_0)\) 为直线上参考点，方向向量 \(\vec{v}=(v_x,v_y)\)，求点 \(P(x_1,y_1)\) 到直线的距离。记向量 \(\vec{AP}=(x_1-x_0,\ y_1-y_0)\)。

\textbf{核心公式：}距离为以 \(\vec{AP}\) 与 \(\vec{v}\) 为邻边的平行四边形的高：
\[
\boxed{d = \frac{|\vec{AP} \times \vec{v}|}{|\vec{v}|} = \frac{|(x_1-x_0)v_y - (y_1-y_0)v_x|}{\sqrt{v_x^2+v_y^2}}}
\]
其中“\(\times\)”表示平面向量的伪叉积（有向面积），结果为一标量。

\textbf{使用场景：}直线以点向式、参数方程或两点确定时，直接利用向量坐标计算距离，避免先求直线一般式再代入距离公式，减少运算环节；在立体几何中求点线距原理一致。

\textbf{简单例子：}求点 \(P(5,7)\) 到过点 \(A(1,2)\) 且方向向量为 \(\vec{v}=(3,4)\) 的直线距离。\\
解：\(\vec{AP}=(4,5)\)，叉积 \(4\times4-5\times3=1\)，\(|\vec{v}|=\sqrt{3^2+4^2}=5\)，故 \(d=\dfrac{1}{5}\)。验证：直线一般式为 \(4x-3y+2=0\)，代入 \(P\) 得 \(\dfrac{|20-21+2|}{5}=\dfrac{1}{5}\)，一致。
