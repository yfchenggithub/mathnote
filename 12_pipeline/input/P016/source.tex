\textbf{结论名称：} 两平行线间的距离公式

\textbf{适用条件：} 两直线方程写成一般式且对应的一次项系数完全相同（或成比例后可化为相同），即两条直线平行且不重合。

\textbf{变量说明：} 设两直线为 \(l_1: Ax+By+C_1=0\)，\(l_2: Ax+By+C_2=0\)，其中 \(A,B\) 为公共系数，\(C_1,C_2\) 为常数且 \(C_1\neq C_2\)。

\textbf{核心公式：}
\[
\boxed{d = \frac{|C_1 - C_2|}{\sqrt{A^{2}+B^{2}}}}
\]

\textbf{使用场景：} 直接求两平行直线间的距离；推导平行四边形、梯形的高；判断圆与直线的位置关系时计算平行切线间距等。

\textbf{简单例子：} 求平行线 \(3x+4y-5=0\) 与 \(3x+4y+10=0\) 的距离。\\
取 \(A=3,\;B=4,\;C_1=-5,\;C_2=10\)，代入公式：
\[
d = \frac{|-5-10|}{\sqrt{3^2+4^2}} = \frac{15}{5}=3.
\]
