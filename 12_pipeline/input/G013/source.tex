\textbf{结论名称：} 线面平行性质定理

\textbf{适用条件：} 一条直线与一个平面平行，且该直线在另一个平面内，两平面相交于一条交线。

\textbf{变量说明：} $a$ 为直线，$\alpha$、$\beta$ 为平面，$l$ 为 $\alpha$ 与 $\beta$ 的交线。

\textbf{核心公式：}
\[
\boxed{\left.\begin{array}{c}
a \parallel \alpha \\[2pt]
a \subset \beta \\[2pt]
\alpha \cap \beta = l
\end{array}\right\} \;\Rightarrow\; a \parallel l}
\]

\textbf{使用场景：} 已知线面平行，需证明线线平行；在截面问题或线面平行判定中转化为交线平行。

\textbf{简单例子：} 在长方体 $ABCD\,A_1B_1C_1D_1$ 中，$A_1B_1 \parallel$ 底面 $ABCD$，又 $A_1B_1 \subset$ 平面 $A_1B_1CD$，且底面 $ABCD \cap$ 平面 $A_1B_1CD = CD$，由性质定理得 $A_1B_1 \parallel CD$。
