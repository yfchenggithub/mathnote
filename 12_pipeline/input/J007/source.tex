\textbf{结论名称：} 相似三角形面积比等于相似比的平方

\textbf{适用条件：} 两个三角形相似（或更一般地，所有对应线段成比例的相似图形）

\textbf{变量说明：} 设两个相似三角形的相似比为 \(k\)（对应边长之比），面积分别为 \(S_1, S_2\)；对应高、中线、角平分线、周长等任一对对应线段的比均为 \(k\)。

\textbf{核心公式：} 
\[
\boxed{\frac{S_1}{S_2} = k^2 = \left(\frac{a_1}{a_2}\right)^2 = \left(\frac{h_1}{h_2}\right)^2 = \left(\frac{C_1}{C_2}\right)^2}
\]
其中 \(a, h, C\) 分别表示对应边长、对应高、周长等。

\textbf{使用场景：} 由相似比快速求面积比，或由面积比反求相似比；在圆锥曲线中，利用相似三角形面积比等于对应线段平方比进行面积比例的速算与转化。

\textbf{简单例子：} 两个相似三角形的对应边长比为 \(2:3\)，即 \(k=\frac{2}{3}\)，则面积比 \(\frac{S_1}{S_2} = \left(\frac{2}{3}\right)^2 = \frac{4}{9}\)。若较小三角形面积 \(S_1 = 8\)，则较大三角形面积 \(S_2 = 8 \times \frac{9}{4} = 18\)。
