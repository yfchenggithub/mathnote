\textbf{结论名称：} 椭圆焦点弦长公式

\textbf{适用条件：} 椭圆标准方程 \(\frac{x^2}{a^2}+\frac{y^2}{b^2}=1\ (a>b>0)\)，焦点在 \(x\) 轴上；弦过椭圆的一个焦点，且弦所在直线的倾斜角 \(\theta\)（与 \(x\) 轴正方向的夹角）已知；当 \(\theta=90^\circ\) 时公式同样适用（得到通径长）。

\textbf{变量说明：} \(a\) 为长半轴长，\(b\) 为短半轴长，\(c=\sqrt{a^2-b^2}\) 为半焦距，\(\theta\) 为弦的倾斜角，\(L\) 为过焦点的弦长。

\textbf{核心公式：} \[ \boxed{L = \frac{2ab^2}{a^2 - c^2\cos^2\theta}} \]

\textbf{使用场景：} 已知椭圆方程与过焦点的弦的倾斜角，快速计算弦长，避免联立方程组；也可由弦长反求倾斜角或椭圆参数。

\textbf{简单例子：} 椭圆 \(\frac{x^2}{4}+\frac{y^2}{3}=1\)，右焦点 \(F(1,0)\)，过 \(F\) 的弦倾斜角 \(\theta=60^\circ\)。此时 \(a=2,\ b=\sqrt{3},\ c=1\)，\(\cos60^\circ=\frac12\)，代入公式：
\[ L = \frac{2\times 2\times 3}{4 - 1^2\times\left(\frac12\right)^2} = \frac{12}{4-\frac14} = \frac{12}{\frac{15}{4}} = \frac{16}{5}. \]
所得弦长 \(16/5\) 可用直线参数方程直接验证。
