\textbf{结论名称：} 不动点法求分式线性递推数列的通项

\textbf{适用条件：} 递推形式为 \( a_{n+1} = \dfrac{A a_n + B}{C a_n + D} \)，其中 \(C \neq 0\)，且 \(AD - BC \neq 0\)（否则数列退化）。不动点方程 \( x = \dfrac{Ax + B}{Cx + D} \) 在实数或复数范围内有解。

\textbf{变量说明：} \(A,B,C,D\) 为给定常数；\(a_n\) 为第 \(n\) 项；不动点方程的根记为 \(\alpha,\beta\)（可能是单根或重根）。

\textbf{核心公式：}
\begin{itemize}
\item 若有两个不同不动点 \(\alpha \neq \beta\)，则
\[
\boxed{ \dfrac{a_{n+1} - \alpha}{a_{n+1} - \beta} = \dfrac{A - \alpha C}{A - \beta C} \cdot \dfrac{a_n - \alpha}{a_n - \beta} }
\]
数列 \(\left\{ \dfrac{a_n - \alpha}{a_n - \beta} \right\}\) 为等比数列。

\item 若有重根 \(\alpha = \beta\)，则
\[
\boxed{ \dfrac{1}{a_{n+1} - \alpha} = \dfrac{1}{a_n - \alpha} + \dfrac{2C}{A + D} }
\]
数列 \(\left\{ \dfrac{1}{a_n - \alpha} \right\}\) 为等差数列。
\end{itemize}

\textbf{使用场景：} 高考模拟题中求分式递推数列的通项，竞赛中处理一阶有理递推的降维与标准化。

\textbf{简单例子：} 设 \(a_{n+1} = \dfrac{3a_n - 1}{a_n + 1}\)，\(a_1 = 2\)。不动点方程 \(x = \dfrac{3x-1}{x+1}\)，得 \((x-1)^2 =0\)，重根 \(\alpha =1\)。由重根公式：
\[
\dfrac{1}{a_{n+1} - 1} = \dfrac{1}{a_n - 1} + \dfrac{2}{3+1} = \dfrac{1}{a_n - 1} + \dfrac12 .
\]
故 \(\dfrac{1}{a_n - 1} = \dfrac{1}{a_1 - 1} + (n-1)\cdot\dfrac12 = 1 + \dfrac{n-1}{2} = \dfrac{n+1}{2}\)，从而通项 \(a_n = 1 + \dfrac{2}{n+1}\)。
