\textbf{结论名称：} 同角三角函数的基本关系

\textbf{适用条件：} 
平方关系 \(\sin^2\alpha+\cos^2\alpha=1\) 对任意 \(\alpha\in\mathbb{R}\) 成立；商数关系 \(\tan\alpha=\frac{\sin\alpha}{\cos\alpha}\) 要求 \(\cos\alpha\neq0\)，即 \(\alpha\neq\frac{\pi}{2}+k\pi,\ k\in\mathbb{Z}\).

\textbf{变量说明：} 
\(\alpha\) 为任意角（实数或角度制），\(\sin\alpha,\cos\alpha,\tan\alpha\) 分别为角 \(\alpha\) 的正弦、余弦、正切.

\textbf{核心公式：} 
\[ \boxed{\sin^2\alpha + \cos^2\alpha = 1} \]
\[ \boxed{\tan\alpha = \frac{\sin\alpha}{\cos\alpha}} \]

\textbf{使用场景：} 
已知同角的一个三角函数值求其余三角函数值（知一求二）；化简含同角正弦、余弦、正切的三角表达式；证明三角恒等式.

\textbf{简单例子：} 
已知 \(\sin\alpha = \frac{3}{5}\) 且 \(\alpha\) 为第一象限角，则
\[ \cos\alpha = \sqrt{1-\sin^2\alpha} = \sqrt{1-\frac{9}{25}} = \frac{4}{5}, \qquad \tan\alpha = \frac{\sin\alpha}{\cos\alpha} = \frac{3/5}{4/5} = \frac{3}{4}. \]
