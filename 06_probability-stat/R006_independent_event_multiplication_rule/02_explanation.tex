\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	独立事件表示：一个事件是否发生，不会改变另一个事件发生的可能性；因此，两事件同时发生的概率可以直接相乘。

	\medskip

	\textbf{\textcolor{CExplanation}{核心拆解}}

	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（独立性定义）：}]
		      事件 $A$ 与 $B$ 相互独立的定义是
		      \[
			      P(AB)=P(A)P(B).
		      \]
		      当 $P(A)>0$ 时，该条件等价于
		      \[
			      P(B\mid A)=P(B).
		      \]
		      同理，当 $P(B)>0$ 时，该条件等价于
		      \[
			      P(A\mid B)=P(A).
		      \]

		\item[\textbf{要点二（乘积应用）：}]
		      已知事件独立时，可以直接利用
		      \[
			      P(AB)=P(A)P(B)
		      \]
		      计算积事件的概率。
	\end{description}

	\medskip

	\textbf{\textcolor{CExplanation}{直观模型（面积模型）}}

	为了帮助理解，可以在面积为 $1$ 的单位正方形中构造一个模型：令事件 $A$ 对应宽为 $P(A)$ 的竖条区域，事件 $B$ 对应高为 $P(B)$ 的横条区域，则两区域交集的面积为
	\[
		P(A)P(B).
	\]
	这个模型可以直观展示独立事件的乘积规律，但它只是辅助理解的构造模型，并不表示任意实际概率问题中的事件区域都天然具有这种形状。

	\medskip

	\textbf{\textcolor{CExplanation}{代数意义（乘积分解）}}

	公式
	\[
		P(AB)=P(A)P(B)
	\]
	将联合概率分解为两个边缘概率的乘积，从而简化涉及独立事件的概率计算。

	\medskip

	\textbf{\textcolor{CExplanation}{考点价值（高频基础）}}

	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接代公式）：}
		      已知独立事件的概率 $P(A),P(B)$，直接求 $P(AB)$。

		\item \textbf{考法二（逆用公式）：}
		      已知 $P(AB)$、$P(A)$，且 $A,B$ 独立并满足 $P(A)>0$，求 $P(B)$。
	\end{itemize}

	\medskip

	\textbf{\textcolor{CExplanation}{顿悟点}}

	独立才可直接相乘；若题目没有给出独立性，就不能盲目套用
	\[
		P(AB)=P(A)P(B).
	\]

	\medskip

	\textbf{\textcolor{CExplanation}{使用场景}}

	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（多次独立试验）：}
		      抛一枚质地均匀的硬币两次，求两次都正面向上的概率。

		\item \textbf{场景二（不同试验组合）：}
		      掷骰子得点数 $6$ 与抽奖中奖；若题目说明两事件独立，则可使用乘积公式。
	\end{itemize}

\end{explanationbox}
