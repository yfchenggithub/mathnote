\textbf{\textcolor{CExample}{例 1（基础）}}

\textbf{\textcolor{CExample}{题目：}}
已知 $P(A)=0.6$，$P(B)=0.7$，且事件 $A$ 与 $B$ 相互独立。求 $P(AB)$ 和 $P(\overline{A}B)$。

\textbf{\textcolor{CExample}{解题步骤：}}

\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]

    \item[\textbf{第一步（识别独立性）：}]
    由于 $A$ 与 $B$ 相互独立，所以
    \[
        P(AB)=P(A)P(B).
    \]
    又因为独立事件的补事件仍保持独立，所以 $\overline{A}$ 与 $B$ 也相互独立，从而
    \[
        P(\overline{A}B)=P(\overline{A})P(B).
    \]

    \item[\textbf{第二步（计算 $P(AB)$）：}]
    \[
        P(AB)
        =
        P(A)P(B)
        =
        0.6\times 0.7
        =
        0.42.
    \]

    \par\textbf{理由：}
    $A$ 与 $B$ 相互独立，可以直接使用乘积公式。

    \item[\textbf{第三步（计算 $P(\overline{A}B)$）：}]
    先求
    \[
        P(\overline{A})=1-P(A)=1-0.6=0.4,
    \]
    再求
    \[
        P(\overline{A}B)
        =
        P(\overline{A})P(B)
        =
        0.4\times 0.7
        =
        0.28.
    \]

    \par\textbf{理由：}
    $\overline{A}$ 与 $B$ 相互独立，可以使用乘积公式。

\end{description}

\textbf{\textcolor{CExample}{关键结论：}}
\textbf{独立事件同时发生的概率可直接相乘；对其中一个事件取补后，独立性仍保持。}

\textbf{\textcolor{CExample}{例 2（稍变形）}}

\textbf{\textcolor{CExample}{题目：}}
甲、乙两人独立射击同一目标，甲命中率为 $0.8$，乙命中率为 $0.7$。求目标被击中的概率，即至少一人命中的概率。

\textbf{\textcolor{CExample}{解题步骤：}}

\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]

    \item[\textbf{第一步（求均不命中概率）：}]
    设 $A$ 表示甲击中，$B$ 表示乙击中。则 $\overline{A}$ 表示甲未击中，$\overline{B}$ 表示乙未击中。

    由于甲、乙射击结果相互独立，$\overline{A}$ 与 $\overline{B}$ 也相互独立，因此
    \[
        P(\overline{A}\,\overline{B})
        =
        P(\overline{A})P(\overline{B})
        =
        (1-0.8)(1-0.7)
        =
        0.2\times 0.3
        =
        0.06.
    \]

    \item[\textbf{第二步（利用对立事件）：}]
    目标被击中事件记为 $C$，则
    \[
        C=\overline{\overline{A}\,\overline{B}},
    \]
    所以
    \[
        P(C)
        =
        1-P(\overline{A}\,\overline{B})
        =
        1-0.06
        =
        0.94.
    \]

    \par\textbf{理由：}
    “至少一人命中”与“两人均未命中”互为对立事件。

    \item[\textbf{第三步（换一种方法核对结果）：}]
    也可以使用加法公式：
    \[
        P(A\cup B)
        =
        P(A)+P(B)-P(AB).
    \]
    因为 $A$ 与 $B$ 相互独立，
    \[
        P(AB)=P(A)P(B)=0.8\times 0.7=0.56.
    \]
    因此
    \[
        P(A\cup B)
        =
        0.8+0.7-0.56
        =
        0.94.
    \]

    \par\textbf{理由：}
    两种计算方法所得结果一致，说明上述计算无误。

\end{description}

\textbf{\textcolor{CExample}{关键结论：}}
\textbf{求“至少一个发生”的概率时，常可先求“一个都不发生”的概率，再利用对立事件计算。}

\textbf{\textcolor{CExample}{例 3（综合应用）}}

\textbf{\textcolor{CExample}{题目：}}
某系统由三个元件组成。设 $A_1,A_2,A_3$ 分别表示三个元件正常工作，且这三个事件相互独立，每个元件正常工作的概率均为 $0.9$。系统正常工作的条件是至少有两个元件正常。求系统正常工作的概率。

\textbf{\textcolor{CExample}{解题步骤：}}

\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]

    \item[\textbf{第一步（事件分解）：}]
    设 $E$ 表示系统正常工作，则 $E$ 可以表示为以下四个互斥事件的并：
    \[
        E
        =
        A_1A_2A_3
        \cup
        A_1A_2\overline{A_3}
        \cup
        A_1\overline{A_2}A_3
        \cup
        \overline{A_1}A_2A_3.
    \]

    \par\textbf{理由：}
    系统正常工作包括“三个元件都正常”以及“恰好两个元件正常”三种情形，这四种情形两两互斥。

    \item[\textbf{第二步（计算各情形的概率）：}]
    由于 $A_1,A_2,A_3$ 相互独立，其补事件参与组成的相应事件也可按乘积计算，因此
    \[
        P(A_1A_2A_3)
        =
        0.9^3
        =
        0.729,
    \]
    且
    \[
        P(A_1A_2\overline{A_3})
        =
        P(A_1\overline{A_2}A_3)
        =
        P(\overline{A_1}A_2A_3)
        =
        0.9^2\times 0.1
        =
        0.081.
    \]

    \par\textbf{理由：}
    每个元件故障的概率为
    \[
        1-0.9=0.1.
    \]

    \item[\textbf{第三步（求和）：}]
    因为上述四个事件互斥，所以
    \[
        P(E)
        =
        0.729+3\times 0.081
        =
        0.729+0.243
        =
        0.972.
    \]

\end{description}

\textbf{\textcolor{CExample}{关键结论：}}
\textbf{复杂的独立事件组合问题，常可先分解为若干互斥情形，再分别使用乘积公式计算并求和。}
