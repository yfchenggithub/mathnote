\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	概率总和为1，正面难则反面易。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（公式结构）：}] 概率公理直接导出 $P(\overline{A}) = 1 - P(A)$，表达对立事件概率互补。
		\item[\textbf{要点二（正难则反）：}] 当直接计算 $P(A)$ 过程繁琐时，转化为计算 $P(\overline{A})$ 再取补，往往简化计算。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（样本空间分割）}}

	整个样本空间 $\Omega$ 被事件 $A$ 与 $\overline{A}$ 分割成两个互斥且完备的区域，两者无交且并集为 $\Omega$，概率和恒为1。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（互补关系）}}

	事件 $A$ 与其对立事件的概率满足 $P(A) + P(\overline{A}) = 1$，是概率中最基本的代数方程。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高频工具）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接应用）：} 求复杂事件的概率时，先判断其对立事件是否更易计算，再套用公式。
		\item \textbf{考法二（综合问题）：} 与条件概率、独立事件、古典概型等结合，常出现在概率解答题的第一步。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{不要总想正面进攻；先问问反面是否更简单。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（复杂概率）：} 古典概型中事件包含样本点较多或分类复杂时，反面往往样本点少。
		\item \textbf{场景二（连续取逆）：} 涉及“至少”“至多”等语句的问题，通常转化为对立事件处理。
	\end{itemize}
\end{explanationbox}
