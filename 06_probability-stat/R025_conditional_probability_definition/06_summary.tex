\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	条件概率$P(B \mid A)=\dfrac{P(AB)}{P(A)}$是在事件$A$发生的条件下事件$B$的概率，相当于在原空间中划定$A$为新的全集重新度量。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（随机事件）：} $A,B$是同一随机试验中的事件。
		\item \textbf{条件2（正概率）：} $P(A)>0$，保证分母非零。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（混淆定义）：} 区分$P(B \mid A)$与$P(AB)$，前者是条件概率，后者是交概率。
		\item \textbf{检查项（分母非零）：} 使用公式前务必确认$P(A)>0$。
	\end{itemize}
\end{summarybox}
