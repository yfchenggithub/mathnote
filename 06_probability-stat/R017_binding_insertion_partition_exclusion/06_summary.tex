\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	\textbf{排列组合计数，见相邻用捆绑，见不相邻用插空，见相同物品分配用隔板，见正面复杂用排除。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件一（相邻问题）：} 题目出现“相邻”“必须排一起”等关键词，使用捆绑法。
		\item \textbf{条件二（不相邻问题）：} 题目出现“不相邻”“不能排一起”等关键词，使用插空法。
		\item \textbf{条件三（相同分配）：} 物品相同且需分给不同对象，每个对象至少得到一个，使用隔板法。
		\item \textbf{条件四（正难则反）：} 正面分类情况多，反面简单，使用排除法（总数减去不符合）。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（条件核对）：} 捆绑法勿漏内部排列；插空法空位包括两端；隔板法只用于相同元素且每对象至少一个。
		\item \textbf{检查项（模型匹配）：} 先判断元素相同还是不同，对象是否可区分，是否满足至少一个等条件，再选择对应策略。
	\end{itemize}

\end{summarybox}
