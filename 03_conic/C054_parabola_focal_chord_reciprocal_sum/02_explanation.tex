\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	抛物线焦点弦两段长$|AF|$和$|BF|$的倒数之和始终为$\frac{2}{p}$，与弦的倾斜程度无关，只与抛物线本身参数$p$有关。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（焦半径公式）：}]
			对于抛物线$y^2=2px$，其上点$A(x_1,y_1)$到焦点$F$的距离$|AF| = x_1 + \frac{p}{2}$，同理$|BF| = x_2 + \frac{p}{2}$。这是后续计算的基础。
		\item[\textbf{要点二（设线联立）：}]
			设过焦点直线方程为$x = my + \frac{p}{2}$，联立抛物线并利用韦达定理，可将长度倒数之和化简为常数$\frac{2}{p}$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（抛物线定义）}}
	抛物线上任意点到焦点的距离等于其到准线的距离。因此$|AF| = x_1 + \frac{p}{2}$，$|BF| = x_2 + \frac{p}{2}$。倒数和定值反映了焦点弦上两点与准线之间的距离关系，体现了抛物线的几何特征。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（坐标消参）}}
	通过设直线方程、联立、消元，将长度倒数之和表示为$x_1,x_2$的对称式，利用韦达定理化简，最终消去变量$x_1,x_2$，只留下参数$p$，得到一个与弦无关的定值。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（解题技巧）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接套用）：} 已知抛物线方程和一段焦点弦长，直接利用结论求另一段长，节省计算时间。
		\item \textbf{考法二（反求参数）：} 已知倒数和的值，可以直接求出$p$，从而确定抛物线方程。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	记住焦半径公式$|AF|=x_1+\frac{p}{2}$，并将过焦点的直线设为$x=my+\frac{p}{2}$，利用韦达定理处理对称量，是此类焦点弦问题的通用处理思路。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（求另一段长）：} 已知$|AF|$，求$|BF|$。
		\item \textbf{场景二（反求参数）：} 已知$\frac{1}{|AF|}+\frac{1}{|BF|}$的值，求$p$。
	\end{itemize}

\end{explanationbox}
