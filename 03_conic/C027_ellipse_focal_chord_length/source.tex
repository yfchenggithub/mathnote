\[
	\boxed{
		\text{椭圆焦点弦长的斜率公式}
	}
\]

设椭圆
\[
	\frac{x^2}{a^2}+\frac{y^2}{b^2}=1
	\quad (a>b>0),
\]
右焦点为
\[
	F_2(c,0),\qquad c^2=a^2-b^2.
\]

若过右焦点 \(F_2\) 的直线斜率为 \(k\)，即
\[
	y=k(x-c),
\]
与椭圆交于 \(P,Q\) 两点，则焦点弦长为
\[
	\boxed{
		|PQ|=\frac{2ab^2(1+k^2)}{a^2k^2+b^2}
	}
\]

同理，若过左焦点 \(F_1(-c,0)\) 的直线为
\[
	y=k(x+c),
\]
与椭圆交于 \(P,Q\) 两点，也有
\[
	\boxed{
		|PQ|=\frac{2ab^2(1+k^2)}{a^2k^2+b^2}
	}
\]

\[
	\textbf{注意：}
\]
该公式适用于斜率存在的焦点弦。当焦点弦垂直于长轴时，
\[
	x=c
\]
或
\[
	x=-c,
\]
此时弦长为通径长：
\[
	\boxed{
		|PQ|=\frac{2b^2}{a}
	}
\]
