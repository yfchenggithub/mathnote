\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	椭圆就是到两个固定点的距离之和保持不变的所有点组成的图形。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（两定点固定）：}] 焦点 $F_1,F_2$ 固定，两点距离 $2c$ 为定值。
		\item[\textbf{要点二（和定值）：}] 椭圆上的任意一点 $P$ 都满足 $|PF_1|+|PF_2|=2a$，$2a>2c$。
		\item[\textbf{要点三（参数关系）：}] $a$、$b$、$c$ 满足 $b^2=a^2-c^2$，其中 $b$ 是短半轴长。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（定义基础）}}

	定义本身给出一种生成椭圆的几何方式：到两定点距离和恒定。这是椭圆最根本的性质，也是推导其他性质（如标准方程、焦半径、准线）的出发点。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（坐标表达）}}

	通过建立坐标系（常用中点为原点、焦点所在直线为坐标轴），将定义式 $|PF_1|+|PF_2|=2a$ 坐标化，经过平方化简可以整理成标准方程 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ 或 $\frac{y^2}{a^2}+\frac{x^2}{b^2}=1$，其中 $b^2=a^2-c^2$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（解题转化）}}

	椭圆定义是圆锥曲线中的核心工具之一，常用于以下场合：
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（轨迹方程）：} 题干中涉及“到两定点距离之和为常数”时，直接利用定义求轨迹。
		\item \textbf{考法二（焦点三角形）：} 椭圆上一点与两焦点构成的三角形，常结合定义与余弦定理求解。
		\item \textbf{考法三（最值问题）：} 利用定义转化距离和，结合三角形不等式或函数单调性求最值。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{定义是“已知距离和”的显化，遇到距离和相关的条件应首先想到椭圆定义。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（直接套定义）：} 己知动点到两定点距离和为常数，且常数大于两定点距离。
		\item \textbf{场景二（转换条件）：} 题干中给出两圆内切或外切、线段和最小值等条件，可转化为距离和为定值。
	\end{itemize}
\end{explanationbox}
