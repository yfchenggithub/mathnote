\begin{summarybox}
\textbf{一句话：} $F\notin\ell$ 时，焦准等距或距离比为 $1$ 刻画抛物线。
\[
PF=PH>0,\qquad e=1,\qquad p=d(F,\ell)>0.
\]
顶点原点、右开口：$y^2=2px$，$F(p/2,0)$，$\ell:x=-p/2$。
$PF=x+p/2\ge p/2$；最短焦半径在顶点取得。
几何上也可识别为“过焦点、切准线的圆”的圆心轨迹。

\textbf{最后四查。}
\begin{enumerate}[leftmargin=*]
\item 焦点是否不在准线上，点到准线是否量垂距？
\item 顶点是否原点；若不是，是否使用平移后的方程？
\item $p$、$p/2$、$2p$ 的几何意义是否一致？
\item 给定焦半径是否至少为 $p/2$，所得点能否代回？
\end{enumerate}
\end{summarybox}

\begin{summarybox}
\textbf{考场上用哪种方法？先看问题要的是什么。}
\begin{enumerate}[leftmargin=*]
\item \textbf{求焦点距离，最快：}先变换 $PF=d(P,\ell)$；右开口标准式直接用 $PF=x+p/2$，免开平方。
\item \textbf{焦点、准线求方程，最快：}若准线水平或竖直，直接列“点到点距离平方=点到线距离平方”，做平方差。
\item \textbf{想真正理解方程来源，门槛最低：}画 $P,Q,F$ 的直角三角形，用勾股和平方差推出 $y^2=2px$。
\item \textbf{只求最短焦半径或最小值，门槛最低：}垂线段最短 $FD\le FH$，再用三角形不等式 $FH\le FP+PH$，得 $PF\ge p/2$。
\item \textbf{看到圆过焦点且切准线：}直接把圆心当 $P$，由半径得到 $PF=d(P,\ell)$。
\item \textbf{准线倾斜：}用点线距离公式，必要时先求垂足 $D$ 和中点顶点 $V$，不能仅平移标准式。
\end{enumerate}
\end{summarybox}

\begin{summarybox}
\textbf{三句记忆法：}
\[
\boxed{\text{点与线等距}}\ \Longrightarrow\
\boxed{\text{焦点与准线}}\ \Longrightarrow\
\boxed{\text{抛物线}}.
\]
\textbf{求方程：}“找垂足 $D$，取中点 $V$，看开口；平方差，出 $2p$。”

\textbf{做题看到 $PF$：}“与其开根号，不如量垂距。”

\textbf{只求最小 $PF$：}“直线到焦点最近是 $p$，动点到两边等距，所以每边至少 $p/2$。”

\textbf{30 秒检索练习（先遮答案）。}
\begin{enumerate}[leftmargin=*]
\item $y^2=6x$：焦准距 $p$、焦点、准线分别是什么？
\item $F=(2,0)$，$\ell:x=6$：向哪边开口，顶点在哪，方程是什么？
\item $y^2=8x$：若 $PF=1$ 是否存在点？若 $PF=2$ 有几个？
\end{enumerate}
\textbf{答案：}
\begin{enumerate}[leftmargin=*]
\item $p=3$，$F=(3/2,0)$，$\ell:x=-3/2$。
\item 向左；$V=(4,0)$；$y^2=-8(x-4)$。
\item $PF\ge2$，所以 $PF=1$ 无点；$PF=2$ 恰为顶点一处。
\end{enumerate}

\textbf{完成标准：}不看公式，也能解释“为什么必须量垂距”、
“为什么先取顶点中点”、
“为什么一眼把焦半径换成 $x+p/2$”。
\end{summarybox}
