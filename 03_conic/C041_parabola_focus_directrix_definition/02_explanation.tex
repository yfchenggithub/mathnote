\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	到焦点的距离等于到准线的距离，这是抛物线特有的几何条件，直接用于建立方程。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（距离等量）：}] 距离比值等于$1$，即$|PF| = d(P,l)$。
		\item[\textbf{要点二（方程建立）：}] 通过设坐标代入距离公式，可推出标准方程$y^2 = 2px$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（距离相等）}}

	抛物线上任意一点到焦点的距离与到准线的距离始终相等，这是抛物线的原始定义。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（方程转化）}}

	将距离等式用坐标表示，整理后得到二次方程，即为抛物线方程。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（常见题型）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求轨迹方程）：} 已知焦点和准线，直接由定义写出曲线方程。
		\item \textbf{考法二（转化距离）：} 抛物线上的点到焦点距离与到准线距离可相互转化，简化计算。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	第二定义与椭圆、双曲线的统一定义（比值$e$）不同，抛物线的离心率$e=1$。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（已知条件）：} 已知焦点坐标和准线方程，求抛物线方程。
		\item \textbf{场景二（动点问题）：} 涉及抛物线上的点到定点或定直线距离的最值问题。
	\end{itemize}
\end{explanationbox}
