\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	平行于渐近线且不重合的直线与双曲线有且仅有一个交点。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（标准曲线）：} 双曲线方程为标准形式 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$ 或 $\frac{y^2}{a^2}-\frac{x^2}{b^2}=1$。
		\item \textbf{条件2（直线平行）：} 直线斜率等于渐近线斜率 $\pm\frac{b}{a}$（或 $\pm\frac{a}{b}$）。
		\item \textbf{条件3（截距非零）：} 直线截距 $c\neq0$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（截距为零）：} 当 $c=0$ 时直线为渐近线，无交点，判断时须检查截距。
		\item \textbf{检查项（焦点轴）：} 注意双曲线焦点位置，正确使用渐近线斜率公式。
	\end{itemize}

\end{summarybox}
