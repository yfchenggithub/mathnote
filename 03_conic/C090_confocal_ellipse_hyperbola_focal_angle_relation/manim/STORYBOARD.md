# C090 共焦曲线焦角动画

事实源：本 UID 正式六段 TeX 与 meta.json；只读，不修改数学源或 PDF。
数学审计：三角形的两腰 aE±aH；余弦定理给半角恒等式；柯西等号
e1=tan(theta/2), e2=cot(theta/2)，在有效离心率范围内仅锐角可取。

独立模型：c=2，aE=4；aH 在 .6 与 1.65 之间连续变化。
每帧公共点为 (aE*aH/c, sqrt((aE²-c²)(c²-aH²))/c)，绝非沿两条
固定曲线的任意运动。椭圆固定、双曲线随参数变化；坐标两轴等尺度。
显示的是右上交点，另三个交点由对称性得到，不暗示交点唯一。

| 时间约/s | 教学任务 | 关键状态 |
|---|---|---|
| 0–1.5 | 建立共同焦点、椭圆及双曲线 | 焦点固定，P 为右上公共点 |
| 1.5–8.5 | 改变双曲线，观察三角形 | 两腰和为8，差为2aH，焦角联动 |
| 8.5–11 | 从和差切入恒等式 | 余弦定理消元，逐步揭示半角式 |
| 11–16 | 参数再变化，观察恒等式 | 两项各变而和始终为1；停在aH=1 |
| 16–20 | 推论等号的精确例证 | P=(2,3)，两腰5、3，sinθ=4/5 |
| 20–24 | 返回初始参数与布局 | 平滑回到起点，固定品牌不淡出 |

主公式中的量全程由同一模型生成。数值采用独立四舍五入，两个显示分量
对本运动轨迹的舍入和需由全帧检查确认。等号段为精确分数，不用近似值冒充精确值。
默认576×1024，24FPS MP4，经冻结导出器生成12FPS无限循环GIF。
工程复用仅限 scripts/manim/ 的冻结工具，没有导入其他 UID 的实现。
颜色：蓝色实线椭圆；橙色虚线双曲线；绿色焦半径和角；金色P。
