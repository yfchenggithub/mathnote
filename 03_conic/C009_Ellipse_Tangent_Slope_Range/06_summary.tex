\begin{summarybox}
\textbf{一句话：过点定截距，相切定平方；先查竖直，再用韦达。}

\textbf{1. 只记两个母式，就能临场推导所有结论：}
\[
\boxed{m=y_0-kx_0},\qquad
\boxed{m^2=a^2k^2+b^2}.
\]
合并即为
\[
\boxed{(a^2-x_0^2)k^2+2x_0y_0k+(b^2-y_0^2)=0.}
\]

\textbf{2. 斜率全集与过点分类：}
\begin{itemize}
\item 整条椭圆的\textbf{有限切线斜率全集}为 $\mathbb R$，此外还有 $x=\pm a$ 两条竖直切线。
\item 记 $S=x_0^2/a^2+y_0^2/b^2$：$S<1$ 无切线，$S=1$ 一条，$S>1$ 两条（包括竖直切线）。
\item $x_0^2\ne a^2$ 且 $S>1$ 时：
\[
k_1+k_2=-\frac{2x_0y_0}{a^2-x_0^2},\quad
k_1k_2=\frac{b^2-y_0^2}{a^2-x_0^2}.
\]
\item $x_0=\pm a$ 时先写 $x=x_0$；若 $y_0\ne0$，另一条的斜率为 $\frac{y_0^2-b^2}{2x_0y_0}$。
\end{itemize}

\textbf{3. 四种证明怎么选：}
\begin{itemize}
\item \textbf{最快：}直接代 $m=y_0-kx_0$ 到切线判定式；三步结束。
\item \textbf{通法：}联立椭圆与直线，令判别式为零。
\item \textbf{求切点：}设点 $T(u,v)$，用切线 $ux/a^2+vy/b^2=1$。
\item \textbf{讲直觉：}三角参数解释截距极值；缩放为圆解释内外点切线条数。
\end{itemize}

\textbf{4. 高频迁移：}两条非竖直切线互相垂直时 $k_1k_2=-1$，加上竖直与水平的特殊情况，得到\textbf{蒙日圆}
\[
\boxed{x_0^2+y_0^2=a^2+b^2}.
\]

\textbf{考场口诀：}“定斜率，移直线；定外点，转直线；方程求有限，竖直单独看。”
\end{summarybox}
