\begin{explanationbox}
\textbf{\textcolor{CExplanation}{一句话直觉}}

在平面内，到两个定点的距离之比为常数（$\lambda>0,\lambda\neq1$）的点，其轨迹是一个圆，这个圆称为阿波罗尼斯圆.

\medskip

\textbf{\textcolor{CExplanation}{核心拆解}}

\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
  \item[\textbf{要点一（距离比条件）：}]
  \[
    \frac{PA}{PB}=\lambda
  \]
  可以平方为
  \[
    PA^2=\lambda^2PB^2.
  \]
  这样可以消去距离公式中的根号.

  \item[\textbf{要点二（代数推导）：}]
  代入坐标后，距离比条件会转化为关于 $x,y$ 的二次方程；由于 $x^2$ 与 $y^2$ 的系数相同，配方后可化为圆的标准方程.
\end{description}

\medskip

\textbf{\textcolor{CExplanation}{几何本质（比例几何）}}

点 $P$ 到两定点 $A,B$ 的距离之比为定值，反映了点 $P$ 在平面中的位置约束；当 $\lambda\neq1$ 时，这种位置约束形成一个圆. 当 $\lambda=1$ 时，轨迹退化为线段 $AB$ 的中垂线，不再是阿波罗尼斯圆.

\medskip

\textbf{\textcolor{CExplanation}{代数意义（方程转化）}}

通过坐标化，距离比条件
\[
  PA^2=\lambda^2PB^2
\]
转化为关于 $x,y$ 的二次方程. 整理后，$x^2$ 与 $y^2$ 的系数相同，没有 $xy$ 项，因此可以通过配方得到以两定点所在直线上的某点为圆心、半径随 $\lambda$ 变化的圆.

\medskip

\textbf{\textcolor{CExplanation}{考点价值（解析几何交汇）}}

\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
  \item \textbf{考法一（直接求轨迹）：} 已知两点和距离比，直接利用公式或平方配方求圆方程.
  \item \textbf{考法二（与其它曲线结合）：} 利用阿波罗尼斯圆把距离比条件转化为圆，再与直线、圆、椭圆等联立求交点、范围或最值.
  \item \textbf{考法三（非标准坐标）：} 若两定点不是 $(-a,0)$ 和 $(a,0)$ 的形式，应先平移、旋转到标准形式，或直接使用一般坐标方程推导.
\end{itemize}

\medskip

\textbf{\textcolor{CExplanation}{顿悟点}}

圆心在线段 $AB$ 所在直线上，并且在 $AB$ 的延长线上：当 $\lambda>1$ 时，圆心在靠近 $B$ 的外侧；当 $0<\lambda<1$ 时，圆心在靠近 $A$ 的外侧. 半径随 $\lambda$ 改变而改变，且始终为正值.

\medskip

\textbf{\textcolor{CExplanation}{使用场景}}

\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
  \item \textbf{场景一（平面轨迹）：} 题目直接给出平面内两定点和距离比，求动点轨迹方程.
  \item \textbf{场景二（复杂问题简化）：} 题目中出现距离比条件时，可先转化为阿波罗尼斯圆，再与其它条件联立.
  \item \textbf{场景三（立体几何需谨慎）：} 若动点 $P$ 在包含 $A,B$ 的某一平面内运动，仍可得到该平面内的阿波罗尼斯圆；若 $P$ 是空间中的任意动点，则轨迹一般是阿波罗尼斯球面，而不是圆.
\end{itemize}
\end{explanationbox}
