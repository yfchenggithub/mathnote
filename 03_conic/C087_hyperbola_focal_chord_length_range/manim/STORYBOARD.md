# C087 焦点弦动画

事实源为本 UID 的 01–06 TeX 与 meta.json；固定示例 a=3,b=4,c=5，独立模型保留一般 a,b。

1. 先看连接两个顶点的普通线段 AB=2a=6，再引入双曲线与右焦点。
2. 异支弦在 0° 与 30° 之间转动，实时弦长与真实交点同步；返回水平时取等。
3. 淡出后切换到同支区间，在 78°、90°、102° 之间转动。竖直弦确实存在并取到 32/3。
4. 另从异支 30° 接近 50°，真实远端远离。视图按两个方向相同尺度缩小，明确提示参数不变；不伪造无穷远端点。
5. 淡出切到临界角 arctan(4/3)，只画唯一有限交点 P，不显示有限弦长；说明平行渐近线不是切线。
6. 回到竖直弦，总结两个闭下界范围；负斜率由关于 x 轴对称覆盖。

临界角不在任何连续运动区间内部；跨临界用淡出切换，避免制造有限交点穿越无穷远的假象。所有距离使用同一坐标比例，数学点和弦长由 model.py 计算。最下方全程固定两行：“查结论 · 看图解 · 学证明｜知树 App”“公众号 ok-shuxue｜获取入口”。结尾对称说明上移，为两行底部文案留出空间。
