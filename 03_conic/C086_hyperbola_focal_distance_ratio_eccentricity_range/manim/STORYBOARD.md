# C086 独立数学分镜

事实源：本 UID 六段 TeX 与 meta.json。教学目标：把存在性上界解释为两条定长线段的总长限制，说明充分性、顶点取等、交点数量。

1. 先只出现普通三角形 ATB，AT=4、TB=2，底边从4拉到6，保持两腰长度不变。拉直显示三角形不等式的等号。
2. 引入 a=1、λ=2：焦半径差为2，两半径确定为4、2。以 F1、F2 为圆心画两个定半径圆，绿色显示真实双曲线，交点同时在两圆和双曲线上。
3. 固定 a 和比值，c 从2增至3；双曲线参数 b²=c²−1 同步变化，上下交点合并在右顶点(1,0)。外切时2c=4+2，e=3。
4. c 继续增至3.5：两圆分离，所有交点消失。不存在“贴着横轴移动的假点”。
5. 回到外切状态，以和/差之比推导一般上界，明确 e>1、λ>0、λ≠1。充分性来自前面真实的两圆交点构造。

坐标：所有几何对象统一等比缩放，圆不压扁；曲线模型直接从 c 更新。橙色长半径、紫色短半径、绿色双曲线与交点。圆是两个定半径焦点圆，不是阿波罗尼斯圆。

源码和测试仅属于 C086；不修改正式 TeX、PDF、meta.json、共享工具或其他 UID。仅使用冻结 render/export/verify 工具生成新 GIF。用户视觉与 Android 真机验收独立等待确认，不标记 FINAL FREEZE。
