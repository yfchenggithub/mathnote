\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	抛物线中，过焦点的弦被焦点分成的两段，其倒数和竟然与弦的倾斜角无关，仅取决于抛物线开口参数 $p$。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（焦半径转化）：}] 利用抛物线定义 $|AF| = x_1 + \frac{p}{2}$，$|BF| = x_2 + \frac{p}{2}$，将问题转化为横坐标的代数关系。
		\item[\textbf{要点二（韦达定理消参）：}] 设过焦点的直线 $y=k\left(x-\frac{p}{2}\right)$，与 $y^2=2px$ 联立，用韦达定理得出 $x_1+x_2$、$x_1x_2$ 的表达式，代入目标式并消去 $k$ 即可得定值。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（焦半径与准线）}}

	由抛物线定义，焦半径等于点到准线的距离；焦点弦的倒数和恒等于 $\frac{2}{p}$ 反映了焦点位置与抛物线通径之间的关系（通径长为 $2p$，其倒数为 $\frac{1}{p}$，而倒数和是通径倒数的两倍）。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（定值消参）}}

	目标式 $\frac{1}{|AF|}+\frac{1}{|BF|}$ 通过定义转化为 $\frac{1}{x_1+\frac{p}{2}}+\frac{1}{x_2+\frac{p}{2}}$，通分后分子出现 $(x_1+x_2+p)$，分母为 $x_1x_2+\frac{p}{2}(x_1+x_2)+\frac{p^2}{4}$。代入韦达结果后，$k$ 被恰好消去，仅剩常数 $\frac{2}{p}$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（重要技巧）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求值）：} 已知抛物线方程和焦点弦端点坐标（或焦半径长），直接代入结论计算；或在选择题中快速得到倒数和。
		\item \textbf{考法二（最值问题）：} 利用 $\frac{1}{|AF|}+\frac{1}{|BF|}=\frac{2}{p}$ 和均值不等式可求 $|AF|+|BF|$ 或 $|AF|\cdot|BF|$ 的最值（如 $|AF|+|BF|\ge 2p$ 等）。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{核心转化：} 将焦半径变成横坐标加 $\frac{p}{2}$，“倒数和”本质是关于 $x_1,x_2$ 的有理分式，通过韦达定理消去 $x_1+x_2$ 和 $x_1x_2$ 中含 $k$ 的部分，最终与 $k$ 无关。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景（典型情形）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（焦点弦计算）：} 已知抛物线方程和一条过焦点弦的焦半径长度，求另一焦半径长度；或求与焦点弦相关的长度比。
		\item \textbf{场景二（最值综合）：} 在解析几何大题中，第（2）问常利用此定值结合函数或不等式求范围，简化运算。
	\end{itemize}
\end{explanationbox}
