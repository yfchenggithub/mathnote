\textbf{结论名称：} 抛物线的焦点弦长公式（倾斜角形式）

\textbf{适用条件：} 标准形式的抛物线 \(y^2=2px\) 或 \(y^2=-2px\) (\(p>0\))，焦点弦所在直线的倾斜角为 \(\theta\)（\(\theta\neq 0,\pi\)，即不与对称轴重合）。

\textbf{变量说明：} \(p\) 为焦准距（焦点到准线的距离），\(\theta\) 为焦点弦所在直线的倾斜角（与 \(x\) 轴正方向的夹角），\(L\) 为焦点弦的长度。

\textbf{核心公式：}
\[
\boxed{ L = \frac{2p}{\sin^2\theta} }
\]

\textbf{使用场景：} 已知焦点弦的倾斜角快速求弦长，或由弦长反求倾斜角；在焦点弦定值、最值问题中简化计算，避免联立方程与弦长公式的复杂运算。

\textbf{简单例子：} 对于抛物线 \(y^2=4x\)，\(2p=4\)。倾斜角 \(\theta=45^\circ\) 的焦点弦长 \(L = \dfrac{4}{\sin^2 45^\circ} = \dfrac{4}{1/2}=8\)。验证：焦点 \(F(1,0)\)，直线 \(y=x-1\) 与抛物线联立得 \(x^2-6x+1=0\)，弦长 \(\sqrt{2}\sqrt{36-4}=8\)，结果一致。
