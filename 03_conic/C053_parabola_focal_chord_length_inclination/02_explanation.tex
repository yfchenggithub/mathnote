\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	当直线穿过抛物线焦点时，弦的长度只取决于直线的倾斜程度；越陡（接近垂直）弦越短，越平（接近平行）弦越长。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（倾斜角与斜率关系）：}] 倾斜角 $\theta$ 的斜率 $k = \tan\theta$，弦长公式与 $k$ 的关系可通过 $\sin^2\theta$ 转换：$L = \dfrac{2p(1+k^2)}{k^2}$（因为 $\sin^2\theta = \dfrac{\tan^2\theta}{1+\tan^2\theta}$，经整理得到用 $k$ 表示的弦长公式 $L = 2p\cdot\dfrac{1+k^2}{k^2}$）。
		\item[\textbf{要点二（通径是最短焦点弦）：}] 当 $\theta = \dfrac{\pi}{2}$ 时，$\sin^2\theta = 1$，$L=2p$ 达到最小值，此时弦垂直于 $x$ 轴，称为通径。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（弦的投影长度）}}

	焦点弦在准线上的投影长度与 $\sin\theta$ 有关，从而得到长度公式。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（坐标运算简化）}}

	利用抛物线定义，将弦长转化为焦半径之和，再通过韦达定理导出与 $\theta$ 的关系。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（常见出题角度）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接套公式求弦长）：} 给出倾斜角或斜率，直接代入公式计算焦点弦长。
		\item \textbf{考法二（已知弦长反求倾斜角）：} 利用公式建立方程，解出 $\theta$ 或斜率，再求其他量。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	该公式的核心是用一个参数 $\theta$ 统一表达了焦点弦长，避免了繁琐的坐标运算；只要知道倾斜角，立即写出弦长。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（焦点弦长度计算）：} 已知抛物线方程和过焦点直线的倾斜角，求弦长。
		\item \textbf{场景二（最值问题）：} 利用 $L = \dfrac{2p}{\sin^2\theta}$ 分析弦长的取值范围，或求最小值。
	\end{itemize}
\end{explanationbox}
