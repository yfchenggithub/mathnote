\begin{summarybox}

	\textbf{\textcolor{CSummary}{一句话核心}}

	\textbf{圆锥曲线标准方程是几何定义与坐标系结合的产物，通过距离公式代数化简得到。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（对称性与中心）：} 曲线关于坐标轴对称，椭圆和双曲线的中心在原点，抛物线的顶点在原点。
		\item \textbf{条件2（焦点轴定位）：} 焦点在 $x$ 轴或 $y$ 轴上，由标准方程形式对应决定。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（参数关系）：} 椭圆中 $c^2=a^2-b^2$，双曲线中 $c^2=a^2+b^2$，二者相反。
		\item \textbf{检查项（形式判断）：} 椭圆看平方项分母较大者（即系数较小者）确定焦点轴；双曲线看正项变量；抛物线看一次项变量。
	\end{itemize}
\end{summarybox}
