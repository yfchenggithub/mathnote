\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	圆锥曲线的通径长可用公式直接计算：椭圆和双曲线为 $2b^2/a$，抛物线为 $2p$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（曲线标准式）：} 圆锥曲线方程必须为标准形式（椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$，双曲线 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$，抛物线 $y^2=2px$ 或 $x^2=2py$）。
		\item \textbf{条件2（弦的定位）：} 弦必须过焦点且垂直于焦点所在坐标轴。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（定义条件）：} 只有同时满足过焦点和垂直于对称轴的弦才能使用通径公式，不可随意套用。
		\item \textbf{检查项（公式选择）：} 椭圆和双曲线用 $2b^2/a$，抛物线用 $2p$；注意参数意义不同，公式不可混用。
	\end{itemize}

\end{summarybox}
