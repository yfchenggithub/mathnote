\begin{summarybox}
\textbf{一句话：} 焦点不在准线上，焦半径等于到准线的垂距。
\[
PF=PH>0,\quad e=1,\quad p=d(F,\ell)>0.
\]
右开口：$y^2=2px$，$F(p/2,0)$，$\ell:x=-p/2$，$PF=x+p/2$。
其他方向用反射或交换坐标得到。

\textbf{最后四查。}
\begin{enumerate}[leftmargin=*]
\item 定点是否不在定直线上？垂足是否真的垂直？
\item $p$、$p/2$、$2p$ 是否分别对应焦准距、焦点坐标大小、一次项系数？
\item 开口是否朝向焦点，准线是否在顶点另一侧？
\item 求最值时是否证明下界，并找到实际满足条件的取等点？
\end{enumerate}
\end{summarybox}
