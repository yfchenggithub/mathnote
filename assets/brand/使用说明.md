# 知树数学 · 品牌角标 V1（公众号 ok-shuxue）

## 这一套文件是做什么的？
- `wechat_original.jpg`：用户原始二维码素材，包含中心 Logo；请永久保留，不让 AI 重新生成。
- `brand_corner_941x1672.png`：小块透明底角标（136px 二维码 + 公众号小字）。
- `brand_corner_1080x1920.png`：1080 宽度版小块角标（156px 二维码 + 公众号小字）。
- `brand_overlay_941x1672.png`：与 941×1672 图片等大的透明覆盖图，坐标已固定。
- `brand_overlay_1080x1920.png`：与 1080×1920 图片等大的透明覆盖图，坐标已固定。
- `brand_preview_*.png`：白底预览，可以使用微信直接真机扫码。
- `brand_config.json`：尺寸、位置、原码及 SHA256 配置。
- `apply_brand.py`：把角标原样叠加到无二维码的底图并校验。

## 具体操作
1. 将整个文件夹保存好。按约定设计 MathNote / 知树 Rose Premium 卡片，右下角**留空**，不要让 AI 绘制任何二维码或模拟二维码。
2. 卡片底图选择固定画布尺寸：`941×1672`（原卡片版式）或 `1080×1920`。
3. 在 Windows PowerShell 进入本文件夹，先执行：`py -m pip install pillow opencv-python`。
4. 合成：`py apply_brand.py "D:\cards\003_视觉底图.png" "D:\cards\003_快用.png"`。
5. 看脚本输出的整图二维码解码是否 PASS；再用微信扫描最终 PNG。真实扫码确认以后，将 `brand_config.json` 与 PNG 当成冻结资产复用。

## 绝对不要做
- 不要把 `brand_corner` 交给 AI，让 AI “贴到图片上”。必须通过 Python/Pillow 叠图。
- 不要把角标嵌入后再调整全图分辨率、压缩为 JPEG，或调用图像编辑模型。
- 不要把自动解码 PASS 当成微信真机 PASS。
- 不要因为缩略图解码失败就擅自放大二维码。
- 不要随意改动角标大小/位置；只有在改正式模板规格时才生成另一套受检资产。
