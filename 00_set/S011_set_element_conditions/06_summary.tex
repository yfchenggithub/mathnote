\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	\textbf{集合元素具有确定性、互异性、无序性——这是所有集合运算和关系判断的底层逻辑，任何时刻都不能违背。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（任意集合均适用）：} 无论用列举法、描述法还是图示法给出的集合，都默认满足三大特性。
		\item \textbf{条件 2（解题中主动应用）：} 在求参、计数、判断相等等问题中，必须主动调用互异性去重、无序性排序、确定性分类讨论。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（参数忘检验）：} 含参集合问题中，参数求出后务必代回检验互异性，这是最常见的失分点。
		\item \textbf{检查项（计数前去重）：} 涉及集合元素个数的题目，第一步就应扫视是否有重复元素并化简，再计数。
	\end{itemize}

\end{summarybox}
