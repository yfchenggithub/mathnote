\begin{proofbox}
	\textbf{\textcolor{CProof}{思路提示}}
	三大特性中，确定性是集合论的基本规定（公理化要求），互异性和无序性则可从集合相等的外延公理加以验证：两个集合相等当且仅当它们的元素完全相同。

	\medskip
	\textbf{\textcolor{CProof}{正式推导}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.55em]
		\item[\textbf{步骤一（确定性确认）：}]
			确定性出自集合的朴素涵义——一个整体的确定个体。它不依赖于推导，而是作为集合必须满足的前提。在形式化表示中，我们规定：对于任意 $x$，命题“$x\in A$”非真即假，且二者必居其一。
			\par\textbf{理由：} 这是建立集合论语言的第一约定，否则无法谈论元素的“属于”关系。
		\item[\textbf{步骤二（互异性验证）：}]
			考察 $\{a,a\}$ 与 $\{a\}$。由外延公理，两集合相等当且仅当：任何对象 $x$ 属于前者亦属于后者，反之亦然。
			\[
				\begin{aligned}
					x\in\{a,a\} &\iff (x=a)\vee (x=a) \\&\iff x=a \\&\iff x\in\{a\}.
			\end{aligned}
			\]
			\par\textbf{理由：} 对 $\{a,a\}$，其定义是“元素为 $a$ 或 $a$”，这等价于“元素为 $a$”。因此 $\{a,a\}$ 与 $\{a\}$ 具有完全相同的元素，故二者相等。
		\item[\textbf{步骤三（无序性验证）：}]
			类似地，比较 $\{a,b\}$ 与 $\{b,a\}$：
			\[
				\begin{aligned}
					x\in\{a,b\} &\iff (x=a)\vee (x=b) \\&\iff (x=b)\vee (x=a) \\&\iff x\in\{b,a\}.
			\end{aligned}
			\]
			\par\textbf{理由：} “或”运算满足交换律，因此两个集合的成员条件完全一致，依据外延公理它们相等。这说明集合的元素书写顺序纯粹是记号上的方便，并不影响集合本身。
	\end{description}

	\medskip
	\textbf{\textcolor{CProof}{结论回扣}}
	\textbf{确定性是前提，互异性和无序性则是集合相等定义的直接推论。三者共同奠定了集合作为一种无序、不重复元素总体的数学对象地位。}
\end{proofbox}
