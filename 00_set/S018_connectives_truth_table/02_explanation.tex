\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	合取即“且”，析取即“或”，否定即“非”，真值表给出严格定义。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（合取）：}] $p\land q=1$ 仅当 $p=1$ 且 $q=1$，否则为 $0$。
		\item[\textbf{要点二（析取）：}] $p\lor q=1$ 当 $p=1$ 或 $q=1$，仅当 $p=q=0$ 时为 $0$。
		\item[\textbf{要点三（否定）：}] $\lnot p$ 与 $p$ 相反。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（枚举表格）}}

	真值表通过穷举所有赋值，将逻辑运算转化为可查表格。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（逻辑运算）}}

	合取类似乘法，析取类似加法（无进位），否定类似补运算。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（基础应用）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接计算）：} 已知 $p,q$ 真假，求复合命题真假。
		\item \textbf{考法二（等价验证）：} 列真值表判断两命题是否等价。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	赋值必须全面，共 $2^n$ 种，不可遗漏。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（真假计算）：} 已知 $p,q$ 真值，直接查表得结果。
		\item \textbf{场景二（逻辑等价）：} 证明 $\lnot(p\land q)\equiv\lnot p\lor\lnot q$ 可通过真值表。
	\end{itemize}
\end{explanationbox}
