\begin{proofbox}
	\textbf{\textcolor{CProof}{思路提示}}

	直接根据合取、析取、否定的定义，枚举所有情况即可验证。

	\medskip
	\textbf{\textcolor{CProof}{正式推导}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.55em]
		\item[\textbf{步骤一（枚举赋值）：}] $p,q$ 共有 $4$ 种赋值：$(1,1),(1,0),(0,1),(0,0)$。
			\par\textbf{理由：}
			每个命题取 $1$ 或 $0$，故 $2\times2=4$。

		\item[\textbf{步骤二（合取结果）：}] $p\land q$ 仅在 $(1,1)$ 时为 $1$，其余为 $0$。
			\par\textbf{理由：}
			合取要求两者皆真。

		\item[\textbf{步骤三（析取结果）：}] $p\lor q$ 仅在 $(0,0)$ 时为 $0$，其余为 $1$。
			\par\textbf{理由：}
			析取至少一真即真。

		\item[\textbf{步骤四（否定结果）：}] $\lnot p$ 与 $p$ 相反：$p=1$ 则 $0$，$p=0$ 则 $1$。
			\par\textbf{理由：}
			否定取反。

		\item[\textbf{步骤五（汇总表格）：}] 将上述结果填入真值表（见结论部分）。
			\par\textbf{理由：}
			表格形式更直观。
	\end{description}

	\medskip
	\textbf{\textcolor{CProof}{结论回扣}}

	真值表完整刻画了三种基本逻辑运算，是后续证明逻辑等价的基础。
\end{proofbox}
