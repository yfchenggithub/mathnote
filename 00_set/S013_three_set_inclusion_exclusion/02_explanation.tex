\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	计算三个集合并集大小时，若直接将各集合元素数相加，会重复计数某些元素，因此需要依次减去两两重叠部分，再加回三重重叠部分。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（重复计数）：}] 直接相加时，元素在多个集合中出现会被多次计数。
		\item[\textbf{要点二（逐步修正）：}] 先减去两两交集，此时三重交集被多减，故需加回。
		\item[\textbf{要点三（符号交替）：}] 加单集、减两两交、加三交，加减交替。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（面积模型）}}

	可借助三个圆的文氏图理解：三个圆的覆盖面积等于各圆面积之和减去两两交面积再加三交面积。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（线性表出）}}

	公式将并集大小表示为各交集大小的线性组合，便于由已知交集通过代数运算求解未知量，而不必直接列出所有元素。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（并集计数）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求并）：} 已知各集合及交集大小，直接代入公式求并集。
		\item \textbf{考法二（反解交集）：} 已知并集及部分交集，通过方程解出未知交集大小。
		\item \textbf{考法三（结合补集）：} 结合全集求“都不”或“只属于某一集合”的人数。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{“多减了就要加回来！”}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（选课统计）：} 统计至少参加一项活动的人数。
		\item \textbf{场景二（事件概率）：} 计算三事件并的概率，公式结构与此完全相同。
	\end{itemize}
\end{explanationbox}
