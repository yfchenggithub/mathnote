\begin{trapbox}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CTrap}{易错点一（补集前提）：}}] 使用补集符号时忽略全集，错误记为 \(\complement A\) 而不注明 \(U\)。
		\item[\textbf{\textcolor{CTrap}{正确理解（全集要求）：}}] 补集必须指明全集，正确写法 \(\complement_U A\)，否则无意义。
		\item[\textbf{\textcolor{CTrap}{错因分析（忽略全集）：}}] 对集合补集定义中全集的作用认识不足，习惯性简写。
	\end{description}

	\medskip
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CTrap}{易错点二（符号混淆）：}}] 混淆并集与交集符号，将并集写成 \(\cap\) 或将交集写成 \(\cup\)。
		\item[\textbf{\textcolor{CTrap}{正确理解（记忆方法）：}}] 并集符号 \(\cup\) 对应“或”（Union首字母U形似容器），交集符号 \(\cap\) 对应“且”（Intersection首字母I形似门）。
		\item[\textbf{\textcolor{CTrap}{错因分析（记忆混淆）：}}] 对符号形状与含义对应关系不清晰，做题时凭感觉。
	\end{description}

	\medskip
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CTrap}{易错点三（端点误判）：}}] 在区间运算中，错误判断端点是否属于集合，导致结果区间开闭错误。
		\item[\textbf{\textcolor{CTrap}{正确理解（端点检查）：}}] 将端点值代入条件逐一验证，确认是否满足元素归属。
		\item[\textbf{\textcolor{CTrap}{错因分析（疏忽端点）：}}] 解不等式或画数轴时不注意端点的等号条件，全凭惯性忽略。
	\end{description}
\end{trapbox}
