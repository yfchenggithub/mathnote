\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	集合运算本质是对元素是否属于集合进行逻辑判断，并按一定规则组合。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（元素归属判定）：}] 每个元素 \(x\) 相对于集合 \(A, B\) 只有四种状态：\(x\in A\) 或 \(\notin A\)，\(x\in B\) 或 \(\notin B\)。运算结果由这些归属组合决定。
		\item[\textbf{要点二（符号与自然语言对应）：}] 并集对应“或”，交集对应“且”，补集对应“非（在全集条件下）”，差集对应“属于 \(A\) 但不属于 \(B\)”。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（韦恩图表示）}}

	用封闭曲线表示集合，重叠区域表示交集，合并区域表示并集，曲线外（全集内）区域表示补集，差集是只属于 \(A\) 但不属于 \(B\) 的区域。图形直观展示运算结果。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（逻辑联结词）}}

	并集：\(A\cup B\) 对应 \(x\in A\) 或 \(x\in B\)（取两个条件至少一个成立）。交集：\(A\cap B\) 对应 \(x\in A\) 且 \(x\in B\)。补集：\(\complement_U A\) 对应 \(x\notin A\)。差集：\(A\setminus B\) 对应 \(x\in A\) 且 \(x\notin B\)。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（基础运算工具）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接运算求值）：}给定具体集合，按定义计算并、交、补、差。通常结合区间、数轴、韦恩图。
		\item \textbf{考法二（利用运算性质求参数）：}已知运算结果，反推集合中参数取值。常与方程不等式结合。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{全集是补集的前提，差集可转化为交集与补集。将符号语言转化为元素归属是解题关键。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（集合基本运算）：}直接求给定集合的并、交、补、差。
		\item \textbf{场景二（综合问题转化条件）：}将复杂条件用集合运算表示，转化为元素关系。
	\end{itemize}
\end{explanationbox}
