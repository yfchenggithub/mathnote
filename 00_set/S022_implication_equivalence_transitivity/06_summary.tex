\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	命题的推出关系与等价关系均满足传递性：若$A\Rightarrow B$且$B\Rightarrow C$则$A\Rightarrow C$；若$A\Leftrightarrow B$且$B\Leftrightarrow C$则$A\Leftrightarrow C$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（链条存在）：} 存在两个或以上连续的推出/等价关系。
		\item \textbf{条件 2（方向一致）：} 传递时箭头方向需一致（单向或双向按情况）。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（方向混淆）：} 注意单向与双向的区别，不可乱用。
		\item \textbf{检查项（中间一致）：} 确保中间命题完全相同，链条无断裂。
	\end{itemize}
\end{summarybox}
