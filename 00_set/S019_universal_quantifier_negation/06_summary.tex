\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	全称命题的否定是存在命题（谓词取反），存在命题的否定是全称命题（谓词取反）。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（论域非空）：} 论域 $M$ 必须是非空集合，否则量词真值定义会变化。
		\item \textbf{条件2（谓词确定）：} 谓词 $p(x)$ 在 $M$ 上有确定的真值。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（转换规则）：} 否定时须同时改变量词和否定谓词，缺一不可。
		\item \textbf{检查项（论域完整）：} 否定后的命题必须保留原论域 $M$。
	\end{itemize}
\end{summarybox}
