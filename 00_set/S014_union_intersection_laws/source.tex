\textbf{结论名称：}集合运算律——交换律、结合律、分配律

\textbf{适用条件：}对任意集合恒成立，运算为并集 $\cup$ 与交集 $\cap$，所有集合视为同一全集 $U$ 的子集。

\textbf{变量说明：}$A,B,C$ 为任意集合，$\varnothing$ 为空集，$U$ 为全集。

\textbf{核心公式：}
交换律：\boxed{A\cup B = B\cup A,\quad A\cap B = B\cap A}
结合律：\boxed{(A\cup B)\cup C = A\cup(B\cup C),\quad (A\cap B)\cap C = A\cap(B\cap C)}
分配律：\boxed{A\cap(B\cup C) = (A\cap B)\cup(A\cap C),\quad A\cup(B\cap C) = (A\cup B)\cap(A\cup C)}

\textbf{使用场景：}化简复杂集合表达式、证明两集合相等、概率论中化事件运算表达式。

\textbf{简单例子：}
验证分配律：设 $A=\{1,2\},B=\{2,3\},C=\{3,4\}$。
\[
B\cup C=\{2,3,4\},\; A\cap(B\cup C)=\{2\},\quad A\cap B=\{2\},\; A\cap C=\varnothing,\; (A\cap B)\cup(A\cap C)=\{2\}.
\]
左右均为 $\{2\}$，故 $A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$ 成立。
