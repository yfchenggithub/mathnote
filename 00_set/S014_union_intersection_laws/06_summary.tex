\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	\textbf{集合的并、交运算满足交换律、结合律和两个分配律，是化简与证明的“代数工具”。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（任意集合）：} 参与运算的集合均为某全集 $U$ 的子集，无其他限制。
		\item \textbf{条件 2（明确运算）：} 仅涉及 $\cup$ 与 $\cap$ 运算；出现补集、差集等其他运算时需结合相应规则。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（分清分配方向）：} $A\cap(B\cup C)$ 与 $A\cup(B\cap C)$ 的展开式不同，右端形式务必记牢。
		\item \textbf{检查项（混合运算加括号）：} 遇到交并混合式，先观察能否运用分配律化为单一运算，勿盲目去括号；证明相等时坚持双向包含。
	\end{itemize}

\end{summarybox}
