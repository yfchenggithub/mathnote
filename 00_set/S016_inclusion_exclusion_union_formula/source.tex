\textbf{结论名称：} Venn图在集合运算中的应用（容斥原理）\\
\textbf{适用条件：} 已知有限集合的元素个数，或通过集合间的交、并、补关系求元素个数。\\
\textbf{变量说明：} 设$A,B,C$为有限集合，$U$为全集；$|A|$表示集合$A$的元素个数；$\complement_U A = U\setminus A$。\\
\textbf{核心公式：} 
\[
\boxed{|A\cup B| = |A| + |B| - |A\cap B|}
\]
对于三个集合（容斥原理）：
\[
\boxed{|A\cup B\cup C| = |A|+|B|+|C| - |A\cap B| - |B\cap C| - |C\cap A| + |A\cap B\cap C|}
\]
\textbf{使用场景：} 利用Venn图直观表示集合间的关系，快速列出关于元素个数的方程，解决“多集合并”类型的计数问题。\\
\textbf{简单例子：} 某班共40人，喜欢数学的有25人，喜欢物理的有20人，两门都喜欢的有10人，问两门都不喜欢的有多少人？设$M$为喜欢数学的集合，$P$为喜欢物理的集合。则
\[
|M\cup P| = 25+20-10 = 35,
\]
故两门都不喜欢的人数为 $|U| - |M\cup P| = 40-35 = 5$。
