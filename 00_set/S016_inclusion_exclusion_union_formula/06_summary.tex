\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	\textbf{容斥原理：求并集大小，先加单个集合基数，再减两两交集基数（两个集合情形），若有三个集合则还需加回三交集基数。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（有限集合）：} 所涉及的集合必须为有限集，否则公式不适用。
		\item \textbf{条件 2（已知交集）：} 需要知道各个交集（两两交及三交）的基数，或能通过其他条件求出。
		\item \textbf{条件 3（项数正确）：} 对于 $n$ 个集合的一般容斥原理，项数依次为单个、两两交、三三交……符号正负交替；高中重点掌握 $n=2,3$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（符号项数）：} 三集合公式务必写全七项：四个正项、三个负项，最后一项为正号。
		\item \textbf{检查项（验算一致性）：} 求得并集大小后，可检查它是否介于各集合大小之间，且不大于总和，不小于最大单个集合的基数。若出入过大，可能计算有误。
	\end{itemize}

\end{summarybox}
