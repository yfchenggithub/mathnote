\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	否定“存在”就是“所有都不”，否定“所有”就是“存在一个不”。\par

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（量词互换）：}]
			存在量词 $\exists$ 与全称量词 $\forall$ 互换。
		\item[\textbf{要点二（谓词取反）：}]
			命题函数 $p(x)$ 取反为 $\neg p(x)$。
	\end{description}
	\par

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（集合观点）}}
	将满足 $p(x)$ 的元素构成集合 $A$。$\exists x\in M,p(x)$ 等价于 $A\neq\emptyset$；$\forall x\in M,\neg p(x)$ 等价于 $A=\emptyset$。因此否定存在量词等价于断言 $A$ 为空集。\par

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（逻辑等价）}}
	该规则是德摩根律在量词上的推广：将“存在”视作“或”的无限，将“全称”视作“与”的无限，则否定交换量词且谓词取反。\par

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（命题否定）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item\textbf{考法一（直接改写）：} 给出命题要求写出否定形式，直接套用规则。\item\textbf{考法二（真假判断）：} 利用否定前后的真值关系求参数范围。
	\end{itemize}
	\par

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	\textbf{否定时不要只加“不”，必须同时换量词。}\par

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item\textbf{场景一（反证法反设）：} 欲证“不存在”时，先假设“存在某个”，然后推出矛盾。\item\textbf{场景二（补集思想）：} 当正面求解困难时，考虑其否定情形，转化为全称命题求解。
	\end{itemize}

\end{explanationbox}
