# C059 逐法配图与 PDF 验收

日期：2026-10-28。范围仅 C059；修改前保留了该目录已存在的用户改动。

## 配图与用途

新增九幅 `assets/tikz/C059_*.tex`，均为由方程和实际交点构造的 TikZ 图，正文以 `\input` 引用。

| 图文件 | 使用位置 | 解决的理解问题 |
| --- | --- | --- |
| `C059_overview.tex` | 首页 | 同取 M(1,1)，对照椭圆、双曲线、抛物线的端点与中点；让三条不同方向的弦对应斜率符号。 |
| `C059_difference_projection.tex` | 方法一 | 画出横向差、竖向差及其符号，解释平方差中的“和”对应中点、“差”对应斜率。 |
| `C059_midpoint_offsets.tex` | 理解说明、方法二 | 先拿开曲线，用普通线段呈现两边的正负偏移，再引入 M±(u,v)，缩短重复设点解释。 |
| `C059_vieta_projection.tex` | 方法三 | 将端点横坐标投影到数轴，直接看见 x1、x0、x2 两侧等距，连接韦达根之和与中点条件。 |
| `C059_gradient_level.tex` | 方法四 | 分别画原曲线和经过中点的等值线；显示梯度与弦的直角，避免把中点误当原曲线切点。 |
| `C059_existence_cases.tex` | 补充存在性论证、陷阱二 | 同尺度对比 Q>1、Q<0 两种有效位置，以及能算候选方向却无实交点的 N(1,1)。 |
| `C059_circle_rescale.tex` | 理解说明、陷阱五 | 对比伸缩前后 OM 与弦的角度，标明新坐标与单位圆刻度；说明垂直关系为何不能直接搬回原坐标。 |
| `C059_center_vertical.tex` | 无分母形式、陷阱一 | 对比同样 y0=0 时的中心弦多方向与非中心竖直弦，排除机械解释 0/0。 |
| `C059_parabola_locus.tex` | 方法三续、例三、陷阱六 | 三条真实平行弦的中点共线；用空心切点显示轨迹是开射线，不是整条直线。 |

四个证明方法和补充存在性论证均有就近配图。首页已消除原 PDF 的仅标题空页；将条件、三类曲线图与通用公式放在同一页。解释部分改为先普通线段、后曲线和公式，压缩重复说明。另补明圆的垂直性质适用于非直径弦，避免与中心弦例外混淆。
