\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	\textbf{直线与圆的位置关系由圆心到直线的距离 $d$ 与半径 $r$ 的大小比较唯一确定：$d<r$ 相交，$d=r$ 相切，$d>r$ 相离。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（圆心半径已知）：} 圆的标准方程 $(x-x_0)^2+(y-y_0)^2=r^2$ 或能直接得到圆心和半径.
		\item \textbf{条件 2（直线一般式）：} 直线方程必须写成 $Ax+By+C=0$ 形式，$A,B$ 不同时为零.
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（公式记忆）：} 距离公式分母 $\sqrt{A^2+B^2}$ 不能丢；比较时注意不等号方向（$d<r$ 相交，$d>r$ 相离）.
		\item \textbf{检查项（参数取等）：} 已知位置关系求参数时，相切情况对应 $d=r$，不等式中是否包含等号需根据题目要求（如“相切”要等号，“相交”要 $d<r$ 不含等号）.
	\end{itemize}
\end{summarybox}
