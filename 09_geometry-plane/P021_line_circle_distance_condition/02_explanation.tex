\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	直线与圆的位置关系本质上就是直线离开圆心的距离是否小于、等于或大于圆的半径，如同比较两个长度。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（点到直线距离）：}] 圆心 $P(x_0,y_0)$ 到直线 $l$ 的距离 $d$ 是几何数量，计算公式为 $d = \dfrac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$.
		\item[\textbf{要点二（比较判据）：}] 以 $r$ 为界：$d$ 越小表示直线越靠近圆心，当 $d<r$ 时直线穿过圆（相交）；$d=r$ 时直线与圆刚好接触（相切）；$d>r$ 时直线远离圆（相离）.
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（距离决定位置）}}

	圆心到直线的距离直接刻画直线与圆的相对位置，这是用“距离”度量“临界状态”的经典模型.

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（绝对值与根式）}}

	距离公式涉及绝对值与二次根号，计算时需注意符号处理和分母合理化，尤其去绝对值时要考虑分子正负.

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（快速判定）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（基础判定）：} 直接给出圆心、半径和直线方程，求距离后比较，判断位置关系.
		\item \textbf{考法二（参数范围）：} 已知位置关系反求直线方程中的参数（如斜率 $k$ 或截距），构造不等式 $d<r$、$d=r$ 或 $d>r$.
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	记住：“距离小于半径必相交，等于必相切，大于必相离”，与生活中“人离圆心越远越碰不到圆”一致.

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（已知方程求位置）：} 给定圆的标准方程和直线一般式，直接套用公式.
		\item \textbf{场景二（含参直线与定圆）：} 利用 $d$ 与 $r$ 的不等式确定参数取值范围.
	\end{itemize}
\end{explanationbox}
