\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	斯特瓦尔特定理可看作在两个共用边 $AD$ 的三角形中，利用余弦定理消去公共角，得到边长间的统一关系。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（余弦定理列式）：}] 在 $\triangle ABD$ 中，$c^{2}=m^{2}+d^{2}-2md\cos\theta$；在 $\triangle ACD$ 中，$b^{2}=n^{2}+d^{2}+2nd\cos\theta$（其中 $\theta=\angle ADB$）。
		\item[\textbf{要点二（加权相加消元）：}] 将两式分别乘以 $n$ 和 $m$ 后相加，$\cos\theta$ 项抵消，化简得 $c^{2}n+b^{2}m = a(d^{2}+mn)$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（加权关系）}}

	公式 $c^{2}n+b^{2}m = a(d^{2}+mn)$ 左边是两边的平方分别乘以对侧分线段，右边是底边 $a$ 乘 $d^{2}+mn$，体现了一种加权平均关系。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（对称结构）}}

	当 $D$ 为 $BC$ 中点时，$m=n=\frac{a}{2}$，公式自动退化为中线公式，展现了该定理的统一性。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（应用方向）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求线段长）：} 直接套用公式求分点与顶点的连线长度。
		\item \textbf{考法二（反求分点）：} 已知连线长度，建立方程求 $m$ 或 $n$，常结合一元二次方程。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{关键在于两个三角形共用 $AD$，且 $\angle ADB$ 与 $\angle ADC$ 互补，导致余弦值相反。加权相加即可消去未知角。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（普通分点）：} 已知三角形三边及分点位置，求分点到顶点距离。
		\item \textbf{场景二（特殊分点）：} 涉及中线、角平分线等特殊点，可结合其他定理简化。
	\end{itemize}
\end{explanationbox}
