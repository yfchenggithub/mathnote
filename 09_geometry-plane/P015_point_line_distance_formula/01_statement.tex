\begin{statementbox}
给定点 $P(x_0,y_0)$ 与直线 $l:Ax+By+C=0$，其中 $A,B$ 不同时为零。
\[
 \boxed{d=\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}}.
\]

\begin{description}[style=nextline,leftmargin=2.8em,labelsep=.5em,itemsep=.45em]
		\item[\textbf{\textcolor{CStatement}{推广结论（特殊直线情形）：}}]
			\textbf{\textcolor{CStatement}{直观描述：}}
			当直线为竖直或水平时，公式简化为横纵坐标差的绝对值。
			\begin{itemize}
			\item 若 $B=0$，则直线为 $x = -\frac{C}{A}$，距离 $d = \left\lvert x_0 + \frac{C}{A} \right\rvert$；
			\item 若 $A=0$，则直线为 $y = -\frac{C}{B}$，距离 $d = \left\lvert y_0 + \frac{C}{B} \right\rvert$。
		\end{itemize}

	\end{description}

\end{statementbox}
