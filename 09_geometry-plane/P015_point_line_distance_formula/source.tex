\textbf{结论名称：}点到直线的距离公式

\textbf{适用条件：}直线方程为一般式 \(Ax+By+C=0\)，点 \(P(x_0,y_0)\) 为平面内任意一点，且 \(A,B\) 不同时为零。

\textbf{变量说明：}\(A,B,C\) 是直线方程系数；\((x_0,y_0)\) 是给定点的坐标；\(d\) 表示点 \(P\) 到直线的最短距离。

\textbf{核心公式：}
\[
\boxed{d = \frac{\,|Ax_0 + By_0 + C|\,}{\sqrt{A^{2} + B^{2}}}}
\]

\textbf{使用场景：}求解点到直线的最短距离；判断直线与圆的位置关系（比较距离与半径）；推导两平行线间的距离公式；几何最值问题中转化为点到直线的距离。

\textbf{简单例子：}求点 \(P(1,2)\) 到直线 \(3x+4y+5=0\) 的距离。
\[
d = \frac{|3\times 1 + 4\times 2 + 5|}{\sqrt{3^{2}+4^{2}}} = \frac{|3+8+5|}{5} = \frac{16}{5} = 3.2.
\]
