\begin{summarybox}
\textbf{一句话核心：} 外角平分线保持邻边的对应比例；外分看差，先定位再计算。

\textbf{速查（非退化三角形，$p=AB,q=AC,a=BC,p\ne q$）：}
\[
 \frac{BD}{DC}=\frac pq,\qquad |BD-DC|=a.
\]
\[
 BD=\frac{ap}{|p-q|},\qquad DC=\frac{aq}{|p-q|}.
\]
\[
 p>q:\ B,C,D;\qquad p<q:\ D,B,C.
\]
\textbf{最短证明记忆：} 同一对三角形 $ABD,ACD$ 的面积比，
从 $A$ 看为 $BD/DC$，从 $D$ 看为 $AB/AC$。

\textbf{最后四查：}
\begin{itemize}[leftmargin=*]
\item 确认是外角平分线，$D$ 在线段 $BC$ 外部。
\item 按 $B$ 对 $AB$、$C$ 对 $AC$ 写比例，不取倒数。
\item 普通长度都为正；长度差的方向应与点的顺序一致。
\item 若 $AB=AC$，立即转为平行情形，没有有限交点。
\end{itemize}
\end{summarybox}
