\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	外角平分线的比例式与内角平分线相同，但交点位置不同，其本质是角平分线性质在边长比例上的体现。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（比例式相同）：}] 外角平分线定理比例式与内角平分线完全相同：$\frac{BD}{DC} = \frac{AB}{AC}$。
		\item[\textbf{要点二（交点位置不同）：}] 外角平分线交点在$BC$的延长线上，内角平分线交点在$BC$线段上。
		\item[\textbf{要点三（证明关键）：}] 证明时常用正弦定理，利用补角正弦相等化简。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（相似与正弦）}}

	利用正弦定理将边与角的正弦联系起来，通过$\angle BAD + \angle CAD = 180^\circ$得到$\sin\angle BAD = \sin\angle CAD$，从而得到边比例。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（分式方程）}}

	比例式$\frac{BD}{DC} = \frac{AB}{AC}$可转化为分式方程，用于求未知边长或比值。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（快速求解）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接套用比例）：} 已知两边长和一段长度，直接列比例求未知。
		\item \textbf{考法二（综合几何题）：} 结合内角平分线或中线，求分点间距离。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{外角平分线比例式与内角平分线完全相同！但交点位置不同，因此线段关系不同（内角和，外角差）。只需记一个比例式，注意区分交点位置和线段关系即可。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（已知比例求边长）：} 已知两边长及外角平分线分出的一段长度，求另一段。
		\item \textbf{场景二（内外角平分线综合）：} 同时出现内外角平分线时，分别用定理求交点位置，再求距离。
	\end{itemize}
\end{explanationbox}
