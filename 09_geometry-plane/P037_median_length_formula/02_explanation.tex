\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	中线长公式可以看作“平行四边形对角线平方和等于四边平方和”的直接推论：将三角形补成平行四边形，对角线即中线的2倍，直接得到关系。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（平行四边形背景）：}]
			将$\triangle ABC$补成以$AB$、$AC$为邻边的平行四边形，则$BC$上的中线$AM$恰好是平行四边形对角线的一半。
		\item[\textbf{要点二（公式对称结构）：}]
			公式中$a$（对边）的系数为负，$b$、$c$（邻边）的系数为正，且整体是平方组合；若轮换字母，形式不变。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（向量中点模关系）}}
	设$M$为$BC$中点，则$\overrightarrow{AM} = \frac12(\overrightarrow{AB} + \overrightarrow{AC})$，两边平方即得$|\overrightarrow{AM}|^2$与$|\overrightarrow{AB}|^2$、$|\overrightarrow{AC}|^2$、$\overrightarrow{AB}\cdot\overrightarrow{AC}$的关系。再通过余弦定理或向量点积表示点积与边长的关系，化简即得中线公式。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（平方线性组合）}}
	中线长平方是三条边长平方的线性组合：两个邻边平方取正，对边平方取负，系数分别为$\frac12$、$\frac12$、$-\frac14$，因此表达式为$\frac12(b^2+c^2)-\frac14 a^2$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（边长中线互求）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求中线）：} 已知三角形三边长度，直接代入公式计算某条中线长，避免作高或使用余弦定理。
		\item \textbf{考法二（方程求边长）：} 已知两边及中线长度，代入公式解关于第三边的方程，注意取舍正根。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	记忆公式时，可联想“中线平方 = (邻边平方和的一半) - (对边平方的四分之一)”。或从平行四边形法则出发：平行四边形对角线的平方和等于四边平方和，而此对角线的一半即中线。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（选填速算）：} 在解三角形选择题或填空题中，遇到求中线可直接套用，节省时间。
		\item \textbf{场景二（复杂构图）：} 当图形中包含多条中线或需要计算有关距离时，中线公式能直接建立边长关系。
	\end{itemize}

\end{explanationbox}
