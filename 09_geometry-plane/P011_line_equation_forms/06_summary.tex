\begin{summarybox}

	\textbf{\textcolor{CSummary}{一句话核心}}

	直线方程的五种形式——点斜式、斜截式、两点式、截距式、一般式——对应不同的已知条件，其本质都是$x$、$y$的一次方程，最终可统一为$Ax+By+C=0$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（已知一点一斜率）：} 使用点斜式，但斜率必须存在。
		\item \textbf{条件2（已知斜率和截距）：} 使用斜截式，要求斜率存在。
		\item \textbf{条件3（已知两点）：} 使用两点式，要求两点横、纵坐标均不相等。
		\item \textbf{条件4（已知两截距）：} 使用截距式，要求两截距均非零。
		\item \textbf{条件5（任意情况）：} 使用一般式，最终归结为二元一次方程。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（斜率不存在）：} 垂直$x$轴的直线不能用点斜式或斜截式，应用$x=x_0$。
		\item \textbf{检查项（分母非零）：} 使用两点式、截距式前必须确认分母不为零。
		\item \textbf{检查项（截距符号）：} 截距可负，不要误认为正数。
	\end{itemize}
\end{summarybox}
