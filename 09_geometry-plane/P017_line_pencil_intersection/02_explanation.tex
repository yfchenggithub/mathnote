\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	就是将两条直线方程像“加权组合”一样混合，得到的方程仍然经过它们的交点。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（加权组合）：}]
			直线系方程可以理解成将 $l_1$ 与 $l_2$ 的方程以 $1$ 和 $\lambda$ 为系数相加，得到的新方程仍是一次方程，代表一条直线。
		\item[\textbf{要点二（过定点保证）：}]
			因为交点坐标同时满足 $l_1=0$ 和 $l_2=0$，所以代入加权和必然得零，故所有直线都过该交点。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（交点直线族）}}
	所有过两条已知直线交点的直线构成的集合，称为直线束。直线系方程就是该直线束的代数表示。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（线性组合）}}
	方程 $l_1+\lambda l_2=0$ 本质上是 $l_1$ 与 $l_2$ 的线性组合（系数比为 $1:\lambda$），体现了直线方程的线性性质。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（快速设线）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求过交点直线）：} 已知两相交直线，求过交点且满足另一条件（如斜率、平行、垂直）的直线方程，可先设为直线系形式，再代入条件解 $\lambda$，避免联立求交点。
		\item \textbf{考法二（含参定点问题）：} 当直线方程含参数时，若可整理为 $l_1+\lambda l_2=0$ 结构，则直线恒过 $l_1$ 与 $l_2$ 的交点。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	直线系方程的本质是“固定交点，变动斜率”。参数 $\lambda$ 控制的是直线的方向（斜率），但不需要直接求交点坐标。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（待定系数求线）：} 问题给出两条相交直线，求过交点且满足某个独立条件（如过另一已知点、与某直线垂直）的直线方程。
		\item \textbf{场景二（动直线过定点）：} 证明直线恒过定点时，将直线方程改写为 $l_1+\lambda l_2=0$ 的形式，找出两条特定直线，交点即为定点。
	\end{itemize}

\end{explanationbox}
