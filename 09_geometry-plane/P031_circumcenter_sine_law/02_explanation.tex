\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	外心到顶点距离都等于外接圆半径，且通过正弦定理，边长可以转化为角的正弦。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（等距关系）：}] 外心 $O$ 是 $\triangle ABC$ 外接圆圆心，故 $OA = OB = OC = R$。
		\item[\textbf{要点二（正弦定理）：}] 由 $OA = OB = OC = R$ 结合圆周角定理，可得 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（图形含义）}}

	外心是中垂线交点，外接圆把所有顶点放在同一圆上，圆心到顶点的距离是半径。这个性质直接给出了边与对角正弦的比值关系。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（边角转化）}}

	正弦定理把边长 $a,b,c$ 与角 $A,B,C$ 的正弦联系起来，使得边角可以互相转化，为解三角形提供工具。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高频题型）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求外接圆半径）：} 已知三角形两边及一角，直接代入求 $R$。
		\item \textbf{考法二（边角互化）：} 将边 $a,b,c$ 统一化为 $2R\sin A$ 等形式简化运算。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	外心距离相等是“外接圆”的本质，正弦定理就是从这个圆性质推导出来的，因此凡是涉及外接圆的问题，优先考虑外心和正弦定理。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（外接圆问题）：} 已知三角形外形或外接圆上的点，求角度或边长。
		\item \textbf{场景二（解三角形）：} 已知两边及其中一边对角，用正弦定理求其他边角。
	\end{itemize}
\end{explanationbox}
