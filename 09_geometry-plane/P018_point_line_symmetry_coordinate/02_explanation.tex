\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	点关于直线的对称点，相当于把点沿垂直方向“翻折”到直线另一侧，保持距离相等。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（中点条件）：}] 对称点与原点的中点必在直线上。
		\item[\textbf{要点二（垂直条件）：}] 对称点与原点的连线与直线垂直。
		\item[\textbf{要点三（距离关系）：}] 对称点到直线的距离等于原点到直线的距离。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（垂直平分线）}}

	直线$l$是线段$PP'$的垂直平分线。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（解方程组）}}

	将中点条件与垂直条件转化为两个方程，联立求解即得对称点坐标。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（对称问题）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求对称点）：} 给出点和直线，直接套公式计算。
		\item \textbf{考法二（反射路径）：} 求入射或反射光线方程时，先求对称点再连线。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	抓住“中点在直线上”和“连线与直线垂直”两个条件，即可绕过记忆公式直接推导。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（解析几何对称）：} 求点关于直线对称、曲线关于直线对称的转化。
		\item \textbf{场景二（物理光学）：} 平面镜反射问题，利用对称点确定光路。
	\end{itemize}
\end{explanationbox}
