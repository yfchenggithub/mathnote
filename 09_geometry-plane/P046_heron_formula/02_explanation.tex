\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	海伦公式用半周长将三边整合成一个对称代数式，直接算出三角形面积，免去作高或查角。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}

	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（半周长运算）：}]
		      $p = \dfrac{a+b+c}{2}$ 是三边之和的一半，对称地包含所有边长。

		\item[\textbf{要点二（根号乘积）：}]
		      在三角形不等式成立时，$p$, $p-a$, $p-b$, $p-c$ 均为正数，
		      因而 $\sqrt{p(p-a)(p-b)(p-c)}$ 对应一个正的面积值。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（边长代数化）}}

	面积原本常由底和高来计算，海伦公式把面积转化为只含三边的对称代数式，本质上是三角形几何关系的代数表达。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（无几何辅助）}}

	海伦公式给出了纯代数途径：只需已知三边数值，即可直接计算面积，无需测量高或角度，非常适合解析几何与代数综合题。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（解题工具）}}

	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接套公式）：} 已知三边数值，直接代入海伦公式求面积。
		\item \textbf{考法二（间接求解）：} 已知三边关系（如比例或方程），先求边长再计算面积。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	海伦公式中
	\[
		p-a = \frac{b+c-a}{2},
		\qquad
		p-b = \frac{a+c-b}{2},
		\qquad
		p-c = \frac{a+b-c}{2}
	\]
	这些因子与三角形不等式直接对应。若某边不小于另两边之和，就会出现非正因子，面积不再是正常三角形的正面积。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}

	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（直接已知三边）：} 给出三边长度，用海伦公式求面积。
		\item \textbf{场景二（三边含参数）：} 三边用字母表示时，可先求半周长再代入，化简代数式。
	\end{itemize}
\end{explanationbox}
