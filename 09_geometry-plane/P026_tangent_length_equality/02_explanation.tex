\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	从圆外一点引圆的两条切线，相当于构造两个完全相同的直角三角形，从而切线长相等、连线平分角。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（全等三角形构造）：}] 连接圆心与切点 $OA$、$OB$，由切线的性质得 $OA\perp PA$、$OB\perp PB$，所以 $\triangle OAP$ 和 $\triangle OBP$ 都是直角三角形。又 $OA=OB$，$OP$ 公共，故由 HL 定理得 $\triangle OAP\cong\triangle OBP$。
		\item[\textbf{要点二（勾股公式推导）：}] 在直角三角形 $OAP$（或 $OBP$）中，利用勾股定理得 $PA^{2}=OP^{2}-OA^{2}$，即 $PA=\sqrt{d^{2}-r^{2}}$。同理 $PB$ 相等。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（全等直角三角形）}}

	切线垂直于半径，产生两个直角三角形。因为半径相等且公共边相等，所以它们全等。全等带来对应边长相等（切线相等）、对应角相等（角平分线）、且由等腰三角形性质可得垂直平分弦。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（勾股定理直接应用）}}

	切线长公式 $l=\sqrt{d^{2}-r^{2}}$ 就是勾股定理的代数表达，将几何长度关系转化为代数运算，是数形结合的典型。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（切线相关计算）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（切线长度计算）：} 已知 $d$ 和 $r$，直接套用公式求切线长。
		\item \textbf{考法二（角度与垂直关系）：} 利用 $OP$ 平分 $\angle APB$ 证明角相等；利用 $OP$ 垂直平分 $AB$ 证明线段相等或垂直。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	遇到圆外一点与两条切线时，先连接圆心与该点，再连接圆心与两个切点，就形成了全等直角三角形，多数性质由此而来。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（切线长与弦长问题）：} 给出 $d$ 和 $r$，求切线长、切点弦长或四边形面积。
		\item \textbf{场景二（角度或位置关系证明）：} 在几何证明题中，利用切线长定理作为全等和角平分线的依据。
	\end{itemize}
\end{explanationbox}
