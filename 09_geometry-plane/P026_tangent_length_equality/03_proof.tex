\begin{proofbox}
	\textbf{\textcolor{CProof}{思路提示}}

	先证明两个直角三角形全等，再由全等推出边长相等、角相等，最后利用等腰三角形性质或全等进一步推出垂直平分关系。

	\medskip
	\textbf{\textcolor{CProof}{正式推导}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.55em]
		\item[\textbf{步骤一（连接半径辅助线）：}] 连接 $OA$、$OB$。
			\[
				OA \perp PA,\quad OB \perp PB.
			\]
			\par\textbf{理由：} 切线与过切点的半径垂直。

		\item[\textbf{步骤二（HL全等判定）：}] 在 $\triangle OAP$ 与 $\triangle OBP$ 中，
			\[
				\because OA = OB,\; OP = OP,\; \angle OAP = \angle OBP = 90^\circ \Rightarrow \triangle OAP \cong \triangle OBP \ ( \text{HL} ).
			\]
			\par\textbf{理由：} 两直角三角形斜边和一条直角边对应相等则全等。

		\item[\textbf{步骤三（切线长相等）：}] 由全等得
			\[
				PA = PB.
			\]
			在 Rt$\triangle OAP$ 中，由勾股定理
			\[
				PA^2 = OP^2 - OA^2 = d^2 - r^2,
			\]
			所以 $PA = PB = \sqrt{d^2 - r^2}$。
			\par\textbf{理由：} 全等三角形对应边相等；勾股定理。

		\item[\textbf{步骤四（角平分线）：}] 由全等得
			\[
				\angle APO = \angle BPO.
			\]
			因此 $OP$ 平分 $\angle APB$。
			\par\textbf{理由：} 全等三角形对应角相等。

		\item[\textbf{步骤五（垂直平分弦）：}] 由全等得 $\angle AOP = \angle BOP$。设 $OP$ 与 $AB$ 交于点 $M$，在等腰 $\triangle AOB$（$OA=OB$）中，顶角平分线 $OM$ 垂直于底边 $AB$ 且平分底边 $AB$。故
			\[
				OM \perp AB,\quad AM = MB.
			\]
			即 $OP$ 垂直平分 $AB$。
			\par\textbf{理由：} 等腰三角形顶角平分线、底边中线、底边高线三线合一。
	\end{description}

	\medskip
	\textbf{\textcolor{CProof}{结论回扣}}

	通过全等直角三角形（HL）直接获得切线相等和角平分，再结合等腰三角形性质得到垂直平分。定理的三个结论环环相扣。
\end{proofbox}
