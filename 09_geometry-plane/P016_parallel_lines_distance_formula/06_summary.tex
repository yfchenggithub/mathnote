\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	平行线间距离公式 $d=\dfrac{|C_1-C_2|}{\sqrt{A^2+B^2}}$，分子代表常数项差的绝对值，分母代表系数向量的模。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（一般式形式）：} 两直线方程均化为 $Ax+By+C=0$。
		\item \textbf{条件 2（系数相同）：} $x,y$ 系数 $A,B$ 相同。
		\item \textbf{条件 3（平行不重合）：} $C_1\neq C_2$（$C_1=C_2$ 时直线重合，距离 $0$）。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（验证前提）：} 使用时先判断两直线是否平行，且系数对应成比例。
		\item \textbf{检查项（分子绝对值）：} 确保分子有绝对值符号。
	\end{itemize}
\end{summarybox}
