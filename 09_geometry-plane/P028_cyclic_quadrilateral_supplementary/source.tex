\textbf{结论名称：}圆内接四边形对角互补

\textbf{适用条件：}四边形四个顶点共圆（存在唯一的外接圆）.

\textbf{变量说明：}四边形 \(ABCD\) 内接于 \(\odot O\)，四个内角分别为 \(\angle A,\angle B,\angle C,\angle D\).

\textbf{核心公式：}\[
\boxed{\angle A + \angle C = 180^\circ,\qquad \angle B + \angle D = 180^\circ}
\]

\textbf{使用场景：}已知部分角度求未知角；证明四点共圆（若四边形一组对角互补则四点共圆）；在圆背景下进行角度代换与等角推理，常用于中考、高考选择题与填空题.

\textbf{简单例子：}已知圆内接四边形 \(ABCD\) 中 \(\angle A = 70^\circ\), \(\angle B = 115^\circ\)，求 \(\angle C\) 和 \(\angle D\).
由对角互补得 \(\angle C = 180^\circ - 70^\circ = 110^\circ\), \(\angle D = 180^\circ - 115^\circ = 65^\circ\). 验算四边形内角和 \(70^\circ+115^\circ+110^\circ+65^\circ=360^\circ\)，符合几何事实.
