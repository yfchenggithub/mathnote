\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	两圆位置如同两个人之间的“安全距离”：$d$ 太小则包容，$d$ 太大则分离。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（半径和差）：}]
			$R+r$ 是“外边界”，当 $d$ 超过此值则两圆不相交；$R-r$ 是“内边界”，当 $d$ 小于此值则两圆内含。
		\item[\textbf{要点二（交点个数）：}]
			交点只出现在 $R-r \le d \le R+r$ 范围内；边界等号对应相切（1个交点），内部严格不等对应相交（2个交点）。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（距离比较）}}
	圆心距 $d$ 直接刻画两圆圆心的远近。当 $d$ 逐渐从 $0$ 变化到 $R+r$ 时，两圆从包含依次过渡到相交、相切、相离。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（方程决定）}}
	将两圆方程联立，消去二次项后得到一条直线（根轴），此直线到两圆心的距离与半径的关系等价于 $d$ 与 $R\pm r$ 的比较，因此代数上同样由判别式（与零比较）判定交点个数。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（快速判定）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（位置判断）：} 给出半径和圆心距，直接套用条件选择正确关系。
		\item \textbf{考法二（参数求解）：} 已知位置关系（如相切、相交），建立 $d$ 与 $R,r$ 的等式或不等式求参数范围。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	“$+$”对应外，“$-$”对应内；“等号相切，不等相交”。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（判断位置）：} 已知两圆方程或圆心距、半径，快速判断位置关系。
		\item \textbf{场景二（参数范围）：} 题目给出“两圆相切”或“相交”等条件，转化为 $d$ 与 $R\pm r$ 的方程或不等式。
	\end{itemize}

\end{explanationbox}
