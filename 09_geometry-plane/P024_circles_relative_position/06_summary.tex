\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	两圆位置由圆心距与半径和、差的比较唯一确定：$d > R+r$ 外离，$d = R+r$ 外切，$R-r < d < R+r$ 相交，$d = R-r$ 内切，$0\le d<R-r$ 内含。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（半径非负）：} $R>r>0$，且 $d\ge 0$。
		\item \textbf{条件2（直接比较）：} 直接计算 $R+r$ 和 $R-r$ 并与 $d$ 比较。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（内外界混淆）：} 外离、外切对应 $R+r$；内切、内含对应 $R-r$。
		\item \textbf{检查项（等号处理）：} 等号出现即相切，切不可漏掉等号。
	\end{itemize}

\end{summarybox}
