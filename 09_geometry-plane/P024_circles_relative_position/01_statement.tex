\begin{statementbox}
	\textbf{\textcolor{CStatement}{条件}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CStatement}{条件1（半径圆心距）：}}]
			两圆半径分别为 $R$ 和 $r$，满足 $R > r > 0$；圆心距为 $d$（$d \ge 0$）。
	\end{description}
	\textbf{\textcolor{CStatement}{结论}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{\textcolor{CStatement}{结论一（位置关系判定）：}}]
			\textbf{\textcolor{CStatement}{直观描述：}}
			通过比较圆心距 $d$ 与半径和 $R+r$、半径差 $R-r$ 的大小，唯一确定两圆位置关系。
			\[
				\begin{cases}
					d > R + r,\\ d = R + r,\\ R - r < d < R + r,\\ d = R - r,\\ 0 \le d < R - r.
			\end{cases}
			\]
			分别对应：外离（0个交点）、外切（1个交点）、相交（2个交点）、内切（1个交点）、内含（0个交点）。
		\item[\textbf{\textcolor{CStatement}{推广结论（公切线数量）：}}]
			\textbf{\textcolor{CStatement}{直观描述：}}
			两圆位置关系决定公切线的总条数，无需重新计算。
			\[
				\begin{cases}
					d > R + r,\\ d = R + r,\\ R - r < d < R + r,\\ d = R - r,\\ 0 \le d < R - r.
			\end{cases}
			\]
			分别对应公切线数：4条、3条、2条、1条、0条。
	\end{description}

\end{statementbox}
