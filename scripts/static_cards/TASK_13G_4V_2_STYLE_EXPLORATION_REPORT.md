## 6. Mathematical Validation

- 正式 TeX 与 `meta.json` 的条件为横轴型 `x²/a²−y²/b²=1`，`a>0,b>0`，`c²=a²+b²`；六张卡均显示这些条件与关系。绘图是同一精确比例示例 `a=3,b=4,c=5`，不是六种不同数学内容。
- `O=(0,0)`、`A=(3,0)`、`B=(3,4)`、`F₂=(5,0)`；`OA=3`、`AB=4`、`OB=OF₂=5`。`B` 是辅助矩形角点，代入双曲线左边得 **0**，并不在值为 1 的曲线上；`B≠F₂`。`OB` 与 `OF₂` 长度相同、几何线段不同。坐标由 C043 的 `Hyperbola` 模型和等比例 `MathFrame` 给出，分支由 `branch_point()` 采样绘制。
- C043 模型的 `validation_results()` **11/11 PASS**，C043 私有模型单元测试 **7/7 PASS**，V1 `--validate-only` 数学及内容 **PASS**。渐近线方向由原模型测试覆盖；本轮候选为减轻图形拥挤而不显示渐近线，不能把未绘制的渐近线说成视觉验收通过。
- 纯形式源 token 检查不等于全面证明；显示的关系和每张卡的几何关联另经逐张人工核对。

## 9. Brand & Module Strategy

可组合的元素：A 的渐变标题/暖黄公式/绿色记忆区；B 的图版、纸面与字体层级；C 的大图与深色结论带；D 的辅助说明与学习笔记感；E 的暗色空间和亮线；F 的参数色块、箭头和对应关系。标题、背景、色彩、公式强调、几何处理、信息模块、记忆提示、字体层级可分别选，不要求机械挑一张完整模板。

初步适配：圆锥曲线适合 B/C/E/F 的等比例图形；函数图像适合 C/E 的曲线主视觉；导数与极值适合 F 的变化关系或 C 的大图；概率统计优先考虑数据可视化而非直接复用曲线版式；排列组合适合 F 的结构流；立体几何需要单独验证空间投影；纯公式结论可取 A/B/D 的重点排版。这些是**下一轮设计假设**，未在其他 UID 实施或验证。品牌编号、数学准确性、3:4 比例与基础字级可统一，表现主题按数学表达类型再选。
