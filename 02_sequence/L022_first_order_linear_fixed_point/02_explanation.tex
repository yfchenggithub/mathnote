\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	递推式减去不动点后变为等比，规律简化。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（不动点含义）：}] 方程 $x = p x + q$ 的根 $\lambda$，是递推的不变点。
		\item[\textbf{要点二（构造消常）：}] 令 $b_n = a_n - \lambda$，则 $b_{n+1} = p b_n$，常数项消除。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（迭代收敛）}}

	递推对应线性函数迭代，不动点是函数图像与 $y=x$ 的交点。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（降阶齐次）}}

	构造新数列将非齐次递推化为齐次等比，降维处理。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（通项求法）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求通项）：} 给出递推，直接代入公式计算。
		\item \textbf{考法二（参数反求）：} 已知数列某两项，列方程解 $p,q$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	为什么减 $\lambda$？因为 $\lambda$ 满足 $\lambda = p\lambda+q$，代入递推恰好消去常数，露出等比关系。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（标准递推）：} 递推形式符合 $a_{n+1}=p a_n+q$。
		\item \textbf{场景二（构造证明）：} 需要证明 $\{a_n-\lambda\}$ 为等比数列。
	\end{itemize}
\end{explanationbox}
