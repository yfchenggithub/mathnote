\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	二阶线性递推的通项公式，思路就是假设指数形式代入递推，把递推问题转化为代数方程求根问题。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（指数假设）：}]
		      设 \(a_n=r^n\)（\(r\neq0\)），代入递推式
		      \(a_{n+2}=p a_{n+1}+q a_n\)，得到
		      \[
			      r^{n+2}=p r^{n+1}+q r^n.
		      \]
		      两边同除以 \(r^n\)，即得特征方程 \(r^2-pr-q=0\)。这个方程的根决定通项的基本形式。

		\item[\textbf{要点二（通项结构）：}]
		      特征根 \(\lambda_1,\lambda_2\) 出现三种常见情况：不等实根时，通项是指数项的线性组合；相等实根时，通项是一次多项式乘以指数；共轭复根时，通项可化为三角形式，体现振荡特征。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（复平面旋转）}}

	当特征根为共轭复数 \(re^{\pm i\theta}\) 时，通项
	\[
		r^n\bigl(C_1\cos n\theta+C_2\sin n\theta\bigr)
	\]
	可以理解为复平面上的“缩放 + 旋转”：模长按 \(r^n\) 缩放，每推进一项旋转 \(\theta\)。若特征根为实数，则表现为实数轴上的指数增长、衰减或交替变化。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（降维求解）}}

	特征根法把二阶递推关系转化为关于 \(r\) 的二次方程，利用代数求根直接写出通项公式，避免逐项迭代。这是“把数列递推代数化”的典型方法。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（常见考法）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（正向求通项）：} 给出递推关系和两个初始值，要求写出通项公式。先写特征方程，再分类讨论特征根。
		\item \textbf{考法二（参数反求）：} 已知通项形式或特征根，反推递推系数 \(p,q\)。常用根与系数关系 \(\lambda_1+\lambda_2=p\)，\(\lambda_1\lambda_2=-q\)。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{抓住“指数代入”这个核心，就能理解为什么通项由特征根决定。高阶常系数线性递推也是类似思想，只是特征方程次数更高。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（Fibonacci 数列）：} 递推 \(a_{n+2}=a_{n+1}+a_n\)，特征方程为 \(r^2-r-1=0\)，特征根为 \(\frac{1\pm\sqrt5}{2}\)，可直接写出 Binet 公式。
		\item \textbf{场景二（常系数递推）：} 任何形如 \(a_{n+2}=p a_{n+1}+q a_n\) 的齐次二阶常系数递推，只要 \(q\neq0\)，均可写出特征方程并求通项。
	\end{itemize}
\end{explanationbox}
