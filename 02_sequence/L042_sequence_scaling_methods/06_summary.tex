\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	\textbf{数列放缩是通过构造可求和或可求积的中间量，间接证明数列不等式的策略。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（通项可放缩）：} 数列通常为正项，通项能放大或缩小为裂项、等比或糖水形式。
		\item \textbf{条件2（放缩后可计算）：} 放缩后的式子必须能通过裂项相消、等比求和或连乘化简等操作算出上界或下界。
		\item \textbf{条件3（方向服务目标）：} 要证小于某个常数，通常找上界；要证大于某个常数，通常找下界。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（方向一致）：} 放缩不等号方向必须与目标一致，不可随意反向。
		\item \textbf{检查项（参数条件）：} 使用裂项放缩注意 $n$ 的范围；等比放缩注意 $0<q<1$；糖水放缩注意 $0<a<b$、$m>0$。
		\item \textbf{核心方法（先估再算）：} 先估计通项，再对估计后的式子求和或求积。
	\end{itemize}
\end{summarybox}
