\textbf{结论名称：}错位相减法标准步骤（等差$\times$等比求和）

\textbf{适用条件：}数列$\{a_n\}$为等差数列，$\{b_n\}$为等比数列且公比$q\neq 1$，求$S_n=\sum_{k=1}^{n} a_k b_k$。

\textbf{变量说明：}$a_1,d$：等差数列的首项与公差；$b_1,q$：等比数列的首项与公比（$q\neq 1$）；记$a_n=a_1+(n-1)d$，$b_n=b_1 q^{\,n-1}$。

\textbf{核心公式：}
\[
\boxed{ S_n = \frac{a_1 b_1 - a_n b_n q}{1-q} + \frac{d\,b_1 q\,(1-q^{\,n-1})}{(1-q)^2} }
\]

\textbf{使用场景：}求通项为“等差$\times$等比”型数列的前$n$项和，如$\{(kn+t)q^{n-1}\}$。

\textbf{简单例子：}求$S_n = 1\cdot 2 + 3\cdot 2^2 + 5\cdot 2^3 + \cdots + (2n-1)2^n$。\\
对应$a_n=2n-1$（$a_1=1,d=2$），$b_n=2^n$（$b_1=2,q=2$）。代入公式得
\[
S_n = \frac{1\cdot 2 - (2n-1)2^{n+1}}{1-2} + \frac{2\cdot 2\cdot 2\,(1-2^{\,n-1})}{(1-2)^2}
     = (2n-3)2^{n+1}+6 .
\]
验证：$n=3$时，直接求和$2+12+40=54$，公式给出$(6-3)\cdot 16+6=54$，一致。
