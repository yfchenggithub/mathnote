\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	等比数列每取连续$m$项的和，将和依次排开，它们也会成等比，比值是$q^m$。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（片段和拆分）：}] 将前$n$项和$S_n$分段。例如$S_{2m}$等于$S_m$加上后$m$项的和。后$m$项和为$q^mS_m$。因此$S_{2m}=S_m(1+q^m)$。
		\item[\textbf{要点二（公比来源）：}] 对比$S_{2m}-S_m$与$S_m$，有$S_{2m}-S_m=q^mS_m$，比值$q^m$。同样，$S_{3m}-S_{2m}=q^{2m}S_m$，与$S_{2m}-S_m$的比值也是$q^m$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（缩进放大）}}

	将等比数列每$m$项看作一组，每组之和构成的新数列中，后一组与前一组之比恒为$q^m$，这源于等比数列每项缩放$q^m$的特性。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（代数结构）}}

	利用等比数列求和公式$S_n=\frac{a_1(1-q^n)}{1-q}$。直接计算可得$\frac{S_{2m}-S_m}{S_m}=q^m$，展示其代数恒等性。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（考法提炼）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（片段求和）：} 在涉及间隔$m$项之和的问题中，利用该性质直接列出比例式，避免逐项计算。
		\item \textbf{考法二（公比判定）：} 通过已知的片段和比值，推断等比数列的公比$q$（需开$m$次方）。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{关键思路：$S_{2m}=S_m+q^mS_m$。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（求公比）：} 已知等比数列的连续两段等长片段和，直接求公比。
		\item \textbf{场景二（证明等比）：} 若一数列的片段和满足此比例，可辅助判断原数列为等比。
	\end{itemize}
\end{explanationbox}
