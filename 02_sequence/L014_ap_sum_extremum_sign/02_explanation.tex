\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	和的增减取决于新加项的符号：加正和增，加负和减。因此和的最值出现在项的正负转换点处。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（和差关系）：}]
			$S_{n+1}-S_n = a_{n+1}$，和的变化完全由$a_{n+1}$的符号决定。
		\item[\textbf{要点二（符号拐点）：}]
			若$d>0$，$a_n$递增，当$a_n\le 0$且$a_{n+1}\ge 0$时，和从减转增，达到最小值；若$d<0$，$a_n$递减，当$a_n\ge 0$且$a_{n+1}\le 0$时，和从增转减，达到最大值。
		\item[\textbf{要点三（公差作用）：}]
			公差$d$的符号决定了$a_n$的单调方向，从而决定最值是最大还是最小。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（抛物线顶点）}}
	设$S_n = \frac{d}{2}n^2 + (a_1-\frac{d}{2})n$，其图象是开口由$d$符号决定的抛物线上的散点。最值对应抛物线顶点附近整数点的函数值。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（不等式组）}}
	最值条件等价于求解不等式组：在$d<0$时，$
	\begin{cases}
		a_n\ge0\\ a_{n+1}\le0
	\end{cases}
	$；在$d>0$时，$
	\begin{cases}
		a_n\le0\\ a_{n+1}\ge0
	\end{cases}
	$。满足$n$唯一或有限。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（求最值工具）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求项数）：} 通过不等式组求出$n$，即最值点。
		\item \textbf{考法二（求最值）：} 代入$n$计算出$S_n$即得最值。
		\item \textbf{考法三（验证极值）：} 检验$a_n$与$a_{n+1}$的符号是否满足条件，判断$S_n$是否为最值。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	“和的最值”不是由$a_n$本身的大小决定，而是由$a_n$与$a_{n+1}$的符号突变决定。把“和”的问题转化为“项”的正负判断。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（已知通项）：} 已知$a_n$的一次式，直接解不等式组。
		\item \textbf{场景二（已知Sn式）：} 若已知$S_n$的表达式，也可通过判别$a_n = S_n - S_{n-1}$再使用本结论。
		\item \textbf{场景三（应用问题）：} 如利润、成长率等差模型，求最值项数。
	\end{itemize}

\end{explanationbox}
