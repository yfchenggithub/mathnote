\textbf{结论名称：} 数列单调性的差比法与商比法判定

\textbf{适用条件：} 差比法 \(a_{n+1}-a_n\) 对任意数列均适用；商比法 \(\dfrac{a_{n+1}}{a_n}\) 一般要求各项同号（通常取正项数列 \(a_n>0\)）。

\textbf{变量说明：} \(\{a_n\}\) 为给定数列，\(n\in\mathbb{N}^*\)；\(a_n\) 为通项。

\textbf{核心公式：}
\[
\boxed{
a_{n+1}-a_n
\begin{cases}
>0 \Rightarrow \{a_n\}\text{ 严格递增}\\
=0 \Rightarrow \{a_n\}\text{ 为常数列}\\
<0 \Rightarrow \{a_n\}\text{ 严格递减}
\end{cases}
\qquad
\text{若 } a_n>0,\;
\frac{a_{n+1}}{a_n}
\begin{cases}
>1 \Rightarrow \{a_n\}\text{ 严格递增}\\
=1 \Rightarrow \{a_n\}\text{ 为常数列}\\
<1 \Rightarrow \{a_n\}\text{ 严格递减}
\end{cases}
}
\]

\textbf{使用场景：} 判断数列单调性，用于求数列的最大项、最小项，证明数列不等式或分析数列的有界性、极限行为。

\textbf{简单例子：} 设 \(a_n = \dfrac{n}{n+1}\;(a_n>0)\)。  
差比法：\(a_{n+1}-a_n = \dfrac{n+1}{n+2}-\dfrac{n}{n+1} = \dfrac{1}{(n+1)(n+2)} >0\)，故 \(\{a_n\}\) 递增。  
商比法：\(\dfrac{a_{n+1}}{a_n} = \dfrac{n+1}{n+2}\cdot \dfrac{n+1}{n}= \dfrac{(n+1)^2}{n(n+2)} = \dfrac{n^2+2n+1}{n^2+2n}>1\)，同样判定递增。
