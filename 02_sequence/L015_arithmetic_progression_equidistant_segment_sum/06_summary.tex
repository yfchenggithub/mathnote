\begin{summarybox}

	\textbf{\textcolor{CSummary}{一句话核心}}

	等差数列每隔固定$m$项取一段求和，得到的新数列仍是等差数列，公差为$m^2 d$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（数列类型）：} 原数列必须是等差数列。
		\item \textbf{条件 2（分段规则）：} 分段长度$m$取定正整数，每段项数相同。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（平方因子）：} 公差包含$m^2$而非$m$，计算时务必平方。
		\item \textbf{检查项（首段定义）：} $T_1=S_m$，注意$S_0=0$的约定，不要漏减。
	\end{itemize}

\end{summarybox}
