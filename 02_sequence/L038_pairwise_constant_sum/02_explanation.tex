\begin{explanationbox}
	\n\textbf{\textcolor{CExplanation}{一句话直觉}}\n\n将原数列与倒序数列逐项对应相加，每一对和均为常数，从而快速求和。\n\n

	\medskip
	\n\textbf{\textcolor{CExplanation}{核心拆解}}\n
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\n
		\item[\textbf{要点一（配对思想）：}]
			对任意$k$，有$a_k + a_{n+1-k} = C$，因此将原数列与倒序数列逐项相加，$n$对的和都是$C$。\n
		\item[\textbf{要点二（等差特例）：}]
			等差数列中，任意对称两项之和等于首末项之和，即$a_1+a_n$，故可套用。\n
	\end{description}
	\n\n

	\medskip
	\n\textbf{\textcolor{CExplanation}{几何本质（对称加和）}}\n\n数列的项关于中心对称时，对称位置之和恒定，这类似于点关于中心对称。\n\n

	\medskip
	\n\textbf{\textcolor{CExplanation}{代数意义（恒等变换）}}\n\n通过倒序相加构造恒等式$2S_n = nC$，将未知求和转化为已知常数。\n\n

	\medskip
	\n\textbf{\textcolor{CExplanation}{考点价值（考查方向）}}\n
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\n
		\item \textbf{考法一（基础应用）：} 直接利用$a_k + a_{n+1-k}=C$，代入求和公式$S_n = nC/2$。\n
		\item \textbf{考法二（构造条件）：} 将一般数列通过换元或恒等变形，构造出对称等和关系再求和。\n
	\end{itemize}
	\n\n

	\medskip
	\n\textbf{\textcolor{CExplanation}{顿悟点}}\n\n关键不是背公式，而是识别“配对后每对和相等”的结构。\n\n

	\medskip
	\n\textbf{\textcolor{CExplanation}{使用场景}}\n
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\n
		\item \textbf{场景一（等差数列求和）：} 已知首项、末项与项数，直接使用$S_n = n(a_1+a_n)/2$。\n
		\item \textbf{场景二（对称数列求和）：} 发现数列满足$a_k + a_{n+1-k}$为定值，即可用倒序相加。\n
	\end{itemize}
	\n
\end{explanationbox}
