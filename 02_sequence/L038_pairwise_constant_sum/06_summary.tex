\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	数列前 \(n\) 项满足对称等和时，前 \(n\) 项和等于 \(n\) 倍常数 \(C\) 的一半：
	\[
		S_n=\frac{nC}{2}.
	\]

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（对称等和）：} 存在常数 \(C\)，使得 \(a_k+a_{n+1-k}=C\) 对所有 \(k=1,2,\dots,n\) 成立。
		\item \textbf{条件2（有限求和）：} 讨论的是前 \(n\) 项和，项数明确为 \(n\)。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（\(C\) 值验证）：} 使用前必须验证所有对称项和是否相等，不能只看首末项。
		\item \textbf{检查项（下标配对）：} 前 \(n\) 项的对称配对下标是 \(k\) 与 \(n+1-k\)。
		\item \textbf{逆向应用：} 已知 \(S_n\) 和 \(n\) 时，可由 \(C=\frac{2S_n}{n}\) 反求对称项和常数。
	\end{itemize}
\end{summarybox}
