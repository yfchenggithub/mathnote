\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	将对数分式 \(\log_a\!\left(1+\frac{1}{n}\right)\) 拆成相邻整数对数差 \(\log_a(n+1)-\log_a n\)，用于数列裂项求和。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（底数要求）：} \(a>0\) 且 \(a\neq1\)。
		\item \textbf{条件 2（真数结构）：} 真数必须能写成 \(1+\frac{1}{n}\)，也就是 \(\frac{n+1}{n}\) 的形式，其中 \(n\in\mathbb N^*\)。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（裂项方向）：} 裂项结果是 \(\log_a(n+1)-\log_a n\)，不是加法，不要与乘法法则混淆。
		\item \textbf{检查项（定义域）：} 使用前检查底数范围，并确认 \(\log_a(n+1)\) 与 \(\log_a n\) 均有定义。
		\item \textbf{检查项（求和首末项）：} 求和时中间项抵消，最后通常只剩首末两项，别漏掉 \(\log_a1=0\)。
	\end{itemize}
\end{summarybox}
