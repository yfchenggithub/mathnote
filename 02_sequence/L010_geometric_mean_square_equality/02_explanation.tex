\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	等比数列中，中间项的平方恰好等于前后两项的乘积，就像一个比例桥。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（公式形式）：}] 对于等比数列中任意连续三项，总有 $a_n^2 = a_{n-1}a_{n+1}$。
		\item[\textbf{要点二（符号多解）：}] 由 $a_n^2 = a_{n-1}a_{n+1}$ 开平方得 $a_n = \pm\sqrt{a_{n-1}a_{n+1}}$，故等比中项可能有两个值。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（比例中项）}}

	在等比数列中，$a_{n-1},a_n,a_{n+1}$ 成等比，则 $a_n$ 是 $a_{n-1}$ 与 $a_{n+1}$ 的比例中项，即 $\frac{a_n}{a_{n-1}} = \frac{a_{n+1}}{a_n}$，这是比例关系的代数表达。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（几何平均数）}}

	$a_n$ 是 $a_{n-1}$ 与 $a_{n+1}$ 的几何平均数，即 $|a_n| = \sqrt{a_{n-1}a_{n+1}}$。这与等差中项（算术平均数）形成对比。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（双解取舍）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求项）：} 已知等比数列中两项，利用等比中项求中间项。
		\item \textbf{考法二（符号甄别）：} 利用题目条件（正负号、公比符号）在双解中选出正确值。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	等比中项有正负两个值，但必须结合数列实际符号条件选择，不可只取正数。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（三项成等比判断）：} 验证三个数是否成等比，只需检查中间数平方是否等于两端积。
		\item \textbf{场景二（数列求项）：} 在已知数列某些项的前提下，可求其他项。
	\end{itemize}
\end{explanationbox}
