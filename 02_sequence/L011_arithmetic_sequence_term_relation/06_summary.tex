\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	等差数列中，任意一项均可通过另一项加上公差乘以项数差得出，即 \(a_n = a_m + (n-m)d\)。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（等差前提）：} 数列 \(\{a_n\}\) 必须是等差数列，公差为 \(d\)。
		\item \textbf{条件2（下标限制）：} \(m,n\) 均为正整数，无其他限制。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（分母顺序）：} 在利用 \(a_n - a_m\) 求公差时，分子分母下标顺序必须保持一致。
		\item \textbf{检查项（项数差）：} 代入公式时仔细核对项数差是 \(n-m\)，不是 \(n-m-1\) 或 \(n-m+1\)。
	\end{itemize}
\end{summarybox}
