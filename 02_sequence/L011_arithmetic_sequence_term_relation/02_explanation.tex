\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	等差数列中，任意两项之差与它们的位置差成正比，比例就是公差。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（结构类比）：}] 公式形如 \(a_n = a_m + (n-m)d\)，类似于直线方程的点斜式，其中 \((m, a_m)\) 为已知点，\(d\) 为斜率。
		\item[\textbf{要点二（公差角色）：}] 公差 \(d\) 表示项数每增加 $1$，项值增加 $d$，这是数列的“变化率”。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（点在直线）}}

	在坐标系中，点 \((n, a_n)\) 分布在斜率为 \(d\)、截距为 \(a_1 - d\) 的直线上。公式直接反映了两点的纵坐标差与横坐标差的比例关系。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（累加通式）}}

	由等差数列定义 \(a_{k+1} - a_k = d\) 累加可得对任意 \(m<n\)，\(a_n = a_m + \sum_{k=m}^{n-1} d = a_m + (n-m)d\)，本质是 \(d\) 的线性叠加。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（应用广泛）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（通项计算）：} 已知等差数列的任意一项和公差，可快速求出其他项。
		\item \textbf{考法二（等差判定）：} 证明数列是等差数列时，常利用 \(a_n - a_{n-1} =\) 常数，该公式提供了判断的代数依据。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	当 \(m=1\) 时，即为标准通项；当 \(n=m+1\) 时，得到相邻项关系；公式统一了等差数列的纵向联系。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（知任意项求值）：} 已知某一项数值及公差，直接代入公式求其他项。
		\item \textbf{场景二（等差证明）：} 若对任意 \(m,n\)，\(a_n - a_m\) 与 \(n-m\) 的比值为常数，则数列为等差数列。
	\end{itemize}
\end{explanationbox}
