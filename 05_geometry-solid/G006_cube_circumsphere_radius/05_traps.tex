\begin{trapbox}\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]\item[\textbf{\textcolor{CTrap}{易错点一（混淆半径公式）}}] 把正方体外接球半径记为$R = \frac{\sqrt{2}}{2}a$或$R = \frac{\sqrt{6}}{2}a$。\item[\textbf{\textcolor{CTrap}{正确理解（正确公式）：}}] 正确公式是$R = \frac{\sqrt{3}}{2}a$，可通过体对角线$d=\sqrt{3}a$且$R = d/2$验证。\item[\textbf{\textcolor{CTrap}{错因分析（混淆来源）：}}] 误以为球直径等于面对角线$(\sqrt{2}a)$，或记错比例。\end{description}\medskip\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]\item[\textbf{\textcolor{CTrap}{易错点二（内外混淆）}}] 将正方体内切球半径$a/2$当作外接球半径。\item[\textbf{\textcolor{CTrap}{正确理解（半径区分）：}}] 外接球过顶点，半径$R=\frac{\sqrt{3}}{2}a$；内切球与面相切，半径$r=\frac{a}{2}$，二者不同。\item[\textbf{\textcolor{CTrap}{错因分析（图形不清）：}}] 没有准确理解外接球和内切球的定义，球心位置不同导致半径不同。\end{description}\medskip\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]\item[\textbf{\textcolor{CTrap}{易错点三（逆解失误）}}] 已知外接球半径$R$反求棱长时，错误得到$a = \frac{\sqrt{3}}{2}R$或$a = \frac{R}{\sqrt{3}}$等。\item[\textbf{\textcolor{CTrap}{正确理解（公式变形）：}}] 由$R = \frac{\sqrt{3}}{2}a$正确变形得$a = \frac{2R}{\sqrt{3}}$。\item[\textbf{\textcolor{CTrap}{错因分析（代数错误）：}}] 解方程时两边同乘以$2/\sqrt{3}$的运算出错，或混淆乘除关系。\end{description}\end{trapbox}
