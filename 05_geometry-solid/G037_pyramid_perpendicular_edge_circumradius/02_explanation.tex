\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	将棱锥外接球问题转化为一个直角三角形勾股定理：球心到底面外心的水平距离和垂直距离构成直角边，斜边即为外接球半径。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（球心定位）：}] 球心在底面外心的正上方，到底面的距离等于侧棱长的一半（$h/2$）。
		\item[\textbf{要点二（勾股计算）：}] 球心到底面外心的水平距离为$r$，垂直距离为$h/2$，故$R = \sqrt{r^{2} + (h/2)^{2}}$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（垂直投影）}}

	由于侧棱垂直于底面，顶点在底面上的投影就是垂足；球心到所有顶点距离相等，迫使球心位于过底面外心且垂直于底面的直线上，且在线段$SA$的垂直平分面上，从而得到距离平分。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（方程求解）}}

	设球心$O$到底面距离为$d$，由$OA = OS$得$r^{2}+d^{2} = r^{2}+(h-d)^{2}$，解得$d=h/2$，代入得$R = \sqrt{r^{2}+(h/2)^{2}}$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（快速计算）}}

	在已知垂直侧棱长和底面外接圆半径的条件下，直接套用公式即可求出外接球半径，无需建立空间坐标系，适合选择题、填空题快速得分。

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	球心并不在侧棱的中点上，而是在底面外心的正上方，高度为$h/2$；这一结论来源于“到两点距离相等的点在线段垂直平分面上”的推广。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（直接套用）：} 已知垂直侧棱长$h$和底面外接圆半径$r$，直接计算$R$。
		\item \textbf{场景二（间接求r）：} 已知底面边长等条件，先求底面外接圆半径$r$，再代入公式。
	\end{itemize}
\end{explanationbox}
