\textbf{结论名称：} 有一条侧棱垂直于底面的棱锥外接球球心位置与半径公式

\textbf{适用条件：} 棱锥中有一条侧棱垂直于底面（底面多边形需存在外接圆，常见于三角形底面）。

\textbf{变量说明：} 设垂直底面的侧棱长为 \(h\)，底面外接圆半径为 \(r\)，外接球半径为 \(R\)，底面外心为 \(O'\)。

\textbf{核心公式：} 球心 \(O\) 在底面外心 \(O'\) 的正上方，且到底面的距离为 \(\frac{h}{2}\)，外接球半径
\[
\boxed{R = \sqrt{r^{2} + \left(\frac{h}{2}\right)^{2}}}
\]

\textbf{使用场景：} 快速求解有一条侧棱垂直于底面的棱锥（常为三棱锥或四棱锥）的外接球半径，多见于高考选填题中的外接球问题。

\textbf{简单例子：} 三棱锥 \(P-ABC\) 中，\(PA \perp\) 底面 \(ABC\)，\(PA = 2\)，\(\triangle ABC\) 是边长为 \(2\sqrt{3}\) 的正三角形，求外接球半径 \(R\)。
解：底面外接圆半径 \(r = \frac{2\sqrt{3}}{\sqrt{3}} = 2\)，\(h = 2\)，则
\(R = \sqrt{2^{2} + 1^{2}} = \sqrt{5}\)。
