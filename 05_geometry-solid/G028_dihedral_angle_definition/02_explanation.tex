\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	二面角的平面角通过在棱上取点作两条垂直于棱的直线得到，从而将空间角的测量转化为平面内三角形的角度问题。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（垂线条件）：}] 两条射线 $OA$ 和 $OB$ 必须均垂直于棱 $l$，且垂足为同一点 $O$，否则所得的角不是平面角。
		\item[\textbf{要点二（余弦定理）：}] 在 $\triangle AOB$ 中，利用三边 $OA, OB, AB$ 可以直接解得 $\angle AOB$ 的余弦值，从而确定二面角大小。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（空间角转化）}}

	二面角的大小由两个半平面同时垂直于棱的射线所夹的角唯一刻画，与棱上点的选取无关（只要作垂线方法相同），体现了空间角向平面角的转化。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（三角桥接）}}

	通过余弦定理，把空间几何元素（二面角）的求解归结为平面三角形中三条边长之间的计算，降低了空间想象的难度。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（基础得分点）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求角）：} 在立体几何小题中，已知相关线段长度，直接用公式求二面角余弦。
		\item \textbf{考法二（辅助线基础）：} 在大题求二面角时，先作出定义中的垂线，找出平面角，再计算。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{作垂线必须从棱上同一点出发在两个半平面内各作一条，且都垂直于棱；只有这样才能保证平面角的大小就是二面角的大小。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（已知三边求角）：} 当题目给出 $OA, OB, AB$ 的长度（或可求）时，直接代入 $\cos\theta = \dots$ 即可。
		\item \textbf{场景二（已知角求边）：} 已知二面角 $\theta$ 及 $OA, OB$ 长度，可反求 $AB$ 长度：$AB^2 = OA^2+OB^2-2\cdot OA\cdot OB\cdot\cos\theta$。
	\end{itemize}
\end{explanationbox}
