\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	二面角的平面角通过作棱的垂线定义，并利用余弦定理将空间角度计算转化为三角形边长的代数运算。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（垂线构造）：} 在棱上取同一点，分别在半平面内作垂直于棱的射线，得到平面角。
		\item \textbf{条件 2（三边可测）：} 三角形 $AOB$ 的三条边长 $OA, OB, AB$ 必须已知或可通过已知条件求出。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（垂线共点）：} 垂足必须为同一点，否则角不唯一。
		\item \textbf{检查项（边角对应）：} 余弦定理中 $AB$ 是 $\angle AOB$ 的对边，分子是 $OA^2+OB^2-AB^2$。
	\end{itemize}
\end{summarybox}
