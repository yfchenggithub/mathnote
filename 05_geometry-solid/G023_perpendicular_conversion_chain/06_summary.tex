\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	垂直转化链实现线线、线面、面面垂直间的双向推导。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（正向判定条件）：} 从线线垂直到面面垂直需依次满足线面垂直判定与面面垂直判定条件。
		\item \textbf{条件2（反向性质条件）：} 从面面垂直到线线垂直需依次满足面面垂直性质与线面垂直性质条件。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（条件忽略）：} 每一步转化都必须检查前提条件，不可跳过。
		\item \textbf{检查项（转化方向）：} 先确定已知属于哪个层级，再选择正确的判定或性质方向。
	\end{itemize}

\end{summarybox}
