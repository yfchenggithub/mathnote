\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	二面角的余弦值等于两个法向量夹角余弦的绝对值，符号由二面角是锐角还是钝角决定。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（向量夹角）：}]
			法向量 $\vec{n}_1,\vec{n}_2$ 夹角的余弦由内积公式给出：$\cos\langle\vec{n}_1,\vec{n}_2\rangle = \frac{\vec{n}_1\cdot\vec{n}_2}{|\vec{n}_1||\vec{n}_2|}$。
		\item[\textbf{要点二（符号规则）：}]
			二面角为锐角或直角时 $\cos\theta\ge 0$，此时 $\cos\theta = |\cos\langle\vec{n}_1,\vec{n}_2\rangle|$；二面角为钝角时 $\cos\theta<0$，此时 $\cos\theta = -|\cos\langle\vec{n}_1,\vec{n}_2\rangle|$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（平面角关系）}}
	设 $\varphi = \langle\vec{n}_1,\vec{n}_2\rangle$。二面角的平面角 $\theta$ 与 $\varphi$ 满足 $\theta = \varphi$ 或 $\theta = \pi-\varphi$，从而 $\cos\theta = \pm\cos\varphi$，$|\cos\theta| = |\cos\varphi|$。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（计算驱动）}}
	将几何量的计算转化为向量代数运算，只需求出法向量内积和模长即可得到 $|\cos\theta|$，再结合图形符号得到最终值。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（二面角求法）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接计算）：} 已知两平面法向量，直接代入公式计算 $\cos\theta$（需额外分类符号）。
		\item \textbf{考法二（法向量求解）：} 由平面上的点坐标先求法向量，再套用本结论。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	不要先纠结符号！先算 $\dfrac{|\vec{n}_1\cdot\vec{n}_2|}{|\vec{n}_1||\vec{n}_2|}$，这就是 $|\cos\theta|$。最后再看图形中二面角是锐角（$\cos\theta>0$）还是钝角（$\cos\theta<0$），加上正负号即可。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（坐标法）：} 在立体几何题中建立空间直角坐标系，求出相关法向量后使用。
		\item \textbf{场景二（图形辅助）：} 当图形直观显示二面角为锐角或钝角时，用来确定符号。
	\end{itemize}

\end{explanationbox}
