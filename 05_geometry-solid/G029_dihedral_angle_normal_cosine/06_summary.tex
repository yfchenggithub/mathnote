\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	二面角 $\theta$ 的余弦绝对值等于两平面法向量夹角余弦的绝对值，符号由 $\theta$ 的锐钝决定：$\cos\theta = \pm\frac{|\vec{n}_1\cdot\vec{n}_2|}{|\vec{n}_1||\vec{n}_2|}$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（法向量已知）：} 已知或可求出两平面的法向量 $\vec{n}_1,\vec{n}_2$。
		\item \textbf{条件 2（锐钝已明）：} 已知二面角的平面角是锐角还是钝角（或可通过图形判断）。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（符号判定）：} 先算绝对值，再根据二面角锐钝添正负号，不可直接用法向量内积结果。
		\item \textbf{检查项（范围验证）：} 确认二面角 $\theta\in[0,\pi]$，余弦值 $\cos\theta\in[-1,1]$。
	\end{itemize}

\end{summarybox}
