\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	若一个平面内的两条相交直线都平行于另一个平面，则这两个平面平行。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（相交直线条件）：}] 必须有两条直线 $a,\;b$，满足 $a\subset\alpha,\;b\subset\alpha,\;a\cap b=P$，且 $a\parallel\beta,\;b\parallel\beta$。这些条件缺一不可，尤其“相交”不能忽略。
		\item[\textbf{要点二（线面推面面）：}] 该定理将面面平行的判断转化为线面平行的判断，是立体几何中证明面面平行的主要依据。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（方向一致性）}}

	平面由其内两条相交直线的方向唯一确定。若这两条直线都平行于平面 $\beta$，则 $\alpha$ 的方向与 $\beta$ 的方向一致，从而两平面没有公共点，即平行。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（向量表述）}}

	设平面 $\alpha$ 的法向量为 $\mathbf{n}_\alpha$，平面 $\beta$ 的法向量为 $\mathbf{n}_\beta$。若 $a\parallel\beta$ 且 $b\parallel\beta$，由线面平行性质可得 $\mathbf{n}_\beta$ 与 $a,\;b$ 均垂直，进而 $\mathbf{n}_\beta$ 也是 $\alpha$ 的法向量，故 $\mathbf{n}_\alpha\parallel\mathbf{n}_\beta$，即 $\alpha\parallel\beta$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（常见考法）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（条件判断）：} 在选择题中，给定一些线面平行条件，判断能否推出面面平行。需重点检查直线是否相交。
		\item \textbf{考法二（证明题应用）：} 在立体几何证明题中，先证明两条相交直线分别平行于目标平面，再使用本定理得到面面平行。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{“相交”是命门。若两条直线平行（不相交）则不能保证结论成立。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（正方体模型）：} 在正方体 $ABCD-A'B'C'D'$ 中，证明平面 $AB'C$ 与平面 $A'C'D$ 平行。
		\item \textbf{场景二（截面平行）：} 在棱锥中，构造一条平行于底面的截面，通过判定定理证明截面与底面平行。
	\end{itemize}
\end{explanationbox}
