\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	直圆锥内切球半径等于轴截面等腰三角形的内切圆半径，计算公式为 $R = \dfrac{rh}{r+l}$（$l = \sqrt{r^2+h^2}$）。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（直圆锥）：} 圆锥顶点在底面圆心正上方，且轴截面为等腰三角形。
		\item \textbf{条件 2（内切关系）：} 球与圆锥底面和侧面均相切。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（公式结构）：} 分母为 $r+l$ 不是 $r+h$，务必先求母线。
		\item \textbf{检查项（母线计算）：} 用勾股定理 $l = \sqrt{r^2+h^2}$，避免算术错误。
	\end{itemize}

\end{summarybox}
