\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	\textbf{将异面直线平移至相交，构造三角形，利用余弦定理的绝对值公式计算所成角余弦。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（平移可交）：} 异面直线通过平移后可以相交（通常平移其中一条）。
		\item \textbf{条件2（三角可解）：} 平移后所得三角形的三条边长度已知或可求。
		\item \textbf{条件3（角度范围）：} 所求角$\theta\in(0^\circ,90^\circ]$，余弦非负，故公式取绝对值。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（忘记绝对值）：} 直接使用$\cos\theta=\frac{m^2+n^2-d^2}{2mn}$忽略了角度范围，结果可能错误；必须加绝对值。
		\item \textbf{检查项（对应边定义）：} 确认$m,n$为平移后两交线段长度，$d$为连接两非交端点的线段长，不可混淆。
	\end{itemize}

\end{summarybox}
