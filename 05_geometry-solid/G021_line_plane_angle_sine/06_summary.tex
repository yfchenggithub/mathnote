\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	线面角的正弦值等于垂线段长度与斜线段长度的比值：$\sin\theta = \dfrac{QH}{PQ}$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（直线与平面相交）：} 直线 $l$ 与平面 $\alpha$ 相交于点 $P$（或可平移至相交），且可作垂线。
		\item \textbf{条件2（有垂线段）：} 在直线上存在一点 $Q$ 可向平面作垂线 $QH$，且 $PQ$ 已知。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（混淆边比）：} 公式是正弦，不是余弦。$\sin\theta = QH/PQ$，而非 $\cos\theta$。
		\item \textbf{检查项（范围验证）：} 计算出的 $\theta$ 应在 $0^\circ$ 到 $90^\circ$ 之间，若 $\sin\theta > 1$ 或 $\theta > 90^\circ$ 必错。
	\end{itemize}
\end{summarybox}
