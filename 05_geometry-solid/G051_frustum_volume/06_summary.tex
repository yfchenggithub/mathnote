\begin{summarybox}

	\textbf{\textcolor{CSummary}{一句话核心}}

	\textbf{台体体积等于高乘以上底面积、下底面积与两者几何平均数之和的三分之一。}

	\medskip

	\textbf{\textcolor{CSummary}{使用条件}}

	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（上下底面平行）：} 几何体必须是棱台或圆台，或锥体、柱体的相应退化情形，上下底面平行且相似。
		\item \textbf{条件 2（面积与高已知）：} 需要知道上底面积 $S_1$、下底面积 $S_2$ 和高 $h$，或能从半径、边长、相似比等条件间接求出。
	\end{itemize}

	\medskip

	\textbf{\textcolor{CSummary}{关键提醒}}

	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（公式混淆）：} 不要与梯形面积公式混淆，台体体积公式有三项，分母为 $3$，中间多出 $\sqrt{S_1S_2}$。
		\item \textbf{检查项（单位一致）：} 确保 $S_1$ 和 $S_2$ 使用相同的面积单位，长度单位统一，最后体积单位应为立方单位。
	\end{itemize}

\end{summarybox}
