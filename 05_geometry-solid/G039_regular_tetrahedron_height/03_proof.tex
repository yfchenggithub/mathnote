\begin{proofbox}
	\textbf{\textcolor{CProof}{思路提示}}

	将高置于直角三角形中，利用底面正三角形的外接圆半径求高。

	\medskip
	\textbf{\textcolor{CProof}{正式推导}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.55em]
		\item[\textbf{步骤一（求底面中心距顶点）：}]在底面正三角形$BCD$中，边长为$a$，其中心$G$（也是重心）到顶点$B$的距离为外接圆半径$R$。由等边三角形性质，
			\[
				R = \frac{a}{\sqrt{3}}
			\]
			\par\textbf{理由：}等边三角形外接圆半径公式$R = \frac{a}{2\sin 60^\circ} = \frac{a}{\sqrt{3}}$；或由高$h_{\triangle}=\frac{\sqrt{3}}{2}a$，重心分中线$2:1$，得$R = \frac{2}{3}h_{\triangle} = \frac{2}{3}\cdot\frac{\sqrt{3}}{2}a = \frac{a}{\sqrt{3}}$.

		\item[\textbf{步骤二（构造直角三角形）：}]在正四面体$A-BCD$中，顶点$A$在底面$BCD$上的投影为底面中心$G$，连接$AG$和$BG$，则$AG\perp BG$，且$AB = a$，$BG = R = \frac{a}{\sqrt{3}}$. 在直角三角形$AGB$中，
			\[
				AG = \sqrt{AB^2 - BG^2} = \sqrt{a^2 - \frac{a^2}{3}}
			\]
			\par\textbf{理由：}因为$AG$是高，$BG$是底面中心到顶点的距离，由正四面体性质可知$AG\perp$底面，所以$AG\perp BG$，故由勾股定理可求.

		\item[\textbf{步骤三（化简得高公式）：}]继续计算：
			\[
				AG = \sqrt{\frac{2}{3}a^2} = \frac{\sqrt{6}}{3}a
			\]
			\par\textbf{理由：}$\sqrt{\frac{2}{3}} = \frac{\sqrt{2}}{\sqrt{3}} = \frac{\sqrt{6}}{3}$，整理即得$h = \frac{\sqrt{6}}{3}a$.
	\end{description}

	\medskip
	\textbf{\textcolor{CProof}{结论回扣}}

	通过构造直角三角形，利用底面正三角形的外接圆半径和勾股定理，得到了正四面体高的精确公式，验证了结论正确。
\end{proofbox}
