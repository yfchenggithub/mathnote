\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	点到平面的距离等于向量 $\vec{AP}$ 在法向量 $\mathbf{n}$ 上投影的绝对值。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（已知一点 $A$ 在平面内）：} 必须知道平面上一个点的坐标。
		\item \textbf{条件 2（已知非零法向量 $\mathbf{n}$）：} 法向量可以通过平面方程或叉积求得，且必须非零。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（绝对值缺失）：} 分子点积必须加绝对值，保证距离非负。
		\item \textbf{检查项（法向量非零）：} 代入公式前应确认 $|\mathbf{n}|\neq0$。
	\end{itemize}
\end{summarybox}
