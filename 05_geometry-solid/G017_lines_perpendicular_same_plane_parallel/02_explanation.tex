\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	两条直线都垂直于同一平面，它们的空间方向必然一致，因此平行。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（线面垂直定义）：}] 直线垂直于平面时，它垂直于平面内的所有直线；这确定了直线的方向是平面的法方向。
		\item[\textbf{要点二（方向一致性）：}] 如果两条直线都垂直于同一平面，则它们的方向都平行于该平面的法线方向，因此必互相平行。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（方向唯一决定）}}

	垂直于平面的直线方向是唯一的（即该平面的法线方向），因此所有与同一平面垂直的直线方向一致，从而平行。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（向量共线）}}

	取平面$\alpha$的法向量$\boldsymbol{n}$，则直线$a$的方向向量$\boldsymbol{u}$满足$\boldsymbol{u}\parallel\boldsymbol{n}$，直线$b$的方向向量$\boldsymbol{v}$也满足$\boldsymbol{v}\parallel\boldsymbol{n}$，因此$\boldsymbol{u}\parallel\boldsymbol{v}$，故$a\parallel b$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（证线线平行）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接应用）：} 在立体几何证明中，若已知两条直线都与同一平面垂直，可直接用该定理证其平行。
		\item \textbf{考法二（间接使用）：} 有时需要先证明一条直线垂直于平面，再与另一条垂线平行，常见于线面、面面垂直的综合题。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	不要被垂足位置干扰——无论垂足是否相同，只要垂直于同一平面，直线就平行。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（已知线面垂直）：} 题目直接给出两条直线都垂直于同一平面，用于证明它们平行。
		\item \textbf{场景二（构造垂线证平行）：} 要证明两条直线平行，可尝试证明它们都垂直于同一个平面。
	\end{itemize}
\end{explanationbox}
