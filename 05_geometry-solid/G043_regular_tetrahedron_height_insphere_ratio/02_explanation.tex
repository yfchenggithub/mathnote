\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	正四面体的高和内切球半径由棱长唯一确定，且满足 $r = h/4$，记住这两个关系可快速求解。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（高线计算）：}] 通过底面中心构造直角三角形，利用勾股定理求高 $h$。
		\item[\textbf{要点二（体积法求半径）：}] 利用等体积法 $V = \frac{1}{3}S r$，其中 $S$ 为总表面积，可得 $r = h/4$。
		\item[\textbf{要点三（球心定位）：}] 球心在高上，到底面距离 $r$，到顶点距离 $3r$。
		\item[\textbf{要点四（比例关系）：}] 球心分高为 $3:1$（顶点到球心:球心到底面）。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（对称性等分）}}

	正四面体的对称性使得其中心（也是内切球心）位于高的四等分点（从底面算起）。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（比例统一）}}

	已知 $h$ 可得 $r = h/4$，反之亦然，无需重复计算底面中心。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高频考法）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接套公式）：} 已知棱长求 $h$ 或 $r$。
		\item \textbf{考法二（逆向求边长）：} 已知 $h$ 或 $r$ 反求棱长或体积。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	$r = h/4$ 是桥梁，将高和内切球半径联系起来，避免记忆两个无关公式。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景（典型应用）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（填空选择）：} 直接代入公式秒杀。
		\item \textbf{场景二（体积计算）：} 快速求内切球体积或表面积。
	\end{itemize}
\end{explanationbox}
