\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	正四面体的高、内切球半径满足 $h = \frac{\sqrt{6}}{3}a$，$r = \frac{h}{4}$，球心将高分为 $3:1$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（正四面体）：} 几何体必须是正四面体（所有棱长相等）。
		\item \textbf{条件2（已知一个量）：} 已知棱长、高、内切球半径之一，可求其余。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（公式混淆）：} 不要记成 $h = \frac{\sqrt{3}}{2}a$（等边三角形高）。
		\item \textbf{检查项（比例关系）：} 内切球半径是高的 $\frac14$，球心到底面距离 $=r$，顶点到球心距离 $=3r$。
	\end{itemize}
\end{summarybox}
