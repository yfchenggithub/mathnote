\textbf{结论名称：} 正四面体内切球半径及球心分高比例。\\
\textbf{适用条件：} 正四面体，已知棱长 $a$。\\
\textbf{变量说明：} $a$为正四面体的棱长，$h$为高，$r$为内切球半径；球心记为 $O$。\\
\textbf{核心公式：} 
\[
\boxed{r = \frac{\sqrt{6}}{12}a}
\]
高 $h = \frac{\sqrt{6}}{3}a$，球心 $O$ 将高分为 $1:3$（由顶点向底面方向），即顶点到球心的距离为 $\frac{1}{4}h = r$。\\
\textbf{使用场景：} 正四面体内切球半径、体积或截面积的计算；判断内切球与面的切点位置；结合体积法求距离等问题。\\
\textbf{简单例子：} 令棱长 $a = 2\sqrt{6}$，则高 $h = \frac{\sqrt{6}}{3} \times 2\sqrt{6} = 4$，内切球半径 $r = \frac{\sqrt{6}}{12} \times 2\sqrt{6} = 1$。球心到顶点距离为 $1$，到底面距离为 $3$，恰为 $1:3$。可用体积法验证：正四面体体积 $V = \frac{\sqrt{2}}{12}a^3 = 8\sqrt{3}$，表面积 $S = 4 \times \frac{\sqrt{3}}{4}a^2 = 24\sqrt{3}$，由 $r = \frac{3V}{S} = 1$，结果一致。
