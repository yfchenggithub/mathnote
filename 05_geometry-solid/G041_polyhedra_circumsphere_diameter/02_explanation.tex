\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	球内接正方体和长方体的外接球直径等于体对角线长；球内接正四面体的外接球直径与高成比例（公式为 $\frac{\sqrt{6}}{2}a$）。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（体对角线原则）：}] 对于长方体，外接球直径等于体对角线长（最远两点间的距离）。最远两点是体对角线的端点，所以 $2R = \sqrt{a^2+b^2+c^2}$。
		\item[\textbf{要点二（常数系数提取）：}] 当几何体具有对称性时，最远距离与棱长成固定比例。正方体比例 $\sqrt{3}$，正四面体比例 $\frac{\sqrt{6}}{2}$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（外接球心）}}

	外接球的球心是几何体所有顶点等距的点。对于正方体和长方体，球心是体对角线的中点。对于正四面体，球心位于高上，且到顶点的距离为高的四分之三（即球心是高的四等分点，靠近底面）。球心到任一顶点的距离即是半径 $R$。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（二次关系）}}

	三个公式均为二次根式形式，反映空间距离的平方和开根。正方体：$2R = \sqrt{3a^2}$；长方体：$2R = \sqrt{a^2+b^2+c^2}$；正四面体：$2R = \sqrt{\frac{3}{2}a^2}$（通过变形可得 $\frac{\sqrt{6}}{2}a$）。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高考常见）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接计算）：} 已知棱长，直接代入公式求外接球直径或半径。
		\item \textbf{考法二（逆向求解）：} 已知外接球半径，反推几何体棱长或边长。
		\item \textbf{考法三（体积结合）：} 先利用公式求出半径，再计算球体积或几何体体积。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	对于正方体和长方体，外接球问题就是“找体对角线”；对于正四面体，需理解高与半径的关系。把公式与几何意义对应起来，不要死记硬背。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（几何体完整时）：} 题目直接给出内接于球的正方体、长方体或正四面体的棱长，求球半径。
		\item \textbf{场景二（条件隐含时）：} 题目描述“所有顶点在球面上”、“外接球”等关键词，需先判断几何体形状再套用公式。
	\end{itemize}
\end{explanationbox}
