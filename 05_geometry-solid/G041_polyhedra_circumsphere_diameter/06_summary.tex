\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	外接球直径：正方体为体对角线 $a\sqrt{3}$，长方体为体对角线 $\sqrt{a^2+b^2+c^2}$，正四面体为 $\frac{\sqrt{6}}{2}a$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（几何体类型）：} 几何体必须为正方体、长方体或正四面体。
		\item \textbf{条件2（顶点共球）：} 所有顶点必须位于同一球面上（外接球）。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（系数混淆）：} 三个公式的系数不同，务必分清：正方体 $\sqrt{3}$，长方体 $\sqrt{a^2+b^2+c^2}$，正四面体 $\frac{\sqrt{6}}{2}$。
		\item \textbf{检查项（体对角线优先）：} 对于正方体和长方体，直接计算体对角线即可得直径；正四面体需借用高或方程。
	\end{itemize}
\end{summarybox}
