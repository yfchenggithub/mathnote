\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	侧棱相等的三棱锥，其外接球球心在过底面外心且垂直于底面的直线上；特殊情况下，球心可以与底面外心重合。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{非退化前提：} $A,B,C$ 不共线，且 $S\notin(ABC)$，即三棱锥不是退化情形。
		\item \textbf{条件 1（侧棱相等）：} 三棱锥的三条侧棱相等，即 $SA=SB=SC$。
		\item \textbf{条件 2（射影为外心）：} 等价地，顶点 $S$ 在底面 $ABC$ 上的射影是 $\triangle ABC$ 的外心 $O$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键公式}}
	\[
		R=\frac{h^{2}+r^{2}}{2h}\quad (h>0),
	\]
	其中 $h=SO$ 是三棱锥的高，$r$ 是底面 $\triangle ABC$ 的外接圆半径。

	\medskip
	\textbf{\textcolor{CSummary}{球心位置分类}}
	\[
		\begin{cases}
			h^{2}>r^{2}, & Q \text{ 在线段 } SO \text{ 上};               \\[4pt]
			h^{2}=r^{2}, & Q=O;                                       \\[4pt]
			h^{2}<r^{2}, & Q \text{ 在 } O \text{ 的远离 } S \text{ 的一侧}.
		\end{cases}
	\]

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（条件前提）：} 不能忽略侧棱相等的条件，随意推广到一般三棱锥。
		\item \textbf{检查项（参数分量）：} 使用半径公式 $R = \dfrac{h^{2}+r^{2}}{2h}$ 时，确认 $h$ 是高、$r$ 是底面外接圆半径，且 $h\neq 0$。
		\item \textbf{措辞提醒（定位线）：} 直线 $SO$ 是球心定位线，不一定是整个三棱锥的几何对称轴。
	\end{itemize}
\end{summarybox}
