\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	两个平行平面被第三个平面切割，得到的交线方向一致。即把面面平行转化为线线平行。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（平行关系传递）：}] 面面平行 $\Rightarrow$ 两平面无公共点，因此交线也不能有交点，否则将得到公共点。
		\item[\textbf{要点二（共面性质）：}] 两条交线都位于第三个平面内部，所以是同一平面内的两条直线，不可能异面。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（空间平行性）}}

	本定理是空间平行关系链的一环：面面平行 $\Rightarrow$ 线线平行（通过中间平面）。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（向量验证）}}

	设 $\vec{n}_1,\vec{n}_2$ 分别是 $\alpha,\beta$ 的法向量，由 $\alpha\parallel\beta$ 得 $\vec{n}_1\parallel\vec{n}_2$。设 $\gamma$ 的法向量为 $\vec{n}_3$，则交线方向 $a$ 同时垂直于 $\vec{n}_1,\vec{n}_3$，$b$ 同时垂直于 $\vec{n}_2,\vec{n}_3$，因为 $\vec{n}_1\parallel\vec{n}_2$，所以 $a\parallel b$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（常见考法）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（证线线平行）：} 在几何体中，若已知两个平面平行及一个截面，直接使用定理得交线平行。
		\item \textbf{考法二（辅助面法）：} 在证明线面或面面平行时，常需构造一个第三平面与两平面相交，利用本定理产生平行关系。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{关键是要识别出“同一个平面与两个平行平面的交线”，这两条交线必定平行。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（截面问题）：} 已知两平面平行，画截面时，交线应画平行。
		\item \textbf{场景二（距离转化）：} 求平行平面间距离时，通过第三平面构造直角三角形，利用平行边关系。
	\end{itemize}
\end{explanationbox}
