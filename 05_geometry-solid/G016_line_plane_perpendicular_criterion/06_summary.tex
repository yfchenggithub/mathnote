\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	如果一条直线同时垂直于一个平面内的两条相交直线，那么这条直线垂直于这个平面。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（两线在面内）：} 两条直线$a$和$b$都必须位于平面$\alpha$内，即$a\subset\alpha$，$b\subset\alpha$。
		\item \textbf{条件2（两线相交）：} $a$与$b$相交于一点$P$，即$a\cap b=P$。
		\item \textbf{条件3（线线垂直）：} 直线$l$与$a$、$b$都垂直，即$l\perp a$，$l\perp b$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（注意相交条件）：} 不能将“相交”换成“平行”，否则结论不成立。
		\item \textbf{检查项（确认直线在面内）：} 在应用前，必须明确所找的两条直线确实在目标平面内。
	\end{itemize}

\end{summarybox}
