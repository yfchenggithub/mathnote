\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	两条相交直线能“撑起”一个平面，所以同时垂直于它们就等于垂直于整个平面。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（相交线定平面）：}]
			两条相交直线唯一确定一个平面，因此平面$\alpha$完全由直线$a$和$b$确定。
		\item[\textbf{要点二（垂直传递性）：}]
			若直线$l$垂直于$a$和$b$，则对于平面$\alpha$内任意一条直线$c$，$c$可由$a$与$b$线性表示，从而$l\perp c$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（平面基向量垂直）}}
	平面$\alpha$内任意向量均可表示为两个不共线向量的线性组合。$l\perp a$且$l\perp b$意味着$l$的方向向量与这两个基向量都垂直，从而与平面内任意向量垂直，即$l\perp\alpha$。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（向量点积为零）}}
	若取直线$l$的方向向量$\vec{v}$，平面$\alpha$内两个不共线向量$\vec{a},\vec{b}$，则$l\perp\alpha$等价于$\vec{v}\cdot\vec{a}=0$且$\vec{v}\cdot\vec{b}=0$（$\vec{a}\not\parallel\vec{b}$）。这是用向量法判定线面垂直的代数条件。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高频命题点）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（证明线面垂直）：} 在几何证明中，需要先找出平面内两条相交直线，再证明目标直线与它们都垂直，从而得到线面垂直。
		\item \textbf{考法二（向量坐标法）：} 在空间直角坐标系中，计算直线方向向量与平面内两个不共线向量的点积，若都为零，则直线垂直于平面。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	为什么两条就可以？因为两条相交直线已经包含了平面所有的方向（任意向量可由它们线性表示）；如果只垂直一条，则无法限制其他方向。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（立体几何证明题）：} 当题目需要证明直线与平面垂直时，首先在平面内寻找两条相交直线（已知或易证垂直关系）。
		\item \textbf{场景二（向量法快速判定）：} 在已知坐标的条件下，通过数量积运算直接验证垂直关系，无需构造几何图形。
	\end{itemize}

\end{explanationbox}
