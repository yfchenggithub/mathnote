# G020 独立三维教学分镜（渲染前）

**Source Gate：PASS。** 正式主题为“三垂线定理及其逆定理”。六段 TeX 与 `meta.json` 的核心条件一致：`PO⊥α` 于 `O`，`A∈α` 且 `A≠O`，`l⊂α`，`OA` 是 `PA` 的正射影；`l⊥OA ⇔ l⊥PA`。例题均使用该关系。`05_traps.tex` 有一处对射影的口语化说明不够严整，本动画只使用正式陈述、证明与明确的点投影定义，不沿用该短句作为字幕；未发现阻塞建模的数学矛盾。原数学源和 PDF 不修改。

**学生看完应理解：** 斜线 `PA` 的高度分量始终垂直于面内直线 `l`，因此 `l` 对斜线是否垂直，只由斜线在平面中的影子 `OA` 决定。

独特动效：先让 `l` 在平面内转到与 `OA` 垂直的方向，随后抬高 `P`，使斜线 `PA` 明显改变而影子 `OA`、`l` 和两条真实垂直关系保持。静态透视图难以同时展示“变化的斜线”和“不变的射影”。没有镜头运动；固定斜视角保留高度和深度线索。另作俯视诊断帧核对面内关系，俯视不是正式 GIF 中的新数学状态。

## 世界坐标与镜头

- `α:z=0`，`O=(0,0,0)`，`A=(2.8,0,0)`，`P=(0,0,h)`，`h>0`。示例选择 `l` 通过 `A`，方向 `(cos θ,sin θ,0)`；正式定理并不要求 `l` 通过 `A`。该选择避免图上把异面线的投影交叉误看成真实交点。
- `θ:48°→90°`，再令 `h:1.6→3.0`。`AP=(2.8,0,-h)`，`OA=(2.8,0,0)`，故 `d_l·AP=d_l·OA=2.8 cos θ`。`θ=90°` 时两者同为零，对所有演示高度都成立。`P` 的正射影是 `O`，整段 `PA` 正射影是 `OA`。
- 固定 Manim `ThreeDScene` 摄像机 `φ=45°`、`θ=-35°`，取景 `zoom=1.4`、中心 `(1.6,0,0.2)`。该角度同时保留高度线索并让面内/空间直角在屏幕上较易辨认；不能把屏幕量角当数学证明。两枚直角标记均由实际世界向量构造；初始非垂直阶段不显示直角标记。
