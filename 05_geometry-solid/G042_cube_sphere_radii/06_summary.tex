\begin{summarybox}

	\textbf{\textcolor{CSummary}{一句话核心}}

	正方体的内切球、棱切球、外接球半径分别为$\frac{a}{2}, \frac{\sqrt{2}}{2}a, \frac{\sqrt{3}}{2}a$，三者大小关系为$r_i < r_m$，$r_m < r_o$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（几何体）：} 必须是正方体（所有棱长相等）。
		\item \textbf{条件2（已知量）：} 棱长$a$已知，或可通过其他条件求出。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（公式混淆）：} 牢记三种球的半径系数比例，切勿张冠李戴。
		\item \textbf{检查项（单位一致）：} 计算时注意长度单位统一，避免与表面积、体积公式使用时出错。
	\end{itemize}

\end{summarybox}
