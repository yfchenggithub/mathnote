\begin{summarybox}

	\textbf{\textcolor{CSummary}{一句话核心}}

	直圆锥外接球半径等于底面半径平方与高平方之和除以两倍高，等价于母线平方除以两倍高。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（适用对象）：}本公式适用于直圆锥（正圆锥），其中$r>0,\ h>0$，且$l^2=r^2+h^2$。
		\item \textbf{条件2（基本量）：}已知直圆锥底面半径$r$和高$h$，可直接代入$R = \dfrac{r^2+h^2}{2h}$。
		\item \textbf{条件3（母线形式）：}已知母线长$l$和高$h$，可用$R = \dfrac{l^2}{2h}$，无需单独求$r$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{公式结构：}注意$R = \dfrac{h}{2} + \dfrac{r^2}{2h}$，第二项是$\dfrac{r^2}{2h}$而非$r$。
		\item \textbf{变量范围：}确认$r>0,h>0$，外接球公式对任意正数均成立；当$h<r$时球心在底面下方，公式仍有效。
		\item \textbf{反求参数：}由$r^2=2Rh-h^2$可知，若要求$r>0$，必须满足$0<h<2R$。
		\item \textbf{概念区分：}外接球半径不一定等于“能容纳圆锥的最小球半径”。若只是求最小容纳球，则
		      \[
			      R_{\min}=\begin{cases}
				      r,                   & 0<h\le r, \\[4pt]
				      \dfrac{r^2+h^2}{2h}, & h\ge r.
			      \end{cases}
		      \]
	\end{itemize}
\end{summarybox}
