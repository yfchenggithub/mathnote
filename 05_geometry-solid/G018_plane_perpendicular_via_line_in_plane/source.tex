\textbf{结论名称：} 面面垂直判定定理（线面垂直推面面垂直）

\textbf{适用条件：} 一条直线在其中一个平面内，且该直线垂直于另一个平面。

\textbf{变量说明：} $l$ 是直线，$\alpha$ 与 $\beta$ 是两个平面。

\textbf{核心公式：}
\[
\boxed{
\left.
\begin{aligned}
l &\subset \beta \\
l &\perp \alpha
\end{aligned}
\right\}
\Rightarrow \alpha \perp \beta
}
\]

\textbf{使用场景：} 证明两平面垂直，将面面关系转化为线面关系，常用于寻找直二面角。

\textbf{简单例子：} 在正方体 $ABCD$-$A_1B_1C_1D_1$ 中，$AB \perp$ 平面 $BCC_1B_1$，且 $AB \subset$ 平面 $ABCD$，由判定定理即得平面 $ABCD \perp$ 平面 $BCC_1B_1$。
