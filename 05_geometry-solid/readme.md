# 立体几何二级结论索引

## 已有结论（G001–G010）

| 编号 | 结论 | 高考价值 |
|------|------|----------|
| G001 | 球体体积与表面积公式 V=4/3πR³, S=4πR² | 基础必考，直接计算与逆向求半径 |
| G002 | 球的半径比与表面积/体积比关系（平方/立方比） | 相似放缩速算，选择填空秒出 |
| G003 | 三棱锥外接球球心定位：侧棱相等用垂线法 | 球心定位通用思路，降低作图难度 |
| G004 | 旋转椭球表面积公式（长轴/短轴情形） | 冷门但压轴可能出现，区分度高 |
| G005 | 长方体外接球半径 R=√(a²+b²+c²)/2（体对角线一半） | 补形法基础，墙角模型依赖此公式 |
| G006 | 正方体外接球半径 R=√3a/2 | 特殊几何体外接球，高频选择填空 |
| G007 | 直棱柱外接球半径：球心在底面外心连线中点 | 直棱柱通用方法，勾股速算 |
| G008 | 正三棱柱外接球半径：底面边长+高直接算 | 正三棱柱专项，考题高频 |
| G009 | 正棱锥外接球半径 R=(r²+h²)/(2h) | 正棱锥通用公式，替代复杂几何作图 |
| G010 | 正四面体外接球半径 R=√6a/4 | 特殊几何体，选择填空秒杀 |
