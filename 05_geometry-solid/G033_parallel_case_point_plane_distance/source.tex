\textbf{结论名称：} 线面距与面面距转化为点面距（平行时等距离）

\textbf{适用条件：} 直线与平面平行，或两平面平行；此时线/面上任意点到目标平面的距离均相等。

\textbf{变量说明：} 平面方程为 \(Ax+By+Cz+D=0\)，点 \(P(x_0,y_0,z_0)\) 为线或面上任意取定的一点；\(d\) 表示所求距离。

\textbf{核心公式：}
\[
\boxed{d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}}
\]
其中，线面距取直线上任一点到平面的距离，面面距取一平面上任一点到另一平面的距离。

\textbf{使用场景：} 计算线面平行时的距离，或面面平行时的距离；将线/面间距离统一转化为点面距以简化运算是教材重点方法。

\textbf{简单例子：} 平面 \(\alpha: 2x - y + 2z - 3 = 0\)，直线 \(l\) 平行于 \(\alpha\) 且过点 \(P(1,2,0)\)。验证 \(l\parallel\alpha\) 后，取 \(P(1,2,0)\) 计算点面距：
\[
d = \frac{|2\times1 - 2 + 2\times0 - 3|}{\sqrt{2^2+(-1)^2+2^2}}
  = \frac{|2 - 2 - 3|}{3} = 1.
\]
故线面距为 \(1\)。若两个平行平面 \(\alpha\) 与 \(\beta: 2x - y + 2z + 5 = 0\)，在 \(\alpha\) 上取点 \((0, -3, 0)\)，代入 \(\beta\) 得面面距相同公式计算。
