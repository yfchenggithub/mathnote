\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	正四面体的外接球球心位于顶点到底面中心的高线上，且到顶点的距离是高的 $\frac{3}{4}$，由此导出半径公式。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（球心位置）：}] 外接球球心必在正四面体的高线上，且距离底面 $\frac{1}{4}$ 高，距离顶点 $\frac{3}{4}$ 高。
		\item[\textbf{要点二（勾股关系）：}] 在高线上取底面中心，利用球心到底面顶点和到上方顶点的距离相等，列出勾股关系，解得 $R=\frac{\sqrt{6}}{4}a$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（高度对称）}}

	正四面体具有高度对称性，但它不是中心对称图形。在正四面体中，外接球球心、内切球球心、重心和垂心重合。该点位于顶点到底面中心的高线上，距离底面为 $\frac{1}{4}h$，距离顶点为 $\frac{3}{4}h$。因此外接球半径为 $\frac{3}{4}h$，内切球半径为 $\frac{1}{4}h$。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（比例系数）}}

	半径 $R$ 与棱长 $a$ 的比例 $\frac{\sqrt{6}}{4}$ 是一个无理常数，由勾股定理和正四面体的空间对称关系共同确定。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（直接公式）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（知棱求径）：} 已知正四面体棱长 $a$，可直接套用 $R = \frac{\sqrt{6}}{4}a$ 求外接球半径。
		\item \textbf{考法二（外接球几何量）：} 先求 $R$，再求外接球的表面积 $S=4\pi R^2$ 或体积 $V=\frac{4}{3}\pi R^3$。
		\item \textbf{考法三（反求棱长）：} 已知外接球半径，解出 $a = \frac{4R}{\sqrt{6}}$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{正四面体的高 $h = \frac{\sqrt{6}}{3}a$，外接球半径 $R = \frac{3}{4}h$，两者比例固定。解题时可在棱长、高、外接球半径之间灵活转换。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（求正四面体相关量）：} 在有关正四面体的棱长、高、外接球半径、外接球表面积、外接球体积等问题中，可直接代入公式。
		\item \textbf{场景二（比较球半径）：} 与其他几何体（如正方体、三棱锥）的外接球半径进行比较或组合计算时，应先确认几何体是否真的是正四面体。
		\item \textbf{场景三（避免正三棱锥误用）：} 正三棱锥不一定是正四面体，只有当所有棱长都相等时，才可使用 $R=\frac{\sqrt{6}}{4}a$。
	\end{itemize}
\end{explanationbox}
