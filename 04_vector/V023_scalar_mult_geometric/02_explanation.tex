\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	把一个非零向量 $\vec{a}$ 乘以实数 $\lambda$，相当于把 $\vec{a}$ 所表示的有向线段沿原直线伸缩 $|\lambda|$ 倍；$\lambda>0$ 时同向，$\lambda<0$ 时反向，$\lambda=0$ 时变成零向量。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（数乘定义）：}]
			$\lambda\vec{a}$ 是一个向量，其模长 $|\lambda\vec{a}| = |\lambda|\,|\vec{a}|$，位置仍在 $\vec{a}$ 所在的直线上。
		\item[\textbf{要点二（共线恒成立）：}]
			无论 $\lambda$ 取任何实数，$\lambda\vec{a}$ 都可以写成 $\vec{a}$ 的实数倍，所以 $\lambda\vec{a}$ 与 $\vec{a}$ 共线；按高中常用约定，也说二者平行。
		\item[\textbf{要点三（符号判方向）：}]
			当 $\lambda > 0$ 时，$\lambda\vec{a}$ 与 $\vec{a}$ 方向相同；当 $\lambda < 0$ 时，方向相反；当 $\lambda=0$ 时，$\lambda\vec{a}=\vec{0}$，零向量没有确定方向。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（一维伸缩）}}
	数乘操作对应于向量所在直线上的伸缩变换：它保持共线关系，按比例 $|\lambda|$ 改变长度，并由 $\lambda$ 的符号决定是否反向。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（坐标统一）}}
	在直角坐标系中，若 $\vec{a}=(x,y)$，则 $\lambda\vec{a}=(\lambda x,\lambda y)$。这体现了数乘对每个坐标分量的统一放缩。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高频考点）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（共线判定）：} 当 $\vec{a}\neq\vec{0}$ 时，利用 $\vec{b}=\lambda\vec{a}$ 是否成立来判断 $\vec{a}$ 与 $\vec{b}$ 是否共线。
		\item \textbf{考法二（模长计算）：} 已知 $|\vec{a}|$ 和 $\lambda$，求 $|\lambda\vec{a}|$；或已知 $|\lambda\vec{a}|$ 和 $\lambda\neq0$，求 $|\vec{a}|$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	向量数乘与实数乘法的重要区别是：实数乘法结果仍是数，而数乘结果是向量；长度看绝对值，方向看正负号，$\lambda=0$ 时要单独处理。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景（常见场景）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（向量表示）：} 用 $\lambda\vec{a}$ 表示与非零向量 $\vec{a}$ 共线的向量，常用于几何证明。
		\item \textbf{场景二（坐标运算）：} 在已知向量坐标时，快速计算数乘后的坐标。
	\end{itemize}
\end{explanationbox}
