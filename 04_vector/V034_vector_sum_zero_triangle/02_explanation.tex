\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	三个向量相加等于零向量，意味着它们平移后能首尾相接围成一个封闭三角形。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（向量平移首尾接）：}]
		      将向量依次平移成首尾相接，和为零等价于最后一个向量的终点回到起点。
		\item[\textbf{要点二（和为零与封闭性）：}]
		      向量代数等式 $\vec{a}+\vec{b}+\vec{c}=\mathbf{0}$ 直接对应几何上的封闭回路。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（封闭三角形）}}
	三个非零向量两两不共线时，和为零的几何意义是它们恰好可以构成一个非退化三角形的三条边（按顺序首尾衔接）。三角形实体不依赖于坐标，只依赖向量的方向与长度。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（系数同为 1 的线性关系）}}
	该结论说明，若三个向量满足系数同为 $1$ 的线性组合为零向量，则它们线性相关；在非零且两两不共线的前提下，这种线性关系可以翻译成三角形三边的封闭关系。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（向量转几何工具）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求向量模长）：} 利用 $|\vec{c}| = |\vec{a}+\vec{b}|$ 转化为已知两边夹角的求模问题。
		\item \textbf{考法二（求数量积和）：} 对 $\vec{a}+\vec{b}+\vec{c}=\mathbf{0}$ 平方，得到
		      \[
			      |\vec{a}|^2+|\vec{b}|^2+|\vec{c}|^2
			      +2(\vec{a}\cdot\vec{b}+\vec{b}\cdot\vec{c}+\vec{c}\cdot\vec{a})=0,
		      \]
		      从而求解内积和。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	\textbf{“和为零”不是终点，而是“三角形封闭”的代数翻译。见到 $\vec{a}+\vec{b}+\vec{c}=\mathbf{0}$，立即想三角形；见到三角形三边，立即想向量和为零。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（由代数式求边长）：} 已知三向量和为零及两个向量的模与夹角，求第三个向量的模。
		\item \textbf{场景二（三角形向量运算）：} 在三角形中利用 $\overrightarrow{AB}+\overrightarrow{BC}+\overrightarrow{CA}=\mathbf{0}$ 进行向量运算。
	\end{itemize}

\end{explanationbox}
