\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	平行四边形两对角线平方和等于四边平方和，即
	\[
		|\vec{a}+\vec{b}|^2 + |\vec{a}-\vec{b}|^2 = 2(|\vec{a}|^2 + |\vec{b}|^2).
	\]

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（平行四边形前提）：} 四边形必须为平行四边形，邻边可表示为向量 $\vec{a},\vec{b}$。
		\item \textbf{条件 2（长度关联）：} 已知边长或对角线长，欲求其他长度。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（应用范围）：} 仅在平行四边形中成立，不能用于一般四边形。
		\item \textbf{检查项（公式选择）：} 区分平方和恒等式（相加）与极化恒等式（相减），避免混淆。
	\end{itemize}
\end{summarybox}
