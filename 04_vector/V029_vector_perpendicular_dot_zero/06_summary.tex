\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	两个非零向量垂直的充要条件是它们的坐标乘积之和为零。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（向量非零）：} 两向量均必须为非零向量。
		\item \textbf{条件 2（坐标已知）：} 向量在平面直角坐标系中的坐标已知或可求出。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（忽略非零）：} 使用公式前必须确认向量非零。
		\item \textbf{检查项（运算核对）：} 计算 $x_1x_2+y_1y_2$ 时，注意是乘后再相加，避免用错运算。
	\end{itemize}

\end{summarybox}
