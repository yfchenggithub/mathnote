\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	向量模的加减结果始终不小于两向量模的差，且不大于两向量模的和，就像三角形边长关系。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[ \textbf{要点一（模的非负性）}]
			模是长度，总是非负，这是不等式取等的根基。
		\item[ \textbf{要点二（三角结构本质）}]
			向量加法的几何意义是三角形第三边，因此模的大小受两边长度制约。
		\item[ \textbf{要点三（共线取等条件）}]
			等号能否成立取决于向量是否共线以及方向是相同还是相反。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（三角形边关系）}}
	在三角形中，两边之和大于第三边，两边之差小于第三边。向量和差对应的模恰好就是这个原理的统一表达。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（平方展开证明）}}
	对任意向量 $\mathbf{a},\mathbf{b}$，计算 $|\mathbf{a}\pm\mathbf{b}|^2 = |\mathbf{a}|^2+|\mathbf{b}|^2\pm2\mathbf{a}\cdot\mathbf{b}$，利用 $|\mathbf{a}\cdot\mathbf{b}|\le|\mathbf{a}||\mathbf{b}|$ 可得不等式。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（求范围与证明）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（模的取值范围）：} 已知两向量模长，直接利用不等式求和差模的最值。
		\item \textbf{考法二（不等式放缩证明）：} 将其他不等式转化为向量模的形式，用三角不等式完成放缩。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	\textbf{向量模的加减问题，本质上就是三角形三边关系问题，把向量首尾相连，一切一目了然。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（纯向量模最值）：} 已知 $|\mathbf{a}|,|\mathbf{b}|$ 和夹角条件，求 $|\mathbf{a}\pm\mathbf{b}|$ 的范围。
		\item \textbf{场景二（函数参数转化）：} 在解析几何或综合题中，将目标式构造成向量和或差，再套用不等式。
	\end{itemize}

\end{explanationbox}
