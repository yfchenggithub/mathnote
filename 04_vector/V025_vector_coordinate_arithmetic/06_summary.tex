\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	\textbf{向量坐标运算法则把向量问题变成数的计算，解决几何问题不再依赖作图。}

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（单位正交基底）：} 坐标系必须为直角坐标系（单位正交基底），点乘公式才成立.
		\item \textbf{条件2（坐标表示前提）：} 向量必须用坐标形式给出，基底为单位正交系.
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（基底限定）：} 点乘的坐标公式 $(x_1x_2+y_1y_2)$ 仅对直角坐标系成立，在斜坐标系中不能直接使用.
		\item \textbf{检查项（结果验证）：} 坐标加减时核对顺序，点乘确认结果为数值而非向量.
	\end{itemize}

\end{summarybox}
