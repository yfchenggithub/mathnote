\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	把向量平行的几何条件（方向相同或相反）转化为坐标之间简单的交叉乘法等式，无需画图。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（坐标表示）：}] 向量坐标化后，平行关系体现在坐标比例一致。
		\item[\textbf{要点二（叉积为零）：}] 等式 $x_1y_2 - x_2y_1 = 0$ 是平行的代数标志。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（交叉积为零）}}

	两向量平行时，它们张成的平行四边形面积为 $0$。因为 $|\vec{a}\times\vec{b}| = |x_1y_2 - x_2y_1|$，所以 $|x_1y_2 - x_2y_1| = 0$。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（比例相等）}}

	若 $\vec{a}\parallel\vec{b}$ 且非零，则存在实数 $\lambda$ 使 $\vec{a} = \lambda\vec{b}$，即 $x_1 = \lambda x_2$，$y_1 = \lambda y_2$。消去 $\lambda$ 可得 $x_1y_2 = x_2y_1$。特别地，当 $x_2, y_2$ 均不为零时，该式等价于 $\displaystyle\frac{x_1}{x_2} = \frac{y_1}{y_2}$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（快速判定）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（判断平行）：} 给出两向量坐标，直接计算 $x_1y_2 - x_2y_1$，为零则平行。
		\item \textbf{考法二（三点共线）：} 将三点共线转化为向量平行，再用坐标等式。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{核心关系：}“平行 $\iff$ 坐标交叉积相等”是一个纯粹代数条件，不涉及角度或长度，适合快速计算。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（向量平行判定）：} 已知坐标，需要判断两向量方向关系。
		\item \textbf{场景二（三点共线判定）：} 已知三点坐标，判断是否共线。
	\end{itemize}
\end{explanationbox}
