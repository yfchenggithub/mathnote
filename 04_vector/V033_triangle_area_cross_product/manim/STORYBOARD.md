# V033 四种辅助线与面积变化

正式事实源为本 UID 的 01–06 TeX 与 meta.json；动画独立建模，不修改知识源。
新数值模型 A=(3,2)、B=(2,3)，来自正式一般公式的合法实例；两轴等比例。

1. 建立 OAB，交叉乘减计算 S=2.5。
2. 过 B 竖直，Ev=(2,4/3)，公共底 5/3，两水平高 2+1，面积和。
3. 过 B 水平，Eh=(9/2,3)，公共底 5/2，两竖直高 3−1，面积差。
4. 过 A 竖直，Fv=(3,9/2)，公共底 5/2，两水平高 3−1，面积差。
5. 过 A 水平，Fh=(4/3,2)，公共底 5/3，两竖直高 2+1，面积和。
6. 固定 A，让 B=(2,y) 从 y=3 连续移到 4/3（共线）、1/2（反向）、3。
   实时显示 Δ=3y−4、S=|Δ|/2，运动路径与数值均由模型驱动。
