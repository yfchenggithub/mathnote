\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	利用向量数量积是否为零判断直角；利用向量模长是否相等判断等腰（$AB=AC$）或等边。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（不共线）：} $A,B,C$ 三点不共线，保证三角形存在。
		\item \textbf{条件2（共起点）：} 判定直角时，必须选取同一顶点的两个边向量。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（共线前提）：} 使用前必须检查三点是否共线，否则结论无效。
		\item \textbf{检查项（起点一致）：} 计算数量积时确保向量起点相同，避免张冠李戴。
	\end{itemize}

\end{summarybox}
