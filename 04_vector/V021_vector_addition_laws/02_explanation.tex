\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	向量加法就是将一个向量的终点与另一个向量的起点重合，然后从第一个起点指向最后一个终点。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（平移构造）：}] 将向量平移，使它们首尾相接或同起点。
		\item[\textbf{要点二（图形法则）：}] 三角形法则用于首尾相接；平行四边形法则用于同起点。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（位移合成）}}

	三角形法则对应连续位移的合位移；平行四边形法则对应两个独立位移的合位移，其对角线表示合位移的大小和方向。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（坐标相加）}}

	若$\vec{a}=(x_1,y_1)$，$\vec{b}=(x_2,y_2)$，则$\vec{a}+\vec{b}=(x_1+x_2,y_1+y_2)$。三角形法则与平行四边形法则均与此坐标运算统一。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（基础运算）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求和）：} 给出两向量起点关系，直接用法则求和向量。
		\item \textbf{考法二（图形结合）：} 在几何图形中找封闭三角形或平行四边形，求指定向量的和。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{三角形法则与平行四边形法则本质上等价：将平行四边形一半切开即为三角形法则。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（首尾相接）：} 多个向量依次首尾相连，求其和向量。
		\item \textbf{场景二（同起点）：} 两个向量从同一点出发，求它们的合力或和向量。
	\end{itemize}
\end{explanationbox}
