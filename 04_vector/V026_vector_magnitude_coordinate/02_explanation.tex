\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	向量模长就是一个向量在坐标系中的长度，通过横纵坐标直接计算出来。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（坐标平方和）：}]
			模长平方等于横坐标与纵坐标的平方和。
		\item[\textbf{要点二（两点坐标差）：}]
			若已知起点和终点，则向量坐标为终点坐标减起点坐标，模长等于坐标差平方和的算术平方根。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（长度量化）}}
	在平面直角坐标系中，向量对应一条有向线段，其长度就是模长；坐标形式的公式是勾股定理的直接体现。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（勾股定理）}}
	设向量 $\vec{a}=(x,y)$，将其起点平移至原点，则终点坐标为 $(x,y)$；过终点向 $x$ 轴作垂线，构造直角三角形，斜边长即为 $\sqrt{x^2+y^2}$。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高频必考）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求模）：} 已知向量坐标，直接代入公式求模长。
		\item \textbf{考法二（列方程求参）：} 已知模长和部分坐标，列方程求解未知数。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	向量模长与实数的绝对值类似，都是长度，只是维度从一维变成二维。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（坐标运算）：} 已知向量坐标求模长。
		\item \textbf{场景二（几何问题）：} 求两点间距离、判断三角形形状等。
	\end{itemize}

\end{explanationbox}
