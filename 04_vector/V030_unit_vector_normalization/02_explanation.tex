\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	将任意非零向量“缩短”或“拉长”成长度恰好为 1 的向量，只保留方向。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（定义公式）：}] 单位向量 $\vec{e} = \frac{\vec{a}}{|\vec{a}|}$，其中 $|\vec{a}| \neq 0$。
		\item[\textbf{要点二（方向性）：}] $\vec{e}$ 与 $\vec{a}$ 方向完全相同。
		\item[\textbf{要点三（模为1）：}] $|\vec{e}| = 1$，是长度固定的向量，常用于表示方向。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（方向归一化）}}

	非零向量除以自身的模，在几何上等价于保持方向不变，将长度缩放为 1。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（模长归一化）}}

	通过除以模长使向量长度标准化为 1，不改变方向。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（基础工具）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求单位向量）：} 已知 $\vec{a}$ 的坐标或长度，直接套用公式 $\vec{e}=\frac{\vec{a}}{|\vec{a}|}$。
		\item \textbf{考法二（向量分解）：} 将任意向量写为 $\vec{a}=|\vec{a}|\vec{e}$，分离大小和方向。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{单位向量是“方向”的代言人；所有同向向量都可以用同一个单位向量配上长度表示。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（基底构造）：} 建立坐标系时，常用单位向量 $\mathbf{i}, \mathbf{j}$ 作基底。
		\item \textbf{场景二（夹角运算）：} 利用 $\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta$，若已知单位向量可简化。
	\end{itemize}
\end{explanationbox}
