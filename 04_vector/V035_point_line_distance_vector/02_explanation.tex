\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	点到直线的距离可以通过向量叉积的几何意义直接计算，无需求垂足坐标。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（叉积几何意义）：}] 任意两个平面向量 $\vec{u},\vec{v}$ 叉积的模 $\lvert\vec{u}\times\vec{v}\rvert$ 等于以它们为邻边的平行四边形面积。
		\item[\textbf{要点二（高与面积关系）：}] 点 $P$ 到直线 $l$ 的距离 $d$ 等于以 $\vec{AP}$ 和 $\vec{v}$ 为邻边的平行四边形的高，即 $d = \frac{\lvert\vec{AP}\times\vec{v}\rvert}{\lvert\vec{v}\rvert}$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（平行四边形高）}}

	距离是以 $\vec{AP}$ 和 $\vec{v}$ 为邻边的平行四边形在 $\vec{v}$ 方向上的高，即面积除以底边长 $\lvert\vec{v}\rvert$。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（坐标交叉积）}}

	平面向量叉积的坐标计算公式：$\vec{AP}\times\vec{v} = (x_1-x_0)v_y - (y_1-y_0)v_x$，故距离公式的坐标形式为：
	\[
		d = \frac{|(x_1-x_0)v_y - (y_1-y_0)v_x|}{\sqrt{v_x^2+v_y^2}}
	\]

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（公式应用）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（距离计算）：} 已知直线一点和方向向量，直接代入公式求点到直线距离。
		\item \textbf{考法二（逆向求解）：} 利用距离等式反求点的坐标或直线方向向量参数。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{距离也可以看成 $|\vec{AP}|$ 与 $\vec{AP}$ 和 $\vec{v}$ 夹角正弦的乘积，即 $d = |\vec{AP}|\sin\theta$，这等价于 $\vec{AP}$ 在垂直于 $\vec{v}$ 方向上的投影长度。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（直接应用）：} 已知直线的方向向量或直线上两点（可构造方向向量），求任意点到该直线的距离。
		\item \textbf{场景二（几何问题）：} 在向量几何问题中，利用叉积求面积，进而求距离。
	\end{itemize}
\end{explanationbox}
