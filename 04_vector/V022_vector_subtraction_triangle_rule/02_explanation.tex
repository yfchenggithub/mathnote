\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	向量减法本质上是“求一个向量终点的相对位置”：从减向量终点直接走向被减向量终点，就是它们的差。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（方向规定）：}] 差向量的方向由 \textbf{减向量终点} 指向 \textbf{被减向量终点}，简记为“后指前”（减数为后，被减数为前）。
		\item[\textbf{要点二（加法逆运算）：}] 由加法 $\vec{a} = \vec{b} + (\vec{a}-\vec{b})$ 可知减法即加法的逆运算，几何表现为三角形闭合。
		\item[\textbf{要点三（坐标运算）：}] 若 $\vec{a}=(x_1,y_1)$，$\vec{b}=(x_2,y_2)$ 共起点 $O$，则 $\vec{a}-\vec{b}=(x_1-x_2,y_1-y_2)$，对应向量 $\overrightarrow{BA}$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（终点连线）}}

	两个共起点向量的差向量等于连接两终点的有向线段，方向从减向量终点指向被减向量终点。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（坐标减法）}}

	在直角坐标系下，差向量即为对应坐标相减，与起点无关（起点均为原点）。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（快速转化）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（方向判断）：} 在选择题中根据图形直接写出差向量，避免坐标计算。
		\item \textbf{考法二（向量运算）：} 结合加法与数乘，进行混合运算时快速对应几何向量。
		\item \textbf{考法三（模长计算）：} 利用 $|\vec{a}-\vec{b}|^2=|\vec{a}|^2+|\vec{b}|^2-2\vec{a}\cdot\vec{b}$ 求两终点距离。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{共起点是前提}，方向决定符号；差向量图形可看作三角形第三边，顶点顺序由减号决定。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（几何作图）：} 已知共起点向量的终点位置，直接连接得差向量。
		\item \textbf{场景二（向量表示）：} 用已知向量表示未知向量时，通过减法构建三角形回路。
		\item \textbf{场景三（对角线差）：} 在平行四边形中，一条对角线对应两邻边和，另一条对应差（注意方向）。
	\end{itemize}
\end{explanationbox}
