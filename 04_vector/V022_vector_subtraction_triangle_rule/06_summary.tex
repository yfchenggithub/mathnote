\begin{summarybox}

	\textbf{\textcolor{CSummary}{一句话核心}}

	共起点时，差向量 $\vec{a}-\vec{b}$ 等于从减向量终点指向被减向量终点的向量 $\overrightarrow{BA}$。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（共起点）：} 两向量必须起点重合，否则需平移后再应用。
		\item \textbf{条件 2（方向规定）：} 差向量方向由减向量终点指向被减向量终点，顺序不可颠倒。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（方向混淆）：} 常误将 $\vec{a}-\vec{b}$ 当作 $\overrightarrow{AB}$，注意箭头方向。
		\item \textbf{检查项（起点一致）：} 应用前确认 $\vec{a}$ 与 $\vec{b}$ 是否共起点。
	\end{itemize}
\end{summarybox}
