\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	半角公式是用一倍角的余弦来直接写出半角的正弦平方和余弦平方，并且正切也有两种等价表达，本质是二倍角公式的逆运算。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（平方公式来源）：}] $\sin^2\frac{\alpha}{2}$ 和 $\cos^2\frac{\alpha}{2}$ 的公式可以直接从 $\cos2\theta = 1-2\sin^2\theta$ 和 $\cos2\theta = 2\cos^2\theta-1$ 中令 $\theta=\frac{\alpha}{2}$ 并解出平方得到。它们将半角的平方转化成 $\alpha$ 的余弦的一次式。
		\item[\textbf{要点二（正切等价形式）：}] $\tan\frac{\alpha}{2}$ 的两个表达式 $\frac{\sin\alpha}{1+\cos\alpha}$ 和 $\frac{1-\cos\alpha}{\sin\alpha}$ 分别从正弦与余弦、余弦与正弦的组合给出，体现了三角恒等式的灵活性。两个形式在定义域内等价。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（倍角公式逆运算）}}

	半角公式在单位圆上可以通过倍角公式的角度二等分推导，是二倍角公式的逆运算，没有独立的新几何模型，但沟通了半角与倍角。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（降幂与统一角度）}}

	半角公式将一个角 $\alpha$ 的三角函数与半角 $\frac{\alpha}{2}$ 的平方联系起来，常用于降低三角函数的幂次，或将不同角度的表达式转化为同角 $\alpha$，为化简和证明提供路径。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（半角公式应用）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接套用求值）：} 已知 $\cos\alpha$ 求 $\sin^2\frac{\alpha}{2}$、$\cos^2\frac{\alpha}{2}$ 或 $\tan\frac{\alpha}{2}$。
		\item \textbf{考法二（恒等变形化简）：} 在较复杂的三角式中出现 $\sin^2\frac{\alpha}{2}$、$\cos^2\frac{\alpha}{2}$ 时，用半角公式替换为 $\frac{1-\cos\alpha}{2}$ 或 $\frac{1+\cos\alpha}{2}$，实现降幂或整合。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	半角公式给出的是平方关系，因此在求 $\sin\frac{\alpha}{2}$ 或 $\cos\frac{\alpha}{2}$ 的数值时，必须根据 $\frac{\alpha}{2}$ 的象限决定符号；而 $\tan\frac{\alpha}{2}$ 公式本身不涉及开方，直接得到值。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（已知余弦求半角）：} 给出一倍角余弦，欲求半角的正弦平方、余弦平方或正切。
		\item \textbf{场景二（恒等式证明与化简）：} 证明含有 $\sin^2\frac{\alpha}{2}$、$\cos^2\frac{\alpha}{2}$ 或 $\tan\frac{\alpha}{2}$ 的三角恒等式时，使用半角公式化为同角 $\alpha$ 的表达式。
	\end{itemize}
\end{explanationbox}
