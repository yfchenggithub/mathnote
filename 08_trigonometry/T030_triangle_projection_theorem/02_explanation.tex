\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	三角形的一边长等于另外两边在该边方向上的投影长度相加。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（投影关系）：}] 从点 $A$ 向边 $BC$ 作垂线，垂足 $D$ 分 $BC$ 为 $BD = c\cos B$ 和 $DC = b\cos C$，故 $a = BD + DC$.
		\item[\textbf{要点二（轮换对称）：}] 同理，对另外两边可写出类似等式，整体构成三个对称公式。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（投影分解）}}

	在 $\triangle ABC$ 中，作 $AD \perp BC$ 于 $D$，则 $BD = c\cos B$，$DC = b\cos C$，且 $a = BD + DC$。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（边角转化）}}

	射影定理将边长与余弦值直接联系起来，可用于消去一边或一角，化简边角混合等式。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（边角互化）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（正余弦联用）：} 在解三角形题中，射影定理常与正余弦定理配合，快速得出边角关系.
		\item \textbf{考法二（化简条件）：} 已知 $b\cos C + c\cos B = a$ 等形式时，直接代换化简.
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	射影定理本质是“线段加和”而非“向量点积”，借助几何垂线极易理解，不需要记忆复杂公式。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（边化角）：} 已知 $a = b\cos C + c\cos B$，可将 $a$ 表示为余弦形式，用于边角互化.
		\item \textbf{场景二（消边）：} 出现 $b\cos C$ 与 $c\cos B$ 的和时，可直接替换为 $a$.
	\end{itemize}
\end{explanationbox}
