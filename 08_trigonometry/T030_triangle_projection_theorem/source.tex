\textbf{结论名称：} 射影定理（三角形）

\textbf{适用条件：} 任意三角形 \(ABC\)，设内角 \(A,B,C\) 所对的边分别为 \(a,b,c\)。

\textbf{变量说明：} \(a=BC,\;b=CA,\;c=AB\)；\(A,B,C\in(0,\pi)\)。

\textbf{核心公式：} 
\[
\boxed{a = b\cos C + c\cos B}
\]
（轮换形式：\(b = c\cos A + a\cos C\)，\(c = a\cos B + b\cos A\)）

\textbf{使用场景：} 三角形边角互化；已知两边及其夹角可以快速求第三边；化简涉及边角混合的三角恒等式。

\textbf{简单例子：} 在 \(Rt\triangle ABC\) 中，\(C=90^\circ\)，\(A=30^\circ\)，\(B=60^\circ\)，对应 \(a=1,\;b=\sqrt3,\;c=2\)。
验证：\(b\cos C+c\cos B = \sqrt3\cdot\cos90^\circ + 2\cdot\cos60^\circ = 0 + 2\times\frac12 = 1 = a\)。
