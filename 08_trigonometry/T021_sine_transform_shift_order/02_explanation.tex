\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	将正弦曲线 $y=\sin x$ 变换到 $y=A\sin(\omega x+\varphi)$，可以先平移后横向伸缩，也可以先横向伸缩后平移。第二条路径须调整平移距离，两条路径才到达同一图像。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（先移后缩）：}] 先向左平移有符号距离 $\varphi$，再将各点横坐标乘以 $1/\omega$，最后将纵坐标乘以 $A$。
		\item[\textbf{要点二（先缩后移）：}] 先将各点横坐标乘以 $1/\omega$，再向左平移有符号距离 $\varphi/\omega$，最后将纵坐标乘以 $A$。
		\item[\textbf{要点三（读懂符号）：}] 因 $\omega>0$，$\varphi>0$ 表示左移，$\varphi<0$ 表示右移，$\varphi=0$ 无须平移。平移距离分别为 $|\varphi|$ 和 $|\varphi|/\omega$；当 $\varphi=0$ 或 $\omega=1$ 时相等。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（图像层次）}}

	先平移的位移也会随随后进行的横向伸缩而改变。基准图像上一点的横坐标为 $x$：先左移 $\varphi$ 再伸缩，得到 $(x-\varphi)/\omega$；先伸缩再左移 $\varphi/\omega$，得到 $x/\omega-\varphi/\omega$。两者相等。若第二条路径仍左移 $\varphi$，通常不会重合；平移与伸缩一般不可直接交换。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（复合函数）}}

	令 $f(x)=\sin x$。因 $\omega x+\varphi=\omega\left(x+\frac{\varphi}{\omega}\right)$，先把横坐标变为 $1/\omega$ 倍后，须平移 $\varphi/\omega$ 才与另一条路径等价。$\omega>1$ 时横向压缩；$\omega=1$ 时横向尺度不变；$0<\omega<1$ 时横向拉伸。$A$ 是带符号的纵向系数，振幅为 $|A|$；$A<0$ 时，乘以 $A$ 相当于先乘以 $|A|$ 再关于 $x$ 轴对称。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（常见题型）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（正向求解）：} 给出变换顺序和参数，写出最终函数解析式。需正确计算平移量。
		\item \textbf{考法二（逆向反推）：} 从最终函数解析式反求变换步骤，常要求区分两种路径下的平移量。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{调整平移量是核心。} 横向伸缩会改变先前位移在最终图像中的大小；$y=f(\omega x+\varphi)=f\big(\omega(x+\frac{\varphi}{\omega})\big)$ 给出先伸缩后平移时的有符号距离 $\varphi/\omega$。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（作图题）：} 要求从基本正弦曲线出发，通过给定的变换顺序画出目标函数图像。
		\item \textbf{场景二（参数求值）：} 已知变换过程及最终函数，求参数 $\omega$、$\varphi$ 或 $A$，需要利用平移量约束。
	\end{itemize}
\end{explanationbox}
