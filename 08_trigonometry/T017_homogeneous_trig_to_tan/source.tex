\textbf{结论名称：}齐次式切化弦（分子分母同除以\(\cos x\)的幂次）

\textbf{适用条件：}所给表达式是关于\(\sin x\)与\(\cos x\)的齐次分式，且分母不为零，通常要求\(\cos x \neq 0\)以保证除法可行。

\textbf{变量说明：}设\(P_n(\sin x,\cos x), Q_n(\sin x,\cos x)\)均为\(n\)次齐次多项式（各项中\(\sin x\)与\(\cos x\)的次数之和恒为\(n\)），转化后变为仅含\(\tan x\)的有理式。

\textbf{核心公式：}
\[
\boxed{\frac{P_n(\sin x,\cos x)}{Q_n(\sin x,\cos x)} = \frac{P_n(\tan x,1)}{Q_n(\tan x,1)}\quad (\cos x \neq 0)}
\]
常见特例：
一次齐次：\[ \frac{a\sin x + b\cos x}{c\sin x + d\cos x} = \frac{a\tan x + b}{c\tan x + d} \]
二次齐次：\[ \frac{a\sin^2 x + b\sin x\cos x + c\cos^2 x}{d\sin^2 x + e\sin x\cos x + f\cos^2 x} = \frac{a\tan^2 x + b\tan x + c}{d\tan^2 x + e\tan x + f} \]

\textbf{使用场景：}已知\(\tan x\)的值，求关于\(\sin x,\cos x\)的齐次分式的值；化简或证明齐次三角恒等式；在解三角形或参数方程中统一变量。

\textbf{简单例子：}已知\(\tan x = 2\)，求\(\dfrac{\sin x - \cos x}{\sin x + 2\cos x}\)的值。\\
解：分子分母同除以\(\cos x\)，得
\[
\frac{\tan x - 1}{\tan x + 2} = \frac{2-1}{2+2} = \frac{1}{4}.
\]
