\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	三角形面积可以直接用“半周长乘以内切圆半径”得到，避免求高或角度，计算简洁。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（分割求和）：}]
			从内心向三边作垂线，将三角形分成三个小三角形，每个小三角形的高均为 $r$，底边分别为 $a,b,c$。
		\item[\textbf{要点二（代数整理）：}]
			三个小三角形面积之和为 $\frac{1}{2}ar + \frac{1}{2}br + \frac{1}{2}cr = \frac{1}{2}(a+b+c)r$，再由 $p = \frac{a+b+c}{2}$ 即得 $S = pr$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（分割与重组）}}
	内心是三条角平分线的交点，到三边距离相等。利用这个等距性质，将三角形等积分割，转化为以边为底、内切圆半径为高的多个三角形面积之和。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（线性关系）}}
	面积与边长之和成线性关系，系数由内切圆半径决定。只要知道三边长度和半径，面积就唯一确定；反之已知面积和半周长可反解半径。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（高频公式）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求面积）：}已知三角形三边和内切圆半径，直接代入 $S = pr$。
		\item \textbf{考法二（反求半径）：}已知三角形面积和周长（或三边），利用 $r = S/p$ 求内切圆半径。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	此公式的妙处在于将面积与三边长度直接挂勾，不需要使用三角函数或高线，尤其适合只给边长但没给高的题目。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（已知边与半径）：}直接计算面积。
		\item \textbf{场景二（综合题中建方程）：}在含内切圆的综合题中，利用该公式列关于半径的方程。
	\end{itemize}

\end{explanationbox}
