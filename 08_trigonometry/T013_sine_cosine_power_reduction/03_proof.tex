\begin{proofbox}

	\textbf{\textcolor{CProof}{思路提示}}

	降幂公式本质是余弦二倍角公式的代数变形。将 $\cos 2x$ 的两种表达式移项即可得到。

	\medskip
	\textbf{\textcolor{CProof}{正式推导}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.55em]
		\item[\textbf{步骤一（写出余弦二倍角公式）：}]
			已知恒等式 $\cos 2x = 1-2\sin^2 x$。
			\[
				\cos 2x = 1-2\sin^2 x.
			\]
			\par\textbf{理由：} 此式为余弦的二倍角公式常见形式，可通过和角公式 $\cos( x+x)$ 推导。

		\item[\textbf{步骤二（移项得到正弦降幂）：}]
			将上一步等式移项，把 $2\sin^2 x$ 单独放在一边。
			\[
				2\sin^2 x = 1 - \cos 2x.
			\]
			\par\textbf{理由：} 等式两边同时减去 $\cos 2x$，再同时加上 $2\sin^2 x$ 得到。

		\item[\textbf{步骤三（系数化为1）：}]
			两边同时除以 $2$，即得第一个降幂公式。
			\[
				\sin^2 x = \frac{1- \cos 2x}{2}.
			\]
			\par\textbf{理由：} 等式性质，非零同除。

		\item[\textbf{步骤四（用另一形式推导余弦降幂）：}]
			由另一二倍角公式 $\cos 2x = 2\cos^2 x-1$ 出发。
			\[
				\cos 2x = 2\cos^2 x - 1.
			\]
			\par\textbf{理由：} 同样是余弦倍角公式的等价形式。

		\item[\textbf{步骤五（移项得到余弦降幂）：}]
			移项得 $2\cos^2 x = 1+\cos 2x$。
			\[
				2\cos^2 x = 1+ \cos 2x.
			\]
			\par\textbf{理由：} 将 $-1$ 移到左边。

		\item[\textbf{步骤六（系数化为1）：}]
			除以 $2$ 即得第二个降幂公式。
			\[
				\cos^2 x = \frac{1+ \cos 2x}{2}.
			\]
			\par\textbf{理由：} 同除 $2$。
	\end{description}

	\medskip
	\textbf{\textcolor{CProof}{结论回扣}}

	至此，两个降幂公式推导完毕。它们将 $\sin^2 x$ 和 $\cos^2 x$ 用 $\cos 2x$ 简洁表示，在三角函数恒等变形时非常实用。
\end{proofbox}
