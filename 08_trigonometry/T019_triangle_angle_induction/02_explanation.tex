\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	三角形内角互补，将 $A+B$ 看作 $\pi - C$，再利用诱导公式直接得到与 $C$ 相关的简单关系。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（补角代换）：}] 由 $A+B+C=\pi$ 得 $A+B = \pi - C$。
		\item[\textbf{要点二（诱导转化）：}] $\sin(\pi - C) = \sin C$，$\cos(\pi - C) = -\cos C$，$\tan(\pi - C) = -\tan C$（$C\neq\frac{\pi}{2}$）。
		\item[\textbf{要点三（半角互余）：}] $\frac{A+B}{2} = \frac{\pi}{2} - \frac{C}{2}$，代入得 $\sin(\frac{\pi}{2} - \frac{C}{2}) = \cos\frac{C}{2}$，$\cos(\frac{\pi}{2} - \frac{C}{2}) = \sin\frac{C}{2}$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（补角关系）}}

	在任意三角形中，两个内角之和与第三个内角互补，即 $A+B = \pi - C$。任何涉及 $A+B$ 的三角函数均可通过补角转化到 $C$。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（变量消元）}}

	利用三角形内角和可将两个角的问题转化为单个角的问题，从而减少变量个数，简化运算。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（快速化简）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求值）：} 已知一角 $C$，直接写出 $\sin(A+B)$、$\cos(A+B)$ 等，无需计算 $A$、$B$ 具体值。
		\item \textbf{考法二（恒等变换基础）：} 在证明或化简含 $A+B$ 的三角式中，优先替换为 $-C$ 或补角关系，再展开。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{遇到 $A+B$ 立即用 $\pi - C$ 代替，所有公式立刻转化为单角 $C$ 的诱导形式。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（三角形求值）：} 如 $\triangle ABC$ 中，已知 $\cos C = \frac{3}{5}$，求 $\cos(A+B)$。
		\item \textbf{场景二（化简条件式）：} 如 $\sin(A+B) + \sin C = 0$ 或 $\frac{\sin(A+B)}{\cos C}$ 等表达式可直接转化为 $C$ 的单值函数。
	\end{itemize}
\end{explanationbox}
