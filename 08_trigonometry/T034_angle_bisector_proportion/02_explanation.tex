\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	角平分线把对边截成的比例，恰好等于相邻两边的边长之比，可视为“等角带来的等比例”。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（面积拆分）：}] 从 $A$ 作 $BC$ 上的高 $AH$，则 $\triangle ABD$ 与 $\triangle ADC$ 等高，面积比等于底边比 $BD:DC$。
		\item[\textbf{要点二（等距转化）：}] 过 $D$ 作 $DE\perp AB$ 于 $E$，$DF\perp AC$ 于 $F$，由角平分线性质得 $DE=DF$，故 $\triangle ABD$ 与 $\triangle ADC$ 面积比也等于 $AB:AC$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（面积比转化）}}

	角平分线的本质是“点到角两边距离相等”，由此将边比例转化为面积比，再通过同底（$BC$）转化为线段比。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（比例方程形式）}}

	比例式 $\frac{BD}{DC}=\frac{AB}{AC}$ 等价于交叉乘积式 $BD\cdot AC = DC\cdot AB$，常用于布列方程求未知线段。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（经典应用）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求线段长）：} 已知三角形两边及角平分线分对边的一段，利用定理求另一段。
		\item \textbf{考法二（证角平分线）：} 已知比例关系及点在对边上，可推出角平分线（逆定理）。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	角平分线定理的核心转化路径：等距（角平分线性质）转化为面积比，再转化为线段比，面积法是关键桥梁。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（求分割线段）：} 在三角形中已知两边长和角平分线分对边的一段，直接套比例求另一段。
		\item \textbf{场景二（判定角平分线）：} 给出线段分对边的比例等于邻边比，可快速证明该线段是角平分线。
	\end{itemize}
\end{explanationbox}
