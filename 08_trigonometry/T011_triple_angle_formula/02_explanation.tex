\begin{explanationbox}

	\textbf{\textcolor{CExplanation}{一句话直觉}}

	三倍角公式源自两角和公式与二倍角公式的反复应用，将 $\sin 3x$ 与 $\cos 3x$ 展开为单倍角的三次多项式。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（两角和展开）：}] 先将 $3x$ 看作 $2x + x$，利用 $\sin(\alpha+\beta)$ 和 $\cos(\alpha+\beta)$ 展开。
		\item[\textbf{要点二（二倍角代换）：}] 再用 $\sin 2x$、$\cos 2x$ 的二倍角公式替换，最终化简为只含 $\sin x$、$\cos x$ 的多项式。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（复数旋转）}}

	在复平面上，复数 $\cos x + i\sin x$ 的三次方对应角度 $3x$，其实部与虚部分别给出 $\cos 3x$ 与 $\sin 3x$ 的表达式。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（幂次转化）}}

	三倍角公式将 $\sin 3x$、$\cos 3x$ 表示为 $\sin x$、$\cos x$ 的三次式，实现“三倍角”与“单倍角”之间的幂次转化。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（考法预览）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求值化简）：} 已知 $\sin x$ 或 $\cos x$，直接代入公式求 $\sin 3x$、$\cos 3x$。
		\item \textbf{考法二（证明恒等式）：} 利用公式将高次项降幂，完成等式的推导与证明。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	牢记系数“3 和 4”的配合：正弦公式是“$3\sin x - 4\sin^3 x$”，余弦是“$4\cos^3 x - 3\cos x$”，符号相反。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景（场景列举）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（单倍角已知）：} 当题目给出 $\sin x$ 或 $\cos x$ 的值，要求 $\sin 3x$、$\cos 3x$ 时，直接套用公式。
		\item \textbf{场景二（降幂处理）：} 当遇到 $\sin^3 x$、$\cos^3 x$ 时，反用公式转化为 $\sin 3x$、$\cos 3x$ 的线性组合。
	\end{itemize}
\end{explanationbox}
