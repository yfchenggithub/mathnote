\begin{trapbox}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CTrap}{易错点一（符号系数混淆）}}] 误记 $\sin 3x = 3\sin x + 4\sin^3 x$ 或 $\cos 3x = 4\cos^3 x + 3\cos x$。
		\item[\textbf{\textcolor{CTrap}{正确理解（符号规律）：}}] 正弦三倍角是“$3\sin x - 4\sin^3 x$”，余弦三倍角是“$4\cos^3 x - 3\cos x$”，二者隐含的系数顺序相反。
		\item[\textbf{\textcolor{CTrap}{错因分析（推导不熟）：}}] 直接从结果记忆，没有通过和角公式推导一遍，导致正负号混淆。
	\end{description}

	\medskip
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CTrap}{易错点二（降幂公式符号错）}}] 将 $\sin^3 x$ 错误写成 $\dfrac{3\sin x + \sin 3x}{4}$，或将 $\cos^3 x$ 写成 $\dfrac{3\cos x - \cos 3x}{4}$。
		\item[\textbf{\textcolor{CTrap}{正确理解（移项定号）：}}] 由 $\sin 3x = 3\sin x - 4\sin^3 x$ 移项得 $4\sin^3 x = 3\sin x - \sin 3x$，所以 $\sin^3 x = \dfrac{3\sin x - \sin 3x}{4}$；同理 $\cos^3 x = \dfrac{3\cos x + \cos 3x}{4}$。
		\item[\textbf{\textcolor{CTrap}{错因分析（缺少推导）：}}] 未从三倍角公式重新整理，仅凭记忆导致符号颠倒。
	\end{description}

	\medskip
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.35em]
		\item[\textbf{\textcolor{CTrap}{易错点三（单位混乱）}}] 在同一个问题中混用“度”与“弧度”，例如把 $\sin 3x$ 中的 $x$ 视为弧度值，但代入的数值按度数计算。
		\item[\textbf{\textcolor{CTrap}{正确理解（一致单位）：}}] 公式中的 $x$ 代表弧度（实数），但若使用角度制需注意换算，且在同一等式中单位必须统一。
		\item[\textbf{\textcolor{CTrap}{错因分析（单位习惯差）：}}] 不区分角度与弧度，直接代入数值导致计算错误。
	\end{description}
\end{trapbox}
