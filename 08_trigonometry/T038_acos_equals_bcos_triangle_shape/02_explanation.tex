\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	边与角的余弦值乘积相等，暗示了边角关系的对称性，可转化为二倍角相等。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（正弦定理化）：}] 利用正弦定理 $a=2R\sin A$，$b=2R\sin B$，代入得 $\sin A\cos A = \sin B\cos B$。
		\item[\textbf{要点二（二倍角公式）：}] 利用 $\sin 2\theta = 2\sin\theta\cos\theta$，将等式化为 $\sin 2A = \sin 2B$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（对称关系）}}

	等式反映了两角二倍角的正弦相等，这种对称性对应等腰或直角两种可能。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（二倍角方程）}}

	$\sin 2A = \sin 2B$ 在三角形内角范围内有 $2A=2B$ 或 $2A+2B=\pi$ 两组解。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（判断形状）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接判断）：} 已知 $a\cos A = b\cos B$，直接利用结论得到三角形形状。
		\item \textbf{考法二（综合求角）：} 结合正弦定理、余弦定理，利用结论列方程求角度。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	由 $\sin 2A = \sin 2B$ 求角时，必须考虑 $2A+2B=\pi$ 的可能性，否则会漏解。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（边角化简）：} 条件中出现 $a\cos A$ 等结构时，优先使用正弦定理化边为角。
		\item \textbf{场景二（形状判断）：} 直接利用本结论快速判断三角形形状。
	\end{itemize}
\end{explanationbox}
