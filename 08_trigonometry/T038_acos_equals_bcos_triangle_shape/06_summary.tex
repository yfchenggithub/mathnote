\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	三角形中，$a\cos A = b\cos B$ 等价于 $A = B$ 或 $A + B = \dfrac{\pi}{2}$，即等腰或直角三角形。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（边角等式）：} 已知条件为 $a\cos A = b\cos B$ 的形式。
		\item \textbf{条件 2（三角形环境）：} $A$、$B$、$C$ 是三角形内角，满足 $A+B+C=\pi$，$A,B,C\in(0,\pi)$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（二倍角漏解）：} 由 $\sin 2A = \sin 2B$ 求解时，除 $2A=2B$ 外还有 $2A+2B=\pi$ 的可能。
		\item \textbf{检查项（验证内角）：} 得出角度关系后应代入内角和验证，排除矛盾情况。
	\end{itemize}
\end{summarybox}
