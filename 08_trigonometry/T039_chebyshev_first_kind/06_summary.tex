\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	第一类切比雪夫多项式$T_n(x)$满足$T_n(\cos\theta)=\cos(n\theta)$，由递推$T_{n+1}=2xT_n-T_{n-1}$生成，是沟通倍角余弦与多项式的桥梁。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（三角代换）：} 需要将$x$表示为$\cos\theta$的形式（$|x|\le1$）才能直接使用三角恒等式。
		\item \textbf{条件2（递推前提）：} 递推公式要求已知前两项$T_0,T_1$（或$T_{n-1},T_n$）方可计算$T_{n+1}$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（定义域区分）：} 多项式定义域为全体实数，但恒等式只在$x=\cos\theta$时成立。
		\item \textbf{检查项（递推下标）：} 递推中$T_{n+1}$的计算依赖$T_n$和$T_{n-1}$，切勿弄反。
	\end{itemize}
\end{summarybox}
