\begin{proofbox}
	\textbf{\textcolor{CProof}{思路提示}}
	本结论直接来源于余弦定理 $\cos A = \frac{b^2+c^2-a^2}{2bc}$。由于分母 $2bc>0$，$\cos A$ 的符号等价于分子 $b^2+c^2-a^2$ 的符号。因此将角的类型与 $a^2$ 和 $b^2+c^2$ 的大小关系一一对应。

	\medskip
	\textbf{\textcolor{CProof}{正式推导}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.55em]
		\item[\textbf{步骤一（写出余弦定理）：}]
			在 $\triangle ABC$ 中，由余弦定理：
			\[
				a^2 = b^2+c^2-2bc\cos A.
			\]
			\par\textbf{理由：} 此为标准余弦定理公式，建立了边 $a$ 与角 $A$ 的关系。
		\item[\textbf{步骤二（移项得关系）：}]
			将 $a^2$ 移到一边，得
			\[
				2bc\cos A = b^2+c^2-a^2.
			\]
			\par\textbf{理由：} 将 $b^2+c^2-a^2$ 与 $\cos A$ 关联。
		\item[\textbf{步骤三（分母正负判号）：}]
			由于 $b>0,c>0$，故 $2bc>0$。因此 $\cos A$ 的正负完全由分子 $b^2+c^2-a^2$ 决定：
			\[
				\cos A > 0 \iff b^2+c^2-a^2 > 0,\quad \cos A = 0 \iff b^2+c^2-a^2 = 0,\quad \cos A < 0 \iff b^2+c^2-a^2 < 0.
			\]
			\par\textbf{理由：} 两边同除以 $2bc$ 不改变不等号方向。
		\item[\textbf{步骤四（联系角类型）：}]
			在 $0^\circ<A<180^\circ$ 范围内，角 $A$ 的类型与 $\cos A$ 符号一一对应：
			\[
				\angle A<90^\circ \iff \cos A>0,\quad \angle A=90^\circ \iff \cos A=0,\quad \angle A>90^\circ \iff \cos A<0.
			\]
			\par\textbf{理由：} 余弦函数在 $(0^\circ,180^\circ)$ 内为减函数，正值对应锐角，零对应直角，负值对应钝角。
		\item[\textbf{步骤五（合并得结论）：}]
			综合步骤三和步骤四，得到
			\[
				\angle A<90^\circ \iff a^2<b^2+c^2,\quad \angle A=90^\circ \iff a^2=b^2+c^2,\quad \angle A>90^\circ \iff a^2>b^2+c^2.
			\]
			\par\textbf{理由：} 分别结合 $\cos A$ 与 $b^2+c^2-a^2$ 的等价关系即得。
	\end{description}

	\medskip
	\textbf{\textcolor{CProof}{结论回扣}}
	由余弦定理直接推出该判据，说明“边判角”是余弦定理的简单推论，但与勾股定理一样是基础工具，在解三角形中用于快速判断角或三角形的类型。
\end{proofbox}
