\textbf{结论名称：} 一次函数的斜率与纵截距

\textbf{适用条件：} 函数解析式可化为 \(y=kx+b\)（\(k,b\)为常数），定义域通常为\(\mathbb{R}\)；当\(k \neq 0\)时为严格一次函数，\(k=0\)时为常函数。

\textbf{变量说明：} \(x\)为自变量，\(y\)为因变量；\(k\)称为斜率，反映直线的倾斜程度；\(b\)称为纵截距，即直线与\(y\)轴交点的纵坐标。

\textbf{核心公式：}
\[
\boxed{y = kx + b}
\]
其中斜率 \(k = \dfrac{y_2 - y_1}{x_2 - x_1} = \dfrac{\Delta y}{\Delta x}\ (x_1 \neq x_2)\)，纵截距 \(b = y(0)\)。

\textbf{使用场景：} 由两点求直线方程、判断函数单调性（\(k>0\)递增，\(k<0\)递减）、利用截距快速作图、为高中直线的斜截式与导数几何意义提供直观基础。

\textbf{简单例子：} 已知直线过点\(A(1,3)\)与\(B(2,5)\)，求其解析式。\\
解：斜率 \(k = \frac{5-3}{2-1} = 2\)，设 \(y=2x+b\)，代入\(A(1,3)\)得 \(3=2\times1+b \Rightarrow b=1\)。\\
故所求一次函数为 \(y = 2x + 1\)。
