\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	圆内接四边形的对角之和恒为 $180^\circ$，因为它源于同弧所对圆心角之和为 $360^\circ$ 的一半.

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（圆周角定理）：}] 圆上同一弧所对的圆周角相等，这一关系是推导对角互补的基础.
		\item[\textbf{要点二（圆心角关系）：}] 同一弧所对的圆心角是圆周角的两倍，两组圆心角之和为 $360^\circ$.
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（圆内角关系）}}

	圆内接四边形的每一个角对应一段弧（对角对应的是另一个弧），利用圆周角定理可得两对角对应的圆心角之和为 $360^\circ$，故对角互补.

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（角度求和）}}

	在圆内接四边形中，直接由圆周角定理可导出角度等式：$\angle A + \angle C = 180^\circ$，$\angle B + \angle D = 180^\circ$，与四边形内角和 $360^\circ$ 一致，但互补关系为解题提供等量变换.

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（常考应用）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（求角度）：} 在圆内接四边形中已知一角，直接利用互补关系求对角.
		\item \textbf{考法二（四点共圆判定）：} 若四边形对角互补，则可判定四点共圆.
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	把对角互补理解为“每对对角弧拼接成整圆”，本质是圆周角定理和圆心角关系的一次应用.

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（圆内接四边形求角）：} 已知圆内接四边形三内角，求第四角.
		\item \textbf{场景二（证明四点共圆）：} 当一个四边形对角互补或外角等于内对角时，可证其四点共圆.
	\end{itemize}
\end{explanationbox}
