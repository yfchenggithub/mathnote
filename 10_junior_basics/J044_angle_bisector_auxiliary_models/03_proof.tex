\begin{proofbox}
	\textbf{\textcolor{CProof}{思路提示}}
	角平分线的定义给出了角相等，结合垂线、等长或平行线，可以构造全等三角形或等腰三角形，从而推导边角关系。核心是应用三角形全等和等腰三角形判定定理。

	\medskip
	\textbf{\textcolor{CProof}{正式推导}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.55em]
		\item[\textbf{步骤一（垂两边证明）：}]
			在 $\triangle PEO$ 和 $\triangle PFO$ 中，
			\[
				\angle POE = \angle POF,\quad \angle PEO = \angle PFO = 90^\circ,\quad OP = OP.
			\]
			\par\textbf{理由：} 由 $OC$ 平分 $\angle AOB$ 得 $\angle POE = \angle POF$；作垂线得 $\angle PEO = \angle PFO = 90^\circ$；$OP$ 是公共边。因此 $\triangle PEO \cong \triangle PFO$（AAS），故 $PE = PF$。
		\item[\textbf{步骤二（截等长证明）：}]
			在 $\triangle ODP$ 和 $\triangle OEP$ 中，
			\[
				OD = OE,\quad \angle DOP = \angle EOP,\quad OP = OP.
			\]
			\par\textbf{理由：} 由截取作法得 $OD = OE$；$OC$ 平分 $\angle AOB$ 得 $\angle DOP = \angle EOP$；$OP$ 公共边。故 $\triangle ODP \cong \triangle OEP$（SAS）。
		\item[\textbf{步骤三（作平行证明）：}]
			过点 $P$ 作 $PA \parallel OB$ 交 $OA$ 于点 $A$。由平行线性质得 $\angle APO = \angle POB$，且角平分线得 $\angle AOP = \angle POB$，因此 $\angle APO = \angle AOP$。
			\[
				\angle APO = \angle AOP \Rightarrow OA = AP.
			\]
			\par\textbf{理由：} 两直线平行，内错角相等；角平分线定义；等角对等边。
		\item[\textbf{步骤四（三线合一证明）：}]
			在等腰 $\triangle ABC$ 中，$AB = AC$，$AD$ 平分 $\angle BAC$。在 $\triangle ABD$ 和 $\triangle ACD$ 中，
			\[
				AB = AC,\quad \angle BAD = \angle CAD,\quad AD = AD.
			\]
			\par\textbf{理由：} 由 $AD$ 平分 $\angle BAC$ 得 $\angle BAD = \angle CAD$；$AD$ 公共边；$AB=AC$（已知）。故 $\triangle ABD \cong \triangle ACD$（SAS），从而 $BD = CD$，$\angle ADB = \angle ADC$。又 $\angle ADB + \angle ADC = 180^\circ$，故 $AD \perp BC$。
	\end{description}

	\medskip
	\textbf{\textcolor{CProof}{结论回扣}}
	以上四个步骤分别证明了角平分线的四种辅助线模型，每种模型通过构造全等或等腰三角形，将角平分线的性质转化为可用的边角关系。
\end{proofbox}
