\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	有限个非负数相加得零，好比一笔笔非负的钱款总和为零，每笔钱款必定为零。因为只要有一笔为正，总和就立刻为正。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（非负性前提）：}]
		      每个 $a_i\ge0$，这是结论成立的根本条件。
		\item[\textbf{要点二（夹逼推导）：}]
		      由和为零及非负性，对任意 $j$ 有
		      \[
			      0\le a_j\le \sum_{i=1}^n a_i=0,
		      \]
		      从而 $a_j=0$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（压缩至原点）}}

	非负数在数轴上可以理解为点到原点的距离（如 $|x|$），或平面中点到原点的距离平方（如 $x^2+y^2$）。多个这样的“距离”之和为零，意味着每个距离都必须为零，即所有点都位于原点。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（归零条件）}}

	在代数方程中，遇到平方和、绝对值之和等非负表达式之和为零，立即可化为多个方程（每个表达式等于零），从而将复杂条件分解为简单方程。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（列方程关键）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（绝对值方程）：} 给出 $|A|+|B|=0$，隐含 $A=0$ 和 $B=0$，求解参数。
		\item \textbf{考法二（平方和方程）：} 给出 $A^2+B^2=0$，隐含 $A=0$ 和 $B=0$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{见到“几个非负式子加起来等于零”，马上写出“每个式子等于零”。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（绝对值求和）：} 形如 $|x-a|+|y-b|=0$。
		\item \textbf{场景二（平方求和）：} 形如 $(x-a)^2+(y-b)^2=0$。
		\item \textbf{场景三（混合非负项）：} 形如 $|x-a|+(y-b)^2=0$。
	\end{itemize}
\end{explanationbox}
