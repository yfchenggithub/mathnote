\textbf{结论名称：}鸡爪模型（一点引共点三线段，构造等边三角形转化）

\textbf{适用条件：}等边三角形 \(ABC\) 内部一点 \(P\)，连接得三条线段 \(PA, PB, PC\)；或从同一点引出的三线段中有两条相等且夹角为 \(60^\circ\)，可通过补全等边三角形实现旋转。

\textbf{变量说明：}设等边 \(\triangle ABC\)，\(PA = a\)，\(PB = b\)，\(PC = c\)。将 \(\triangle ABP\) 绕点 \(B\) 逆时针旋转 \(60^\circ\) 至 \(\triangle CBQ\)，连接 \(PQ\)。则 \(\triangle PBQ\) 为等边三角形，\(PQ = b\)，\(CQ = a\)。

\textbf{核心公式：}旋转后，\(\triangle PQC\) 的三边分别为 \(a, b, c\)，且 \(\angle PQC = \angle APB - 60^\circ\)。由余弦定理，
\[
c^2 = a^2 + b^2 - 2ab\cos(\angle APB - 60^\circ).
\]
特别地，当 \(a^2 + b^2 = c^2\) 时，\(\angle APB - 60^\circ = 90^\circ\)，即
\[
\boxed{a^2 + b^2 = c^2 \ \Longrightarrow\ \angle APB = 150^\circ}.
\]

\textbf{使用场景：}求等边三角形内部一点到三顶点连线所成的角；由三线段长度判断特殊角；向量奔驰定理的几何证明中，通过旋转将面积关系转化为边长关系。

\textbf{简单例子：}在等边 \(\triangle ABC\) 内，\(P\) 满足 \(PA = 3\)，\(PB = 4\)，\(PC = 5\)，求 \(\angle APB\)。  
解：绕 \(B\) 旋转 \(60^\circ\) 得 \(\triangle CBQ\)，则 \(PQ = PB = 4\)，\(CQ = PA = 3\)，在 \(\triangle PQC\) 中 \(3^2 + 4^2 = 5^2\)，\(\angle PQC = 90^\circ\)，故 \(\angle APB = 60^\circ + 90^\circ = 150^\circ\)。
