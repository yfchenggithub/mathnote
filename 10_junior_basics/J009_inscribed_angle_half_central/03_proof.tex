\begin{proofbox}
	\textbf{\textcolor{CProof}{思路提示}}
	先证明点$C$在优弧$AB$上（即$AB$为劣弧）的情形，此时圆周角等于圆心角的一半；再利用圆内接四边形的性质，将点$C$在劣弧$AB$上的情形转化为前者，得到互补关系。

	\medskip
	\textbf{\textcolor{CProof}{正式推导}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.55em]
		\item[\textbf{步骤一（劣弧情形）：}]
			设点$C$在优弧$AB$上，即$AB$为劣弧，$\angle AOB$为劣弧所对的圆心角．连接$OA,OB,OC$．分三种情况：
			\begin{enumerate}[leftmargin=*, itemsep=0.3em]
			\item 若圆心$O$在$\angle ACB$的一边上（例如$BC$为直径），则易见$\angle ACB = \frac12\angle AOB$．
			\item 若$O$在$\angle ACB$内部，作直径$CD$．由$OA=OC$得$\angle OAC=\angle OCA$，故外角$\angle AOD = \angle OAC+\angle OCA = 2\angle OCA$；同理$\angle BOD = 2\angle OCB$．此时$\angle ACB = \angle OCA+\angle OCB$，且$\angle AOB = \angle AOD+\angle BOD$，所以$\angle AOB = 2\angle ACB$，即$\angle ACB = \frac12\angle AOB$．
			\item 若$O$在$\angle ACB$外部，作直径$CD$．由外角定理，$\angle AOD = 2\angle ACD$，$\angle BOD = 2\angle BCD$．此时$\angle ACB = |\angle ACD - \angle BCD|$，$\angle AOB = |\angle AOD - \angle BOD|$．故$\angle AOB = 2\angle ACB$．
		\end{enumerate}
			综上，当$C$在优弧$AB$上时，恒有$\angle ACB = \frac12\angle AOB$．
		\item[\textbf{步骤二（优弧情形转化）：}]
			若点$C$在劣弧$AB$上（即$AB$为优弧）．在优弧$AB$上任取一点$D$，则四边形$ACBD$内接于$\odot O$．由圆内接四边形对角互补知，$\angle ACB + \angle ADB = 180^\circ$．而$D$在优弧上，由步骤一得$\angle ADB = \frac12\angle AOB$，代入得
			\[
				\angle ACB = 180^\circ - \frac12\angle AOB = \frac12(360^\circ - \angle AOB).
			\]
		\item[\textbf{步骤三（等弧等角）：}]
			同弧或等弧所对的圆周角，由上述可知其大小唯一确定（等于该弧所对圆心角的一半或其补角的一半），故相等．
	\end{description}

	\medskip
	\textbf{\textcolor{CProof}{结论回扣}}
	综上，圆周角定理得证：对于任意弧$AB$，其所对的圆周角要么等于圆心角的一半（弧为劣弧时），要么等于互补圆心角的一半（弧为优弧时），且同弧所对的圆周角相等．
\end{proofbox}
