\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	二次函数与直线图象的交点个数，等于联立消去 $y$ 后所得一元二次方程的实根个数：$\Delta>0$ 两个交点，$\Delta=0$ 一个交点（相切），$\Delta<0$ 无交点。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（二次函数形）：} 有明确的二次函数 $y=ax^{2}+bx+c$，且 $a\neq0$（保证二次）。
		\item \textbf{条件 2（直线方程）：} 有明确的直线 $y=kx+m$，其中 $x$ 轴 $y=0$ 是 $k=0,\ m=0$ 的特例。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（二次项系数）：} 当题目未明确 $a\neq0$ 时，需先讨论 $a=0$ 的情况，否则直接使用判别式会遗漏解。
		\item \textbf{检查项（移项正确）：} 联立后必须正确变形为 $ax^{2}+(b-k)x+(c-m)=0$，特别留意常数项的符号。
	\end{itemize}
\end{summarybox}
