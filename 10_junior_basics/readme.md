# 高考必备初中基础 二级结论索引

> 本模块收录初中阶段对高考有直接影响的二级结论。定位：**高考天天用、高中不再教**。不收录高中已系统重学的内容（如统计初步、概率入门、三视图等）。

| 编号 | 结论主题 | 来源 | 高考关联 |
|------|----------|------|----------|
| J001 | A字型相似：平行截相似，对应边成比例，面积比=相似比² | 初中相似模型 | 解析几何中面积比速算，立体几何截面比例 |
| J002 | 8字型相似：交叉相似模型，对顶角为公共角 | 初中相似模型 | 解析几何中线段比例转化，圆锥曲线中点差法几何背景 |
| J003 | 母子相似：直角三角形斜边高⇒三组相似，射影定理 CD²=AD·DB，AC²=AD·AB，BC²=BD·AB | 初中直角三角形 | 解三角形、平面几何辅助线构造的核心工具 |
| J004 | 平行线分线段成比例定理：一组平行线截两条直线，所得对应线段成比例 | 初中相似基础 | 立体几何中平行关系的比例推理，向量共线定理的原型 |
| J005 | 一线三等角模型（K型全等/相似）：同侧或异侧三个等角构造全等或相似 | 中考高频模型 | 解析几何中构造全等/相似解决最值问题 |
| J006 | 三垂直模型（弦图）：两直角三角形共用斜边或直角边构造全等 | 中考几何压轴 | 平面向量建系时的几何直觉，勾股定理的构图证明 |
| J007 | 相似三角形面积比=相似比的平方（所有对应线段的平方比） | 初中相似性质 | 圆锥曲线中面积比例问题速算 |
| J008 | 相似三角形的五种判定方法（AA/SAS/SSS/HL/平行截）汇总 | 初中教材 | 高中几何证明的底层工具，解析几何中构造相似的依据 |

| J013 | 弦切角定理：弦切角=所夹弧对的圆周角 | 初中圆专题 | 切线与圆周角的关系，圆的切线问题入口 |
| J014 | 圆内接四边形对角互补（对角和=180°） | 初中圆专题 | 四点共圆的直接推论，角度计算高频 |

| J016 | 切线判定定理：过半径外端且垂直于半径的直线是切线 | 初中直线与圆 | 圆的切线判定唯一充要条件 |
| J017 | 切线性质定理：切线垂直于过切点的半径 | 初中直线与圆 | 构造直角三角形，切线与半径的垂直关系 |
| J018 | 相交弦定理：圆内两弦AB、CD交于P，则 PA·PB=PC·PD | 初中直线与圆 | 圆幂定理之一，线段乘积恒等关系 |
| J019 | 切线长定理：圆外一点引两切线，切线长相等，点与圆心连线平分切线的夹角 | 初中直线与圆 | 切线长相等的应用 |
| J020 | 割线定理：圆外一点P引两条割线PAB、PCD，则 PA·PB=PC·PD | 初中直线与圆 | 圆幂定理之二，线段乘积关系 |
| J021 | 切割线定理：PT²=PA·PB（PT为切线长，PAB为割线） | 初中直线与圆 | 圆幂定理之三，一切一割模型 |
| J022 | 垂径定理：垂直于弦的直径平分此弦，且平分弦所对的两条弧 | 初中圆专题 | 弦长、半径、弦心距的直角三角形关系：半弦²+弦心距²=半径² |

## 使用说明

- **编号规则**：J = Junior（初中），001–055 按板块排列
- **收录标准**：高考中直接使用、但高中教材不再系统讲解的初中结论
- **与高中模块的关联**：
  - J001–J004、J009–J022 → `09_geometry-plane` 平面几何
  - J005–J008、J038–J045 → `04_vector` 向量 / `09_geometry-plane` 平面几何
  - J023–J029 → `01_function` 函数与导数
  - J030–J037 → `03_conic` 圆锥曲线 / `05_geometry-solid` 立体几何
  - J046–J050 → `03_conic` 圆锥曲线分类讨论
  - J051–J055 → 全模块通用代数基础
