\textbf{结论名称：}截长补短辅助线法

\textbf{适用条件：}证明线段的和、差、倍、分关系（如 $AB+CD=EF$），直接证明困难，特别是需构造全等三角形时。

\textbf{变量说明：}设长线段为 $L$，两条短线段分别为 $a,b$，目标为证 $a+b=L$（或类似线段和差关系）。

\textbf{核心公式：}
\[
\boxed{\text{截长法：在 } L \text{ 上截 } L_1=a \xrightarrow{\triangle\cong\triangle} L_2=b;\qquad
\text{补短法：延长 } a \text{ 至 } C \text{ 使 } AC=a+b \xrightarrow{\triangle\cong\triangle} AC = L}
\]
通过截取或补齐构造全等三角形，实现边角关系的等量代换。

\textbf{使用场景：}中考几何中涉及线段和差（如 $a+b=c$）的证明，常见于角平分线模型、含半角模型、一边等于两边之和等问题。

\textbf{简单例子：}在 $\triangle ABC$ 中，$AD$ 平分 $\angle BAC$，$\angle B=2\angle C$，求证 $AB+BD=AC$。
\noindent（截长法）在 $AC$ 上截取 $AE=AB$，连接 $DE$。由角平分线和公共边 $AD$ 得 $\triangle ABD \cong \triangle AED$ (SAS)，故 $BD=ED$，$\angle B=\angle AED=2\angle C$。由外角性质 $\angle AED=\angle C+\angle EDC$，得 $\angle EDC=\angle C$，所以 $ED=EC$，即 $BD=EC$。因此 $AC=AE+EC=AB+BD$，得证。
