\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}

	琴生不等式：严格凸函数加权平均的函数值不超过函数值的加权平均，等号当且仅当变量全相等。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件1（凹凸性）：} 函数$f$必须在区间$I$上严格凸（或严格凹）。
		\item \textbf{条件2（变量及权重）：} $x_i\in I$，$\lambda_i>0$且$\sum_{i=1}^n\lambda_i=1$。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（方向判断）：} 凸函数用$\le$，凹函数用$\ge$，方向不可混淆。
		\item \textbf{检查项（取等条件）：} 严格凸/凹时，等号必须所有$x_i$相等；验证时检查函数是否严格。
	\end{itemize}
\end{summarybox}
