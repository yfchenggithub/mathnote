\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	一组非负实数，它们的算术平均（加起来平均）总不小于几何平均（乘起来开方）。简言之，和平均不小于积平均。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（算术平均）：}]
			$n$ 个数的和除以 $n$，反映数值的集中趋势。
		\item[\textbf{要点二（几何平均）：}]
			$n$ 个数的乘积开 $n$ 次方，反映数值的居中水平。
		\item[\textbf{要点三（大小关系）：}]
			算术平均总不小于几何平均，等号当所有数相等时成立。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（矩形面积比较）}}
	对两数 $a,b>0$，算术平均 $(a+b)/2$ 是两边长的平均值，几何平均 $\sqrt{ab}$ 是等面积正方形的边长。周长固定时（即 $a+b$ 固定），正方形面积最大，因此算术平均不小于几何平均。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（不等式基石）}}
	均值不等式是推导柯西不等式、排序不等式等的基础，也是直接求最值与证明不等式的核心工具。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（求最值证明）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（和定积最大）：} 已知几个正数的和为定值，求它们的乘积的最大值。
		\item \textbf{考法二（积定和最小）：} 已知几个正数的积为定值，求它们的和的最小值。
		\item \textbf{考法三（证明不等式）：} 将待证不等式与均值不等式形式对接，构造出所需形式。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	使用均值不等式的关键三要素：各项非负（正）、和或积为定值、等号可以取到。简记“正、定、等”。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（和定求积最大）：} 如 $x+y= S$（定值），求 $xy$ 最大值。
		\item \textbf{场景二（积定求和最小）：} 如 $xy= P$（定值），求 $x+y$ 最小值。
		\item \textbf{场景三（配凑转化）：} 通过拆项、系数调整构造出和定或积定形式。
	\end{itemize}

\end{explanationbox}
