\textbf{结论名称：}含绝对值不等式解法

\textbf{适用条件：}$a>0$，$f(x)$为实数集上的表达式。

\textbf{变量说明：}$f(x)$：含变量$x$的表达式；$a$：给定的正常数。

\textbf{核心公式：}
\[
\boxed{|f(x)| < a \iff -a < f(x) < a}
\]
\[
\boxed{|f(x)| > a \iff f(x) < -a \ \text{或}\ f(x) > a}
\]

\textbf{使用场景：}将含绝对值的不等式转化为不含绝对值的不等式组，用于求解一元一次、二次等不等式。

\textbf{简单例子：}
解$|x-2|<3$：由公式得$-3<x-2<3$，解得$-1<x<5$；
解$|2x+1|>5$：由公式得$2x+1<-5$或$2x+1>5$，解得$x<-3$或$x>2$。
