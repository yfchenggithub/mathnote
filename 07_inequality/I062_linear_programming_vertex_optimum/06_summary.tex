\begin{summarybox}
	\textbf{\textcolor{CSummary}{一句话核心}}
	线性规划求最值，只需比较各顶点目标函数值；通过截距符号可判断最优顶点方向。

	\medskip
	\textbf{\textcolor{CSummary}{使用条件}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{条件 1（有界凸多边形）：} 可行域需是有界凸多边形，或至少最优解存在（无界时必须单独分析）。
		\item \textbf{条件 2（线性目标）：} 目标函数必须是一次式 $z=ax+by$（$a,b$ 不全为零）。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CSummary}{关键提醒}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{易错点（忽略有界性）：} 不要忘记先检验可行域是否有界，否则可能误用结论。
		\item \textbf{检查项（顶点完整性）：} 列出所有边界线交点，并逐一验证是否满足所有约束，确保顶点集完备。
	\end{itemize}

\end{summarybox}
