\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}

	原不等式移项后可以得到完全平方$(ad-bc)^2$，所以不等式恒成立。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（平方差结构）：}] 左边是两个平方差的乘积，右边是差的平方。
		\item[\textbf{要点二（配方转换）：}] 作差后可以整理成完全平方$(ad-bc)^2$。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（叉积平方）}}

	$ad-bc$可视为向量$(a,b)$与$(c,d)$的叉积（行列式），其平方总是非负。因此原不等式等价于叉积平方的非负性。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（恒等变形）}}

	原不等式等价于$(ac-bd)^2-(a^2-b^2)(c^2-d^2)=(ad-bc)^2\ge0$，因此本质上是平方非负的代数恒等式。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（题型应用）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接比较）：} 当出现$(a^2-b^2)(c^2-d^2)$与$(ac-bd)^2$比较时，直接使用反向柯西。
		\item \textbf{考法二（配凑等号）：} 已知等号条件$ad=bc$，可建立比例关系$\dfrac{a}{c}=\dfrac{b}{d}$（分母非零时），用于后续计算。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}

	\textbf{核心在于移项后的完全平方，无需复杂技巧。}

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（结构识别）：} 在代数式中看到$(a^2-b^2)(c^2-d^2)$和$(ac-bd)^2$同时出现。
		\item \textbf{场景二（证明最值）：} 需要证明类似不等式或求最值时构造此形式。
	\end{itemize}
\end{explanationbox}
