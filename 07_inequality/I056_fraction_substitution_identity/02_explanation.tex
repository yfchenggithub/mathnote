\begin{explanationbox}
	\textbf{\textcolor{CExplanation}{一句话直觉}}
	通过平方运算，将$x$与$\frac{1}{x}$的和与平方和联系起来；同时利用基本不等式，得到该和绝对值的最小值。

	\medskip
	\textbf{\textcolor{CExplanation}{核心拆解}}
	\begin{description}[style=nextline, leftmargin=2.8em, labelsep=0.5em, itemsep=0.45em]
		\item[\textbf{要点一（倒数换元）：}]
			令$t = x + \frac{1}{x}$，可将$x^2 + \frac{1}{x^2}$表示为$t^2 - 2$，实现降次。
		\item[\textbf{要点二（绝对值下界）：}]
			由$ (x- \frac{1}{x})^2 \ge 0$推出$|t|\ge 2$，即和$t$的取值范围分两段。
	\end{description}

	\medskip
	\textbf{\textcolor{CExplanation}{几何本质（对称结构）}}
	该恒等式刻画了自变量与其倒数之间的平方和与和的平方之间的线性关系，本质上是对称分式的恒等变形。

	\medskip
	\textbf{\textcolor{CExplanation}{代数意义（降次工具）}}
	将高次分式$x^2+\frac{1}{x^2}$转化为一次和$t$的二次式，从而简化运算，将二次表达式化为一次表达式。

	\medskip
	\textbf{\textcolor{CExplanation}{考点价值（最值对称）}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{考法一（直接求值）：} 给出$x+\frac{1}{x}$的值，求$x^2+\frac{1}{x^2}$的值；或反之。
		\item \textbf{考法二（求取值范围）：} 利用$|t|\ge2$求解分式函数在指定区间上的最值。
	\end{itemize}

	\medskip
	\textbf{\textcolor{CExplanation}{顿悟点}}
	平方产生交叉项$2$，减去$2$即为平方和；基本不等式的使用条件为$x$和$\frac{1}{x}$同号或异号导致$|t|$下界。

	\medskip
	\textbf{\textcolor{CExplanation}{使用场景}}
	\begin{itemize}[leftmargin=*, itemsep=0.5em, topsep=0.4em]
		\item \textbf{场景一（对称分式化简）：} 题目中出现$x+\frac{1}{x}$与$x^2+\frac{1}{x^2}$的表达式，要求将$x^2+\frac{1}{x^2}$转化为含$t$的式子。
		\item \textbf{场景二（函数最值问题）：} 研究函数$f(x)=x+\frac{1}{x}$的最值、值域，需用到$|t|\ge2$。
	\end{itemize}

\end{explanationbox}
