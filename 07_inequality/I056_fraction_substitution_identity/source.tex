\textbf{结论名称：} 分式函数最值换元法（令 $t=x+\frac{1}{x}$ 型整体换元）

\textbf{适用条件：} 目标函数可表示为关于 $x+\frac{1}{x}$ 与 $x^2+\frac{1}{x^2}$ 的有理式，且 $x \neq 0$。常用于分子分母次数相差 $1$ 的分式或对称分式的最值问题。

\textbf{变量说明：} 设整体变量 $t = x + \frac{1}{x}$。当 $x>0$ 时，$t \ge 2$；当 $x<0$ 时，$t \le -2$。常用恒等式 $x^2 + \frac{1}{x^2} = t^2 - 2$。

\textbf{核心公式：}
\[ \boxed{x^2 + \frac{1}{x^2} = t^2 - 2,\qquad |t| \ge 2} \]
其中 $t = x + \frac{1}{x}$，等号当且仅当 $x = \pm 1$ 时成立。

\textbf{使用场景：} 求形如 $y = \frac{x^2+1}{x}$，或 $y = x^2 + \frac{1}{x^2} + x + \frac{1}{x}$ 等函数的最值。通过整体换元将原函数化为关于 $t$ 的二次函数或对勾函数，在 $|t| \ge 2$ 的约束下求最值。

\textbf{简单例子：} 求 $y = x^2 + \frac{1}{x^2} + x + \frac{1}{x}\;(x>0)$ 的最小值。\\
解：令 $t = x + \frac{1}{x} \ge 2$，则 $x^2 + \frac{1}{x^2} = t^2 - 2$，
\[ y = (t^2 - 2) + t = t^2 + t - 2. \]
二次函数 $f(t) = t^2 + t - 2$ 在 $[2,+\infty)$ 上单调递增，故当 $t=2$ 时
$y_{\min} = 2^2 + 2 - 2 = 4$，此时 $x = 1$。
